# K-CppErr

Visual Studio 2022 / 2026 用の拡張です。C++ のビルドエラーを、**自分のコードの場所つき**で一覧にします。

`std::make_unique<SwapChain>(...)` の引数を間違えると、エラー一覧の先頭は `memory(3511)` になります。ダブルクリックすると `<memory>` が開きますが、直す場所は、自分の `Main.cpp` の呼び出しです。K-CppErr は、ビルド出力にある「see reference to function template instantiation ... being compiled」の行を辿って、自分のコードの行を探し出します。

## 機能

- ビルドが終わると、エラー一覧のとなりに「C++ エラー(かんたん表示)」が出る（エラーがあるときだけ）
- 見出しをダブルクリックすると、**自分のコードの原因の場所**へ飛ぶ（ライブラリのヘッダーではない）
    - 自分のコード = ソリューションのフォルダーの下のファイル。vcpkg・標準ライブラリ・Windows SDK は除く
- 見出しの下に、次の項目が並ぶ
    - 日本語のヒント（`C2664` `C2665` `C2512` `C2280` `LNK2019` など、よくあるエラー）
    - 渡した引数の並び（`引数リスト '(int, float)' を一致させようとしているとき` から取り出す）
    - 呼び出しの経路（内側から外側へ。自分のコードの行は青）。ダブルクリックで、その行へ飛ぶ
    - 候補（`could be` / `or` の宣言）
    - 元のメッセージ（`with [ _Ty=... ]` なども含む）
- 警告は、「警告も表示」のチェックで出す
- 拡張機能 メニューの「C++ エラー(かんたん表示)を開く」から、いつでも開ける。「ビルド出力を読み直す」で再取得する
- MSVC（`cl.exe` / `clang-cl`）の形式に加えて、GCC / Clang の `required from here` の形式も読む

## インストール

`bin\K-CppErr.vsix` をダブルクリックして、Visual Studio を再起動します。

## しくみ

ビルドが終わった時点で、「出力」ウィンドウの「ビルド」欄の文字を読み、解析します。エラー一覧の内容は読みません（そこには `see reference to ...` の行が入らないため）。ビルド出力を詳細（ツール → オプション → プロジェクトおよびソリューション → ビルドして実行 → MSBuild プロジェクトのビルド出力の詳細度）にしなくても、これらの行は標準で出ます。

## ビルド

```powershell
.\build.ps1
```

事前に、Visual Studio の「Visual Studio extension development」ワークロードが要ります。解析部分だけのテストは、次で動きます。

```powershell
dotnet run --project tests\ParserTest
```
