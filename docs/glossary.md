# 用語集

このサイトに出てくる**専門用語**を**五十音・アルファベット順**にまとめた一覧です。**本文の用語にマウスを乗せる**（スマホはタップ）と、**ここに載っている説明**がそのまま出ます。**用語をクリックすると、詳しく解説したページ**へ移動します。

!!! tip "使い方"
    - <strong>上の入力欄</strong>で、用語や説明の一部から<strong>絞り込める</strong>。
    - 右端の<strong>「→」</strong>は、<strong>その用語を詳しく説明しているページ</strong>へのリンク。
    - 1 つの用語に<strong>別名</strong>（英語・略称）がある場合は、<strong>用語の下に小さく</strong>並べている。
