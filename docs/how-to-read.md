# このサイトの読み方

## 重要度ランク

各ページと各関数には 4 段階の重要度が付いています。**上から順に覚えれば OK** です。

| ランク | 意味 |
| --- | --- |
| <span class="rank rank-must">必須</span> | 知らないとゲームが書けない。最優先で覚える |
| <span class="rank rank-often">よく使う</span> | 週に何回かは書く。覚えておくと楽 |
| <span class="rank rank-sometimes">たまに</span> | 必要になったときに調べれば十分 |
| <span class="rank rank-rare">知ってるだけ</span> | 存在だけ知っていればいい。使う場面はほぼない |

## 速さ

<strong>クラス（型）</strong>には、ゲームの中でよくある使い方をしたときの速さの目安を 4 段階で付けています。ページの上部と、一覧ページの表に出てきます。計算量だけでなく、メモリ確保やキャッシュ効率も含めた実感ベースの評価です。

| 速さ | 意味 | 例 |
| --- | --- | --- |
| <span class="perf perf-4">◎ 速い</span> | 全要素を回す・アクセスするのがとても速い | `vector`, `array`, `span` |
| <span class="perf perf-3">○ 普通</span> | 毎フレーム使って問題ない | `unordered_map`, `map`, `string` |
| <span class="perf perf-2">△ やや重い</span> | 使い方によっては重くなる | `std::any` |
| <span class="perf perf-1">× 重い</span> | 同じことをするなら他のクラスのほうが速い | `list`, `forward_list` |

関数には速さを付けていません。`size()` は速くて `clear()` は遅い、といった違いは「どちらを使うか」で選ぶものではないからです。関数ごとの重さは、各関数の「計算量」と説明を見てください。

!!! note
    目安なので、要素数が数十個程度なら × でも問題にならないことがほとんどです。気になったら Release ビルドで測ってください。

## 並び順

関数やフラグの一覧は、**よく使う順**に並べています。アルファベット順ではありません。

## バージョンバッジ

その機能がどの規格で入ったかを表します。

<span class="ver ver-11">C++11</span>
<span class="ver ver-14">C++14</span>
<span class="ver ver-17">C++17</span>
<span class="ver ver-20">C++20</span>
<span class="ver ver-23">C++23</span>

C++23 の機能はコンパイラによってまだ使えないことがあります。各ページの「コンパイラ対応」を確認してください。このサイトは Visual Studio 2026（MSVC `v145`）を前提にしているので、表に「VS 2022 17.x〜」と書いてある機能は、2026 ではすべて使えます。表の版は、「その機能が初めて入った版」を表します。

## 各ページの構成

上から順に、この並びで書いています。

| 見出し | 書いてあること |
| --- | --- |
| （冒頭） | 「〇〇は〜です」というざっくりした説明 |
| ポイント | 「迷ったらこれ」「9 割はこう書く」 |
| このページを読む前に | 先に知っておくと楽な基礎（用語集へのリンク） |
| 宣言 | テンプレート引数とコンストラクタ |
| 関数一覧 | 全関数の一覧。重要度・計算量つき。よく使う順 |
| よくある使い方 | 一覧の関数を実際にどう組み合わせるか |
| 関数の詳しい説明 | 1 関数ずつ、引数・戻り値・計算量・実行例 |
| フラグ・オプション | 指定できる値をすべて解説 |
| 古い書き方と今の書き方 | ネットの古い記事との違い |
| ゲームでの使いどころ | 具体的な場面 |
| パフォーマンス | 速さ・メモリで気をつけること。図解つき |
| 未定義動作・例外 | 落ちる・壊れるパターン |
| よくあるミス | 学生がハマりがちなところ |
| 類似クラス | 似たものとの使い分け |
| コンパイラ対応 | MSVC / GCC / Clang の対応状況 |
| これだけ覚える | 読み返す用の 3〜5 行まとめ |

## サンプルコードについて

- C++23 前提です（`-std=c++23` / `/std:c++latest`）
- [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html) に従っています
- 解説のためにコメントを多めに書いています
- 出力があるサンプルには、すぐ下に「実行結果」を載せています
- `int main` があるサンプルには「▶ Compiler Explorer で実行」リンクが付いていて、ブラウザ上で書き換えて試せます
