# Git

ゲームを作っていると「昨日まで動いていたのに、いま動かない」が必ず起きます。複数人で作れば同じファイルを同時に直して、片方が消えることもあります。<strong>Git</strong> はファイルの変更を履歴として残し、好きな時点に戻せる道具です。別々に直した内容をあとから合体する仕組みも持っています。

このカテゴリは、Git の使い方を、毎日の操作からチームでの使い方、事故の直し方まで順にまとめています。<strong>操作は、SourceTree の画面で説明します</strong>（コマンドを打つ必要はありません）。コマンドを使うのは、プッシュの拒否や消えたコミットの救出のような、画面だけでは直せないトラブルの場面だけです。
