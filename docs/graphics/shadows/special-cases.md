# 特殊な影

ここまでの影は、**ソリッドな物体が光を完全に遮る**ことを前提にしていました。実際のゲームでは、**半透明・アルファ テストの葉・キャラクターの足元・非常に遠い物・一時的なエフェクト**など、**標準の方式では扱いにくい影**が必要になります。このページでは、**アルファ テストの影・半透明の影・ブロブ（丸）シャドウ・平面投影シャドウ・遠景の影・キャラクターの影**など、**特殊なケースの方法**をまとめます。

!!! tip "ポイント"
    - <strong>アルファ テスト（葉・柵）</strong>：<strong>シャドウ パスにもアルファ テスト（clip/discard）</strong>が必要。<strong>Early-Z が効かなくなる</strong>。
    - <strong>半透明の影</strong>：<strong>色付きシャドウ（透過の色を保存）</strong>・<strong>ステッポリング（スクリーン ドア）</strong>・<strong>確率的な透過</strong>。
    - <strong>ブロブ シャドウ</strong>：<strong>足元に丸い暗いデカール</strong>。<strong>安く、モバイル向け</strong>。
    - <strong>平面投影シャドウ</strong>：<strong>物体を地面（平面）に押し潰して</strong>描く。<strong>平らな地面のみ</strong>。
    - <strong>遠景</strong>：<strong>カスケードの外</strong>は、<strong>距離場・ベイク済みのマスク・フェード</strong>で。
    - <strong>キャラクター</strong>：<strong>専用のシャドウ マップ</strong>・<strong>カプセル シャドウ</strong>で<strong>品質と安さを両立</strong>。

## アルファ テストの影（葉・柵）

**葉・柵・金網**などは**テクスチャの透明部分を `clip` で捨てて**、**形**を作っています。**シャドウ マップ**を描くときも、**同じアルファ テスト**をしないと、<strong>影がポリゴンの形（四角）</strong>になってしまいます。

```hlsl
void ShadowPS(float2 uv : TEXCOORD0) {
  float alpha = albedo_tex.Sample(linear_sampler, uv).a;
  clip(alpha - kAlphaCutoff);
}
```

| 点 | 説明 |
| --- | --- |
| **シャドウ パスでも `clip`** | **アルファ付きのマテリアル**は、**ピクセル シェーダー付き**のシャドウ パスで描く |
| **Early-Z の無効化** | `clip` があると**深度の書き込みがシェーダーの後**になる。**重くなる** |
| **不透明の物は、PS なし** | **深度のみ**のパス（**PS を設定しない**）で、**最速**。**マテリアルごとにパスを分ける** |
| **ミップの影響** | **アルファ テストの葉**は、**ミップでアルファが薄まる**。**ミップ レベルのバイアス**や、**アルファのカバレッジ保存**が必要（遠くで影が薄くなる） |

**描画順**を<strong>「不透明（PS なし）→ アルファ テスト（PS あり）」</strong>にすると**効率**が良いです。

## 半透明の影

**ガラス・煙・半透明の布**は**光を部分的に通します**。**シャドウ マップは、深度しか持たない**ので<strong>「完全に遮る」か「完全に通す」</strong>の**2 択**になります。

| 方法 | 内容 |
| --- | --- |
| **影を落とさない** | **一番簡単**。**半透明の物**は**影を落とさない**設定 |
| <strong>スクリーン ドア（ステッポリング）</strong> | <strong>透明度に応じた、確率的（ディザ パターン）</strong>に、**一部の画素を `clip`**。**少し遮る**。**PCF・TAA**で**平均され**て、**薄い影**に見える |
| **不透明として扱う** | **ガラスでも影を濃く**落とす（**嘘だが手軽**） |
| **色付きシャドウ マップ** | **別のシャドウ マップ**（**RGB ＋ 深度**）に、**半透明の物の色と透過率**を**乗算ブレンド**で保存。**ステンドグラス**のような**色付きの影**。**不透明の物の影とは、別に引く** |
| <strong>多層（Deep Shadow Maps）</strong> | **深度ごとの透過率**を保存（**煙・髪**）。**メモリが重く**、**専用** |
| <strong>レイトレース影（Any-Hit）</strong> | **Any-Hit シェーダー**で、**透過率を累積**（[レイトレース影](ray-traced.md)） |

### ステッポリングの例

```hlsl
float threshold = Bayer4x4(pixel_position);
clip(opacity - threshold);
```

<strong>ディザ（Bayer 行列・IGN）</strong>で、**透明度の割合**だけ**画素を残し**、**影の濃さ**を**確率的に**表現します。**ノイズ**が出るので、**PCF や TAA**で**消します**。

## ブロブ シャドウ（丸い影）

**足元に柔らかい丸い暗い画像**（**ブロブ**）を、**地面に貼る**だけの影です。**シャドウ マップなし**で、**最も安く**、<strong>「地面に接している」感じ</strong>を出せます。

| 項目 | 内容 |
| --- | --- |
| **実装** | <strong>地面に丸いグラデーションの四角形（デカール）</strong>を、**キャラの足元**に**置く**（デカール） |
| **変化** | **高さに応じて、薄く・大きく**（**ジャンプ中は薄くぼける**） |
| **利点** | **非常に安い**。**モバイル・多数のキャラ**に向く |
| **欠点** | **形が丸いだけ**。**光の方向・物の形**を反映しない。**傾斜地**で浮く |

**ブロブ ＋ 本格的な影**を組み合わせ、**近くは本格、遠くはブロブ**のように<strong>切り替える（LOD）</strong>ことも一般的です。

## 平面投影シャドウ

**物体のジオメトリを、「地面の平面」に押し潰す**行列を**かけて**描き、**暗い単色**で塗ります。

<div class="formula">平面 n·x + d = 0 へ、光の方向 L に沿って投影する行列（4×4）</div>

```cpp
XMVECTOR plane = XMVectorSet(0, 1, 0, 0);
XMVECTOR light = XMVectorSet(light_dir.x, light_dir.y, light_dir.z, 0);
XMMATRIX shadow_matrix = XMMatrixShadow(plane, XMVectorNegate(light));
```

| 項目 | 内容 |
| --- | --- |
| **`XMMatrixShadow`** | DirectXMath の関数。**平面と光の方向**から、**投影行列**を作る |
| **描画** | **物体を、`shadow_matrix` で変換して**、<strong>黒（半透明）</strong>で描く |
| **Z ファイティング対策** | **平面と同じ高さ**になるので、**少しオフセット**・**ステンシルで二重描画を防ぐ** |
| **利点** | **形が正確**・**シャドウ マップ不要** |
| **欠点** | **平らな床のみ**。**他の物への落とす影**・**自己影**は不可。**ハード エッジ** |

**古い手法**ですが**平らな床のゲーム**（スポーツ・シンプルな 3D）では今でも**有効**です。

## 遠景の影

**カスケードの最大距離**を超えた先は、**影がなくなります**。**遠景の山・建物**の**大きな影**を**どう扱うか**です。

| 方法 | 内容 |
| --- | --- |
| **フェードアウト** | **最大距離で影を徐々に消す**（[カスケード](cascaded.md)） |
| **ベイク済みの影** | **静的な遠景**は**ライトマップ・影のマスク**に**ベイク** |
| **距離場の影** | **遠景に距離場の影**を使う（[距離場の影](sdf-shadows.md)） |
| **大きな最後のカスケード** | **最後のカスケードを非常に大きく**（粗いが**遠くの大きな影**は捉える） |
| **雲の影** | **雲のテクスチャを地面に投影して**、**大規模な、移動する影**を**安く**表現 |

### 雲の影

**雲のアルファ テクスチャ**を、**太陽の方向**から**地面に投影**し、**ライティングに乗算**します。**時間でスクロール**させれば、**雲の影がゆっくり動く**様子になります。

```hlsl
float2 cloud_uv = world_pos.xz * cloud_scale + wind * time;
float cloud_shadow = lerp(1.0, cloud_tex.Sample(linear_sampler, cloud_uv).r, cloud_strength);
lit *= cloud_shadow;
```

## キャラクターの影

**キャラクター**は、**画面の主役**で**影の品質**が**目立ち**ます。**専用の工夫**がよく使われます。

| 方法 | 内容 |
| --- | --- |
| **専用のシャドウ マップ** | **キャラクターだけ**を**高解像度のシャドウ マップ**に描く（**カスケードとは別**）。**顔・手の細部まで**、**鋭く** |
| **カプセル シャドウ** | **骨**に<strong>カプセル（線分 ＋ 半径）</strong>を割り当て、**解析的な、柔らかい影**。**変形するキャラ**にも**安い**（[距離場の影](sdf-shadows.md)） |
| **コンタクト シャドウ** | **足元・細部**の**接触**を**補う**（[コンタクト シャドウ](contact-shadows.md)） |
| **フェイク ライト** | **キャラクター用に専用のライト**（**リム ライト・影の向き**を**演出的に調整**） |

### 髪・肌の影

**髪**は**細い**ので**シャドウ マップ**では**ほぼ点**になります。**髪専用の深いシャドウ（Deep Opacity Maps）・近似的な、半透明の影**が使われます（肌・髪・布の節を参照）。

## 影の色・濃さの調整

| 項目 | 内容 |
| --- | --- |
| **影の色** | **真っ黒ではなく、環境光の色**（**空の青**）に**寄せる**。**間接光**が**影の中**にも**届く**から |
| **影の濃さ** | **0〜1 の係数**で**影の暗さ**を**調整**（`lerp(1, shadow, strength)`）。**シーンの雰囲気**に合わせる |
| **環境光の遮蔽（AO）との併用** | **シャドウ マップが覆えない**、**細かい隙間の暗さ**を、AO が補う（[AO](../ao/index.md)） |

```hlsl
float3 direct = sun_color * n_dot_l * shadow;
float3 ambient = sky_ambient * ao;
float3 lit = direct + ambient;
```

**影の中も環境光で少し明るい**ので**影を完全な黒にしない**ことが、**自然な見た目**の基本です。

## よくあるミス

??? failure "葉の影が、四角い板の形になる"
    <strong>シャドウ パスにもアルファ テスト（`clip`）</strong>を入れます。

??? failure "全メッシュを PS 付きのシャドウ パスで描いて、遅い"
    **不透明は、PS なし**・**アルファ テストだけ PS 付き**に**分け**ます。

??? failure "遠景で、突然、影が消える"
    **最大距離の手前でフェード**・**遠景は別の方式**を併用します。

??? failure "影が、真っ黒で浮いて見える"
    **環境光・間接光**を**足し**、**影の色**を**調整**します。
