# Peter Panning

シャドウ アクネ（自分の面に落ちる縞模様の影）を消そうとして、バイアスを大きくしていくとある所から、今度は影が物から離れて物が地面から浮いて見えるようになります。足元に光の筋のような隙間ができます。

<strong>バイアスを大きくしすぎると、物体の接地部分の影が欠けて影が物から離れます</strong>。これがピーター パンニングです。名前はピーター パンの影が体から離れる話に由来します。アクネとピーター パンニングはバイアスの大小のトレードオフです。このページでは影が離れる幅の式（検算つき）、薄い物が影を落とせない条件、見分け方、避ける工夫（複数のバイアスの分担）を説明します。

!!! tip "ポイント"
    - ピーター パンニングはバイアスが大きすぎて、影が物から離れる現象です。足元や接地している物で目立ちます。
    - 垂直な壁の足元で、影が離れる幅はワールドのバイアス `b` × `cos θ` です（`θ` は光の仰角）。低い光ほど `b` に近い幅になります。
    - バイアスより薄い物は地面に近いと影を落とせません。
    - アクネを消すためにバイアスを上げると、必ずトレードオフになります。
    - 対策は法線オフセット、前面カリング、受け手平面バイアスなど浮きにくい方法を分担させることです。

## ピーター パンニングとは {#what}

バイアスは画素の深度から一定量を引くことで、自己影を防ぎます。引く量が大きすぎると物のすぐ近くの影まで、「光が当たる」と判定されます。物の接地部分の影が消えて影が足元から離れます。

```text
 本来の影:                      ピーター パンニング:
   ┌──┐                           ┌──┐
   │物│                           │物│
 ━━┷━━┷━━━━━                    ━━┷━━┷━━━━━
   ▓▓▓▓      ← 足元に接する         ░░░░▓▓▓   ← 影が足元から離れている（浮いている）
```

バイアスの大きさと見え方の関係は次のとおりです。小さいと物の足元から影が始まりますが、自己影（シャドウ アクネ）が出ます。ちょうどよいと足元から影が始まって、自己影もありません。大きすぎると足元の影が欠けて、影が物から離れます。

## 離れる幅を計算する {#gap}

影が離れる幅は光の角度とバイアスで、式にできます。垂直な壁が地面に立っていて光が壁の側から、仰角 `θ`（水平から何度上か）で当たっているとします。壁の向こう側の地面の点が壁から水平に `x` だけ離れているとき光源へ向かう線は、壁に高さ `x · tan θ` で当たります。この線に沿った壁と地面の点の距離は `x / cos θ` です。

シャドウ マップには壁の面の深度が入っています。バイアス `b`（光に沿ったワールドの距離）を引いて比べるので、壁から `b` 以内の点は光が当たると判定されます。つまり、`x / cos θ < b` を満たす点が影になりません。

<div class="formula">影が欠ける幅（地面で） = b · cos θ</div>

Python で壁と地面を 2 次元で数値的に調べて、式と一致することを確かめました。`b = 0.05 m` で仰角 10° の幅は 0.0493 m（式は 0.0492）、30° で 0.0433 m（0.0433）、45° で 0.0354 m、60° で 0.025 m、80° で 0.0087 m でした。

低い光（仰角が小さい）ほど `cos θ` が 1 に近いので、幅が `b` にほぼ等しくなります。高い光では幅が小さくなります。朝夕の低い太陽はピーター パンニングが目立ちやすいということです。

見た目への影響も数字で見積もります。正射影の太陽のシャドウ マップで、範囲が 100 m、正規化バイアスが 0.001 ならワールドの `b` は 10 cm で、仰角 30° の幅は約 8.7 cm です。5 m 離れた物を画角 60°、縦 1080 ピクセルで見ると、1 ピクセルが約 5.3 mm なので、隙間は約 16 ピクセルあります。目に見える隙間です。

## 薄い物は影を落とせない {#thin}

バイアスより薄い物は地面に近いと影を落とせません。浮いている板が地面から光に沿って `d` の距離にあるとします。バイアス `b` について `d < b` なら地面の点は、板から `b` 以内なので光が当たると判定されます。板の影が完全に消えます。薄い壁、屋根、板、紙のような物で目立ちます。

## 見分け方 {#symptoms}

- 物の足元に隙間（光の筋）が見えるならバイアスが大きすぎます。
- 薄い壁の影が無いまたは途切れるならバイアスが壁の厚みや地面との距離より大きいです。
- 物が浮いて見えるのは影が接地していないからです。
- 光が斜めのときに特に目立つなら傾き依存のバイアスが暴走しています。

## 対策 {#fixes}

### バイアスを必要最小限にする

根本的な対策はバイアスを必要最小限に抑えることです。ただし、シャドウ アクネとトレードオフです。ほかの方法でアクネを防いでバイアスを小さく保ちます。

### 法線オフセットを使う

深度を引く（バイアス）代わりに位置を法線方向にずらす方法で、アクネを防ぎます（[Normal Offset](normal-offset.md)）。深度の値はいじらないのでピーター パンニングが起きにくくなります。

### 裏面を描く

シャドウ パスで光に向いた面ではなく、裏面を描きます（[Front-Face Culling](front-face-culling.md)）。表と裏の間の物の厚みがそのままバイアスの代わりになります。表面を描く + 大きなバイアスでは起きますが、裏面を描く（バイアス小）なら起きにくいです。薄い物は別の問題（影が欠ける）があります。

### 傾き依存バイアスに上限を設ける

傾き依存のバイアスは光にほぼ平行な面で暴走します。上限（`DepthBiasClamp`）を設けます（[Slope-Scale Bias](slope-scale-bias.md)）。

### 薄い物に厚みを持たせる

薄い壁や板が影を落とせないのは、ジオメトリが薄すぎるためです。影用に少し厚みを持たせたメッシュを使うか壁そのものに厚みをつけます。

### 接地部分を偽の影で補う

足元の接地が重要（キャラクター）なら足元にブロブ状の影（[Blob and Planar Projected Shadows](../special-cases/blob-planar.md)）や、コンタクト シャドウ（[Contact Shadows](../contact-shadows.md)）を足します。

## 分担させるシェーダー {#shader}

1 つの方法を大きくするより複数の方法をそれぞれ小さく分担させます。法線オフセット、小さな定数バイアス、上限つきの傾き依存バイアスを 1 つの関数にまとめた例です。

```hlsl
Texture2D<float> g_shadow_map : register(t0);
SamplerComparisonState g_shadow_sampler : register(s0);

cbuffer ShadowBiasConstants : register(b0) {
  float4x4 g_world_to_light;
  float3 g_light_dir;          // 光の来る向き（太陽へ向かう単位ベクトル）
  float g_shadow_texel_world;  // シャドウ マップの 1 テクセルのワールドでの大きさ（メートル）
  float g_normal_offset_scale; // 法線オフセットの強さ（テクセル単位）。例: 1.5
  float g_constant_bias;       // 正規化深度での小さな定数。例: 0.0002
  float g_slope_bias_scale;    // 傾き依存の係数。例: 0.0005
  float g_slope_bias_max;      // 傾き依存の上限（正規化深度）。例: 0.002
};

float ShadowWithBias(float3 world_pos, float3 world_normal) {
  float3 n = normalize(world_normal);
  float n_dot_l = saturate(dot(n, g_light_dir));

  // ① 法線オフセット: 光に斜めな面ほど、位置を法線方向へ大きくずらす。深度はいじらない
  float slope_factor = sqrt(1.0 - n_dot_l * n_dot_l);                  // sin θ。斜めなほど 1
  float3 offset_pos = world_pos + n * (g_shadow_texel_world * g_normal_offset_scale * slope_factor);

  float4 clip = mul(float4(offset_pos, 1.0), g_world_to_light);
  float3 ndc = clip.xyz / clip.w;
  float2 uv = float2(ndc.x * 0.5 + 0.5, 0.5 - ndc.y * 0.5);

  // ② 傾き依存の深度バイアス。tan θ に比例させて、上限で暴走を止める
  float tan_theta = slope_factor / max(n_dot_l, 0.05);
  float slope_bias = min(g_slope_bias_scale * tan_theta, g_slope_bias_max);

  // ③ 小さな定数バイアス（量子化誤差のぶんだけ）
  float depth = ndc.z - g_constant_bias - slope_bias;
  return g_shadow_map.SampleCmpLevelZero(g_shadow_sampler, uv, depth);
}

float4 PeterPanningSafePS(float3 world_pos : TEXCOORD0, float3 normal : TEXCOORD1) : SV_Target {
  float lit = ShadowWithBias(world_pos, normal);
  return float4(lit, lit, lit, 1.0);
}
```

①は斜めの面ほど大きくずらします。位置のずれなので足元のずれはテクセル数個ぶん（数 cm）になります。②の `tan θ` は面が光に平行に近づくと発散するので、`max(n_dot_l, 0.05)` と `slope_bias_max` で止めます。③は量子化誤差を覆うだけの小さな値にとどめます。3 つの役割を分けるのでどれか 1 つを大きくする必要がありません。

C++ 側のラスタライザー ステートで、傾き依存と上限を設ける場合は次のとおりです。

```cpp
// （コンパイルしていない）シャドウ パスのラスタライザー ステート
D3D11_RASTERIZER_DESC rs = {};
rs.DepthBias = 0;                   // 定数はシェーダーで引くので 0
rs.SlopeScaledDepthBias = 1.5f;     // 傾きに比例して引く係数
rs.DepthBiasClamp = 0.005f;         // 傾き依存のバイアスの上限。暴走を防ぐ
device->CreateRasterizerState(&rs, &shadow_rs);
```

!!! note "確かめた範囲"
    HLSL は `fxc`（`ps_5_0`）で、`PeterPanningSafePS` をコンパイルしてエラーが出ないことを確かめました。C++ はコンパイルしていません。影が離れる幅の式 `b · cos θ` は Python の 2 次元の数値計算で確かめました。画素の大きさと隙間の数字は式からの手計算です。GPU での描画は確認していません。

## 判断の目安 {#guide}

1. まずバイアスを最小から始めます（アクネが出ない最小値）。
2. 斜めの面のアクネは法線オフセットで抑えます。
3. 薄い物は影用のメッシュか裏面を描く方法を使います。
4. 接地が重要ならコンタクト シャドウで補います。

## よくあるミス {#mistakes}

??? failure "1 つの定数バイアスだけで両立しようとして、調整が終わらない"
    原因はアクネとピーター パンニングが、定数 1 つのトレードオフになっていることです。法線オフセット、小さな定数、上限つきの傾き依存を少しずつ組み合わせます（[Shadow Bias](index.md)）。

??? failure "朝夕に足元の影が大きく離れる"
    原因は低い光では離れる幅がバイアスにほぼ等しいことです（`b · cos θ`）。バイアスを仰角に応じて小さくするか法線オフセットを主にします。

??? failure "薄い壁や板の影が出ない"
    原因は壁や板がバイアスより薄いか地面に近いことです。影用に厚みを持たせたメッシュを使うかバイアスを下げます。

## これだけ覚える {#summary}

!!! abstract "まとめ"
    - [x] バイアスが大きいと影が物から離れます。垂直な壁の足元で離れる幅は `b · cos θ` です。
    - [x] 低い光ほど離れる幅が `b` に近くなります。
    - [x] 法線オフセット、小さな定数、上限つきの傾き依存を分担させます。
    - [x] 薄い物はバイアスより薄いと影を落とせません。
