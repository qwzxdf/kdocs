# ピーター パンニング

**バイアスを大きくしすぎると、影が物体から離れて、物が浮いているように見えます**。これが**ピーター パンニング**（**ピーター・パンの影が体から離れる話に由来**）です。**アクネとピーター パンニングは、バイアスの大小のトレードオフ**で、**両方を避けるには、バイアスを複数の方法で、少しずつ組み合わせます**。このページでは、**発生の理由・見分け方・避ける工夫**を説明します。

!!! tip "ポイント"
    - **ピーター パンニング ＝ バイアスが大きすぎて、影が物から離れる**。
    - **接地している物（足元）で目立つ**。
    - **アクネを消すためにバイアスを上げると、必ずトレードオフ**になる。
    - **対策**：**法線オフセット・前面カリング・受け手平面**など、**浮きにくい方法を使う**。

## ピーター パンニング
**バイアスが大きすぎる**と、**影が物体の接地部から離れて**見えます（物体が地面から浮いたように見える）。これが**ピーター パンニング**（影が体から離れる、ピーター パンの影の話から）です。

| 症状 | 原因 |
| --- | --- |
| **影が足元から離れる** | 定数バイアスが大きすぎる |
| **薄い壁の向こうに光が漏れる** | 法線オフセットが大きすぎる・裏面レンダリングで薄い物 |
| **細い物体の影が消える** | バイアスで遮蔽物自体が無視される |

**対策**は**バイアスを必要最小限**にして、**スロープ スケール・法線オフセット・受け手平面バイアス**を**組み合わせる**ことです。**どれか 1 つを大きくするより、分担**させます。

## よくあるミス

??? failure "1 つの定数バイアスだけで、両立しようとして調整が終わらない"
    **複数の方法を少しずつ**組み合わせる（[バイアス](index.md)）。
