# Peter Panning

<strong>バイアスを大きくしすぎると、影が物体から離れて物が浮いているように見えます</strong>。これがピーター パンニング（ピーター・パンの影が体から離れる話に由来）です。アクネとピーター パンニングは、バイアスの大小のトレードオフで、両方を避けるにはバイアスを複数の方法で、少しずつ組み合わせます。このページでは発生の理由・見分け方・避ける工夫を説明します。

!!! tip "ポイント"
    - ピーター パンニング ＝ バイアスが大きすぎて、影が物から離れる。
    - 接地している物（足元）で目立つ。
    - アクネを消すためにバイアスを上げると、必ずトレードオフになる。
    - 対策：法線オフセット・前面カリング・受け手平面など、浮きにくい方法を使う。

## ピーター パンニング
<strong>バイアスが大きすぎる</strong>と 影が物体の接地部から離れて見えます（物体が地面から浮いたように見える）。これがピーター パンニング（影が体から離れる、ピーター パンの影の話から）です。

ピーター パンニングの症状と原因を対応づけます。影が足元から離れるのは定数バイアスが大きすぎるためです。薄い壁の向こうに光が漏れるのは、法線オフセットが大きすぎるあるいは薄い物に裏面レンダリングを使っているためです。細い物体の影が消えるのはバイアスで遮蔽物自体が無視されるためです。

対策はバイアスを必要最小限にして、スロープ スケール・法線オフセット・受け手平面バイアスを組み合わせることです。どれか 1 つを大きくするより、分担させます。

## ピーター パンニングとは

<strong>バイアスを大きくしすぎた</strong>ときに 影が物から離れて、浮いて見える現象です。ピーター パンが影が体から離れた（影を、縫いつけた）という話にちなんで、こう呼ばれます。

```text
 本来の影:                      ピーター パンニング:
   ┌──┐                           ┌──┐
   │物│                           │物│
 ━━┷━━┷━━━━━                    ━━┷━━┷━━━━━
   ▓▓▓▓      ← 足元に、接する       ░░░░▓▓▓   ← 影が、足元から、離れている（浮いている）
```

## 原因

バイアスは <strong>画素の深度から一定量を、引く</strong>ことで 自己影を防ぎます。引く量が大きすぎると物のすぐ近くの影まで、「光が当たる」と判定されます（物の接地部分の影が、消える）。

| バイアス | 影の見え方 |
| --- | --- |
| 小さい | 物の足元から影が、始まる。ただし、自己影（シャドウ アクネ） |
| ちょうどよい | 足元から影が、始まる。自己影なし |
| 大きすぎる | 足元の影が、欠ける。影が物から離れる |

特に薄い物（壁、屋根、板）で 目立ちます。バイアスより薄い物は影を落とせません（影が完全に、消える）。

## 見分け方

| 症状 | 原因 |
| --- | --- |
| 物の足元に隙間（光の筋）が、見える | バイアスが大きすぎる |
| 薄い壁の影が無いまたは途切れる | バイアスが、壁の厚みより大きい |
| 物が浮いて見える | 影が、接地していないので物が地面から浮いて、見える |
| 光が斜めのとき特に目立つ | 傾き依存の、バイアスが暴走している |

## 対策

### ① バイアスを小さくする

<strong>根本的</strong>な対策は バイアスを、必要最小限に抑えることです。ただし、シャドウ アクネ（バイアスが、足りない症状）とトレード オフです。他の方法でアクネを防ぎバイアスを、小さく保ちます。

### ② 法線オフセットを使う

深度を引く（バイアス）代わりに、位置を法線方向にずらす（[Normal Offset](normal-offset.md)）ことで、アクネを防ぎます。深度の値はいじらないのでピーター パンニングが、起きにくくなります。

### ③ 表面のカリング（裏面を描く）

シャドウ パスで 光に向いた面ではなく、裏面（光から遠い側の面）を、描きます（[Front-Face Culling](front-face-culling.md)）。表と裏の間の物の厚みがそのまま、バイアスの代わりになりバイアスをほぼ、不要にできます。

| 方法 | ピーター パンニング |
| --- | --- |
| 表面を描く + 大きなバイアス | 起きる |
| 裏面を描く（バイアス小） | 起きにくい（物の厚みが接地を、保つ）。薄い物は別の問題（影が欠ける） |

### ④ 傾き依存バイアスの上限

傾き依存バイアスは 光に、ほぼ平行な面で暴走します。上限（`DepthBiasClamp`）を設けます（[Slope-Scale Bias](slope-scale-bias.md)）。

```cpp
rs.DepthBiasClamp = 0.005f;        // バイアスの、上限。暴走を、防ぐ
```

### ⑤ 薄い物は厚みを持たせる

薄い壁や板が影を落とせないのは、ジオメトリが薄すぎるためです。影用に少し厚みを持たせたメッシュ（影用のメッシュ）を使うか、壁そのものに厚みをつけます。

### ⑥ 接地部分を偽の影で補う

足元の 接地が重要（キャラクター）なら、足元にブロブ状の影（[Blob and Planar Projected Shadows](../special-cases/blob-planar.md)）や、コンタクト シャドウ（[Contact Shadows](../contact-shadows.md)）を足して、補います。

## 判断の目安

| 優先 | 内容 |
| --- | --- |
| 1 | まずバイアスを最小から、始める（アクネが出ない最小値） |
| 2 | 斜めの面のアクネは、法線オフセットで抑える |
| 3 | 薄い物は影用のメッシュ、または裏面を描く |
| 4 | 接地が重要ならコンタクト シャドウで、補う |

## よくあるミス
