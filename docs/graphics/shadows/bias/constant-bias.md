# Constant Bias

**もっとも簡単なバイアス**は、**比較する深度から、一定の値を引く（足す）**ことです。**実装が 1 行**で**最初に試すべき**ですが、**面の傾きが大きいと足りず、小さい面では大きすぎて影が浮く**ので、**単独では不十分**です。このページでは、**定数バイアスの式・値の目安・限界**を説明します。

!!! tip "ポイント"
    - **定数バイアス ＝ 比較時に、深度に一定の値を足す**（**例：0.001**）。
    - **簡単だが、傾きに依らないので、斜めの面でアクネ・正面で浮き**になる。
    - **値は、シーンの大きさと深度の精度で決まる**。
    - **他の方式と組み合わせる**前提で使う。

## 対策 1：定数バイアス
**比較する深度から、一定の値を引きます**。

```hlsl
float depth = ndc.z - 0.001;
```

定数バイアスの利点は、簡単なことです。欠点は、斜めの面には足りずアクネが残ること、大きくすると全体が浮く（ピーター パンニング）こと、値の調整がシーンの大きさと解像度に依存することです。
