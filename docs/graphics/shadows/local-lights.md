# スポット・点光源の影

太陽（平行光）の影は**正射影のシャドウ マップ**で作れました。**スポットライト・点光源**は**位置から放射状に光が出る**ので、**透視投影**が必要です。点光源は**全方向**を覆う必要があり、**キューブ マップ**などを使います。**光の数が多い**ほど、**シャドウ マップの枚数・描画コスト**が膨らむので、**どのライトに影を付けるか**の設計が大切です。このページでは、**スポット・点光源・多数のライトの影**の作り方を説明します。

!!! tip "ポイント"
    - <strong>スポットライト</strong>：光の円錐に合わせた<strong>透視投影 1 枚</strong>。
    - <strong>点光源</strong>：<strong>6 方向（キューブ マップ）</strong>、または<strong>デュアル パラボロイド</strong>。
    - キューブの面の選択は、<strong>ライトから画素へのベクトルの、絶対値が最大の軸</strong>。
    - 透視投影の深度は<strong>非線形</strong>。<strong>バイアス・比較の深度を揃える</strong>必要がある。
    - 多数のライトは、<strong>影付きの数を制限</strong>し、<strong>アトラス・優先度・更新頻度</strong>で管理。
    - 光の<strong>範囲外・画面外・遠方</strong>のライトは、影を描かない。

## スポットライト

**スポットライト**の光は、**位置・向き・円錐の角度**で決まります。**円錐の外には光が届かない**ので**円錐を覆う透視投影**の**シャドウ マップ 1 枚**で済みます。

| 項目 | 内容 |
| --- | --- |
| **ビュー行列** | ライトの位置・向きから（`XMMatrixLookToLH`） |
| **射影行列** | **視野角 ＝ 円錐の全角**、アスペクト 1、近・遠はライトの範囲 |
| **シャドウ マップ** | **正方形**（1 枚） |

```cpp
XMMATRIX view = XMMatrixLookToLH(light_position, light_direction, up);
XMMATRIX proj = XMMatrixPerspectiveFovLH(outer_cone_angle * 2.0f, 1.0f, near_z, light_range);
```

**近クリップ面**を**小さくしすぎない**ことが大切です。**近すぎる**と**深度の精度**が**遠くで足りなく**なります（透視投影の深度は、近くに集中）。

## 点光源：キューブ マップ

**点光源**は**あらゆる方向**に光を出します。**6 方向（±X, ±Y, ±Z）に、視野角 90 度の透視投影**で描けば、**全方向を覆えます**（**キューブ シャドウ マップ**）。

| 方式 | 内容 |
| --- | --- |
| **6 枚のレンダー ターゲット** | `Texture2DArray` の 6 スライス（または `TextureCube`）に、**6 回**描く |
| **ジオメトリ シェーダーで 1 回** | **`SV_RenderTargetArrayIndex`** で、**1 回の描画で 6 面**へ（環境による。効率は微妙） |
| **ビュー インスタンシング** | 対応環境で、**1 回のドロー**で複数面 |

### サンプル：方向ベクトルで引く

**キューブ マップ**は、**ライトから画素へのベクトル**で、**サンプル**できます。**比較には保存された深度**と<strong>そのベクトルの長さ（または面ごとの深度）</strong>を使います。

```hlsl
float PointShadow(float3 world_pos) {
  float3 v = world_pos - light_position;
  float3 a = abs(v);
  float major = max(a.x, max(a.y, a.z));
  float depth = (light_far * (major - light_near)) / (major * (light_far - light_near));
  return shadow_cube.SampleCmpLevelZero(shadow_sampler, v, depth - bias);
}
```

| 点 | 説明 |
| --- | --- |
| **`major`** | **絶対値が最大の成分**＝**その面の、ビュー空間の z** |
| **`depth`** | **透視投影の深度の式**で**射影後の深度**（0〜1）に変換（左手系の `XMMatrixPerspectiveFovLH` と同じ） |
| **`shadow_cube`** | `TextureCube`（比較サンプラー）。**面の境界もハードウェアが補間** |

### 線形な距離を保存する方法

**射影後の深度**でなく、**ライトからの線形距離**（`length(v) / light_far`）を、**ピクセル シェーダーで書く**方式もあります。**比較は単純**ですが**ハードウェアの深度テスト・Early-Z を使えない**（深度を自分で書く）ので**描画が遅く**なります。**射影後の深度**が一般的です。

### 面の境界と PCF

**面の境界をまたぐ PCF**は、**隣の面のテクセル**を参照する必要があります。**キューブ マップのハードウェア サンプラー**は、**面をまたぐ補間**を**正しく**処理します。**自前で面ごとの 2D テクスチャ配列**を使うと、**境界で PCF が途切れる**ので、**注意**が必要です。

## デュアル パラボロイド

**パラボロイド**（放物面）で、**半球ごと**を**1 枚**に**写す**方式です。**2 枚**で**全方向を覆えます**。

| 項目 | キューブ | デュアル パラボロイド |
| --- | --- | --- |
| **枚数** | 6 | **2** |
| **描画回数** | 6 | 2 |
| **歪み** | なし（直線のまま） | <strong>強い（頂点の写像が非線形）</strong> |
| **注意** | 面の境界 | **三角形が大きいと歪みで破綻**（**テッセレーション**が必要）。**境界の継ぎ目** |

**描画回数が少ない**利点がありますが、**歪みが扱いにくい**ため、**現在はキューブが主流**です。

## 多数のライトの影

**ライトが多い**ほど、**影の計算がすぐに破綻**します。

| 問題 | 内容 |
| --- | --- |
| **描画回数** | 点光源 ＝ 6 回 ＋ スポット ＝ 1 回、ライトごと |
| **メモリ** | キューブ 1 つ（1024²×6 面）は、約 24 MB（D32）。**数十個**で**数百 MB** |
| **フィルタのコスト** | 画素ごと**影付きのライト数だけ**、サンプル |

### 管理の方法

| 方法 | 内容 |
| --- | --- |
| **影付きライトの数を制限** | **重要なライトだけ**影付き（例：画面の近く・大きい・明るい） |
| **優先度付け** | **画面上の大きさ・明るさ・距離**で**スコア**を付け、**上位 N 個**だけに影 |
| **アトラス** | **1 枚の大きなテクスチャ**に、**複数のシャドウ マップ**を**敷き詰める**。**ライトごとに解像度を可変**（近いライトは大きく） |
| **解像度の可変** | **画面上で小さいライト**は、**低い解像度** |
| **更新頻度** | **静的なライト・静的な物**は**キャッシュ**し、**動く物が入ったときだけ更新** |
| **遠方・画面外の除外** | **視錐台の外・遠いライト**は**描かない** |

### シャドウ マップのキャッシュ

**静的なシーンのシャドウ マップ**は、**一度描いた結果を再利用**できます。

| 戦略 | 内容 |
| --- | --- |
| **静的物のみをキャッシュ** | 静的なジオメトリの影は、**キャッシュ**。**動的な物の影**だけ、<strong>毎フレーム、上書き（または合成）</strong> |
| **ライトが動いたとき**のみ再生成 | **動かないライト**は、再描画しない |
| **ダーティ領域** | **動く物のいる範囲**だけ、**部分的に更新** |

**2 枚**（静的用・動的用）を**持ち、画素ごとに両方を引いて、小さい方（より暗い方）を取る**方法もあります。

## 影のあるライトの描画での使い方

**ライティング**の段階で**ライトごとの影の係数**を、**そのライトの寄与に掛けます**。

```hlsl
float shadow = SpotShadow(world_pos, light_index);
float3 lit = EvaluateLight(light, surface) * shadow;
```

**クラスター ライティング**・**タイル ベース**と組み合わせると、**影付きライトの情報**を**ライト リストに含めて、引けるようにします**（[ライト カリング](../../rendering/light-culling.md)）。

## バイアスと精度

| 点 | 内容 |
| --- | --- |
| **透視の深度は非線形** | **近くに集中**し、**遠くで精度不足**。**近クリップ面を大きく**・**遠クリップ面を短く**で**精度を保つ** |
| **バイアス** | **距離によって、必要な量が変わる**ので**ワールド単位**（法線オフセット）が扱いやすい（[バイアス](bias.md)） |
| **Reversed-Z** | **シャドウ マップにも有効**（浮動小数点の深度） |

## よくあるミス

??? failure "近クリップ面を極端に小さくして、遠くで深度精度が足りず、アクネ"
    **近クリップ面を大きめ**にし、<strong>Reversed-Z（浮動小数点）</strong>を検討します。

??? failure "キューブの面の選択を誤り、特定の方向で影が欠ける"
    **絶対値最大の成分**で**面**を決め、**ライトのビューの向き**（左手系の面の向き）を**揃え**ます。

??? failure "全ライトに影を付けて、メモリ・描画が破綻"
    **優先度付け**と**アトラス・キャッシュ**で**数を制限**します。

??? failure "静的な影も毎フレーム描き直して、無駄"
    **キャッシュ**します。
