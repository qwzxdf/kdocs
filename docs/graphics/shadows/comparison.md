# Shadow Techniques Compared

ここまで<strong>シャドウ マップの基礎・バイアス・フィルタ（PCF・PCSS・VSM）・カスケード・ローカル ライト・コンタクト・距離場・レイトレース・仮想シャドウ マップ・シャドウ ボリューム</strong>を見てきました。実際のゲームでは、1 つの方式だけでなく、複数を組み合わせて使います。このページでは、方式の比較表・組み合わせ方・プラットフォーム別の標準的な構成・調整の順序をまとめます。

!!! tip "ポイント"
    - <strong>基本の骨格</strong>：<strong>太陽 ＝ カスケード シャドウ マップ</strong>、ローカル ライト ＝ スポット/キューブ。
    - ぼかし：PCF（＋ノイズ＋TAA）が標準。接触硬化が欲しければ PCSS。
    - 補助：コンタクト シャドウで接触部、距離場で遠景・キャラ。
    - ハイエンド：仮想シャドウ マップ・レイトレース影。
    - モバイル：少数のカスケード ＋ 軽い PCF ＋ ブロブ影。
    - バイアス・ちらつき対策（スナップ）は、どの方式でも必須。

## 全方式の比較

| 方式 | 精度 | ソフトさ | コスト | 動的な物 | 実装の難しさ | 主な用途 |
| --- | --- | --- | --- | --- | --- | --- |
| <strong>シャドウ マップ（基本）</strong> | 解像度依存 | なし（ハード） | 小 | ○ | 易 | すべての土台 |
| PCF | 解像度依存 | 一定のぼけ | 小〜中 | ○ | 易 | 標準のフィルタ |
| PCSS | 解像度依存 | 接触硬化あり | 中〜大 | ○ | 中 | ソフト シャドウ |
| VSM / EVSM / MSM | 解像度依存 | 安くソフト | 中 | ○ | 中 | 限定（光漏れに注意） |
| カスケード（CSM） | 近いほど細かい | PCF 次第 | 中 | ○ | 中 | 屋外の太陽 |
| スポット/キューブ | 解像度依存 | PCF 次第 | ライト数に比例 | ○ | 中 | ローカル ライト |
| コンタクト シャドウ | 画面空間（細かい） | ほぼ硬い | 小 | ○ | 中 | 接触部の補助 |
| 距離場の影 | 距離場の解像度 | 自然にソフト | 小〜中 | ✕（静的） | 難 | 遠景・カプセル |
| 仮想シャドウ マップ | 画素に 1 テクセル | PCF/RT 次第 | 中（キャッシュ） | ○ | 難 | ハイエンド・大規模 |
| レイトレース影 | 正確 | 物理的に正確 | 大（デノイズ込み） | ○ | 難（DXR が必要） | ハイエンド |
| シャドウ ボリューム | ピクセル正確 | ハード | 大（フィル レート） | ○ | 中 | 歴史的 |
| ブロブ / 平面投影 | 低 | ブロブ：ぼかし / 投影：ハード | 極小 | ○ | 易 | モバイル・簡易 |

## 現実の構成例

### 標準的な PC / 家庭用機

| 影の種類 | 方式 |
| --- | --- |
| 太陽 | <strong>カスケード シャドウ マップ（3〜4 枚）＋ PCF（ノイズ ＋ TAA）</strong> |
| 接触部 | コンタクト シャドウ |
| ローカル ライト（重要なもの） | スポット / キューブ ＋ PCF（数を制限・アトラス） |
| 遠景 | 距離場・ベイク・フェード |
| キャラクター | （任意）専用シャドウ ＋ カプセル |
| 環境光の遮蔽 | AO（[Ambient Occlusion (AO)](../ao/index.md)） |

### ハイエンド（最新 GPU）

ハイエンド（最新 GPU）の構成です。太陽や主要なライトには、仮想シャドウ マップと半影のレイ マーチ、あるいはレイトレース影とデノイズを使います。多数のローカル ライトには、ライトごとの仮想シャドウ マップを使います。間接光との組み合わせでは、レイトレース GI を併用します。

### モバイル

| 影の種類 | 方式 |
| --- | --- |
| 太陽 | 1〜2 カスケード ＋ 軽い PCF（少ないサンプル） |
| キャラクター | ブロブ シャドウ（またはキャラのみ専用のシャドウ） |
| ローカル ライト | 影なし・ベイク |
| 遠景 | ベイク済み |

## 組み合わせの原則

| 原則 | 内容 |
| --- | --- |
| 遠近で方式を切り替える | <strong>近く：細かい影（高解像度・PCSS・コンタクト）</strong>、遠く：粗い・安い（距離場・ベイク） |
| 動的 / 静的で分ける | 静的な影はキャッシュ・ベイク、動的な物だけ毎フレーム |
| 重要度で予算を配る | 主ライト・画面の中心に多くのコスト |
| 補助で穴を埋める | シャドウ マップの弱点（接触部・細部）をコンタクトや AO で補う |
| ノイズ ＋ 時間蓄積 | サンプルを減らし、TAA で平均して滑らかに |

## 調整の順序

影の調整は<strong>順序</strong>が大切です。上から進めると手戻りが少なくなります。

| 手順 | 内容 |
| --- | --- |
| ① 範囲と解像度 | カスケードの数・最大距離・解像度 |
| ② 投影の安定化 | 球フィット・テクセル スナップ（ちらつきを止める） |
| ③ バイアス | 定数 ＋ 傾き ＋ 法線オフセット（アクネとピーター パンニングを両立）→ [Shadow Bias](bias/index.md) |
| ④ フィルタ | PCF のサンプル数・カーネル。ノイズ ＋ TAA |
| ⑤ 補助 | コンタクト シャドウ・AO |
| ⑥ 例外処理 | アルファ テスト・半透明・キャラクター・遠景 |
| ⑦ 最適化 | カリング・キャッシュ・更新頻度・LOD（[影のコスト](../../rendering/shadows.md)） |

## デバッグのヒント

| 症状 | 確認すること |
| --- | --- |
| <strong>面にしま模様（アクネ）</strong> | バイアス・法線オフセット・受け手平面バイアス（[Shadow Bias](bias/index.md)） |
| 影が物から浮く | バイアスが大きすぎる・コンタクト シャドウで補う |
| 影の縁がギザギザ | PCF・シャドウ マップの解像度 |
| カメラの動きで影がちらつく | テクセル スナップ・球フィット |
| カスケードの境目が見える | ブレンド・テクセルの大きさに合わせた PCF |
| 影が欠ける | 視錐台の外の遮蔽物（深度クランプ）・カリングが強すぎる |
| 遠くの影が突然消える | フェード・遠景の方式 |
| 葉の影が四角 | シャドウ パスのアルファ テスト |

### 可視化

| 方法 | 内容 |
| --- | --- |
| カスケードを色分け | どのカスケードを使っているかを色で表示 |
| シャドウ マップを表示 | 深度テクスチャを画面の隅に表示（範囲・解像度・視錐台との関係を確認） |
| 影のマスクだけ表示 | ライティングを外し、影の係数のみを見る |
| バイアスの量を調整して比べる | パラメータをスライダー化して、リアルタイムに調整 |
