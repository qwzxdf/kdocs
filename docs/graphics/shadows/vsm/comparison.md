# Comparison with PCF

<strong>VSM 系は、方式ごとに、光漏れ・メモリ・計算のバランスが違います</strong>。<strong>PCF と比べても、得意な場面が違う</strong>ので、用途で使い分けます。このページでは、VSM 系の比較表・PCF との使い分けを説明します。

!!! tip "ポイント"
    - VSM：安い・光漏れあり。ESM：簡単・数値に注意。EVSM：光漏れ少・重い。MSM：光漏れほぼなし・複雑。
    - PCF は、深度の比較を正しく行うので、光漏れがないが、大きなぼかしは重い。
    - VSM 系は、大きなぼかしが安いが、光漏れ・メモリ。
    - 柔らかい影が主役なら VSM 系、安定・単純さなら PCF。

## VSM 系の比較
| 項目 | VSM | ESM | EVSM | MSM |
| --- | --- | --- | --- | --- |
| チャンネル数 | 2 | 1 | 4（または 2） | 4 |
| 光漏れ | <strong>あり（大）</strong> | 小（接触部で薄い） | 小 | 最小 |
| 精度の要求 | F32 | F32（オーバーフロー注意） | F32 | F16 でも可（工夫） |
| 計算コスト | 小 | 最小 | 中 | 中〜大 |
| フィルタ可能 | ○ | ○ | ○ | ○ |
| 実装の簡単さ | ○ | ○ | △ | × |

## PCF との使い分け
| 状況 | おすすめ |
| --- | --- |
| 広いソフト シャドウを、安く | VSM・EVSM（シャドウ マップをぼかすだけ） |
| 精度・光漏れを避けたい | PCF（扱いが素直） |
| 接触硬化が欲しい | PCSS・レイトレ |
| メモリ・帯域が厳しい | PCF（深度 1 チャンネル）・ESM |
| 多くのライト | VSM 系（ぼかしが、1 回） |

<strong>現代のゲームでは、PCF（＋ ノイズ ＋ TAA）が、主流</strong>です。VSM 系は<strong>光漏れ・精度・メモリ</strong>の問題から、限定的に使われます（スポットライト・遠景・UI や特殊な効果など）。

## PCF と、VSM 系の、違い

| 観点 | PCF（比較サンプラー + 複数回） | VSM 系（VSM、ESM、EVSM、MSM） |
| --- | --- | --- |
| 保存するもの | 深度（1 チャンネル） | モーメント（2〜4 チャンネル） |
| 縁の、なめらかさ | 複数回、読み込む（3×3 で 9 回、5×5 で 25 回）。サンプルが、増えるほど、重い | シャドウ マップを、ぼかして、1 回読む。ぼかしの、大きさは、自由 |
| 読み込み（画素あたり） | 数回〜数十回 | 1 回 |
| 広い、ぼかし | 重い（サンプルが、半径の 2 乗で、増える） | 安い（ぼかしの、半径を、変えても、シェーダーは、同じ） |
| ミップ・異方性 | 使えない（深度の、ミップは、意味がない） | 使える（遠くの影の、エイリアシングを、減らせる） |
| 光漏れ | ない | ある（VSM、ESM）。EVSM、MSM で、軽減 |
| バイアス | 必要（自己影を、防ぐ） | 小さくて、よい（確率的な、判定） |
| メモリ | 小さい | 2〜4 倍 |
| シャドウ パス | 深度のみ（ピクセル シェーダー不要。速い） | ピクセル シェーダーが、必要（モーメントを、計算） |
| 実装 | 簡単 | やや複雑（ぼかしパス、光漏れ対策） |

## 速さの、違い（目安）

| 手法 | シャドウ パス | ぼかし | メイン パスの、読み込み |
| --- | --- | --- | --- |
| PCF 3×3（ハードウェア 2×2 × 9 = 実質 4 サンプル） | 最速 | 不要 | 4〜9 回 |
| PCF 5×5 | 最速 | 不要 | 25 回 |
| VSM（`R32G32`） | 少し重い | ガウスぼかし（シャドウ マップ全体で、1 回） | 1 回 |
| EVSM（`R32G32B32A32`） | 重い | ガウスぼかし（4 チャンネル） | 1 回 |
| MSM | 重い | ガウスぼかし | 1 回 + 判定の計算 |

PCF は、<strong>画素ごとの、サンプル数</strong>が、コストの、大部分を占めます。VSM 系は、<strong>シャドウ マップの、ぼかし</strong>（解像度ぶん）が、コストの、大部分で、画素ごとのコストは、一定です。

## どちらを、選ぶか

| 状況 | おすすめ |
| --- | --- |
| 標準的な、ゲーム（太陽 + 数個のライト） | PCF（3×3〜5×5）。シンプルで、安定。まず、これ |
| 広い、ぼかしの、影（柔らかい影、PCSS 風） | PCF だと、非常に、重い。VSM 系が、有利（ただし、光漏れの、対策が、必要） |
| 遠景の、カスケード（粗い、シャドウ マップ） | VSM 系 + ミップで、エイリアシングを、減らす |
| 光漏れが、許せない（重なる物が、多い、細かい構造） | PCF |
| メモリが、厳しい | PCF（1 チャンネル） |

## 近年の、傾向

| 傾向 | 内容 |
| --- | --- |
| PCF + ブルー ノイズ + TAA | 少ないサンプル（4〜8）を、画素ごとに、ずらして、時間方向に、平均。光漏れなしで、ぼかしも、柔軟 |
| ハードウェア レイトレーシング | ソフトな影を、正確に（[Ray-Traced Shadows](../ray-traced.md)） |
| VSM 系の、使いどころは、狭まった | 光漏れの、対策が、複雑。PCF + TAA で、品質が、十分に、得られるため |
