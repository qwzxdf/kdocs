# Comparison with PCF

**VSM 系は、方式ごとに、光漏れ・メモリ・計算のバランスが違います**。**PCF と比べても、得意な場面が違う**ので、**用途で使い分けます**。このページでは、**VSM 系の比較表・PCF との使い分け**を説明します。

!!! tip "ポイント"
    - **VSM**：**安い・光漏れあり**。**ESM**：**簡単・数値に注意**。**EVSM**：**光漏れ少・重い**。**MSM**：**光漏れほぼなし・複雑**。
    - **PCF は、深度の比較を正しく行うので、光漏れがない**が、**大きなぼかしは重い**。
    - **VSM 系は、大きなぼかしが安い**が、**光漏れ・メモリ**。
    - **柔らかい影が主役なら VSM 系、安定・単純さなら PCF**。

## VSM 系の比較
VSM 系の 4 方式の違いです。チャンネル数は、VSM が 2、ESM が 1、EVSM が 4（または 2）、MSM が 4 です。光漏れは、VSM が大きく、ESM が小さい（接触部で薄い）、EVSM が小さい、MSM が最小です。精度の要求は、VSM・ESM・EVSM が F32（ESM はオーバーフローに注意）、MSM は工夫すれば F16 でも可能です。計算コストは、VSM が小、ESM が最小、EVSM が中、MSM が中〜大です。フィルタできるのは 4 方式とも可能です。実装の簡単さは、VSM と ESM が簡単、EVSM がやや難しく、MSM が難しいです。

## PCF との使い分け
PCF との使い分けです。広いソフト シャドウを安く出したいなら、VSM・EVSM（シャドウ マップをぼかすだけ）。精度や光漏れを避けたいなら、扱いが素直な PCF。接触硬化が欲しいなら、PCSS やレイトレ。メモリや帯域が厳しいなら、PCF（深度 1 チャンネル）か ESM。多くのライトがあるなら、ぼかしが 1 回で済む VSM 系です。

**現代のゲームでは、PCF（＋ ノイズ ＋ TAA）が、主流**です。VSM 系は**光漏れ・精度・メモリ**の問題から、**限定的**に使われます（**スポットライト・遠景・UI や特殊な効果**など）。
