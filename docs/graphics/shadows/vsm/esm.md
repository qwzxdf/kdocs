# ESM

**ESM（指数シャドウ マップ）**は、**深度を指数関数で変換して保存する**ことで、**フィルタできて、しかも光漏れが出にくい**方式です。**VSM より、実装が簡単で、光漏れが少ない**ですが、**指数のオーバーフロー・精度**に**注意**が**必要**です。このページでは、**ESM の式・実装・パラメータ（c の値）・欠点**を説明します。

!!! tip "ポイント"
    - **ESM ＝ `exp(c · 深度)` を保存し、比較は `exp(−c · 受け手の深度) × 保存値`**。
    - **フィルタ（ぼかし）は、保存値の平均**。**指数だから、乗算で比較できる**。
    - **`c` が大きい**と**影が硬く**、**小さいと柔らか**。
    - **欠点**：**数値の範囲（オーバーフロー）・精度**。**浮動小数 32 ビット**が**無難**。

## ESM（指数シャドウ マップ）
**ESM**（Exponential Shadow Maps）は、**深度の指数 `exp(c · z)`** を保存します。

<div class="formula">日向 = clamp( exp(−c · t) · E[exp(c · z)] , 0, 1 )</div>

| 項目 | 内容 |
| --- | --- |
| **保存するもの** | `exp(c · z)`（**1 チャンネル**） |
| **フィルタ** | **ぼかしても意味が保たれる**（指数は平均できる） |
| **`c`** | **鋭さ**。大きいほど、**影が鋭く**（`z` の差を強く強調）。ただし、<strong>浮動小数点の範囲（オーバーフロー）</strong>に注意 |
| **利点** | **1 チャンネル**で済む。**VSM のような、光漏れは小さい** |
| **欠点** | **受け手が遮蔽物に近い**と**影が薄く**なる（**接触部が明るく漏れる**）。`c` と**精度のトレードオフ** |

## よくあるミス

??? failure "`c` を大きくしすぎて、オーバーフローして真っ白"
    **`c` は 20〜80 程度・32 ビット浮動小数・深度を 0〜1 に正規化**。
