# ESM

<strong>ESM（指数シャドウ マップ）</strong>は、深度を指数関数で変換して保存することで、フィルタできてしかも光漏れが出にくい方式です。VSM より実装が簡単で光漏れが少ないですが、指数のオーバーフロー・精度に注意が必要です。このページでは ESM の式・実装・パラメータ（c の値）・欠点を説明します。

!!! tip "ポイント"
    - ESM ＝ `exp(c · 深度)` を保存し、比較は `exp(−c · 受け手の深度) × 保存値`。
    - フィルタ（ぼかし）は、保存値の平均。指数だから乗算で比較できる。
    - `c` が大きいと影が硬く、小さいと柔らか。
    - 欠点：数値の範囲（オーバーフロー）・精度。浮動小数 32 ビットが無難。

## ESM（指数シャドウ マップ）
<strong>ESM</strong>（Exponential Shadow Maps）は、深度の指数 `exp(c · z)` を保存します。

<div class="formula">日向 = clamp( exp(−c · t) · E[exp(c · z)] , 0, 1 )</div>

| 項目 | 内容 |
| --- | --- |
| 保存するもの | `exp(c · z)`（1 チャンネル） |
| フィルタ | ぼかしても意味が保たれる（指数は平均できる） |
| `c` | 鋭さ。大きいほど影が鋭く（`z` の差を強く強調）。ただし、浮動小数点の範囲（オーバーフロー）に注意 |
| 利点 | 1 チャンネルで済む。VSM のような光漏れは小さい |
| 欠点 | 受け手が遮蔽物に近いと影が薄くなる（接触部が明るく漏れる）。`c` と精度のトレードオフ |

## 考え方：深度を指数に変える

<strong>ESM</strong>（Exponential Shadow Maps、Annen ら 2008）は 深度 `z` の代わりに `exp(c × z)` を、保存します。`c` は大きな正の定数（80 など）です。

通常の、影の判定は `t ≤ z_保存` なら光が当たる（1）、そうでなければ影（0）、という階段関数です。これを指数関数で近似します。

```text
通常:   lit = (t ≤ z) ? 1 : 0
ESM:    lit = saturate( exp(c × z) × exp(−c × t) ) = saturate( exp(c × (z − t)) )
```

| 状況 | `z − t` | `exp(c(z−t))` | 意味 |
| --- | --- | --- | --- |
| 画素が遮蔽物より手前（光が当たる） | `z − t > 0` | 1 以上（saturate で 1） | 光が当たる |
| 画素が遮蔽物と同じ位置 | 0 | 1 | 光が当たる（境界） |
| 画素が遮蔽物の奥（影の中） | `z − t < 0` | 0 に近い（`c` が、大きいほど急に 0） | 影 |

`c` が 大きいと 階段関数に近づき（影の縁が鋭い）、小さいとなめらかですが影が薄れます。

## フィルタのうまみ

<strong>`exp(c × z)`</strong> は ぼかして平均しても、正しい性質を持ちます。平均の `exp` は `exp` の平均ではありませんが `exp(c × z)` を、ぼかしたものは「周りの遮蔽物の深度の、重みつき平均」として意味があります。

```hlsl
// シャドウ パス: exp(c × z) を、書き出す（R32_FLOAT のレンダー ターゲット）。
// c が大きいと、浮動小数点が、あふれる。c × z を、ある範囲に、収める（c = 40〜80、z は、0〜1）。
float main(float4 pos : SV_Position) : SV_Target {
  return exp(kExponent * pos.z);
}
```

```hlsl
// メイン パス: ぼかした exp(c × z) を読み、exp(−c × t) を掛ける。
float stored = g_shadow_esm.SampleLevel(g_linear_clamp, uv, 0);
float lit = saturate(stored * exp(-kExponent * depth));
```

`exp(c × z)` は 非常に大きい値になります（`c = 80`、`z = 1` で `e⁸⁰ ≈ 5×10³⁴`）。32 ビット浮動小数点の上限（約 3.4×10³⁸）に、近いので `c` を大きくしすぎない。logarithmic ブラー（`log(exp(a) + exp(b))` の形で、ぼかす）というあふれないぼかし方も、あります。

## 長所と短所

| | 内容 |
| --- | --- |
| 長所 | 1 チャンネル（メモリが、小さい）。VSM より光漏れが起きにくい（分散を、使わないので） |
| 長所 | 実装が簡単。ぼかしもミップも使える |
| 短所 | 影が薄くなる（遮蔽物から、離れた所で影が薄れる）。`exp(c(z−t))` は差が大きいほど 0 に近づくので、遠くの影は濃いが近くの影は薄い（逆の性質） |
| 短所 | `c` の調整が必要（大きすぎる→あふれる、小さすぎる→影が薄い） |
| 短所 | 深度の範囲に依存する（正規化した深度の範囲が広いと精度が、足りない） |

### 影が薄れる問題

<strong>遮蔽物のすぐ近く</strong>（同じ面の、少し奥）では `z − t` が 小さいので `exp(c(z − t))` は、1 に近く影が薄い（光が当たると、判定）。遮蔽物から十分に離れた所（`z − t` が、大きい負）で初めて濃い影になります。接地部分の影が薄くなるので足元が、浮いて見える（[Peter Panning](../bias/peter-panning.md) に、似た見え方）。

| 対策 | 内容 |
| --- | --- |
| `c` を大きく | 影が濃くなるが、あふれる危険 |
| EVSM にする | 2 つの、指数（正と負）で影を補強（[EVSM](evsm.md)） |
