# MSM

**MSM（モーメント シャドウ マップ）**は、**深度の 1 次・2 次だけでなく、3 次・4 次のモーメントも保存**することで、**VSM の光漏れを、さらに抑える**方式です。**深度の分布を、より正確に表現できる**ので、**光漏れがほぼ見えない影**が**得られます**。**計算が複雑**ですが、**ストレージは 4 チャンネル**で**EVSM と同程度**です。このページでは、**考え方・保存する値・使いどころ**を説明します。

!!! tip "ポイント"
    - **MSM ＝ 深度の 4 つのモーメント（d, d², d³, d⁴）を保存**。
    - **高次のモーメントで、分布を正確に表せ、光漏れが少ない**。
    - **4 チャンネル**。**EVSM と同程度のメモリ**。
    - **比較の計算は、少し複雑**（**方程式を解く**）。

## MSM（モーメント シャドウ マップ）
**MSM**（Moment Shadow Maps、Peters & Klein 2015）は、**4 つのモーメント**（z, z², z³, z⁴）を保存し、**ハンバーガーのモーメント問題**を解いて、**より正確な、可視性の上限**を求めます。

| 項目 | 内容 |
| --- | --- |
| **保存** | 4 つのモーメント（**4 チャンネル**。**16 ビットでも変換すれば足りる**ように工夫） |
| **利点** | **光漏れが非常に小さい**。**VSM・ESM より、安定** |
| **欠点** | **計算が複雑**（4 モーメントから、可視性を求める計算が重い） |

## よくあるミス

??? failure "モーメントを 16 ビットで保存して、精度が足りない"
    **専用の最適化ベクトル変換**を使い、**16 ビット整数で保存**する実装（Peters 方式）を**参照**。
