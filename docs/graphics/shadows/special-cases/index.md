# Special Cases

**シャドウ マップは、不透明な立体には素直に使えますが、アルファ テストの葉・半透明のガラス・キャラクターの顔・遠景の雲など、そのままでは扱いにくい物**が**あります**。このセクションでは、**アルファ テストの影・半透明の影・ブロブ/平面投影の影・遠景の影・キャラクターの影と影の色**を、**1 つずつ別のページ**で説明します。
