# バイアス

シャドウ マップの最大の悩みは、<strong>「自分自身の影が自分に落ちる」（シャドウ アクネ）</strong>と、<strong>「バイアスを大きくすると、影が物体から浮く」（ピーター パンニング）</strong>の、**板挟み**です。このページでは、**なぜアクネが出るのか**を、深度の離散化から**原理的に**説明し、**定数バイアス・スロープ スケール・法線オフセット・受け手平面バイアス・面のカリング**など、**各対策の仕組みと限界**を整理します。

!!! tip "ポイント"
    - アクネの原因は、<strong>シャドウ マップが離散的（テクセルごとに 1 つの深度）</strong>なこと。<strong>テクセルの代表深度と面の本当の深度がずれる</strong>。
    - ずれは<strong>面が光に対して斜めなほど大きい</strong>（<strong>tanθ に比例</strong>）。
    - <strong>定数バイアス</strong>：一定の値を引く。<strong>斜めの面に足りない</strong>。
    - <strong>スロープ スケール</strong>：<strong>面の傾きに比例</strong>して増やす（ハードウェアの機能）。
    - <strong>法線オフセット</strong>：<strong>位置を法線方向にずらして</strong>から比べる（<strong>ピーター パンニングが小さい</strong>）。
    - <strong>受け手平面バイアス</strong>：<strong>サンプルごとに面の傾きに沿って</strong>深度を補正（PCF と相性が良い）。
    - <strong>どの対策も完全ではない</strong>。<strong>組み合わせて、調整</strong>する。

## アクネの原因

シャドウ マップの 1 テクセルは、<strong>光から見たとき、面の上の「ある大きさの領域」</strong>に対応しますが**保存される深度は 1 つ**です。**面が斜め**だと**その領域の中で面の本当の深度は、一定ではなく、傾いて**います。

テクセルの代表深度より、**面の点の方が奥**にある場所（上の図でテクセルの下側）では<strong>「自分より手前に何かある」</strong>と誤判定されて、**影になります**。これが<strong>縞模様（アクネ）</strong>です。

### ずれの大きさ

**1 テクセルのワールドでの大きさ**を `s`、**光の向きと面の法線のなす角**を `θ` とします。**面が傾いている**ほど、テクセルの中での深度のずれが大きくなります。

<div class="formula">深度のずれ ≈ s · tan θ　（θ：法線と光の向きのなす角）</div>

| θ | tan θ | ずれ |
| --- | --- | --- |
| <strong>0°（光が真上から）</strong> | 0 | ほぼ無い |
| **45°** | 1 | s と同じ |
| <strong>80°（ほぼ水平）</strong> | 約 5.7 | **s の 5.7 倍**（アクネが激しい） |

**斜めの面ほど、大きなバイアスが要る**ことが分かります。**一定のバイアス**では、**斜めの面に足りません**。

## 対策 1：定数バイアス

**比較する深度から、一定の値を引きます**。

```hlsl
float depth = ndc.z - 0.001;
```

| 利点 | 欠点 |
| --- | --- |
| **簡単** | **斜めの面には足りない**（アクネが残る） |
| | **大きくすると全体が浮く**（ピーター パンニング） |
| | **値の調整がシーンの大きさ・解像度に依存** |

## 対策 2：スロープ スケール バイアス

**面の傾き（深度の勾配）に比例**して、バイアスを大きくします。**Direct3D のラスタライザ ステート**に、機能があります。

```cpp
D3D11_RASTERIZER_DESC desc = {};
desc.DepthBias = 100;
desc.SlopeScaledDepthBias = 2.0f;
desc.DepthBiasClamp = 0.01f;
```

| 項目 | 内容 |
| --- | --- |
| **`DepthBias`** | **定数**。**深度バッファの最小単位**（精度）の倍数。**D32_FLOAT の場合は、深度値の大きさに応じて変わる** |
| **`SlopeScaledDepthBias`** | **ポリゴンの画面上での深度の勾配**（`max(|dz/dx|, |dz/dy|)`）に、**この値を掛けて加える** |
| **`DepthBiasClamp`** | バイアスの**上限**（極端に傾いた面で暴走しない） |

**この設定はシャドウ マップを描くとき**に使います（**書き込む深度にオフセットを足す**）。

| 利点 | 欠点 |
| --- | --- |
| **斜めの面ほど、自動で大きく**なる | **浮動小数点の深度では、定数バイアスの意味が変わる**（値の大きさで単位が変わる） |
| ハードウェアで**追加のシェーダーコスト無し** | **全ての面に同じ係数**。**極端に斜めな面**では、結局、浮く |

## 対策 3：法線オフセット

**バイアスを深度ではなく、位置**で与えます。**サンプルする点を法線方向に少しずらして**から、光の座標に変換します。

<div class="formula">P′ = P + N · offset · texel_size · (1 − N·L)</div>

| 項 | 意味 |
| --- | --- |
| **N** | 面の法線 |
| **offset** | 調整値（0.5〜2 程度） |
| **texel_size** | シャドウ マップの 1 テクセルの、ワールドでの大きさ |
| <strong>(1 − N·L)</strong> | **斜めの面ほど、大きく**ずらす |

```hlsl
float3 shadow_pos = world_pos + normal * (normal_offset * texel_world_size * (1.0 - saturate(dot(normal, light_dir))));
float4 light_clip = mul(float4(shadow_pos, 1.0), light_view_projection);
```

| 利点 | 欠点 |
| --- | --- |
| **ピーター パンニングが小さい**（面に沿って、法線方向にずらす） | **法線が必要**（丸みのある法線では、角が丸くずれる） |
| **斜めの面で効果が大きい** | **影の位置がわずかにずれる**（薄い物・細い隙間で光漏れ） |
| **テクセルの大きさに比例**するので、解像度の変化にも追従 | **追加の計算**（法線の読み込み・行列の乗算） |

**スロープ スケール＋法線オフセット**を併用するのが、**実用上の定番**です。

## 対策 4：受け手平面バイアス（Receiver Plane Depth Bias）

**PCF**（複数点のサンプル）と組み合わせると**周りのサンプル点**の深度を、**中心の点と同じ面の上にあるもの**として**補正**する必要があります。**面の傾き**から、**サンプルごとに深度を補正**します。

**シャドウ マップの座標 (u, v) が動いたときの面の深度の変化**（`dz/du`、`dz/dv`）を、**画面上の微分**（`ddx`・`ddy`）から求めます。

```hlsl
float2 ReceiverPlaneDepthBias(float3 uvz_ddx, float3 uvz_ddy) {
  float2 bias;
  bias.x = uvz_ddy.y * uvz_ddx.z - uvz_ddx.y * uvz_ddy.z;
  bias.y = uvz_ddx.x * uvz_ddy.z - uvz_ddy.x * uvz_ddx.z;
  float det = uvz_ddx.x * uvz_ddy.y - uvz_ddx.y * uvz_ddy.x;
  return bias / det;
}
```

| 引数 | 意味 |
| --- | --- |
| **`uvz_ddx`・`uvz_ddy`** | 光の座標 (u, v, z) の、**画面上の x・y 方向の微分** |
| **戻り値** | <strong>(dz/du, dz/dv)</strong>。**uv が 1 だけ動いたときの、面の深度の変化** |

**サンプル点が中心から (du, dv) ずれているとき**の**補正した深度**は、次のとおりです。

<div class="formula">z′ = z + dot( (dz/du, dz/dv), (du, dv) )</div>

```hlsl
float depth = center_depth;
float2 receiver_bias = ReceiverPlaneDepthBias(ddx(uvz), ddy(uvz));
for (each sample offset) {
  float sample_depth = depth + dot(receiver_bias, offset_uv);
  shadow += shadow_tex.SampleCmpLevelZero(shadow_sampler, uv + offset_uv, sample_depth - bias);
}
```

| 利点 | 欠点 |
| --- | --- |
| **PCF の広いカーネルでも、アクネが出にくい** | **微分の精度**が悪い所（深度の不連続）で、**バイアスが暴れる** |
| **サンプルごとに面に沿った補正** | **計算が増える** |
| 傾いた面でも**浮かせずに**済む | **微分を使う**ので**ブランチ内で使えない**など、シェーダーの制約 |

## 対策 5：前面カリングで描く（裏面レンダリング）

**シャドウ マップを描くとき**、<strong>表面（光に向いた面）ではなく、裏面（光に背を向けた面）</strong>を描く方法です。

| 描く面 | 保存される深度 | アクネ | ピーター パンニング |
| --- | --- | --- | --- |
| **表面** | 光に向いた面の深度 | **出やすい**（受け手の面と深度がほぼ同じ） | 小さい |
| **裏面** | **物体の裏側の深度**（表面より、奥） | **出にくい**（表面は裏面より手前にあるので、自己遮蔽にならない） | **薄い物体で出る**（裏面と表面の間隔が狭いと、影が離れる／漏れる） |

**閉じた、厚みのあるメッシュ**では、**裏面レンダリング**が**アクネを減らす**のに効きます。**薄い板・葉・布**には使えません（影が浮いたり、漏れたりする）。

```cpp
D3D11_RASTERIZER_DESC desc = {};
desc.CullMode = D3D11_CULL_FRONT;
```

**表裏の定義**は**時計回りが表**（[座標系](../../gamemath/coordinate-systems.md)）に従います。**光から見て**、表を向いた面（光に面した面）が**カリングされ**、裏が描かれます。

## ピーター パンニング

**バイアスが大きすぎる**と、**影が物体の接地部から離れて**見えます（物体が地面から浮いたように見える）。これが**ピーター パンニング**（影が体から離れる、ピーター パンの影の話から）です。

| 症状 | 原因 |
| --- | --- |
| **影が足元から離れる** | 定数バイアスが大きすぎる |
| **薄い壁の向こうに光が漏れる** | 法線オフセットが大きすぎる・裏面レンダリングで薄い物 |
| **細い物体の影が消える** | バイアスで遮蔽物自体が無視される |

**対策**は**バイアスを必要最小限**にして、**スロープ スケール・法線オフセット・受け手平面バイアス**を**組み合わせる**ことです。**どれか 1 つを大きくするより、分担**させます。

## 組み合わせの設計

| 目的 | 推奨の組み合わせ |
| --- | --- |
| **平らな面のアクネを防ぐ** | **スロープ スケール** ＋ 小さな定数 |
| **斜めの面・曲面のアクネを防ぐ** | **法線オフセット** |
| **PCF で広くぼかす** | **受け手平面バイアス**（サンプルごとの補正） |
| **閉じた厚い物体** | **裏面レンダリング**（併用） |
| **ピーター パンニングを抑える** | **各バイアスを最小限に**。調整は**明るい光・斜めの光**で確認 |

## 調整の手順

| 手順 | 内容 |
| --- | --- |
| **① アクネが出る状態を作る** | 光を**低い角度**（斜め）にして、平らな面・曲面を見る |
| **② スロープ スケールから足す** | アクネが消える**最小の値** |
| **③ 法線オフセットを足す** | 曲面・角で残ったアクネを消す |
| **④ ピーター パンニングを確認** | 物体の接地部で影が離れていないか |
| **⑤ 光の角度を変えて再確認** | **全ての角度**で破綻しないか |
| **⑥ カスケードごとに調整** | **解像度（テクセルの大きさ）が違う**ので**カスケードごとにバイアスを変える** |

**テクセルの大きさに比例**するように、**ワールド単位で**バイアスを決めると、**解像度・カスケードを変えても安定**します。

## よくあるミス

??? failure "定数バイアスだけで、斜めの面にアクネが残り、バイアスを増やして、全体が浮く"
    **スロープ スケール・法線オフセット**を併用します。

??? failure "法線オフセットを、テクセルの大きさに依存させず、カスケードごとに効きが変わる"
    **ワールドでのテクセルの大きさ**に比例させます。

??? failure "薄い板に、裏面レンダリングをして、影が浮く・漏れる"
    薄い物は**表面レンダリング**にします（または別の設定）。

??? failure "バイアスを、平らな床だけで調整して、曲面・斜めの光で破綻する"
    **斜めの光・曲面**でも確認します。

??? failure "受け手平面バイアスで、深度の不連続でバイアスが暴れる"
    <strong>上限（クランプ）</strong>を設けます。
