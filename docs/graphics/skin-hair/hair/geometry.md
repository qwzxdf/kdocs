# Hair Geometry

髪の形をどう作るか。これが髪の描画の設計の出発点で、後の透明・影・シェーディングのすべてに影響します。大きく 2 つの方法があります。髪の束を<strong>板（カード）</strong>で近似する方法と 1 本ずつ（ストランド）描く方法です。このページではそれぞれの作り方、長所と短所、使い分けを説明します。

!!! tip "ポイント"
    - カード ＝ 髪の束の絵を貼った板ポリ。軽くアーティストが形を制御しやすい。ゲームの大半。
    - ストランド ＝ 髪を1 本ずつ線で描く。10 万本規模で最高品質だが重い。
    - カードは<strong>層状に重ねて</strong>、厚みと奥行きを出す。テクスチャのアルファで切り抜く。
    - ストランドは<strong>線分の列</strong>。GPU でカメラに向いた細い帯に展開して描く。
    - 髪の動きはボーン（カード）か物理シミュレーション（ストランド）で与える。

## カード（ヘア カード）

カード方式は髪の束を<strong>細長い板ポリゴン</strong>で表し、そこに髪の絵（アルベド・アルファ・法線など）を貼ります。1 枚の板が数十本から数百本の髪の毛の束を表します。

### 作り方

1. 髪の束の絵を用意する。髪の毛が束になって流れる様子を描いたテクスチャで、背景は透明（アルファ）です。1 枚のテクスチャ アトラスにいろいろな形・太さの束を並べておきます。
2. 板を髪の流れに沿って配置する。頭に沿ってカードを重ね前髪、側面、後ろ髪を作ります。各カードの向きは髪が流れる向きに揃えます。
3. 層状に重ねる。1 層だけだと平坦なので内側から外側へ何層にも重ねます。内側のカードは暗く外側は明るくして、奥行きを出します。
4. 毛先を細くする。カードの端は細く尖らせ毛先がバラける様子をアルファで表現します。

### 長所と短所

長所は軽いことです。1 キャラクターで数千ポリゴンに収まります。アーティストが形を直接コントロールできるので、髪型の作り込みが容易です。アルファ テストで描けるので、Z バッファをそのまま使えます。

短所は 近づくと板だと分かることです。カードの輪郭が硬く髪が「紙のように」見えます。髪の動きもカード全体が硬く動くため、細かな毛先の動きは表せません。髪型の細かさ（束の細かさ）がテクスチャの解像度で決まります。

### カードのシェーディングで気をつけること

カードを使うときは 法線の向きが重要です。カードの法線は板の面の法線です。髪のシェーディングは法線でなく髪の流れの方向（接線）を基準にします（[Kajiya-Kay](kajiya-kay.md)）。そこで、カードの UV の V 方向（またはU方向）を髪の流れの方向に揃えて作り、接線として使います。

もう 1 つ 法線を頭の中心から外へ向けて調整する方法がよく使われます。カードの法線を頭の中心から外向きに（球面に近く）設定すると、髪全体が 1 つの球のように滑らかに照らされのっぺりしたカードの境目が目立たなくなります。さらに、髪の毛先に向かうほど暗くなる AO を頂点カラーに焼いておくと立体感が増します。

## ストランド

ストランド方式は髪の毛を<strong>1 本ずつ線分の列</strong>として表します。1 本のストランドは根元から毛先まで、数個から十数個の制御点（頂点）で表されます。ストランドの本数は見た目の品質に直結します。

### データの持ち方

髪の本数は 1 キャラクターで、数万〜十万本を扱います。全部を描画するのは重いので ガイド ヘアと呼ばれる少数の代表的なストランドだけを物理シミュレーションします。残りのストランドはガイド ヘアの周りに補間して生成します。たとえば、1 本のガイドにつき 10 本の追従するストランドを生成します。

頂点の情報は各制御点の位置、太さ接線方向などです。10 万本のストランドで 1 本あたり 16 点なら 160 万点で、メモリは数十 MB 程度です。

### 描画の流れ

ストランドは線として描かれますが、GPU は線を細い（1 画素）幅でしか描けません。そこで、ストランドの各線分を カメラに向いた細い帯（ビルボード）に展開して描きます。ジオメトリ シェーダーやメッシュ シェーダー、または頂点シェーダーで線分を 2 つの三角形に展開します。

```hlsl
float3 tangent = normalize(p1 - p0);
float3 to_camera = normalize(camera_pos - p0);
float3 side = normalize(cross(tangent, to_camera));
float3 left = p0 - side * (width * 0.5);
float3 right = p0 + side * (width * 0.5);
```

帯の幅はストランドの実際の太さ（0.05〜0.1 mm）を使うと画面上で 1 画素に満たないことが多く、ちらつきが出ます。そのため、画面上で 1 画素以上になるように幅を補正し、足りない分をアルファで薄めます（[Hair Anti-Aliasing](anti-aliasing.md)）。

### 長所と短所

長所は品質です。1 本 1 本の髪が見えるので、近づいたときのリアルさが圧倒的です。物理シミュレーションで動かせば、風になびく様子、毛先の動き髪どうしの絡みが自然に表せます。

短所は重さです。描画するプリミティブが多くほとんどが画素より細いため、ラスタライザの効率が悪くなります。半透明の扱い（透明、影、自己影）もカードより難しく専用の処理が必要です。メモリと GPU 時間のコストが大きく、描画できるキャラクター数が限られます。

## LOD：カードとストランドの併用

実際のゲームではカードとストランドを<strong>距離で切り替える</strong>設計が現実的です。近距離ではストランドで高品質に描き中距離では、本数を減らしたストランドやカードに切り替え遠距離では、簡易なカードやメッシュにします。切り替えの境で見た目が急に変わらないようシェーディングを共通にし、カードのテクスチャをストランドの見た目からベイクして作るのが一般的です。

Unreal Engine の Groom は、同じヘア アセットからストランド、カード、メッシュを自動生成する LOD の仕組みを持ちます。

## 髪の動き

髪が動かない（頭に固定された）ゲームでは、髪の形は静的です。髪を動かす場合、方法はデータの持ち方によって違います。

カード方式ではカードに<strong>ボーン</strong>を付けて、物理シミュレーション（バネ・ダンパーや位置ベース動力学）で動かします。ボーンの数は少ない（髪の束ごとに数本）ので、軽く済みます。ただし、硬い板が動くので柔らかい髪の動きにはなりません。

ストランド方式ではガイド ヘアを物理シミュレーションします。各ストランドを質点とバネ（または位置ベース動力学の拘束）の列としてモデル化し、重力・風・頭の動き・衝突（頭や肩との接触）を解きます。シミュレーションは GPU のコンピュート シェーダーで並列に実行されます（AMD の TressFX、NVIDIA の HairWorks）。計算は重いためシミュレーションを行うのは、ガイド ヘアの数千本程度に絞ります。

## 実装：ストランドをカメラに向けて、帯にする

ストランドは 1 本の線（頂点の列）ですが、線のままでは細すぎて描けません。頂点シェーダーでカメラを向く、細い帯（ビルボード）に広げます。

### 頂点バッファ

```cpp
// 各ストランドの、頂点（位置と太さ）を StructuredBuffer に入れる。
struct StrandVertex { DirectX::XMFLOAT3 position; float thickness; };
D3D11_BUFFER_DESC desc = {};
desc.ByteWidth = sizeof(StrandVertex) * vertex_count;
desc.StructureByteStride = sizeof(StrandVertex);
desc.BindFlags = D3D11_BIND_SHADER_RESOURCE | D3D11_BIND_UNORDERED_ACCESS;   // 物理シミュレーションが書き込む
desc.MiscFlags = D3D11_RESOURCE_MISC_BUFFER_STRUCTURED;
device->CreateBuffer(&desc, nullptr, &strand_vertices);
```

シミュレーション（髪の動き）を計算シェーダーで行うなら UAV で書き込み、描画では SRV で読みます。

### 帯に広げる

```hlsl
// 頂点 ID から、どのセグメントの、どちら側の頂点かを決め、線の接線に直交する向きに、幅だけ広げる。
VSOut StrandVS(uint vertex_id : SV_VertexID) {
  uint segment = vertex_id / 2;
  float side = (vertex_id & 1) ? 1.0 : -1.0;
  StrandVertex v = g_strand[segment];
  StrandVertex next = g_strand[min(segment + 1, g_strand_vertex_count - 1)];
  float3 tangent = normalize(next.position - v.position);                  // 毛の向き
  float3 to_camera = normalize(g_camera_position - v.position);
  float3 side_dir = normalize(cross(tangent, to_camera));                  // カメラに向いた帯の、幅の向き
  float3 world = v.position + side_dir * side * v.thickness * 0.5;
  VSOut o;
  o.position = mul(float4(world, 1.0), g_view_proj);
  o.tangent = tangent;                                                       // シェーディング（Kajiya-Kay、Marschner）で使う
  return o;
}
```

`cross(接線, 視線)` で帯の幅の向きが決まります。接線はシェーディングで必要なので、ピクセル シェーダーへ渡します（[Kajiya-Kay](kajiya-kay.md)、[Marschner](marschner.md)）。

### 太さの下限：細すぎる毛はサブピクセルに消える

```hlsl
// 画面上で 1 画素より細くなる毛は、幅を 1 画素に保ち、かわりにアルファを下げて、ちらつきを防ぐ。
float pixel_world = length(clip_w) * g_pixel_size;                          // 1 画素がその距離で覆う、ワールドの幅
float width = max(thickness, pixel_world);
float coverage = thickness / width;                                          // 太さが足りない分は、アルファで補う
```

幅を画素より細くするとストランドがラスタライザーに拾われずちらちら消えます。幅を保ちアルファで実際の太さを表す方法が定番です（TressFX など）。

## よくあるミス

??? failure "カードが 1 層で、髪が薄っぺらい"
    <strong>内側から外側へ何層も重ねる</strong>。内側を暗く外側を明るくして奥行きを出す。

??? failure "カードの境目がはっきり見える"
    カードの法線を頭の中心から外向きに調整する。毛先を細くアルファで消す。

??? failure "ストランドが細すぎてちらつく"
    画面上で 1 画素以上になるよう幅を補正し、足りない分をアルファで薄める。

??? failure "ストランドの本数が多すぎて、フレーム時間が足りない"
    ガイド ヘアだけをシミュレーションし、残りは補間。距離で本数を減らす（LOD）。
