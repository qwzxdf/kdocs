# Kajiya-Kay

髪の光り方を計算する、最も古く、最も軽い式が **Kajiya-Kay モデル**です。1989 年に Kajiya と Kay が、毛皮のレンダリングのために考案しました。「髪は細い円柱であり、その**接線方向（髪の流れ）**が、光の反射を決める」という考え方で、法線を使わず、接線だけでハイライトを計算します。このページでは、通常の面の反射と何が違うのか、式の導出、2 本のハイライトを作る**ずらし**の工夫（Scheuermann の方法）を説明します。

!!! tip "ポイント"
    - 髪は<strong>細い円柱</strong>。**1 点に法線が無数にある**（円柱の周り全方向）。**接線 T** で考える。
    - 拡散 ＝ <strong>sin(T, L)</strong>、鏡面 ＝ <strong>(sin(T, L)·sin(T, V) − cos(T, L)·cos(T, V))^p</strong>。
    - ハイライトは、<strong>髪の軸に垂直な方向に</strong>光が反射された**円錐**の上にある。
    - **接線を法線方向にずらす**ことで、**ハイライトの位置を動かす**（**2 本のハイライト**）。
    - **ノイズでずらし量を変える**と、**髪の束の質感**が出る。

## 円柱への反射

ふつうの面の反射（ランバートやフォンなど）は、**面の法線**を基準にします。面の 1 点に、法線が 1 本あります。ところが、髪は細い円柱で、1 点の周りに**法線が無数に**あります（円柱の周り 360 度のすべての向き）。「この点の法線」を 1 つに決められません。

髪の向きを表す、確かな量は、髪の軸に沿った**接線ベクトル T**（単位ベクトル）です。そこで、Kajiya と Kay は、接線 T と、光の向き L・視線の向き V の関係だけで、反射を表しました。

## 拡散反射

まず拡散反射です。円柱に光が当たるとき、円柱の軸に**垂直に**光が当たるほど、よく照らされます。軸に**平行**に光が当たると、円柱の表面をかすめるだけで、ほとんど照らされません。この関係は、T と L のなす角 θ の sin で表されます。

<div class="formula">diffuse = sin(T, L) = √(1 − (T·L)²)</div>

T·L が 0（T と L が垂直）のとき、sin = 1 で最大。T·L が ±1（平行）のとき、sin = 0 で最小です。通常のランバートが `N·L` を使うのに対し、髪では `√(1 − (T·L)²)` を使うことが、最大の違いです。この式は、円柱の周りの、すべての法線方向で平均した結果に対応しています。

## 鏡面反射

鏡面反射は、もう少し複雑ですが、考え方は単純です。円柱に光が当たって反射するとき、反射光は、円柱の軸に対して、入射光と**同じ角度**で、反対側へ出ます。この反射光は、軸の周りに**円錐**を描いて、あらゆる方向に出ます（円柱の周りのどの法線で反射するかで、円錐の上のどこへ出るかが決まる）。

この円錐の上に視線 V があるとき、ハイライトが見えます。視線が円錐から離れるほど、ハイライトは弱まります。この様子は、次の式になります。

<div class="formula">specular = ( √(1−(T·L)²) · √(1−(T·V)²) − (T·L)(T·V) )^p</div>

括弧の中は、**T·L の角度と T·V の角度の差**に関する式です。T·L = cos α、T·V = cos β とすると、`sin α sin β − cos α cos β = −cos(α + β)` となります。α と β の和が 180°に近い、つまり、**入射角と反射角が軸に対して対称**のとき、括弧の中が 1 に近づいて、ハイライトが最大になります。べき指数 p は、ハイライトの鋭さで、大きいほど細くなります。

```hlsl
float KajiyaKaySpecular(float3 t, float3 l, float3 v, float exponent) {
  float t_dot_l = dot(t, l);
  float t_dot_v = dot(t, v);
  float sin_tl = sqrt(1.0 - t_dot_l * t_dot_l);
  float sin_tv = sqrt(1.0 - t_dot_v * t_dot_v);
  float dir_atten = smoothstep(-1.0, 0.0, t_dot_l);
  return dir_atten * pow(max(sin_tl * sin_tv - t_dot_l * t_dot_v, 0.0), exponent);
}
```

`dir_atten` は、光が髪の「裏」から当たるときの減衰を調整する項で、必要に応じて足します。

## ハイライトの形

この式で出るハイライトは、髪の**軸に沿って**流れる帯です。髪が頭に沿って弧を描いているとき、ハイライトは、頭を一周する**光の輪（天使の輪）**になります。髪の流れに沿ってハイライトが伸びるのは、現実の髪の特徴で、ふつうの法線ベースの反射では出せません。

## 2 本のハイライト：接線のずらし

現実の髪には、**2 本のハイライト**があります（[Hair Overview](index.md) の R と TRT）。白い（光源の色の）ハイライトと、髪の色がついた、少しずれたハイライトです。Kajiya-Kay は 1 本しか出せません。そこで、Scheuermann（2004）は、**接線を法線方向にずらして**、ハイライトを 2 回計算する方法を提案しました。

髪のキューティクルが傾いているため、ハイライトは、髪の軸の方向から少しずれます。これを、接線 T を、法線 N の方向にずらすことで表します。

```hlsl
float3 ShiftTangent(float3 t, float3 n, float shift) {
  return normalize(t + n * shift);
}
```

ずらし量 `shift` を変えて、2 回計算します。1 回目は、小さなずれ（例：−0.1）と大きなべき指数（例：80）で、**鋭く白い**ハイライト（R の成分）にします。2 回目は、大きなずれ（例：0.2）と小さなべき指数（例：20）で、**広く、色のついた**ハイライト（TRT の成分）にします。

```hlsl
float shift_value = shift_tex.Sample(linear_wrap, input.uv).r - 0.5;
float3 t1 = ShiftTangent(tangent, normal, kShift1 + shift_value);
float3 t2 = ShiftTangent(tangent, normal, kShift2 + shift_value);

float3 spec1 = light_color * KajiyaKaySpecular(t1, l, v, kExponent1);
float3 spec2 = hair_color * light_color * KajiyaKaySpecular(t2, l, v, kExponent2);
float3 specular = spec1 + spec2 * noise_value;
```

1 本目は光源の色（白）、2 本目は髪の色を掛けます。この 2 本が重なると、白い芯の周りに色のついたハイライトが出て、髪の艶がリアルに見えます。

## ノイズで質感を出す

`shift_tex` は、**ずらし量のノイズ テクスチャ**です。髪の毛 1 本 1 本で、キューティクルの傾きやハイライトの位置が微妙に違うため、ハイライトは、一様な帯でなく、細かい筋に分かれて見えます。このノイズ テクスチャを、髪の流れに沿った方向に引き伸ばしておき、ずらし量に加えると、ハイライトが細かい筋になり、髪の束らしい質感が出ます。2 本目のハイライトには、別のノイズ（`noise_value`）を掛けて、きらめきを足すこともあります。

## 長所と短所

長所は、軽いことです。式は、内積が 2 つとべき乗だけで、ピクセル シェーダーでの計算が少なく、カードに十分適します。接線とずらし量のテクスチャだけで、髪の質感を、アーティストが調整できます。

短所は、物理的な正確さがないことです。**エネルギー保存**を満たさず、強い光で非現実的に光ることがあります。髪の**透け**（TT 成分）を表せません。逆光で髪が透けて、縁が明るく光る様子は、別の処理（透過項）で足す必要があります。ハイライトの色の変化（TRT の色づき）も、2 回目のハイライトに髪の色を掛けるだけの、大雑把な近似です。

これらの限界を超えるには、髪の光の散乱を物理に沿ってモデル化した、Marschner のモデルを使います（[Marschner Model](marschner.md)）。

## よくあるミス

??? failure "接線の向きが、髪の流れと逆または垂直になっている"
    ハイライトが**流れに垂直**に出る。UV の向きと**接線の定義**を確認する。

??? failure "ハイライトが 1 本のベタッとした塊になる"
    **接線を 2 回ずらして、2 本**を作る。**ノイズでずらし量を変える**。

??? failure "接線を補間後に正規化していない"
    頂点の接線を補間すると**長さが変わる**。ピクセル シェーダーで**正規化**する。

??? failure "光が裏から当たっても、ハイライトが出る"
    **`dir_atten`** で、光が髪の裏にあるときのハイライトを弱める（または、透過項を別に足す）。
