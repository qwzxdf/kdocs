# Skin Overview

<strong>肌をきれいに描く</strong>ことはゲーム描画の最も難しい課題の 1 つです。難しい理由は肌が半透明の物体だからです。ふつうの描画では物体の表面に当たった光をそこで反射して終わりと考えます。ところが肌では 光の多くが皮膚の中へ入り込み内部で散らばり少し離れた場所から出てきます。この出てくる光が肌の「柔らかさ」と「血色」を作ります。このページでは肌の構造と光がどう振る舞うかを整理し、後のページで扱う技術の全体像を示します。

## 肌の構造

人間の皮膚を光の振る舞いの観点で、3 つの層に分けて考えます。

一番外側は<strong>脂質の層</strong>（皮脂の膜と角質層）です。数十マイクロメートルの薄い層で、表面を覆う油の膜が光を鏡のように反射します。これが肌のつや（ハイライト）です。この層での反射は色がほぼ付かず白っぽい光です。屈折率が約 1.4 なので真正面から見たときの反射率は約 2.8 % と低く、斜めから見ると強くなります（[Skin Specular](specular.md)）。

その下が表皮（約 0.1 mm）です。ここには メラニンという色素が含まれています。メラニンは主に青い光を吸収し、肌の「地の色」（色の濃さ）を決めます。肌の色の違いはおもにメラニンの量の違いです。

最も深い真皮（数 mm）には 血管があり ヘモグロビンを含む血液が流れています。ヘモグロビンは緑の光を吸収して、赤い光を残します。真皮の中で光は強く散乱され広がり赤い光ほど遠くまで広がります。この散らばって出てくる光が肌の柔らかい赤みを作ります。

## 光の振る舞い

肌に光が当たると次の 2 つの経路に分かれます。

1. <strong>表面で反射する光</strong>。脂質の層で跳ね返る色のない鏡面反射です。入射光のうち数 % です。
2. 内部に入る光。残りの 90 % 以上は肌の中に入ります。真皮の中で何度も散乱され広がりながら、一部は吸収されます。そして、入った点から離れた別の点で肌の表面から外へ出てきます。

2 番目の経路が肌の描画を難しくします。普通のレンダリングでは「表面の点 P に入った光は、点 P から出る」と仮定します（拡散反射）。肌では点 P に入った光が 半径数 mm の範囲に広がって出てきます。この広がりを無視すると光が当たった点と当たっていない点の境が、くっきりしすぎます。実際の肌では、影と日向の境が柔らかくにじみその境が赤く染まります。

!!! note "なぜ赤く染まるのか"
    赤い光は肌の中で吸収されにくく、遠くまで広がります。緑や青の光は吸収されやすくあまり広がりません。そのため、光が当たった点の周りには赤い光だけが遠くまで漏れ出し、明暗の境が赤みを帯びます。これが耳に強い光を当てたときに耳が赤く透けて見える理由でもあります。

## 全体の組み立て

実際のゲームでは肌の見た目を次の部品に分けて作ります。

<strong>拡散反射（SSS）</strong>は内部で散らばった光です。ライティングの拡散項に散乱の広がりを反映します。実装は事前積分の LUT、画面空間の分離ぼかしガウス和のうちから、予算で選びます。鏡面反射は皮脂の膜によるハイライトです。二重のローブで油の膜と肌の粗い面の両方を表します。透過は耳や指のように薄い部分を光が突き抜けてくる効果です。微細なディテールは毛穴・しわ・血流による色の変化で、テクスチャと法線マップで表します。最後に、目は肌とは別の素材として、角膜の屈折と湿った反射を処理します。

```hlsl
float3 shaded = 0;
shaded += EvaluateDiffuseSSS(...);
shaded += EvaluateSkinSpecular(...);
shaded += EvaluateTransmittance(...);
shaded *= ao;
```

## 技術の選び方

肌の SSS を実装する技術は品質とコストで並べると、次のようになります。

最も軽いのが[事前積分](pre-integrated.md)です。法線の向きと表面の曲率からあらかじめ計算した LUT を引くだけで、ライティングの段階で SSS の柔らかさが出ます。画面空間のぼかしが不要でモバイルでも使えます。ただし、影の縁の赤みは出にくく薄い所の透けも別に処理が必要です。

標準的なのが[画面空間の分離ぼかし](screen-space-sss.md)です。ライティングが終わった画像を肌の画素だけ深度を考慮しながら、横と縦の 2 方向にぼかします。コストは 1080p で 0.5〜1 ms 程度です。影の縁の赤みも自然に出て現代のゲームのほぼ標準です。

最も高品質で重いのが[ガウス和によるテクスチャ空間のぼかし](diffusion-profile.md)です。顔の UV 空間にライティングの結果を一度書き出し、6 枚のガウスで何段もぼかして足し合わせます。映画に近い品質ですが UV 空間を使うため、キャラクターごとに専用のパスが要り重いです。

## よくあるミス

??? failure "肌が、のっぺりしたプラスチックに見える"
    SSS を入れていない、または<strong>影の縁の広がりが足りない</strong>。散乱の幅（`sss_width`）を顔の大きさに合わせる。

??? failure "SSS が強すぎて、顔がぼやけてろうそくのように見える"
    ぼかしの幅を狭くし、毛穴などの高周波はぼかしの対象から外す（ぼかすのは拡散反射の低周波だけ）。

??? failure "鏡面反射まで、一緒にぼかしてしまう"
    SSS でぼかすのは、拡散反射だけ。鏡面反射は表面で起きる現象なので、ぼかさずに別に足す。

??? failure "テクスチャの色をぼかしの前後で二重に掛ける"
    アルベドは ぼかしの前後に半分ずつ（√アルベド）掛けるかぼかしの前にまとめて外す（[Separable SSS](screen-space-sss.md)）。
