# Skin Overview

**肌をきれいに描く**ことは、ゲーム描画の最も難しい課題の 1 つです。難しい理由は、肌が<strong>半透明の物体</strong>だからです。ふつうの描画では、物体の表面に当たった光を、そこで反射して終わり、と考えます。ところが肌では、**光の多くが皮膚の中へ入り込み、内部で散らばり、少し離れた場所から出てきます**。この出てくる光が肌の「柔らかさ」と「血色」を作ります。このページでは、肌の構造と、光がどう振る舞うかを整理し、後のページで扱う技術の全体像を示します。

!!! tip "ポイント"
    - 肌の見た目 ＝ <strong>表面の反射（鏡面）</strong> ＋ <strong>内部で散らばって出てくる光（SSS）</strong>。
    - 皮膚は<strong>3 層</strong>（脂質の層・表皮・真皮）。**赤い光ほど遠くまで広がる**ので、影の縁が赤く染まる。
    - SSS を省くと、**肌がプラスチック**に見える。**入れすぎると、ろうそく**になる。
    - 実装は、**事前積分（軽い）→ 分離ぼかし（標準）→ ガウス和（重い）**の階段。
    - 薄い部分（耳・鼻）の**透け**と、**目**は別に処理する。

## 肌の構造

人間の皮膚を、光の振る舞いの観点で、3 つの層に分けて考えます。

一番外側は<strong>脂質の層</strong>（皮脂の膜と、角質層）です。数十マイクロメートルの薄い層で、表面を覆う油の膜が、光を鏡のように反射します。これが肌の<strong>つや（ハイライト）</strong>です。この層での反射は、色がほぼ付かず、白っぽい光です。屈折率が約 1.4 なので、真正面から見たときの反射率は約 2.8 % と低く、斜めから見ると強くなります（[Skin Specular](specular.md)）。

その下が<strong>表皮</strong>（約 0.1 mm）です。ここには、**メラニン**という色素が含まれています。メラニンは主に青い光を吸収し、肌の「地の色」（色の濃さ）を決めます。肌の色の違いは、おもにメラニンの量の違いです。

最も深い<strong>真皮</strong>（数 mm）には、**血管**があり、**ヘモグロビン**を含む血液が流れています。ヘモグロビンは緑の光を吸収して、赤い光を残します。真皮の中で光は強く散乱され、広がり、**赤い光ほど遠くまで広がります**。この散らばって出てくる光が、肌の柔らかい赤みを作ります。

## 光の振る舞い

肌に光が当たると、次の 2 つの経路に分かれます。

1. <strong>表面で反射する光</strong>。脂質の層で跳ね返る、色のない鏡面反射です。入射光のうち数 % です。
2. <strong>内部に入る光</strong>。残りの 90 % 以上は肌の中に入ります。真皮の中で何度も散乱され、広がりながら、一部は吸収されます。そして、**入った点から離れた別の点**で、肌の表面から外へ出てきます。

2 番目の経路が、肌の描画を難しくします。普通のレンダリングでは、「表面の点 P に入った光は、点 P から出る」と仮定します（拡散反射）。肌では、点 P に入った光が、**半径数 mm の範囲に広がって**出てきます。この広がりを無視すると、光が当たった点と、当たっていない点の境が、くっきりしすぎます。実際の肌では、影と日向の境が柔らかくにじみ、その境が**赤く染まります**。

!!! note "なぜ赤く染まるのか"
    赤い光は、肌の中で吸収されにくく、遠くまで広がります。緑や青の光は、吸収されやすく、あまり広がりません。そのため、光が当たった点の周りには、赤い光だけが遠くまで漏れ出し、**明暗の境が赤みを帯びます**。これが、耳に強い光を当てたときに、耳が赤く透けて見える理由でもあります。

## 全体の組み立て

実際のゲームでは、肌の見た目を次の部品に分けて作ります。

<strong>拡散反射（SSS）</strong>は、内部で散らばった光です。ライティングの拡散項に、散乱の広がりを反映します。実装は、事前積分の LUT、画面空間の分離ぼかし、ガウス和のうちから、予算で選びます。<strong>鏡面反射</strong>は、皮脂の膜によるハイライトです。二重のローブで、油の膜と、肌の粗い面の両方を表します。<strong>透過</strong>は、耳や指のように薄い部分を、光が突き抜けてくる効果です。**微細なディテール**は、毛穴・しわ・血流による色の変化で、テクスチャと法線マップで表します。最後に、**目**は、肌とは別の素材として、角膜の屈折と湿った反射を処理します。

```hlsl
float3 shaded = 0;
shaded += EvaluateDiffuseSSS(...);
shaded += EvaluateSkinSpecular(...);
shaded += EvaluateTransmittance(...);
shaded *= ao;
```

## 技術の選び方

肌の SSS を実装する技術は、品質とコストで並べると、次のようになります。

最も軽いのが、[事前積分](pre-integrated.md)です。法線の向きと表面の曲率から、あらかじめ計算した LUT を引くだけで、ライティングの段階で SSS の柔らかさが出ます。画面空間のぼかしが不要で、モバイルでも使えます。ただし、影の縁の赤みは出にくく、薄い所の透けも別に処理が必要です。

標準的なのが、[画面空間の分離ぼかし](screen-space-sss.md)です。ライティングが終わった画像を、肌の画素だけ、深度を考慮しながら、横と縦の 2 方向にぼかします。コストは 1080p で 0.5〜1 ms 程度です。影の縁の赤みも自然に出て、現代のゲームのほぼ標準です。

最も高品質で重いのが、[ガウス和によるテクスチャ空間のぼかし](diffusion-profile.md)です。顔の UV 空間に、ライティングの結果を一度書き出し、6 枚のガウスで何段もぼかして足し合わせます。映画に近い品質ですが、UV 空間を使うため、キャラクターごとに専用のパスが要り、重いです。

## よくあるミス

??? failure "肌が、のっぺりしたプラスチックに見える"
    SSS を入れていない、または**影の縁の広がりが足りない**。散乱の幅（`sss_width`）を、顔の大きさに合わせる。

??? failure "SSS が強すぎて、顔がぼやけて、ろうそくのように見える"
    **ぼかしの幅を狭くし**、**毛穴などの高周波は、ぼかしの対象から外す**（ぼかすのは拡散反射の低周波だけ）。

??? failure "鏡面反射まで、一緒にぼかしてしまう"
    SSS でぼかすのは、**拡散反射だけ**。鏡面反射は表面で起きる現象なので、**ぼかさずに別に足す**。

??? failure "テクスチャの色を、ぼかしの前後で二重に掛ける"
    アルベドは、**ぼかしの前後に半分ずつ（√アルベド）掛ける**か、ぼかしの前にまとめて外す（[Separable SSS](screen-space-sss.md)）。
