# Subsurface Scattering

**次表面散乱**（Subsurface Scattering、SSS）は、光が物体の内部に入り、散らばり、**入った点とは別の点から出てくる**現象です。肌・大理石・ろうそく・牛乳・葉・ジェイドなど、半透明の物体で起きます。ふつうの BRDF は、「光は入った点から出る」と仮定しますが、SSS はその仮定を外します。このページでは、SSS を表す BSSRDF という考え方と、現実的な計算の基になる**拡散近似**と**双極子モデル**を、順に説明します。

!!! tip "ポイント"
    - BRDF は「入る点＝出る点」。**BSSRDF は「入る点と出る点が違ってよい」**。
    - 内部の光は、何度も散乱して**拡散**する。拡散近似なら、**出る点と入る点の距離 r だけ**の関数 R(r) で書ける。
    - R(r) を<strong>拡散プロファイル</strong>と呼ぶ。**中心が高く、すそ野が長い**形。**色ごとに違う**（赤が最も広い）。
    - 双極子モデル（Jensen 2001）が、実用の出発点。**吸収係数と散乱係数**から R(r) を計算できる。
    - リアルタイムでは、R(r) を**ガウスの和**で近似して、ぼかしで実装する。

## BRDF から BSSRDF へ

まず、ふつうの反射の式を思い出します。ある点 x に入る光 L_i(ω_i) が、BRDF f_r で反射されて、視線方向 ω_o に出ていきます。

<div class="formula">L_o(x, ω_o) = ∫ f_r(ω_i, ω_o) · L_i(x, ω_i) · (n·ω_i) dω_i</div>

この式では、**入る点も出る点も x** です。SSS を扱うには、これを拡張します。入る点 x_i と、出る点 x_o を別にして、**表面全体で足し合わせます**。

<div class="formula">L_o(x_o, ω_o) = ∫_A ∫_Ω S(x_i, ω_i; x_o, ω_o) · L_i(x_i, ω_i) · (n·ω_i) dω_i dA(x_i)</div>

この S を **BSSRDF**（Bidirectional Scattering-Surface Reflectance Distribution Function、双方向散乱面反射率分布関数）と呼びます。式の意味は、「面上のあらゆる点 x_i に入った光が、x_o からどれだけ出てくるか」を、全部足し合わせる、ということです。BRDF は 4 次元の関数ですが、BSSRDF は 8 次元（入る点 2 + 出る点 2 + 入る向き 2 + 出る向き 2）で、そのまま扱うのは現実的ではありません。そこで、単純化が必要になります。

## 拡散近似

肌のような**散乱が強い物質**では、光は内部で何十回も散乱するので、**どの方向から入った光も、内部ではほぼ等方（どの向きにも均等）に広がります**。この性質を利用すると、BSSRDF が劇的に単純になります。

散乱が強い媒質では、光のエネルギーの流れは、熱の拡散と同じ**拡散方程式**で近似できます。熱を板の 1 点に当てると、同心円状に広がっていく様子と同じです。拡散近似の下では、入る向きと出る向きの依存が単純になり（フレネルの透過だけが残る）、BSSRDF は次の形にまとまります。

<div class="formula">S(x_i, ω_i; x_o, ω_o) = (1/π) · F_t(η, ω_i) · R_d(‖x_i − x_o‖) · F_t(η, ω_o)</div>

F_t はフレネルの透過率（表面を通り抜ける割合）で、R_d(r) が**拡散プロファイル**（diffusion profile）です。r は入る点と出る点の距離です。つまり、**入る点と出る点の距離 r だけが、散らばりの大きさを決めます**。向きの依存は、表面でのフレネルの項だけに任せればよいのです。

これにより、次の考え方が使えます。ある点 x_o の SSS の光は、「周りの点 x_i に入った光」を、**距離に応じた重み R_d(r) を掛けて足し合わせたもの**です。これは、**画像のぼかし（畳み込み）そのもの**です。ライティングの結果の画像を、R_d(r) の形のカーネルでぼかせば、SSS の結果が得られます。画面空間の SSS が、ぼかしだけで実装できる理由は、ここにあります。

## 双極子モデル

R_d(r) の具体的な形を、物質の性質から計算する方法が、Jensen らの**双極子モデル**（dipole model、SIGGRAPH 2001）です。考え方は、「物質の内部に、光の点光源を置いたとき、その光がどう広がるか」を、境界条件を満たすように 2 つの点光源（双極子）で表すことです。

物質は、2 つの係数で特徴づけられます。**吸収係数 σ_a**（単位長さあたりに光が吸収される割合）と、**換算散乱係数 σ_s'**（単位長さあたりに光が散乱される割合、方向の偏りを補正したもの）です。これらは RGB ごとに値が違います。ここから次の量が決まります。

<div class="formula">σ_t' = σ_a + σ_s'　　α' = σ_s' / σ_t'　　σ_tr = √(3 σ_a σ_t')</div>

σ_t' は換算消散係数、α' は換算アルベド（1 に近いほど散乱が強い）、σ_tr は有効消散係数で、拡散の減衰の速さを表します。さらに、光源の深さを決めます。

<div class="formula">z_r = 1 / σ_t'　　z_v = z_r + 4AD　　D = 1/(3σ_t')　　A = (1 + F_dr)/(1 − F_dr)</div>

z_r は表面の内側にある実の点光源の深さ、z_v は表面の外側にある仮想の（負の）点光源の高さです。A は境界での内部反射を表す係数で、F_dr はフレネルの拡散反射率です。これらから、拡散プロファイルは次の式になります。

<div class="formula">R_d(r) = (α'/4π) · [ z_r (σ_tr d_r + 1) e^(−σ_tr d_r) / d_r³ + z_v (σ_tr d_v + 1) e^(−σ_tr d_v) / d_v³ ]　　d_r = √(r² + z_r²)、d_v = √(r² + z_v²)</div>

式は複雑ですが、形はシンプルです。r が小さいところで高く、r が大きくなるにつれて、**指数関数的に減る**曲線です。ただし、中心付近は 1/d³ 的に鋭く尖り、遠くは e^(−σ_tr d) でゆっくり裾を引く、**二つの性質を併せ持ちます**。この「鋭い中心」と「長い裾」が、肌の柔らかさを作ります。

## 色ごとの違い

R_d(r) は、RGB で別々の曲線になります。肌では、σ_a が赤で小さく（赤は吸収されにくい）、青で大きいため、σ_tr は赤で小さく、青で大きくなります。その結果、**赤の R_d(r) は幅が広く、青は狭く**なります。典型的な値で、赤は数 mm、緑は 1 mm 前後、青は 0.5 mm 程度まで広がります。

この色ごとの違いが、影の縁の赤みを作ります。同じ点光源の光をぼかしたとき、赤が広く、青が狭ければ、中心から離れた位置では、赤だけが残ります。

!!! note "Jensen の論文について"
    Jensen らの 2001 年の論文は、実測した大理石・肌・牛乳などの散乱係数も載せています。この論文で SSS が実用的な計算になり、映画の『ゴラム』（ロード・オブ・ザ・リング）などで使われました。リアルタイムでは、この R_d(r) を、**ガウスの和**や、事前積分の LUT で近似します。

## リアルタイムでの考え方

リアルタイムでは、双極子の式を、毎フレーム、画素ごとに計算することはできません。そこで、次の流れで実装します。

R_d(r) を、あらかじめ（オフラインで）計算しておきます。その曲線を、**数個のガウス関数の和**で近似します（[Diffusion Profiles](diffusion-profile.md)）。ガウスは、ぼかしの計算が速く（分離可能で、段階的に重ねられる）、実装が簡単だからです。あるいは、画面空間で、1 回のぼかしにまとめた**カーネル**を使います（[Separable SSS](screen-space-sss.md)）。あるいは、さらに単純化して、曲率と N·L だけで決まる LUT にします（[Pre-Integrated Skin Shading](pre-integrated.md)）。

## よくあるミス

??? failure "SSS を、ただの半透明（アルファ ブレンド）で表そうとする"
    半透明ブレンドは、背後の物を透かすだけで、**内部で光が広がる**現象を表せない。SSS は、**拡散反射の光を、周りの画素へ広げる**処理。

??? failure "距離 r を、画面上の画素の距離で測る"
    r は**物体の表面上の実際の距離**（mm 単位）。画面上の画素の距離は、カメラからの距離で変わるので、**深度で補正して**、画素の間隔を実際の長さに直す。

??? failure "RGB を同じカーネルでぼかす"
    **赤・緑・青で、広がりが違う**ことが、SSS の見た目の核心。色ごとに別の重みを使う。
