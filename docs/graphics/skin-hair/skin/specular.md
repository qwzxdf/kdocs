# Skin Specular

肌には <strong>つや</strong>（ハイライト）があります。額や鼻の頭、頬が光を受けて光るあの部分です。SSS が肌の「柔らかさ」と「血色」を作るのに対して、鏡面反射は肌の質感（脂っぽさ・乾燥・湿り気）を作ります。顔のつやが不自然だとせっかくの SSS も台無しになります。このページでは肌の鏡面反射の物理的な性質と二重ローブの考え方、フレネルの扱いを説明します。

!!! tip "ポイント"
    - 肌の鏡面反射は<strong>皮脂の膜</strong>で起きる。色が付かない（白い）。
    - 肌の F0 は約 0.028（屈折率 1.4）。金属ではないのでとても低い。
    - 斜めから見ると強く光る（フレネル）。顔の輪郭が光るのはそのため。
    - 二重ローブ：鋭い小さなローブ（皮脂の膜）と広いなだらかなローブ（肌の粗さ）を足す。
    - 粗さは部位で違う。額・鼻は低く（つるつる）、頬・顎は高くする。

## 肌の鏡面反射の性質

肌の表面は薄い皮脂の膜に覆われています。この膜の屈折率は約 1.4 です。真正面から光が当たったときの反射率（F0）は、次の式で求まります。

<div class="formula">F0 = ((n − 1) / (n + 1))² = ((1.4 − 1) / (1.4 + 1))² ≈ 0.028</div>

約 2.8 % と小さい値です。プラスチックの 4 % より低く、金属（50〜90 %）とは大違いです。正面から見ると肌はほとんど光らず <strong>斜めから見るほどフレネルによって強く光ります</strong>。顔の輪郭（耳の縁、鼻の稜線、頬の端）が白く光って見えるのは、この効果です。

この反射は 皮脂の表面で起きるので、肌の色（アルベド）の影響を受けず 光源の色のまま（白）になります。金属では鏡面反射が物体の色になりますが、肌のような非金属では鏡面は光の色のままです。これは PBR の基本です（[PBR](../../../3d/pbr.md)）。

## 粗さと分布

反射の「広がり」は表面の粗さで決まります。肌の表面は顕微鏡で見ると <strong>毛穴や細かいしわ</strong>があり完全な鏡ではありません。皮脂の膜で覆われた肌の鏡面反射は PBR の標準的な GGX 分布でもそれらしくなりますが、肌の質感には Beckmann 分布がよく使われてきました。

Kelemen と Szirmay-Kalos の "A Microfacet Based Coupled Specular-Matte BRDF with Importance Sampling"（2001）の式は、肌の鏡面反射の定番で d'Eon と Luebke の GPU Gems 3 の記事でも使われています。Beckmann 分布は次のとおりです。

<div class="formula">D(h) = exp(−tan²θ_h / m²) / (π m² cos⁴θ_h)</div>

m は粗さのパラメータで肌では 0.3 前後の値がよく使われます（小さいほど鋭いハイライト）。θ_h はハーフベクトルと法線のなす角です。

Beckmann 分布は GGX と比べて、裾が短くハイライトの周りがすっと切れます。GGX の長い裾を使うと肌のつやがぼんやりと広がりすぎて、脂っぽく見えることがあります。ただ、実際の制作では GGX を使って粗さを調整することも多く、どちらを使っても 粗さのテクスチャで部位ごとに調整することのほうが、見た目への影響が大きいです。

## 二重ローブ

肌の鏡面反射は <strong>1 つの分布では表しきれません</strong>。実際の肌には、2 種類の反射があるからです。

1 つは 皮脂の膜による鋭い反射です。膜が薄く滑らかなので小さく鋭いハイライトになります。もう 1 つは 肌の凹凸（毛穴や細かなしわ）による広くなだらかな反射です。この 2 つを合成すると鋭い芯の周りに柔らかい裾を持つハイライトになり肌の質感がリアルになります。

そこで、2 つのローブを足し合わせます。

<div class="formula">S = w · D(h; m₁) + (1 − w) · D(h; m₂)</div>

m₁ は鋭いローブの粗さ（例：0.15）、m₂ は広いローブの粗さ（例：0.5）で、w は混合の重み（例：0.5〜0.8）です。この二重ローブは Naughty Dog の『Uncharted』シリーズなど、多くのゲームで使われています。粗さのテクスチャから m₁ を決めて、m₂ を m₁ の倍程度にするなど簡単な関係で 1 つのパラメータにまとめることもできます。

```hlsl
float BeckmannD(float n_dot_h, float m) {
  float cos2 = n_dot_h * n_dot_h;
  float tan2 = (1.0 - cos2) / cos2;
  return exp(-tan2 / (m * m)) / (3.14159265 * m * m * cos2 * cos2);
}

float SkinSpecular(float3 n, float3 v, float3 l, float roughness) {
  float3 h = normalize(l + v);
  float n_dot_h = saturate(dot(n, h));
  float n_dot_l = saturate(dot(n, l));
  float n_dot_v = saturate(dot(n, v));
  float v_dot_h = saturate(dot(v, h));

  float d = 0.5 * BeckmannD(n_dot_h, roughness * 0.5) + 0.5 * BeckmannD(n_dot_h, roughness * 1.5);
  float f = 0.028 + (1.0 - 0.028) * pow(1.0 - v_dot_h, 5.0);
  float g = 1.0 / (4.0 * max(n_dot_l, 0.01) * max(n_dot_v, 0.01));
  return d * f * g * n_dot_l;
}
```

## 部位ごとの粗さ

顔の部位によって皮脂の量と肌のきめが違うので、粗さも違います。額・鼻の頭・あごの先は皮脂が多く、つるつるしているので粗さが低くなります（つやが強い）。頬・目の下は皮脂が少なくきめが細かいため、粗さが高くなります（つやが弱い）。唇は湿っているので粗さが低くなります。

この違いを <strong>粗さのテクスチャ</strong>（または、鏡面強度のテクスチャ）に描き込みます。1 枚のテクスチャで顔全体の質感の差を表すので、鏡面の質感はテクスチャで決まる部分が大きいです。同じシェーダーで粗さのテクスチャだけを差し替えて、乾燥した肌と汗をかいた肌を表現できます。汗をかいたときは粗さを全体に下げ（つやが強くなる）、法線マップをなめらかにします（細かい凹凸を埋める）。

## 鏡面反射とSSSの関係

鏡面反射は <strong>表面の現象</strong>なので、SSS のぼかしの対象ではありません。画面空間の SSS では拡散反射と鏡面反射を別々のターゲットに書き拡散だけをぼかしてから、鏡面を足します（[Separable SSS](screen-space-sss.md)）。鏡面をぼかしてしまうとつやが消えて、硬い印象になります。

また、拡散反射と鏡面反射のエネルギーの保存にも注意します。鏡面反射で反射した分だけ拡散反射に回る光が減ります。肌の F0 は小さい（2.8 %）ので、真正面では影響は小さいですが、斜めから見て鏡面が強い（フレネルが 1 に近づく）場所では、拡散反射を `(1 − F)` で弱めるとエネルギー保存が正しくなります。

## 環境光の鏡面反射

肌は環境（空）の景色もわずかに映します。IBL（環境マップ）の鏡面反射では <strong>粗さに応じたぼけた景色</strong>をフレネルで重みを付けて足します（[Reflection Probes](../../reflections/probes/index.md)）。肌の F0 が低いので正面ではほとんど映りませんが、顔の輪郭では空の光が淡く映り込み 輪郭のリムライトのように見えます。この効果は肌の立体感を大きく高めるので、省略せずスペキュラ遮蔽（耳の内側などで反射を弱める）と合わせて入れます（[GTAO](../../ao/gtao.md)）。

## よくあるミス

??? failure "肌が金属やプラスチックのように光る"
    F0 が高すぎる。<strong>肌の F0 は 0.028</strong>。粗さも低くしすぎない（0.3 前後）。

??? failure "肌のつやが、色付いている"
    鏡面反射は光源の色のまま（白）。アルベドを掛けない。

??? failure "顔全体が同じようにテカる"
    粗さのテクスチャで、部位ごとの差（額・鼻は低く頬は高く）を付ける。

??? failure "斜めから見ても、輪郭が光らない"
    フレネルを入れていない。`F0 + (1 − F0)(1 − V·H)⁵`。
