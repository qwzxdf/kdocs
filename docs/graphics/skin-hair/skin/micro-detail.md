# Skin Micro-Detail

SSS と鏡面反射がどれだけ正確でも、<strong>細かいディテール</strong>が足りないと、肌は人形のように見えます。<strong>毛穴、小じわ、産毛、そばかす、血管の透け、表情によるしわ</strong>。これらは、ジオメトリではなく、テクスチャと法線マップで表します。このページでは、肌のディテールをどう作り、どう重ねるか、そして、表情によって変わるしわと血流の扱いを説明します。

!!! tip "ポイント"
    - ディテールは<strong>ベース（顔の形）＋ 中間（しわ）＋ 微細（毛穴）</strong>の3 層で作る。
    - 毛穴の法線マップは、細かくタイリングする。顔の位置で強さを変えるマスクを掛ける。
    - しわマップは、表情に応じて混ぜる。ブレンドシェイプ（表情）と連動する。
    - 血流で色が変わる。表情で顔が赤くなる・青ざめるを、アルベドの切り替えで表す。
    - SSS のぼかしでディテールを消さない。アルベドは、ぼかしの外に置く。

## 3 層のディテール

肌のディテールは、大きさの違う 3 つの層に分けて作ります。

1 つ目は<strong>顔の形</strong>（ベース）です。顔のジオメトリ（ポリゴン）そのもので、頬骨、鼻筋、あごなど、数センチ以上の形を表します。2 つ目は<strong>中間のディテール</strong>で、数ミリから数センチのしわ（目尻のしわ、ほうれい線、額のしわ）です。法線マップで表します。3 つ目は<strong>微細なディテール</strong>で、毛穴、肌のきめ、産毛の根元など、1 ミリ以下の模様です。ここは、顔全体に敷き詰めて繰り返す、小さなタイリング法線マップで表します。

各層は、別々のテクスチャとして作り、重ねて使います。顔全体の法線マップ（中間まで）は、顔専用の高解像度のテクスチャ（たとえば 4K）で、一度だけ貼ります。微細なディテールは、同じ小さなパターンを、UV の何倍もの密度で繰り返し貼ります（ディテール法線マップ）。

## 法線マップの重ね方

2 つの法線マップを重ねる（ブレンドする）には、単純に足して正規化するより、もう少し丁寧な方法が良いです。Reoriented Normal Mapping（RNM）や、Whiteout ブレンドがよく使われます。ベースの法線マップ n₁ の上に、ディテールの法線マップ n₂ を重ねる Whiteout ブレンドは、次のとおりです。

```hlsl
float3 BlendNormals(float3 base, float3 detail) {
  return normalize(float3(base.xy + detail.xy, base.z * detail.z));
}
```

ベースの法線マップの XY に、ディテールの XY を足し、Z を掛けます。単純ですが、ディテールがベースの傾きに沿って自然に重なります。ディテールの強さは、XY に係数を掛けて調整します（`detail.xy * strength`）。

## 顔の位置による強さ

微細なディテールの強さは、顔の部位で違います。鼻の頭や頬は毛穴が目立ち、額や唇はなめらかです。唇は毛穴がなく、縦のしわだけがあります。目の周りの皮膚は薄く、毛穴が細かいです。

この違いは、<strong>マスク テクスチャ</strong>で表します。顔の UV 展開に対応した白黒の画像で、白い所ほどディテールを強く、黒い所ほど弱くします。このマスクを、ディテール法線マップの強さに掛けるだけで、部位ごとの差が出せます。

```hlsl
float detail_mask = detail_mask_tex.Sample(linear_wrap, input.uv).r;
float3 detail_n = UnpackNormal(detail_normal_tex.Sample(linear_wrap, input.uv * kDetailTiling));
detail_n.xy *= detail_mask * kDetailStrength;
float3 n = BlendNormals(base_normal, detail_n);
```

## 表情によるしわ

人の顔は、表情で皮膚が伸び縮みして、しわが出たり消えたりします。眉を上げれば額に横のしわが、眉をひそめれば眉間に縦のしわが、笑えば目尻としわが出ます。ゲームの顔のアニメーションは、<strong>ブレンドシェイプ</strong>（表情ごとの頂点の形）で表されますが、頂点の形の変化だけでは、細かいしわは表せません。

そこで、<strong>しわの法線マップ（wrinkle map）</strong>を、表情に応じて混ぜます。たとえば、「眉を上げた」表情のブレンドシェイプの重みを w とするとき、額のしわの法線マップを、w に比例する強さで、ベースの法線マップに重ねます。表情が戻れば、w が 0 になり、しわも消えます。

* 額のしわ：眉を上げる表情と連動。
* 眉間のしわ：眉をひそめる表情と連動。
* 目尻のしわ：笑う表情と連動。
* ほうれい線：笑う、または口を引く表情と連動。

しわマップは、顔の UV の部位ごとに領域を分けた 1 枚のテクスチャに、複数のしわを描き、<strong>チャンネルごと</strong>（RGBA）に別の表情に割り当てると効率的です。マスクの代わりに、ブレンドシェイプの重みを、直接シェーダーに渡します。

```hlsl
float3 wrinkle_n = float3(0, 0, 1);
wrinkle_n = BlendNormals(wrinkle_n, SampleWrinkle(brow_up_map) * weights.brow_up);
wrinkle_n = BlendNormals(wrinkle_n, SampleWrinkle(brow_down_map) * weights.brow_down);
wrinkle_n = BlendNormals(wrinkle_n, SampleWrinkle(smile_map) * weights.smile);
float3 n = BlendNormals(base_normal, wrinkle_n);
```

## 血流による色の変化

表情が変わると、肌の色も変わります。怒れば顔が赤くなり、怖がれば青ざめます。これは、皮膚の血流量が変わり、ヘモグロビンの量が変わるためです。

血流の表現は、<strong>アルベド（肌の色）を、2〜3 種類のテクスチャで切り替える</strong>のが一般的です。

* 通常の肌色。
* 血が集まった肌色（赤みが強い）。
* 血が引いた肌色（青白い）。

表情やキャラクターの感情の状態に応じて、これらを混ぜます。さらに、<strong>しわの周りは血が集まる</strong>ので、しわのある部分だけを赤くするマスクを使うと、リアルです。血管の透け（目の周り、こめかみ）も、アルベドに描き込みます。

## 産毛とそばかす

<strong>産毛</strong>（うぶげ）は、肌を覆う細かい毛で、光を受けるとうっすら白く光り、肌に柔らかな輪郭を与えます。ジオメトリで産毛を作るのは重いので、<strong>輪郭付近に白い微細な反射を足す</strong>シェーダー（リム ライトに近い効果）で近似することが多いです。カメラが肌に近づいたときだけ、シェル法（顔のメッシュを少しずつ膨らませた複数の層に、毛のテクスチャを貼る）で産毛を出す手法もあります。

<strong>そばかす</strong>・<strong>ほくろ</strong>・あざは、アルベドのテクスチャに描き込みます。ここで大切なのは、これらを SSS のぼかしの前に置かないことです。ぼかしの前にアルベドを掛けると、そばかすの輪郭がぼやけてしまいます。[Separable SSS](screen-space-sss.md) で説明したとおり、アルベドは、ぼかしの外（後）に掛けます。

## 解像度とメモリ

顔の高品質なテクスチャは、データ量が大きくなります。顔のアルベド・法線・粗さ・しわ・マスクを、それぞれ 4K で持つと、1 キャラクターで数十 MB になります。メモリを節約するために、いくつかの工夫があります。

* 白黒の情報（粗さ、マスク、AO）は、1 枚のテクスチャのチャンネルに詰める（RGBA）。
* 法線マップは、XY だけを 2 チャンネルに保存し、Z はシェーダーで復元する（BC5 圧縮）。
* 対称な顔は、左右対称に UV を作り、半分のテクスチャで済ませる（ただし、対称すぎる顔は不自然なので、非対称のマスクで崩す）。
* テクスチャのストリーミングで、画面に大きく映るときだけ高解像度を読み込む。

## よくあるミス

??? failure "毛穴の模様が、顔全体で同じ強さで、マスクのような肌になる"
    <strong>部位のマスク</strong>で強さを変える。鼻・頬は強く、唇・額は弱く。

??? failure "しわが、表情に関係なく常に出ている"
    しわマップを<strong>常時</strong>ベースに焼き込んでいる。<strong>ブレンドシェイプの重みで混ぜる</strong>。

??? failure "微細な法線マップの繰り返しが、目立つ"
    タイリングの倍率を、顔の UV と<strong>整数倍にしない</strong>。<strong>2 層を異なる倍率で重ねる</strong>と周期が隠れる。

??? failure "そばかすが、SSS でぼけて消える"
    アルベドを<strong>ぼかしの外</strong>に置く。
