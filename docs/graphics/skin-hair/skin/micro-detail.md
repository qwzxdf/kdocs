# Skin Micro-Detail

SSS と鏡面反射がどれだけ正確でも <strong>細かいディテール</strong>が足りないと肌は人形のように見えます。毛穴、小じわ産毛、そばかす血管の透け表情によるしわ。これらはジオメトリではなくテクスチャと法線マップで表します。このページでは肌のディテールをどう作りどう重ねるかそして、表情によって変わるしわと血流の扱いを説明します。

!!! tip "ポイント"
    - ディテールは<strong>ベース（顔の形）＋ 中間（しわ）＋ 微細（毛穴）</strong>の3 層で作る。
    - 毛穴の法線マップは細かくタイリングする。顔の位置で強さを変えるマスクを掛ける。
    - しわマップは表情に応じて混ぜる。ブレンドシェイプ（表情）と連動する。
    - 血流で色が変わる。表情で顔が赤くなる・青ざめるをアルベドの切り替えで表す。
    - SSS のぼかしでディテールを消さない。アルベドはぼかしの外に置く。

## 3 層のディテール

肌のディテールは大きさの違う 3 つの層に分けて作ります。

1 つ目は<strong>顔の形</strong>（ベース）です。顔のジオメトリ（ポリゴン）そのもので頬骨、鼻筋、あごなど数センチ以上の形を表します。2 つ目は中間のディテールで、数ミリから数センチのしわ（目尻のしわほうれい線、額のしわ）です。法線マップで表します。3 つ目は微細なディテールで毛穴、肌のきめ産毛の根元など 1 ミリ以下の模様です。ここは顔全体に敷き詰めて繰り返す小さなタイリング法線マップで表します。

各層は別々のテクスチャとして作り重ねて使います。顔全体の法線マップ（中間まで）は顔専用の高解像度のテクスチャ（たとえば 4K）で、一度だけ貼ります。微細なディテールは同じ小さなパターンを UV の何倍もの密度で繰り返し貼ります（ディテール法線マップ）。

## 法線マップの重ね方

2 つの法線マップを重ねる（ブレンドする）には、単純に足して正規化するよりもう少し丁寧な方法が良いです。Reoriented Normal Mapping（RNM）や Whiteout ブレンドがよく使われます。ベースの法線マップ n₁ の上にディテールの法線マップ n₂ を重ねる Whiteout ブレンドは、次のとおりです。

```hlsl
float3 BlendNormals(float3 base, float3 detail) {
  return normalize(float3(base.xy + detail.xy, base.z * detail.z));
}
```

ベースの法線マップの XY にディテールの XY を足し、Z を掛けます。単純ですがディテールがベースの傾きに沿って自然に重なります。ディテールの強さは XY に係数を掛けて調整します（`detail.xy * strength`）。

## 顔の位置による強さ

微細なディテールの強さは顔の部位で違います。鼻の頭や頬は毛穴が目立ち額や唇はなめらかです。唇は毛穴がなく縦のしわだけがあります。目の周りの皮膚は薄く毛穴が細かいです。

この違いは <strong>マスク テクスチャ</strong>で表します。顔の UV 展開に対応した白黒の画像で、白い所ほどディテールを強く黒い所ほど弱くします。このマスクをディテール法線マップの強さに掛けるだけで、部位ごとの差が出せます。

```hlsl
float detail_mask = detail_mask_tex.Sample(linear_wrap, input.uv).r;
float3 detail_n = UnpackNormal(detail_normal_tex.Sample(linear_wrap, input.uv * kDetailTiling));
detail_n.xy *= detail_mask * kDetailStrength;
float3 n = BlendNormals(base_normal, detail_n);
```

## 表情によるしわ

人の顔は表情で皮膚が伸び縮みして、しわが出たり消えたりします。眉を上げれば額に横のしわが眉をひそめれば眉間に縦のしわが、笑えば目尻としわが出ます。ゲームの顔のアニメーションは <strong>ブレンドシェイプ</strong>（表情ごとの頂点の形）で表されますが、頂点の形の変化だけでは細かいしわは表せません。

そこで、しわの法線マップ（wrinkle map）を表情に応じて混ぜます。たとえば、「眉を上げた」表情のブレンドシェイプの重みを w とするとき額のしわの法線マップを w に比例する強さでベースの法線マップに重ねます。表情が戻れば w が 0 になりしわも消えます。

* 額のしわ：眉を上げる表情と連動。
* 眉間のしわ：眉をひそめる表情と連動。
* 目尻のしわ：笑う表情と連動。
* ほうれい線：笑うまたは口を引く表情と連動。

しわマップは顔の UV の部位ごとに領域を分けた 1 枚のテクスチャに複数のしわを描き、チャンネルごと（RGBA）に別の表情に割り当てると効率的です。マスクの代わりにブレンドシェイプの重みを直接シェーダーに渡します。

```hlsl
float3 wrinkle_n = float3(0, 0, 1);
wrinkle_n = BlendNormals(wrinkle_n, SampleWrinkle(brow_up_map) * weights.brow_up);
wrinkle_n = BlendNormals(wrinkle_n, SampleWrinkle(brow_down_map) * weights.brow_down);
wrinkle_n = BlendNormals(wrinkle_n, SampleWrinkle(smile_map) * weights.smile);
float3 n = BlendNormals(base_normal, wrinkle_n);
```

## 血流による色の変化

表情が変わると肌の色も変わります。怒れば顔が赤くなり怖がれば青ざめます。これは皮膚の血流量が変わりヘモグロビンの量が変わるためです。

血流の表現は <strong>アルベド（肌の色）を 2〜3 種類のテクスチャで切り替える</strong>のが一般的です。

* 通常の肌色。
* 血が集まった肌色（赤みが強い）。
* 血が引いた肌色（青白い）。

表情やキャラクターの感情の状態に応じて、これらを混ぜます。さらに、しわの周りは血が集まるので、しわのある部分だけを赤くするマスクを使うとリアルです。血管の透け（目の周りこめかみ）もアルベドに描き込みます。

## 産毛とそばかす

<strong>産毛</strong>（うぶげ）は肌を覆う細かい毛で、光を受けるとうっすら白く光り肌に柔らかな輪郭を与えます。ジオメトリで産毛を作るのは重いので、輪郭付近に白い微細な反射を足すシェーダー（リム ライトに近い効果）で近似することが多いです。カメラが肌に近づいたときだけシェル法（顔のメッシュを少しずつ膨らませた複数の層に毛のテクスチャを貼る）で産毛を出す手法もあります。

そばかす・ほくろ・あざはアルベドのテクスチャに描き込みます。ここで大切なのはこれらを SSS のぼかしの前に置かないことです。ぼかしの前にアルベドを掛けると、そばかすの輪郭がぼやけてしまいます。[Separable SSS](screen-space-sss.md) で説明したとおりアルベドは、ぼかしの外（後）に掛けます。

## 解像度とメモリ

顔の高品質なテクスチャはデータ量が大きくなります。顔のアルベド・法線・粗さ・しわ・マスクをそれぞれ 4K で持つと 1 キャラクターで数十 MB になります。メモリを節約するためにいくつかの工夫があります。

* 白黒の情報（粗さマスク、AO）は 1 枚のテクスチャのチャンネルに詰める（RGBA）。
* 法線マップは XY だけを 2 チャンネルに保存し、Z はシェーダーで復元する（BC5 圧縮）。
* 対称な顔は左右対称に UV を作り半分のテクスチャで済ませる（ただし、対称すぎる顔は不自然なので非対称のマスクで崩す）。
* テクスチャのストリーミングで、画面に大きく映るときだけ高解像度を読み込む。

## よくあるミス

??? failure "毛穴の模様が顔全体で同じ強さでマスクのような肌になる"
    <strong>部位のマスク</strong>で強さを変える。鼻・頬は強く唇・額は弱く。

??? failure "しわが、表情に関係なく常に出ている"
    しわマップを常時ベースに焼き込んでいる。ブレンドシェイプの重みで混ぜる。

??? failure "微細な法線マップの繰り返しが、目立つ"
    タイリングの倍率を顔の UV と整数倍にしない。2 層を異なる倍率で重ねると周期が隠れる。

??? failure "そばかすが、SSS でぼけて消える"
    アルベドをぼかしの外に置く。
