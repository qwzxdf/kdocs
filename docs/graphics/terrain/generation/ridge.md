# Ridged Noise

<strong>通常のノイズは丸い丘になりがち</strong>で、<strong>山脈の鋭い稜線は出ません</strong>。ノイズの絶対値を反転させると、尖った稜線ができます。このページではリッジ ノイズを説明します。

!!! tip "ポイント"
    - 1 − |ノイズ| で、稜線ができる。
    - fBm と同じように重ねて使う。
    - 山脈・峡谷に向く。
    - 丘と混ぜて使い分ける。

## リッジ ノイズ
<strong>山脈の尾根</strong>を作るには <strong>ノイズの絶対値を取って反転</strong>します。ゼロ付近が鋭い尾根になります。

```hlsl
float RidgedFbm(float2 p, int octaves, float lacunarity, float gain) {
  float sum = 0.0;
  float amplitude = 0.5;
  float weight = 1.0;
  for (int i = 0; i < octaves; ++i) {
    float n = 1.0 - abs(PerlinNoise(p));
    n *= n;
    n *= weight;
    weight = saturate(n * 2.0);
    sum += n * amplitude;
    p *= lacunarity;
    amplitude *= gain;
  }
  return sum;
}
```

| 点 | 説明 |
| --- | --- |
| `1 − abs(noise)` | 0 付近の線が尾根になる |
| `n *= n` | 尾根を鋭くする |
| `weight` | 低い所では細かい起伏を弱める（谷を滑らかに尾根をごつごつ） |
| 使い分け | 山地はリッジ、平原は通常の fBm。ノイズでブレンド |

## 通常の fBm は山の稜線が丸い

fBm はノイズの値（−1〜1）を、そのまま高さにするので山頂は、<strong>丸い丘</strong>になります。現実の山脈には <strong>鋭い稜線（尾根）</strong>があります。尾根を作るにはノイズの値を折り返す加工をします。

## 尾根ノイズ（ridged multifractal）の考え方

ノイズの値は 0 の近くをゆっくり通り抜けます。<strong>ノイズが 0 になる場所は、曲線（等値線）</strong>を作ります。この曲線を <strong>山の尾根</strong>にします。

1. ノイズの絶対値を取る（0 の位置で、V の字に折り返される）
2. 1 から引いて上下をひっくり返す（0 の位置が山頂の、尖った稜線になる）
3. 値を 2 乗して尾根をさらに鋭くする

```text
signal = 1 − |noise|        尾根が、尖る
signal = signal²            尾根が、さらに鋭く、谷が平らに
```

Musgrave がこの方式を、マルチフラクタルとして整理しました（Ebert ら、2002）。

## 実装

```hlsl
// リッジ マルチフラクタル（Musgrave）。
float RidgedMulti(float2 p, int octaves, float lacunarity, float gain,
                  float offset, float weight_gain, uint seed) {
  float sum = 0.0;
  float amplitude = 1.0;
  float weight = 1.0;
  for (int i = 0; i < octaves; ++i) {
    float signal = GradientNoise(p, seed + i);
    signal = offset - abs(signal);        // 折り返し（offset は 1.0 が標準）
    signal *= signal;                      // 2 乗で、尾根を鋭く
    signal *= weight;                      // 下のオクターブの結果で、重みを変える

    sum += signal * amplitude;
    // 尾根の上（signal が大きい所）にだけ、次のオクターブの細かい起伏を、乗せる。
    weight = saturate(signal * weight_gain);

    p *= lacunarity;
    amplitude *= gain;
  }
  return sum;
}
```

| パラメーター | 一般的な値 | 意味 |
| --- | --- | --- |
| `offset` | 1.0 | 折り返しの高さ。小さくすると尾根が低く谷が広くなる |
| `weight_gain` | 2.0 | 次のオクターブへ、重みを渡す強さ |
| `gain` | 0.5 | 振幅の減り方 |

### 重み（weight）が肝心

`weight` は <strong>前のオクターブで尾根に近かった場所だけ、次のオクターブを強く足す</strong>ための係数です。

| 場所 | 前の signal | weight | 次のオクターブ |
| --- | --- | --- | --- |
| 尾根の上 | 大きい | 大きい | 強く足される。尾根に細かい起伏が付く |
| 谷 | 小さい | 小さい | ほとんど足されない。谷が平らに残る |

結果として、<strong>尾根はごつごつして谷はなだらか</strong>になります。これがリッジ ノイズと fBm の、一番の違いです。山脈や荒れた岩山でよく使います。

## fBm と組み合わせて使う

尾根ノイズだけでは全体が山脈になります。<strong>平地・丘・山脈</strong>を混ぜる場合は、2 種類のノイズを <strong>マスク</strong>で混ぜます。

```hlsl
// 低周波のノイズで「山の領域」を決め、その領域だけ、尾根ノイズを使う。
float height_fbm = Fbm(p, 6, 2.0, 0.5, seed);                         // 丘・平地
float height_ridge = RidgedMulti(p, 6, 2.0, 0.5, 1.0, 2.0, seed + 100);  // 山脈
float mountain_mask = smoothstep(0.2, 0.6, Fbm(p * 0.1, 3, 2.0, 0.5, seed + 200) * 0.5 + 0.5);
float height = lerp(height_fbm * 0.2, height_ridge, mountain_mask);
```

低周波のノイズ（`p * 0.1`）をマスクにして、<strong>地域ごとに地形の性格を変える</strong>のは、手続き的な地形の基本の考え方です（[Converting Noise to Height](height-conversion.md)）。

## 注意点

| 項目 | 内容 |
| --- | --- |
| 値の範囲 | `offset − |n|` を 2 乗するので値は、0〜1 程度。fBm（−1〜1）と混ぜるときは範囲を、そろえる |
| 尾根が直線的になる | 勾配ノイズの格子の向きが、出ることがある。座標を少し回転させてオクターブごとに、変える |
| 谷が平らすぎる | `weight_gain` を下げるまたは、谷にだけ別の fBm を足す |
| 傾きが急すぎる | 2 乗で、尾根が急になる。高さの変換（スケール）で調整する |
