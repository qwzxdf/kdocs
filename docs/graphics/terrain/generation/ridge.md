# Ridged Noise

fBm で山を作るとできあがるのは、丸い丘の連なりです。現実の山脈には鋭い稜線（尾根）があって谷には、水が刻んだ筋があります。ノイズの値をそのまま高さにする限りこの鋭さは出ません。

<strong>ノイズの絶対値を取って反転させると、ノイズが 0 になる場所が尖った尾根になります</strong>。このページでは尾根ができる仕組み重み（`weight`）の役目、完成形の HLSL（勾配ノイズから fBm、リッジ マルチフラクタルまで）、実測した値の範囲と傾き fBm との混ぜ方、注意点を説明します。

!!! tip "ポイント"
    - `1 − |noise|` でノイズが 0 になる等値線が、尖った尾根になります。2 乗するとさらに鋭くなります。
    - 重み `weight` は前のオクターブで尾根に近かった場所にだけ次の細かい起伏を足します。尾根はごつごつして谷はなだらかになります。
    - 山地はリッジ、平原は通常の fBm にして、低周波のノイズのマスクで混ぜます。
    - 値の範囲が違います。fBm は正負にまたがりリッジは正の側に偏ります。混ぜる前に範囲をそろえます。
    - 同じ正規化の高さで、傾きの中央値が約 7.5 倍になります。高さのスケールで調整します。

## 通常の fBm は山頂が丸い {#why}

fBm はノイズの値（おおよそ −1〜1）をそのまま高さにします。ノイズは極大や極小の付近でなだらかなので山頂は、丸い丘になります。尖った尾根を作るにはノイズの値を折り返す加工をします。

## 尾根ができる仕組み {#idea}

ノイズの値は 0 の付近をゆっくり通り抜けます。ノイズが 0 になる場所は平面の上で曲線（等値線）になります。この曲線を山の尾根にします。

1. ノイズの絶対値を取ります。0 の位置で V の字に折り返されます。
2. 1 から引いて上下をひっくり返します。0 の位置が山頂の尖った稜線になります。
3. 値を 2 乗して尾根をさらに鋭くします。谷（値が小さい所）は 2 乗でより平らになります。

```text
signal = 1 − |noise|        尾根が尖る
signal = signal²            尾根がさらに鋭く、谷が平らになる
```

この方式は Musgrave がマルチフラクタルとして整理しました（Ebert ら、2002）。

## 実装 {#implementation}

リッジ マルチフラクタルは勾配ノイズを土台にします。ここでは、自己完結した HLSL として、ハッシュ、勾配ノイズ、fBm、リッジ マルチフラクタルを通して書きます。

まず、整数のハッシュと勾配ノイズです。格子点ごとにハッシュから勾配ベクトルを決めて、4 隅の寄与を補間します。

```hlsl
// PCG ハッシュ。整数 1 つを、よく混ざった整数にする
uint Pcg(uint v) {
  uint state = v * 747796405u + 2891336453u;
  uint word = ((state >> ((state >> 28u) + 4u)) ^ state) * 277803737u;
  return (word >> 22u) ^ word;
}

// 格子点 (ix, iy) の単位勾配ベクトル。seed でオクターブごとに変える
float2 GradientAt(int ix, int iy, uint seed) {
  uint h = Pcg(uint(ix) + Pcg(uint(iy) + Pcg(seed)));
  float angle = (h & 0xffffu) * (6.2831853 / 65536.0);
  return float2(cos(angle), sin(angle));
}

// Perlin の 5 次の補間曲線（6t⁵ − 15t⁴ + 10t³）。格子上で 1 階・2 階の微分が 0 になり、筋が出ない
float2 Fade(float2 t) {
  return t * t * t * (t * (t * 6.0 - 15.0) + 10.0);
}

// 2D の勾配ノイズ。値はおおよそ -1..1
float GradientNoise(float2 p, uint seed) {
  int2 i = int2(floor(p));
  float2 f = p - floor(p);
  float n00 = dot(GradientAt(i.x,     i.y,     seed), f - float2(0, 0));
  float n10 = dot(GradientAt(i.x + 1, i.y,     seed), f - float2(1, 0));
  float n01 = dot(GradientAt(i.x,     i.y + 1, seed), f - float2(0, 1));
  float n11 = dot(GradientAt(i.x + 1, i.y + 1, seed), f - float2(1, 1));
  float2 u = Fade(f);
  return lerp(lerp(n00, n10, u.x), lerp(n01, n11, u.x), u.y);
}
```

次に、通常の fBm です。オクターブごとに周波数を `lacunarity` 倍、振幅を `gain` 倍にして重ねます。

```hlsl
float Fbm(float2 p, int octaves, float lacunarity, float gain, uint seed) {
  float sum = 0.0;
  float amplitude = 1.0;
  for (int i = 0; i < octaves; ++i) {
    sum += amplitude * GradientNoise(p, seed + i);
    p *= lacunarity;
    amplitude *= gain;
  }
  return sum;
}
```

最後に、リッジ マルチフラクタルです。

```hlsl
// リッジ マルチフラクタル（Musgrave）
float RidgedMulti(float2 p, int octaves, float lacunarity, float gain,
                  float offset, float weight_gain, uint seed) {
  float sum = 0.0;
  float amplitude = 1.0;
  float weight = 1.0;
  for (int i = 0; i < octaves; ++i) {
    float signal = GradientNoise(p, seed + i);
    signal = offset - abs(signal);        // 折り返し（offset は 1.0 が標準）
    signal *= signal;                      // 2 乗で尾根を鋭く
    signal *= weight;                      // 前のオクターブの結果で重みを変える

    sum += signal * amplitude;
    // 尾根の上（signal が大きい所）にだけ、次のオクターブの細かい起伏を乗せる
    weight = saturate(signal * weight_gain);

    p *= lacunarity;
    amplitude *= gain;
  }
  return sum;
}
```

`offset` は折り返しの高さです。1.0 が標準で小さくすると、尾根が低く谷が広くなります。`weight_gain` は次のオクターブへ重みを渡す強さで、標準は 2.0 です。`gain` は振幅の減り方で 0.5 が標準です。

### 重み（weight）が肝心

`weight` は前のオクターブで尾根に近かった場所だけに次のオクターブを強く足すための係数です。尾根の上では前の `signal` が大きいので、`weight` も大きくなって細かい起伏が強く足されます。谷では `signal` が小さいので `weight` も小さく、細かい起伏はほとんど足されません。谷が平らに残ります。結果として、尾根はごつごつして谷はなだらかになります。これがリッジ ノイズと fBm の一番の違いです。山脈や荒れた岩山でよく使います。

## 実測した値の範囲と傾き {#measure}

Python で同じ構造の勾配ノイズを実装して、6 オクターブ、`lacunarity = 2`、`gain = 0.5`、`offset = 1`、`weight_gain = 2` で 8 × 8 の範囲を 512 × 512 サンプルして測りました。ノイズの格子や乱数は HLSL と違うので、数字は目安です。

fBm の値は約 −0.85 から 0.80 で、平均はほぼ 0 でした。リッジは約 0.27 から 1.97 で、平均は 1.32 でした。上限の 1.97 は振幅の合計 `1 + 0.5 + … + 0.5⁵ = 1.96875` に当たります。リッジは正の値に偏るので fBm と混ぜるときは、範囲をそろえます。

傾きは高さを 0〜1 に正規化したうえで、サンプル間の差から求めました。傾きの中央値は fBm が約 1.0、リッジが約 7.5 でした。99 パーセンタイルは fBm が約 2.5、リッジが約 21.5 です。尾根が鋭いので同じ高さの範囲でもリッジは桁違いに急です。高さのスケール（メートルへの換算）を fBm より小さくします。

## fBm と組み合わせる {#mix}

リッジ ノイズだけでは全体が山脈になります。平地、丘、山脈を混ぜるには低周波のノイズをマスクにして、領域ごとに使い分けます。

```hlsl
float TerrainHeight(float2 p, uint seed) {
  float hills = Fbm(p, 6, 2.0, 0.5, seed);                              // 丘と平地（-0.85..0.8 程度）
  float ridge = RidgedMulti(p, 6, 2.0, 0.5, 1.0, 2.0, seed + 100);      // 山脈（0.27..1.97 程度）

  // 範囲をそろえる: fBm を 0..1 に、リッジを 0..1 にする（実測の範囲から決めた定数。一例）
  float hills01 = saturate(hills * 0.3 + 0.5);
  float ridge01 = saturate((ridge - 0.3) / 1.7);

  // 低周波のノイズで「山の領域」を決める（0.1 倍の周波数 = 10 倍広い領域）
  float mask_noise = Fbm(p * 0.1, 3, 2.0, 0.5, seed + 200) * 0.5 + 0.5;
  float mountain_mask = smoothstep(0.35, 0.65, mask_noise);

  // 山の領域は高さも持ち上げる（山地が谷より高くなる）
  return lerp(hills01 * 0.25, ridge01, mountain_mask);
}

float4 HeightPS(float4 pos : SV_Position, float2 uv : TEXCOORD0) : SV_Target {
  float h = TerrainHeight(uv * 8.0, 1234u);       // uv 0..1 を、ノイズ空間の 8 倍の範囲に
  return float4(h, h, h, 1.0);                     // 高さマップとして書き出す
}
```

低周波のノイズ（`p * 0.1`）をマスクにして、地域ごとに地形の性格を変えるのは、手続き的な地形の基本の考え方です（[Converting Noise to Height](height-conversion.md)）。マスクの `smoothstep` の幅を広げると、平原から山地への移り変わりがなだらかになります。

!!! note "確かめた範囲"
    HLSL は `fxc`（`ps_5_0`）で `HeightPS` とそこから呼ぶ関数をコンパイルして、エラーが出ないことを確かめました。値の範囲、傾き断面の図は同じ構造のノイズを Python で実装して計算した値で、HLSL を実行した結果ではありません。

## 注意点 {#notes}

- 値の範囲に気をつけます。`offset − |n|` を 2 乗するので値は正に偏ります。fBm と混ぜるときは範囲をそろえます。
- 尾根が直線的になることがあります。勾配ノイズの格子の向きが出ているので、オクターブごとに座標を少し回転させます。
- 谷が平らすぎるなら `weight_gain` を下げるか谷にだけ別の fBm を足します。
- 傾きが急すぎるなら高さの変換（スケール）で調整します。実測では傾きの中央値が fBm の約 7.5 倍でした。

## よくあるミス {#mistakes}

??? failure "山が丸くて、山脈らしくない"
    原因は fBm だけで山を作っていることです。リッジ ノイズを混ぜます。山の領域を低周波のマスクで決めて、その領域だけリッジを使います。

??? failure "リッジと fBm を混ぜたら、山が谷より低くなる"
    原因は 2 つの値の範囲がそろっていないことです。fBm は正負にまたがりリッジは正の側に偏ります。それぞれを 0〜1 に正規化してから混ぜます。

??? failure "尾根が、格子状の筋になって見える"
    原因は勾配ノイズの格子の向きが、そのまま出ていることです。オクターブごとに座標を回転させるか補間曲線を 5 次の `Fade` にして、格子上の筋を消します。

## これだけ覚える {#summary}

!!! abstract "まとめ"
    - [x] `1 − |noise|` を 2 乗すると、ノイズが 0 の線が尖った尾根になります。
    - [x] `weight` で尾根にだけ細かい起伏を足します。谷は平らに残ります。
    - [x] fBm とは低周波のマスクで混ぜて、値の範囲をそろえてから混ぜます。
    - [x] リッジは fBm より傾きが急です。高さのスケールで調整します。
