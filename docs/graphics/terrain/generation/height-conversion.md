# 地形の高さへの変換

**ノイズの値を、そのまま高さにすると、平らな所と山が同じ比率になって不自然**です。**カーブを通して、平地を広く、山を高くする**と、**地形らしくなります**。このページでは、**ノイズから高さへの変換**を説明します。

!!! tip "ポイント"
    - **カーブで、分布を整える**（平地を広く）。
    - **海面より下は平ら**に。
    - **高さに応じて、ノイズの種類を変える**。
    - **スケール（高さの最大）を調整**。

## 地形の高さへの変換
**ノイズ値をそのまま高さにするのではなく、形を整えます**。

| 工夫 | 内容 |
| --- | --- |
| **べき乗** | **`pow(h, 2.0)`** で**平地を広く、山を急に** |
| **大陸の形** | **低周波のノイズで陸と海の分布**を作り、**山のノイズを陸にだけ掛ける** |
| <strong>高さの段差（テラス）</strong> | **`floor` で段にし、少し滑らかに** |
| **島の形** | **中心から離れるほど、高さを下げる**（**円のマスク**） |
| **バイオーム** | **高さ・湿度（別のノイズ）で、地面の種類を決める** |

## よくあるミス

??? failure "どこも似た起伏で、変化が無い"
    **カーブで、平地と山の差を付ける**。
