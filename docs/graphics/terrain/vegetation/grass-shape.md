# Grass Shape

**草は、細長い板ポリを、数枚、交差させて作るのが基本**です。**1 枚の草を、少ない頂点で、それらしく見せる工夫**が要ります。このページでは、**草の形**を説明します。

!!! tip "ポイント"
    - **板ポリを十字に交差させる**。
    - **1 本ずつ、曲げた細いメッシュ**にする方法もある。
    - **頂点カラーで、風の効き方（根元は動かない）を指定**。
    - **テクスチャで、葉の形を切り抜く**。

## 草の形
**草は細い葉が大量に生えている**ので、**ポリゴンを工夫**します。

草の形の作り方は 4 つあります。クロス板（板ポリを十字）は、草の絵を貼った板を 2 枚、十字に交差させる簡単で古典的な方法です。3 枚以上の房は、3〜5 本の葉の板を扇状に並べ、ポリゴンは 6〜10 枚です。1 本ずつの葉は、細長い三角形の帯（3〜7 セグメント）を 1 本ずつ作る方法で、曲げて風で揺らせ、距離で本数を減らせます。ビルボードは、常にカメラを向く板で、遠景用です（回転しても形が崩れない草原の塊）。

**1 本ずつの葉**は、**頂点が先端ほど細く、少し曲がっている**メッシュです。**インスタンスごとに高さ・曲がり・色を変える**と**自然**です。

```hlsl
float bend = instance.bend * pow(input.height_t, 2.0);
local.x += bend;
local.y *= lerp(1.0, 0.9, bend);
```

コードの要点です。`height_t` は、葉の根元が 0、先端が 1 です。二乗で曲げると、先端ほど大きく曲がります（根元は動きません）。根元の色を暗くすると、地面との馴染みや AO の代わりになります。先端は明るくします。草の根元の色を地形のテクスチャの色から取ると、境目が消えます。
