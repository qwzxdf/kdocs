# Geometry Clipmaps

**クリップマップは、カメラを中心に、同心の格子を重ねる手法**で、**外側ほど粗く**なります。**メッシュがシンプルで、四分木が要りません**。このページでは、**クリップマップの仕組み**を説明します。

!!! tip "ポイント"
    - **カメラ中心に、入れ子の格子（リング）を並べる**。
    - **外側のリングほど、2 倍の大きさ・粗さ**。
    - **カメラが動くと、格子をずらす**。
    - **高さデータも、同じ入れ子で持つ**。

## クリップマップ
**ジオメトリ クリップマップ**（Losasso & Hoppe、2004）は、**カメラを中心に入れ子になった正方形リング**で**LOD を表現**します。**一番内側が最も細かく、外側ほど 2 倍ずつ粗く**なります。

クリップマップの特徴です。構造は、同じ頂点数の正方形リングが倍々の大きさで重なる形です（例：各 255×255）。カメラが動くと、リングをグリッド単位でスクロールします（円環バッファで高さを更新）。利点は、三角形の数が一定で、構造が単純で、GPU に向くことです。欠点は、視点から遠くてもリングの数だけは描くこと（画面外を捨てにくい）と、高さデータをリングごとに管理することです。用途は広大な地形や海面で、[水面のクリップマップ](../../water/waves/index.md)と同じ構造です。

**四分木はノードごとにカリングができて柔軟**、**クリップマップは、構造が単純で三角形数が一定**という**違い**があります。

## よくあるミス

??? failure "カメラの移動で、地形が揺れる"
    **格子の幅の整数倍で移動**して、**スナップ**する。
