# Single-Scattering Integral

<strong>視線に沿って進みながら各点で太陽の光が、視線方向に散乱される量を足し合わせます</strong>。これが単散乱の積分で空の色の大部分を決めます。このページでは単散乱の積分を説明します。

!!! tip "ポイント"
    - 視線を分割し各点で「太陽の光 × 散乱 × 透過率」を足す。
    - 太陽の光も大気で減衰した後のもの。
    - 分割数（16〜32）で、精度とコストが決まる。
    - LUT に入れると、積分が不要になる。

## 単散乱の積分
<strong>視線に沿った各点で「太陽光が届く量」×「視線方向へ散る割合」を足し合わせる</strong>のが空の色です。

<div class="formula">L = ∫ T(カメラ → p) · σs(p) · P(θ) · T(p → 太陽) · E_sun ds</div>

| 項 | 意味 |
| --- | --- |
| T(カメラ → p) | 点 p から、カメラまで届く間の減衰 |
| σs(p) | 点 p の散乱係数（高さで決まる） |
| P(θ) | 位相関数：太陽の向きから視線の向きへ、どれだけ散るか |
| T(p → 太陽) | 太陽から点 p まで届く間の減衰 |
| E_sun | 大気の外での太陽の強さ |

```hlsl
float3 SingleScattering(float3 ray_origin, float3 ray_dir, float ray_length, float3 sun_dir, int steps) {
  float step_length = ray_length / steps;
  float3 rayleigh_sum = 0;
  float3 mie_sum = 0;
  float3 optical_depth_view = 0;

  float cos_theta = dot(ray_dir, sun_dir);
  float phase_r = RayleighPhase(cos_theta);
  float phase_m = HenyeyGreenstein(cos_theta, kMieG);
```

レイを `steps` 個に分け歩幅を決めます。レイリー散乱とミー散乱の積分を別々に貯め、視線方向の光学的厚さ `optical_depth_view` も、足していきます。位相関数は散乱の向きによる明るさで、レイ全体で同じ角度なのでループの外で、1 度だけ求めます。

```hlsl
  for (int i = 0; i < steps; ++i) {
    float3 p = ray_origin + ray_dir * (i + 0.5) * step_length;
    float h = length(p) - kPlanetRadius;
    float density_r = exp(-h / kRayleighScaleHeight);
    float density_m = exp(-h / kMieScaleHeight);

    optical_depth_view += (kRayleighScattering * density_r + kMieExtinction * density_m) * step_length;
```

区間の中点の位置を求め惑星の中心からの高さに、直します。高さが上がるほど空気は指数関数的に、薄くなるので `exp(−高さ / スケール高さ)` で密度を求めます。視線に沿ってここまでの光学的厚さを、足します。

```hlsl
    float3 optical_depth_sun = SunOpticalDepth(p, sun_dir);
    float3 attenuation = exp(-(optical_depth_view + optical_depth_sun));
```

太陽からこの点までの光学的厚さを、求め（別の関数）、視線側と足して減衰をビア・ランベルトの法則で、求めます。

```hlsl
    rayleigh_sum += attenuation * density_r * step_length;
    mie_sum += attenuation * density_m * step_length;
  }
```

減衰した光に密度と歩幅を掛けて積分に、足します。

```hlsl
  return sun_intensity * (kRayleighScattering * phase_r * rayleigh_sum
                        + kMieScattering * phase_m * mie_sum);
}
```

コードの要点です。`SunOpticalDepth` は点 p から太陽方向へ、大気の外まで進んだ光学的厚さで、内側のループです。地面で遮られる向きは 0 として扱います。二重ループになるので視線 16 ステップに太陽 8 ステップで 128 回の密度計算が必要になり、リアルタイムには重い処理です。レイリーとミーは位相関数が違うため、別々に足します。

## 1 回散乱の積分

<strong>カメラに届く光</strong>を考えます。太陽の光は 大気の外から来て、視線の途中のある点で 1 回だけ散乱し、カメラの方向へ向きを変えます。この 1 回散乱の光を視線に沿って、すべての点について足し合わせるのが、1 回散乱の積分です（Nishita ら、1993）。

```text
L(x, v) = ∫₀^D  T(x → p(s))  ×  σ_s(p(s))  ×  Σ [ P(θ) × E_sun × T(p(s) → 大気の外) ]  ds
```

| 項 | 意味 |
| --- | --- |
| `T(x → p(s))` | 点 `p(s)` からカメラ `x` までの、透過率（散乱した光がカメラまで、届く割合） |
| `σ_s(p)` | 点 `p` での散乱係数（密度に、比例） |
| `P(θ)` | 位相関数（太陽の光が、視線の方向へ散る割合） |
| `E_sun` | 太陽の光の強さ |
| `T(p → 外)` | 点 `p` から太陽方向への、透過率（太陽の光が点 `p` まで、届く割合） |

3 つの透過率の掛け算です。太陽 → 点 `p`（太陽の光が、点まで来る）、点 `p` で散乱、点 `p` → カメラ（散乱した光が、カメラまで来る）。

## 実装：視線に沿ったループ

```hlsl
// 視線（カメラ位置 origin、方向 dir、長さ ray_length）に沿って、1 回散乱を積分する。
float3 SingleScattering(float3 origin, float3 dir, float ray_length, float3 sun_dir, float3 sun_illuminance) {
  const int kSteps = 32;
  float step_len = ray_length / kSteps;
```

視線を <strong>32 区間に分けて</strong>、各区間の 中央で評価します。`step_len` は 1 区間の長さです。

```hlsl
  float cos_theta = dot(dir, sun_dir);                    // 視線と太陽の間の角度（太陽が、視線の向こうにあるとき 1）
  float phase_r = RayleighPhase(cos_theta);
  float phase_m = CornetteShanks(cos_theta, 0.8);
```

位相関数は 視線と太陽の間の角度だけで決まり、視線に沿って一定なのでループの外で、1 回だけ計算します。

```hlsl
  float3 sum = 0.0;                                       // 散乱光の、積算
  float3 throughput = 1.0;                                // 視線に沿った、ここまでの、透過率（カメラ → 点）
  for (int i = 0; i < kSteps; ++i) {
    float3 p = origin + dir * ((i + 0.5) * step_len);
    float h = length(p) - g_planet_radius;
    float density_r = exp(-h / 8000.0);
    float density_m = exp(-h / 1200.0);
```

ループの中で 点 `p` の高度から、レイリーとミーの密度を求めます。

```hlsl
    // この区間での、消散（吸収 + 散乱）で、視線の光が、どれだけ減るか。
    float3 sigma_t = g_rayleigh_scatter * density_r + g_mie_extinction * density_m;
    float3 step_transmittance = exp(-sigma_t * step_len);
```

区間を通るときの透過率です。これを `throughput` に掛けていくことで、カメラから各点までの透過率が順に、求まります（区間ごとの透過率の積）。

```hlsl
    // 太陽方向の透過率（LUT から）。大気の外から、この点まで、太陽の光が届く割合。
    float3 sun_t = SunTransmittance(p, sun_dir);
```

太陽の光が点 `p` まで届く割合を、透過率 LUT（[Transmittance](transmittance.md)）から、1 回の読み込みで得ます。

```hlsl
    // この点で、視線の方向に、散乱される光。
    float3 scatter = (g_rayleigh_scatter * density_r * phase_r + g_mie_scatter * density_m * phase_m) * sun_t * sun_illuminance;
```

散乱係数 × 位相関数 × 太陽の光が、この点で視線の方向へ散る光です。レイリーとミーを別々の位相関数で、足します。

```hlsl
    // 区間内の、積分（解析的に、減衰を考慮した形）を、足し込む。throughput は、カメラまでの、透過率。
    float3 scatter_integral = (scatter - scatter * step_transmittance) / max(sigma_t, 1e-6);
    sum += throughput * scatter_integral;
    throughput *= step_transmittance;
  }
  return sum;
}
```

区間の中でも、光は進むほど減るので区間の中の積分を、解析的に計算します（`(1 − exp(−σ_t Δs)) / σ_t`）。Hillaire（2020）が区間が、粗くてもエネルギーを保つために、使っている改良です。単純に `scatter × step_len` を足す方法よりステップ数が、少なくても安定します。

## 地面に当たる場合

視線が <strong>地面に当たる</strong>場合は、地面までで積分を止め、地面の色を足します（地平線の、下を向いている空ではなく地面を見ている場合）。

```hlsl
float2 t_ground = RaySphere(origin, dir, g_bottom_radius);
float2 t_top = RaySphere(origin, dir, g_top_radius);
float ray_length = (t_ground.x > 0.0) ? t_ground.x : t_top.y;       // 地面に当たるなら、そこまで。そうでなければ、大気の上端まで
```

| 視線の向き | 積分する範囲 |
| --- | --- |
| 空へ向かう | カメラ → 大気の上端 |
| 地面へ向かう | カメラ → 地面 |
| カメラが宇宙にある | 大気の入口から上端、または地面まで |

## 1 回散乱の限界

<strong>1 回だけ</strong>散乱した光を足し合わせた空は、見た目が暗く、不自然です（特に太陽が低いとき日陰、夜明け日没後）。現実の大気では光が何度も散乱して、空全体が明るくなります（[Multiple Scattering](multiple-scattering.md)）。

| 状況 | 1 回散乱のみ | 実際 |
| --- | --- | --- |
| 昼の空 | やや暗い（青が、足りない） | 明るい青 |
| 夕焼けの反対側の空 | 暗い | 青紫に、うっすら明るい |
| 太陽が地平線の下 | ほぼ、真っ暗 | しばらく空が明るい（薄明） |
