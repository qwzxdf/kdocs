# Where to Apply Fog

**フォグは、屋外では重要ですが、夜や屋内では、使い方を変える必要があります**。このページでは、**フォグを適用する場所と、夜・閉所の扱い**を説明します。

!!! tip "ポイント"
    - **不透明・半透明の両方に、フォグを適用**する。
    - **加算ブレンドは、フォグで黒に近づける**。
    - **夜は、フォグを暗い色に**。
    - **屋内は、フォグを弱める・別設定**にする。

## 適用する場所
フォグを適用する場所は 4 つあります。<strong>フル スクリーン パス</strong>は、不透明描画の後に、深度から位置を再構築して一括で適用する方法で、簡単です。<strong>マテリアルのシェーダー内</strong>は、各物体のピクセル シェーダーでフォグを適用する方法で、半透明にも自然に適用できます。<strong>半透明</strong>は、深度バッファに無いので、物ごとにシェーダー内で適用します（パーティクル、ガラスなど）。いずれも、<strong>ポストプロセスの前</strong>の HDR リニア空間で行います。

**加算ブレンドの物**は、**フォグの色を足さず、透過率だけ掛けます**（**霞の中で光が薄まるだけ**）。**足すと遠くの加算パーティクルが白く浮きます**。

## 夜と閉所
夜と閉所の扱いです。夜は、フォグの色を暗くし、月明かりで少しだけ明るくします。室内は、フォグを薄くするか、区画ごとに変えます（ボリューム フォグ）。洞窟や屋内の区画では、区画（ボリューム）ごとにフォグの設定を持ち、境界で補間します。ライトの周りだけ霧が光る表現は、ボリューメトリック フォグを使います（[Volumetric Fog](../volumetric-fog/index.md)）。

### 設計上の注意

フォグは、どこにどのように適用するかで、見た目の一貫性が大きく変わります。まず、<strong>すべての描画物に適用すること</strong>が基本です。不透明物だけにフォグをかけて、パーティクルや半透明の物にかけないと、遠くの煙や窓ガラスが、霞の中で不自然に浮き出ます。

次に、<strong>描画の順番と合成方法</strong>です。通常のアルファ ブレンドの物は、シェーダーの出力色にフォグを適用してからブレンドします。加算ブレンドの物（炎、光）は、フォグの色を足すのでなく、<strong>透過率だけを掛けて</strong>薄めます。霞の中で光が減衰するだけだからです。フォグの色を足すと、遠くの加算パーティクルが白く浮いてしまいます。

また、<strong>空</strong>にもフォグを適用するかを決めます。空は無限遠にあり、フォグの色の源でもあるので、通常は空にフォグを重ねません。ただし、雲や星のような空の中の物は、地平線付近でフォグがかかるように調整することがあります。

## よくあるミス

??? failure "半透明の物だけ、フォグがかかっていない"
    **半透明にも、フォグを適用**する。
