# スクリーン空間の可視性

**AO の式の中の可視性 V（その方向が、遮られているか）**を、**スクリーン空間の AO では、深度バッファだけから推定**します。**見えている面の深度しか分からない**ので、**「画面に写らない裏側」は分からず、推定には限界**があります。このページでは、**深度バッファから V を求める考え方・限界**を説明します。

!!! tip "ポイント"
    - **スクリーン空間では、深度バッファが、唯一のジオメトリ情報**。
    - **サンプル点を画面に投影し、その点の深度とバッファの深度を比べる**。
    - **限界**：**画面外・薄い物の裏側・遮蔽物の厚み**は**分からない**。
    - **これがハロー・画面端の欠点**につながる（[アーティファクト](../artifacts/index.md)）。

## スクリーン空間では、V をどう求めるか
本来の V(ω) は、**方向 ω にレイを飛ばして、シーンに当たるかを調べる**ものです。しかし、**深度バッファ**から求まるのは、**画面から見える、一番手前の面**の情報だけです。そこで<strong>スクリーン空間 AO（SSAO）</strong> は、V を次のように代用します。

| 本来 | スクリーン空間での代用 |
| --- | --- |
| 方向 ω に遮蔽物があるか | **p の近くの点 s**（p から ω 方向にずらした点）を**画面に投影**し、**その画素の深度**と比べて、**s が面の奥にあれば、遮られている**とみなす |
| 遮蔽物の表面 | 深度バッファが示す、**画面から見える面** |

この代用には避けられない誤差があります。

| 誤差の原因 | 起きること |
| --- | --- |
| **画面に映らない物は、遮蔽物にならない** | カメラの後ろ・画面外の壁・隠れた物は、AO に寄与しない |
| **深度バッファは、手前の面だけ** | 薄い柱の**後ろ側**は、柱が「厚い」とみなされ、**必要以上に暗く**なる（ハロー） |
| <strong>深度は 1 枚の面（高さ場）</strong> | 面の**裏側・内部**は分からない |
| **解像度が有限** | 小さな物体・細い隙間は**取りこぼす** |

これらの誤差は、**スクリーン空間の手法**であるかぎり、どの方式（SSAO・HBAO・GTAO）でも同じです。方式の違いは**誤差を小さく、速く**する工夫にあります。**誤差を根本から無くす**なら、**シーンを直接調べる**方式（[レイトレ AO・距離場 AO](../world-space/index.md)）が必要です。
