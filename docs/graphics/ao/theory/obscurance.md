# オブスキュランス

**AO の式は、遠くの物（部屋の反対側の壁）まで「遮蔽」と数えます**。**しかし実際には、遠い物は、近い物ほどは光を遮らない**ので、**距離で遮蔽を弱める**のが**オブスキュランス（Obscurance）**です。**多くの実装は、実はオブスキュランスに近い**ものです。このページでは、**距離の減衰を足す考え方**を説明します。

!!! tip "ポイント"
    - **オブスキュランス ＝ AO に、距離による減衰を加えたもの**。
    - **半径（影響範囲）を決め、それより遠い物は無視**する。
    - **減衰の関数**：**線形・二次・指数**。
    - **スクリーン空間の AO は、半径があるので、実質オブスキュランス**。

## オブスキュランス：距離の減衰を足す
上の AO は、**どれだけ遠くの遮蔽物でも**、方向を塞いでいれば遮蔽とみなします。これでは**屋外の広い場所で遠くの山に遮られて、全体が暗くなる**といった不都合が起きます。そこで**近くの遮蔽だけ**を効かせます。それが**オブスキュランス**（obscurance）です。

<div class="formula">AO = (1 / π) · ∫ ρ(d(ω)) · (n·ω) dω</div>

- <strong>d(ω)</strong>：方向 ω に最初に当たる物体までの距離。
- <strong>ρ(d)</strong>：距離の関数。<strong>近いほど 1（強く遮る）</strong>、<strong>遠いほど 0（無視）</strong>。
- **ρ の例**：`ρ(d) = max(0, 1 − d² / R²)`（R は影響半径）。

実際のスクリーン空間 AO は、**ほぼすべて**この「半径 R 以内の遮蔽だけを見る」形です。**半径 R が見た目の調整パラメータ**になります。

| 半径の大きさ | 見た目 |
| --- | --- |
| **小さい** | 接地・小さな隙間だけが暗い。細かいディテールが際立つ |
| **大きい** | 大きな陰影。部屋全体がどんよりする。**サンプルも増える** |

## よくあるミス

??? failure "AO の半径が大きすぎて、全体が暗く汚い"
    **半径を、ゲームのスケールに合わせて小さく**。
