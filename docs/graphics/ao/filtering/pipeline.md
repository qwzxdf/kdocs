# Typical Pipeline

**ここまでの技法を組み合わせた、典型的な AO のパイプライン**を**見ます**。**低解像度で計算 → 時間蓄積 → 空間フィルタ → アップサンプル**の**順**が**標準**で、**各段のパラメータの目安**も**あります**。このページでは、**組み合わせの順序とパラメータの目安**を説明します。

!!! tip "ポイント"
    - **順序**：**① 半解像度で AO 計算 → ② 時間蓄積 → ③ バイラテラル ブラー → ④ アップサンプル**。
    - **ブラーの半径は 4〜8 画素**。**サンプル数は 4〜16**。
    - **品質設定で、解像度とサンプル数を変える**。
    - **全体で 0.3〜1 ms**（1080p）が**目安**。

## 組み合わせ：典型的なパイプライン
| 順番 | 内容 |
| --- | --- |
| **① AO の計算** | 少ないサンプル、画素・フレームごとにノイズの向き |
| **② 空間フィルタ** | **バイラテラル ブラー**（小さな半径で、1〜2 回） |
| **③ 時間蓄積** | 再投影・検証・混ぜる |
| **④ （低解像度なら）アップサンプル** | **ジョイント バイラテラル** |
| **⑤ 適用** | 間接光に掛ける |

**順番は実装で変わります**（空間 → 時間、時間 → 空間）。**ゴーストを避けるため、時間蓄積を空間フィルタの前に置く**構成もあります。

## パラメータの目安
| パラメータ | 目安 |
| --- | --- |
| **ブラーの半径** | 2〜4 画素 |
| **深度の鋭さ** | 境界でにじみが出なくなる最小の値 |
| **時間蓄積の α** | 0.05〜0.2 |
| **深度の棄却しきい値** | 相対 5% 程度 |
| **ノイズ** | IGN またはブルー ノイズ。フレームごとに位置をずらす |

## よくあるミス

??? failure "段の順序を間違えて、ノイズが残る・にじむ"
    **計算 → 時間 → 空間 → アップサンプル**の順にする。
