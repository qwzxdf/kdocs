# Typical Pipeline

<strong>ここまでの技法を組み合わせた、典型的な AO のパイプライン</strong>を<strong>見ます</strong>。低解像度で計算 → 時間蓄積 → 空間フィルタ → アップサンプルの順が標準で、各段のパラメータの目安もあります。このページでは、組み合わせの順序とパラメータの目安を説明します。

!!! tip "ポイント"
    - 順序：① 半解像度で AO 計算 → ② 時間蓄積 → ③ バイラテラル ブラー → ④ アップサンプル。
    - ブラーの半径は 4〜8 画素。サンプル数は 4〜16。
    - 品質設定で、解像度とサンプル数を変える。
    - 全体で 0.3〜1 ms（1080p）が目安。

## 全体の流れ

これまでの技法は、1 本のパイプラインとして組み合わせて使います。典型的な構成を、順番に説明します。

<strong>① 低解像度で AO を計算する</strong>。深度と法線を縦横 1/2 に縮小（画素数では 1/4）して、AO を計算します。AO は低周波の量なので、解像度を下げても見た目の損失が小さく、コストはほぼ 1/4 になります。縮小のときは、深度を平均せず代表の 1 点を選びます（[SAO](../sao.md)）。画素ごと・フレームごとに、サンプルの向きを変えます（[Noise Patterns](noise-pattern.md)）。

<strong>② 時間蓄積</strong>。前フレームの結果を再投影して混ぜ、ノイズを減らします（[Temporal Accumulation](temporal.md)）。履歴が使えない画素は、フラグを立てておきます。

<strong>③ バイラテラル ブラー</strong>。深度と法線の近い画素だけを平均して、残ったノイズを均します（[Bilateral Blur](bilateral-blur.md)）。履歴の使えなかった画素は、ブラーの範囲を広げて補います。

<strong>④ アップサンプル</strong>。低解像度の AO をフル解像度に戻します。単純な双線形補間だと輪郭で AO がにじむので、フル解像度の深度を見ながら補間する<strong>ジョイント バイラテラル</strong>で戻します（[Upsampling](upsample.md)）。

<strong>⑤ 適用</strong>。最終的な AO を、間接光（環境光）に掛けます（[Application Mistakes](../artifacts/application-mistakes.md)）。

### 順番について

時間蓄積とブラーの順番は、実装によって異なります。「空間 → 時間」の構成では、ブラーしたものを履歴に混ぜるので、ノイズが入る前の安定した値が履歴に溜まります。逆に「時間 → 空間」の構成は、時間蓄積で十分に減ったノイズを、最後にブラーで仕上げます。履歴にブラーの結果を混ぜると、にじみが履歴に残ってゴーストが強くなることがあるため、後者を採る実装もあります。どちらが良いかはシーン次第なので、<strong>両方を切り替えて見比べる</strong>のが確実です。

## パラメータの目安

初期値の目安は、次のとおりです。

* ブラーの半径は、2〜4 画素。大きいほど滑らかですが、細部が消えます。
* 深度に対する鋭さは、輪郭でにじみが出なくなる<strong>最小の値</strong>にします。鋭くしすぎると、ブラーが効かずにノイズが残ります。
* 時間蓄積のブレンド率 α は、0.05〜0.2。小さいほど滑らかですが、残像が出やすくなります。
* 深度による履歴の棄却は、相対差 5 % 程度。
* ノイズは IGN かブルー ノイズを使い、フレームごとに位置をずらします。

全体のコストは、1080p で 0.3〜1 ms 程度が目安です。品質設定は、<strong>解像度（フル / 1/2）とサンプル数（4 / 8 / 16）</strong>の 2 つの軸で切り替えるのが一般的です。低品質では 1/2 解像度で 4 サンプル、高品質ではフル解像度で 16 サンプルのように分けます。
