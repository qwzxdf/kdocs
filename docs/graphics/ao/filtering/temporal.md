# Temporal Accumulation

**1 フレームのサンプル数が少なくても、毎フレーム違うサンプルで計算して、過去のフレームの結果と混ぜれば、時間をかけて、サンプルが蓄積されます**。これが**時間蓄積**です。**カメラや物が動くと、過去の結果は位置がずれるので、速度（動きのベクトル）で再投影**し、**合わなければ捨てます**。このページでは、**再投影・履歴の拒否・ブレンド率・ゴースト対策**を説明します。

!!! tip "ポイント"
    - **毎フレーム違うサンプル ＋ 前フレームの結果と混ぜる**＝**サンプルが蓄積**。
    - **速度バッファで、前フレームの位置を求める**（[Velocity Buffer](../../postprocess/motion-blur/velocity-buffer.md)）。
    - **深度・法線が合わない履歴は拒否**（**ゴースト対策**）。
    - **ブレンド率は 0.05〜0.1**（**履歴 90〜95 %**）。

## 時間蓄積とは

AO を毎フレーム 8 サンプルで計算し、前のフレームの結果と平均すれば、数フレームで実質的に数十サンプルを使ったのと同じ精度になります。これが時間蓄積です。[TAA](../../postprocess/antialiasing/taa.md) と全く同じ発想で、サンプルを空間（1 画素の中）でなく時間（複数フレーム）に分散させて集めます。

静止しているなら、前のフレームの同じ画素の値をそのまま使えます。難しいのは<strong>動くとき</strong>です。カメラが動けば、画面上の同じ場所に映る物が変わります。前のフレームの同じ画素ではなく、<strong>「今映っている点が、前のフレームでは画面のどこにあったか」</strong>を調べ、その位置の値を読む必要があります。これが再投影です。

## 手順

### ① 再投影

今の画素の点が、前のフレームで画面のどこにあったかを求めます。方法は 2 つあります。

* <strong>動きベクトル（速度バッファ）</strong>を使う。画素ごとに「前のフレームでの位置との差」が書かれていて、物体の動きも含めて扱えます（[Velocity Buffer](../../postprocess/motion-blur/velocity-buffer.md)）。
* <strong>深度とカメラ行列</strong>から求める。今の深度で点のワールド位置を復元し、前フレームのビュー射影行列で変換します。カメラの動きだけに対応し、動く物体には使えません。

### ② 履歴を読む

求めた位置から、前フレームの AO を読みます。位置が画素の中心にぴったり合うことはないので、バイリニアで補間して読みます。補間はわずかなボケを生むため、毎フレーム繰り返すと次第に広がります（TAA と同じ問題で、鮮明さを保ちたい場合は、バイキュービックで読みます）。

### ③ 履歴の検証

読んだ履歴が<strong>今の点と同じ面の値か</strong>を確かめます。動いた物体の背後から現れた場所は、前のフレームでは別の物体が映っていたので、その履歴は無関係です。前フレームの深度・法線と今のそれを比べ、違いが大きければ履歴を捨てます。

### ④ 混ぜる

<div class="formula">AO = lerp(履歴, 今の結果, α)</div>

α が小さいほど履歴を重視して滑らかになりますが、変化への追従が遅れます。0.05〜0.2 が目安です。

```hlsl
float TemporalAO(float2 uv, float current_ao) {
  float2 history_uv = Reproject(uv);
  float history_ao = history_tex.SampleLevel(linear_sampler, history_uv, 0).r;
  float history_z = history_depth_tex.SampleLevel(point_sampler, history_uv, 0).r;

  float depth_diff = abs(LinearDepth(uv) - history_z) / LinearDepth(uv);
  bool valid = all(saturate(history_uv) == history_uv) && depth_diff < 0.05;

  float alpha = valid ? 0.1 : 1.0;
  return lerp(history_ao, current_ao, alpha);
}
```

このコードのポイントは次のとおりです。再投影した位置が画面の外（0〜1 の外）なら履歴はないので α = 1（今の結果だけ）にします。深度の差は、<strong>相対値</strong>で比べます。遠い所は、絶対値で比べると誤差に埋もれるからです。

### 履歴の長さに応じた α

固定の α の代わりに、<strong>履歴の長さ n（何フレーム分溜まっているか）</strong>を数えて α = 1/(n+1) にする方法があります。これは単純平均と同じで、n が小さい（履歴が新しい）うちは今の結果を大きく取り込み、n が大きくなるほど履歴を重視します。履歴が捨てられたら n を 0 に戻します。α を下限（たとえば 0.05）で止めれば、長く溜めても追従性が残ります。起動直後や、物が現れた直後でも素早く収束するのが利点です。

## ゴーストとその対策

時間蓄積の最大の弱点は<strong>ゴースト</strong>です。動く物体の跡に、前の位置の AO が残像のように残ります。

主な対策を、状況別に整理します。

動く物体には、<strong>動きベクトルで再投影</strong>するのが基本です。動きベクトルがなければ、深度と法線の差で履歴を拒否して、尾を引かないようにします。カメラが急に切り替わったときは、履歴を全部捨てます。履歴が捨てられた画素は、サンプル数が足りずノイズが目立つので、<strong>その画素だけ空間フィルタを強める</strong>とよいでしょう。ライトの変化には、AO はライトに依存しないので影響を受けません。形が変わるとき（ドアが開く、物が動く）だけが問題です。

## 分散のクランプ

最後に、一歩進んだ工夫です。TAA の<strong>近傍クランプ</strong>と同じように、今のフレームの周囲の画素の最小値・最大値（あるいは平均と分散）を求め、履歴の値をその範囲に収めます。範囲から外れた履歴は、今のフレームの状況と明らかに合わないので、「古い値の暴走」だと見なして範囲の端まで引き戻します。ゴーストの多くをこれで抑えられます。AO は 1 チャンネルのスカラーなので、実装は簡単です。

## よくあるミス

??? failure "動く物の後ろに、AO の残像（ゴースト）が出る"
    **深度・法線で、履歴を拒否**する。
