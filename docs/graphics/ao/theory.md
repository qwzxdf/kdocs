# AO の理論

AO の各方式（SSAO・HBAO・GTAO など）は、**同じ 1 つの積分を別々の方法で近似したもの**です。このページでは、その積分がどこから出てくるのかを、レンダリング方程式から順に導きます。式を一度理解しておくと、後の方式が「何を省略して、何を残したのか」として読めるようになります。

!!! tip "ポイント"
    - 面の上の 1 点 p（法線 n）に届く、**周囲からの光**（間接光）を考える。**天球が一様に明るい**と仮定すると、<strong>光の量は「可視な方向のコサイン重み付きの割合」</strong>で決まる。
    - これが <strong>AO ＝ (1/π) ∫ V(ω) (n·ω) dω</strong>（0〜1）。<strong>V は方向 ω が遮られていないか</strong>（1 または 0）。
    - 遮蔽物が<strong>遠すぎる</strong>と無視したい。<strong>距離の減衰</strong>を足したものが<strong>オブスキュランス</strong>。
    - 積分を<strong>モンテカルロ法</strong>で近似するのが、サンプルを使う方式。<strong>解析的に近似</strong>するのが Alchemy・HBAO・GTAO。
    - <strong>可視性 V は、本来、シーン全体のレイキャスト</strong>。スクリーン空間では<strong>深度バッファで代用</strong>する（ここで誤差が生まれる）。
    - AO は<strong>間接光だけ</strong>に掛ける。直接光に掛けない。

## 出発点：レンダリング方程式

面上の点 p から、方向 ω_o へ出ていく光の量 L_o は、次の式で表されます。

<div class="formula">L_o(p, ω_o) = ∫ f_r(p, ω_i, ω_o) · L_i(p, ω_i) · (n·ω_i) dω_i　（積分は法線 n 側の半球 Ω）</div>

| 記号 | 意味 |
| --- | --- |
| <strong>L_i(p, ω_i)</strong> | 方向 ω_i から点 p に届く光の強さ（入射放射輝度） |
| **f_r** | 面の反射の仕方（BRDF）。物体の色・粗さ・金属度で決まる |
| **n·ω_i** | 入射方向と法線のなす角のコサイン。**斜めから来る光ほど、面を照らす量が少ない** |

### 面が拡散反射だけの場合

拡散反射（ランバート）では、`f_r = ρ / π`（ρ はアルベド）で、**方向によらず一定**です。式は次のように簡単になります。

<div class="formula">L_o = (ρ / π) · ∫ L_i(ω_i) · (n·ω_i) dω_i</div>

## 天球が一様に明るいと仮定する

AO では**周囲の明るさを一様**（どの方向からも同じ強さ L_sky）と仮定します。遮られていなければ、空の光がそのまま届きます。遮られている方向からは、**空の光が来ません**（遮蔽物自体の明るさは、ここでは考えません）。

そこで**可視性** V(ω) を導入します。

| V(ω) | 意味 |
| --- | --- |
| **1** | ω 方向に遮蔽物がなく、空が見える |
| **0** | ω 方向が近くの物体で遮られている |

すると入射光は `L_i(ω) = L_sky · V(ω)` となり、出ていく光は次のとおりです。

<div class="formula">L_o = (ρ / π) · L_sky · ∫ V(ω) · (n·ω) dω</div>

**何も遮られていない**（V = 1）場合の積分は半球全体のコサイン重み付きの立体角で、**ちょうど π** になります。

<div class="formula">∫ (n·ω) dω = π　（半球全体）</div>

そのため、遮蔽のない面の明るさは `ρ · L_sky` になります。**遮蔽がある面の遮蔽のない面に対する比**を、**AO の値**と定義します。

<div class="formula">AO(p, n) = (1 / π) · ∫ V(ω) · (n·ω) dω　（0 〜 1）</div>

- **1**：遮蔽なし（完全に明るい）。
- **0**：すべての方向が遮られている（真っ暗）。
- 平らな床の上の点は、**ほぼ 1**。壁との角の点は、**約 0.5**、部屋の隅（3 面が交わる所）は、**約 0.3 前後**になります。

!!! note "なぜコサインが付くのか"
    斜めに入ってくる光は、面を**薄く**照らします（同じ光の束が広い面積に広がるため）。その効果が `n·ω` です。**真上（法線の方向）の遮蔽は横の遮蔽より、明るさに効きます**。この重みが、AO の見た目の自然さにつながり、後の GTAO では、**この重みを正しく扱う**ことが改善点の 1 つになります。

## 球面座標での書き直し

半球の方向 ω を**法線を軸にした角度**で表します。法線からの角度を θ（0 〜 π/2）、方位角を φ（0 〜 2π）とすると、`n·ω = cosθ`、`dω = sinθ dθ dφ` です。

<div class="formula">AO = (1 / π) · ∫₀^{2π} ∫₀^{π/2} V(θ, φ) · cosθ · sinθ  dθ dφ</div>

**V がすべて 1** なら、`∫ cosθ sinθ dθ = 1/2`、`∫ dφ = 2π` で、`AO = (1/π)(2π)(1/2) = 1` となり、先ほどの結論と合います。

## オブスキュランス：距離の減衰を足す

上の AO は、**どれだけ遠くの遮蔽物でも**、方向を塞いでいれば遮蔽とみなします。これでは**屋外の広い場所で遠くの山に遮られて、全体が暗くなる**といった不都合が起きます。そこで**近くの遮蔽だけ**を効かせます。それが**オブスキュランス**（obscurance）です。

<div class="formula">AO = (1 / π) · ∫ ρ(d(ω)) · (n·ω) dω</div>

- <strong>d(ω)</strong>：方向 ω に最初に当たる物体までの距離。
- <strong>ρ(d)</strong>：距離の関数。<strong>近いほど 1（強く遮る）</strong>、<strong>遠いほど 0（無視）</strong>。
- **ρ の例**：`ρ(d) = max(0, 1 − d² / R²)`（R は影響半径）。

実際のスクリーン空間 AO は、**ほぼすべて**この「半径 R 以内の遮蔽だけを見る」形です。**半径 R が見た目の調整パラメータ**になります。

| 半径の大きさ | 見た目 |
| --- | --- |
| **小さい** | 接地・小さな隙間だけが暗い。細かいディテールが際立つ |
| **大きい** | 大きな陰影。部屋全体がどんよりする。**サンプルも増える** |

## 積分を近似する 3 つのやり方

AO は**積分**なのでそのままでは計算できません。次の 3 通りの近似があります。

| 近似 | 考え方 | 代表的な方式 |
| --- | --- | --- |
| **① モンテカルロ法** | 半球から方向（またはサンプル点）を**ランダムに N 個**選び、**遮られているかを数えて割合を出す** | Crytek SSAO・半球 SSAO・レイトレ AO |
| **② 地平線（ホライゾン）の積分** | **方向を決めて**、その方向で<strong>遮蔽が始まる角度（地平線）</strong>を探し、**間の角度を解析的に積分** | HBAO・HBAO+・GTAO |
| **③ 式の近似** | 遮蔽物の表面の点ごとに、**影響を表す簡単な式**を足し合わせる | Alchemy・SAO |

### ① モンテカルロ法

`AO = (1/π) ∫ V (n·ω) dω` を**コサイン重みの分布**（pdf = cosθ / π）で方向をサンプルすると、`(n·ω)` が**打ち消され**、次のようになります。

<div class="formula">AO ≈ (1 / N) · Σ V(ω_i)　（ω_i はコサイン分布のサンプル）</div>

つまり、**コサイン分布で半球から方向を選び、遮られていない割合を数える**だけです。N が大きいほど正確で、**誤差は 1/√N で減ります**。

**サンプル数 N が少ない**と、結果が**ノイズ**だらけになります。リアルタイムでは N が 8〜16 程度なので、**ノイズをぼかしや時間蓄積で消す**のが前提です（[フィルタ](filtering.md)）。

### ② 地平線の積分

**サンプルを点でなく、方向の線（スライス）にして、解析的に積分**します。半球を**スライスに分け**、各スライスで<strong>「遮蔽が始まる地平線の角度」</strong>を見つければ、**スライス内の積分は、角度の関数として、閉じた式**で求まります。サンプル数を減らして精度を保てる、というのが利点です（[HBAO](hbao.md)・[GTAO](gtao.md)）。

### ③ 式の近似

遮蔽物の表面の各点 q が、点 p を**どれだけ遮るか**を、**p から q へのベクトル**だけで書く、簡単な式に置き換えます。サンプル点ごとにその式を足すだけで AO が出ます（[Alchemy](alchemy-ao.md)・[SAO](sao.md)）。

## スクリーン空間では、V をどう求めるか

本来の V(ω) は、**方向 ω にレイを飛ばして、シーンに当たるかを調べる**ものです。しかし、**深度バッファ**から求まるのは、**画面から見える、一番手前の面**の情報だけです。そこで<strong>スクリーン空間 AO（SSAO）</strong> は、V を次のように代用します。

| 本来 | スクリーン空間での代用 |
| --- | --- |
| 方向 ω に遮蔽物があるか | **p の近くの点 s**（p から ω 方向にずらした点）を**画面に投影**し、**その画素の深度**と比べて、**s が面の奥にあれば、遮られている**とみなす |
| 遮蔽物の表面 | 深度バッファが示す、**画面から見える面** |

この代用には避けられない誤差があります。

| 誤差の原因 | 起きること |
| --- | --- |
| **画面に映らない物は、遮蔽物にならない** | カメラの後ろ・画面外の壁・隠れた物は、AO に寄与しない |
| **深度バッファは、手前の面だけ** | 薄い柱の**後ろ側**は、柱が「厚い」とみなされ、**必要以上に暗く**なる（ハロー） |
| <strong>深度は 1 枚の面（高さ場）</strong> | 面の**裏側・内部**は分からない |
| **解像度が有限** | 小さな物体・細い隙間は**取りこぼす** |

これらの誤差は、**スクリーン空間の手法**であるかぎり、どの方式（SSAO・HBAO・GTAO）でも同じです。方式の違いは**誤差を小さく、速く**する工夫にあります。**誤差を根本から無くす**なら、**シーンを直接調べる**方式（[レイトレ AO・距離場 AO](world-space.md)）が必要です。

## 方式を分けるもの

| 観点 | 例 |
| --- | --- |
| **積分の近似法** | モンテカルロ・地平線・式の近似 |
| **コサイン重み** | 正しく入れるか（GTAO）、省略するか（HBAO は立体角の割合） |
| **必要な入力** | 深度のみ（Crytek SSAO・SAO・HBAO+ の一部）、深度＋法線（半球・Alchemy・HBAO・GTAO） |
| **サンプルの配置** | 球・半球・螺旋・方向ごとのステップ |
| **メモリ アクセスの工夫** | ミップ（SAO）・デインターリーブ（HBAO+） |
| **後処理** | ぼかし・時間蓄積・アップサンプル |

## AO の使い方

| 項目 | 説明 |
| --- | --- |
| **掛ける相手** | **間接光（環境光）だけ**。**直接光（ライトの当たり）には掛けない**。AO はライトを考えていない量なので、直接光に掛けると**照らされている所まで暗く**なる |
| **IBL との組み合わせ** | 環境光 ＝ IBL の拡散項。**AO を拡散項に掛ける**。反射項には**スペキュラ遮蔽**（[GTAO](gtao.md)）を使う |
| **テクスチャの AO と併用** | メッシュに焼いた AO テクスチャ（**マイクロ AO**）と、スクリーン空間 AO（**マクロ AO**）を**掛け合わせる**。細かいくぼみは焼いた AO、物体どうしの接触は SSAO |
| **ガンマ** | AO は**線形の光の量**。**リニア空間で掛ける**（[色の数学](../../gamemath/color.md)） |
| **強さの調整** | `pow(AO, 指数)` で、コントラストを調整する（指数が大きいほど、暗い所が濃くなる） |

```hlsl
float3 ambient = irradiance * albedo * ao;
float3 color = direct_light + ambient;
```

## よくある誤解

??? failure "AO は、ライトの影の代わりになる"
    AO は**ライトを考慮しない**ので、**影の向きを表せません**。接地感を出すだけで**光源の方向による影**は、シャドウ マップなどで別に作ります。

??? failure "AO をシーン全体に掛けて、明るい場所まで暗くなる"
    **間接光だけ**に掛けます。直接光に掛けると**日向まで暗く**なります。

??? failure "半径を大きくして、広い範囲の陰影を出そうとする"
    半径に比例して、サンプルの取りこぼしとコストが増えます。大きな陰影は**間接光の方式**（[GI](../index.md)）や、ライトマップの役目です。
