# 画面端と薄い物体

**スクリーン空間の AO には、構造的な弱点**が**2 つ**あります。**画面の端では、画面外の情報がないため AO が欠け**、**薄い物体（柵・葉）は、厚みが分からず、後ろの面を誤って遮蔽する**ことです。このページでは、**画面端の対策（保守的な扱い・拡張）・薄い物体の対策（厚みの仮定）**を説明します。

!!! tip "ポイント"
    - **画面端 ＝ 画面外の深度が無く、AO が欠ける**。
    - **対策**：**範囲外のサンプルは、遮蔽なしとして扱う**、**画面を少し広く描く（オーバースキャン）**。
    - **薄い物体 ＝ 厚みが分からず、後ろを遮る**。
    - **対策**：**厚みを仮定する（深度の厚み）**・**世界空間 AO と併用**。

## 画面端
### 症状

**画面の端に近いほど**、AO が**消える**、**暗くなりすぎる**、**縞**が出る、といった不整合が出ます。

### 原因

サンプル点が**画面の外**に出ると**深度が読めません**。**ラップや境界の設定**で**意味のない値**（クランプされた端の画素の深度）を読んでしまいます。

### 対策

| 対策 | 内容 |
| --- | --- |
| **画面外の寄与を 0 にする** | サンプルが画面外なら、**遮蔽なし**として扱う（またはそのサンプルを無視して、割合を調整） |
| **ガード バンド** | **画面より少し広い範囲**を描画して、AO の計算に使う（GBuffer・深度を少し大きく作る） |
| **端でフェード** | 画面の端に近いほど、**AO の強さを弱める** |
| **サンプラーの設定** | 深度は<strong>ボーダー（境界の値）</strong>か、クランプか、意図して選ぶ |

## 薄い物体
### 症状

**細い柱・フェンス・葉**の**後ろ**にある面が**必要以上に暗く**なります。

### 原因

深度バッファは、**手前の面の表の側だけ**を持ちます。**柱がどれだけ薄くても**、**柱の後ろ**にある面の点から見ると、<strong>「厚みが無限の壁」</strong>に見えます。

### 対策

| 対策 | 内容 |
| --- | --- |
| **厚みのヒューリスティック** | 「物体は手前の面から、**一定の厚み**しかない」と仮定して、**地平線の更新を弱める**（GTAO） |
| **深度差による弱め** | 遮蔽物と p の深度差が大きいほど、効きを弱める |
| **半径を小さく** | 影響範囲を狭める |
| <strong>（高コスト）背面の深度</strong> | 背面を描いて、**厚み**を測る |

## よくあるミス

??? failure "画面端だけ AO が薄い・暗い"
    **範囲外のサンプルの扱いを統一**（**遮蔽なし**）。
