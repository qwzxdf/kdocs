# AO Artifacts

**AO には、方式によらず出やすい不具合（アーティファクト）**が**いくつかあります**。**物の輪郭のハロー・平らな面の斑点・画面端の欠け・薄い物の欠け・ノイズとバンディング・ちらつき・適用の間違い・座標の取り違え**などです。このセクションでは、**症状から原因と対策を引く**ために、**症状別に 1 つずつ別のページ**で説明します。

!!! tip "ポイント"
    - **症状から原因を探す**。
    - **ハロー ＝ 輪郭の周りに、明るい（暗い）縁**。
    - **自己遮蔽 ＝ 平らな面に、縞・斑点**。
    - **画面端 ＝ 画面外の情報が無く、AO が欠ける**。
    - **デバッグは、AO 単体を画面に出す**。

## 症状別の一覧
| 症状 | 主な原因 | 対策 |
| --- | --- | --- |
| <strong>手前の物の周りに暗い輪（ハロー）</strong> | 範囲チェック不足・手前の物の厚みが無限とみなされる | 範囲チェック・厚みの近似・バイラテラル ブラー |
| <strong>平らな面に縞・斑点（自己遮蔽）</strong> | バイアス不足・深度の精度不足 | バイアスを大きく・32 ビット深度・距離で変える |
| **平らな面が灰色** | 球のサンプル（Crytek SSAO） | 半球にする |
| **画面の端で、AO が消える・変** | 画面外の深度が無い | ガード バンド・端でフェード |
| **細い柱の後ろが暗すぎる** | 薄い物の厚みが分からない | 厚みのヒューリスティック・半径を小さく |
| **ざらざらしたノイズ** | サンプル不足 | ブラー・時間蓄積・ノイズの質 |
| <strong>規則的な縞（バンディング）</strong> | サンプルの向きが全画素で同じ | 画素ごとに回転 |
| **動くとちらつく** | 時間方向の不安定・深度のちらつき | 時間蓄積・フル解像度の深度 |
| **動く物体に残像** | 時間蓄積の履歴が不正 | 動きベクトル・深度での履歴の棄却 |
| **暗すぎて、重い感じ** | 強度過多・マルチ バウンスの欠如 | 強度を下げる・マルチ バウンス |
| **直接光の当たりも暗い** | AO を直接光に掛けた | **間接光だけ**に掛ける |
| **遠景がにじんで暗い** | 半径が画面上で大きすぎる・減衰なし | 距離でフェード・半径の制限 |

## デバッグの進め方

AO の不具合は、原因が 1 つとは限りません。段階ごとに切り分けるのが、遠回りに見えて一番早い方法です。

最初に、<strong>入力を可視化</strong>します。線形深度・法線・復元した位置を画面に出して、おかしな値（階段状の深度、反転した法線）がないかを確かめます。AO の式が正しくても、入力が壊れていれば結果は壊れます。

次に、<strong>AO だけを表示</strong>します。ブラーや時間蓄積の前の、生の結果を白黒で出します。ここでノイズや縞が見えるのは正常で、確認したいのは、ハローや自己遮蔽のような<strong>構造的な不具合</strong>があるかどうかです。

そのあとに、疑わしい画素で<strong>サンプルを 1 つずつ可視化</strong>します。どのサンプルが遮蔽と判定されたかを色で出すと、バイアスが足りないのか、範囲チェックが足りないのか、一目で分かります。

ブラーと時間蓄積は、<strong>切って比べます</strong>。ブラーを切って消える症状なら、ブラーが原因です。逆に、ブラーを入れて初めて出る症状（輪郭をまたいだにじみなど）もあります。

最後に、半径・バイアスなどのパラメータを<strong>極端な値に振って</strong>、画面がどう変わるかを観察します。パラメータの効き方が分かれば、ちょうどよい値も見つけやすくなります。

デバッグ表示の作り方は、[調査ツール](../../../rendering/tools.md)を参照してください。
