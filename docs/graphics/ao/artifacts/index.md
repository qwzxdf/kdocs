# AO のアーティファクト

**AO には、方式によらず出やすい不具合（アーティファクト）**が**いくつかあります**。**物の輪郭のハロー・平らな面の斑点・画面端の欠け・薄い物の欠け・ノイズとバンディング・ちらつき・適用の間違い・座標の取り違え**などです。このセクションでは、**症状から原因と対策を引く**ために、**症状別に 1 つずつ別のページ**で説明します。

!!! tip "ポイント"
    - **症状から原因を探す**。
    - **ハロー ＝ 輪郭の周りに、明るい（暗い）縁**。
    - **自己遮蔽 ＝ 平らな面に、縞・斑点**。
    - **画面端 ＝ 画面外の情報が無く、AO が欠ける**。
    - **デバッグは、AO 単体を画面に出す**。

## 症状別の一覧
| 症状 | 主な原因 | 対策 |
| --- | --- | --- |
| <strong>手前の物の周りに暗い輪（ハロー）</strong> | 範囲チェック不足・手前の物の厚みが無限とみなされる | 範囲チェック・厚みの近似・バイラテラル ブラー |
| <strong>平らな面に縞・斑点（自己遮蔽）</strong> | バイアス不足・深度の精度不足 | バイアスを大きく・32 ビット深度・距離で変える |
| **平らな面が灰色** | 球のサンプル（Crytek SSAO） | 半球にする |
| **画面の端で、AO が消える・変** | 画面外の深度が無い | ガード バンド・端でフェード |
| **細い柱の後ろが暗すぎる** | 薄い物の厚みが分からない | 厚みのヒューリスティック・半径を小さく |
| **ざらざらしたノイズ** | サンプル不足 | ブラー・時間蓄積・ノイズの質 |
| <strong>規則的な縞（バンディング）</strong> | サンプルの向きが全画素で同じ | 画素ごとに回転 |
| **動くとちらつく** | 時間方向の不安定・深度のちらつき | 時間蓄積・フル解像度の深度 |
| **動く物体に残像** | 時間蓄積の履歴が不正 | 動きベクトル・深度での履歴の棄却 |
| **暗すぎて、重い感じ** | 強度過多・マルチ バウンスの欠如 | 強度を下げる・マルチ バウンス |
| **直接光の当たりも暗い** | AO を直接光に掛けた | **間接光だけ**に掛ける |
| **遠景がにじんで暗い** | 半径が画面上で大きすぎる・減衰なし | 距離でフェード・半径の制限 |

## デバッグの進め方
| 手順 | 内容 |
| --- | --- |
| **① 入力を可視化** | **線形深度・法線・復元した位置**を画面に出して、おかしな値がないか確かめる |
| **② AO だけを表示** | 生の結果（ブラー前）を、そのまま白黒で表示 |
| **③ サンプルを、1 つずつ可視化** | 特定の画素で**どのサンプルが遮蔽と判定されたか**を、色で出す |
| **④ ブラー・時間蓄積を切って見る** | どの段階でアーティファクトが出るか切り分ける |
| **⑤ パラメータを極端に振る** | 半径・バイアスを極端にして、**効き方**を観察する |

デバッグ表示の作り方は、[デバッグ描画](../../index.md)（予定）と、[調査ツール](../../../rendering/tools.md)を参照してください。
