# Self-Occlusion

**平らな面なのに、縞や斑点が出る**のが**自己遮蔽の失敗**です。**深度バッファの精度が足りず、自分自身の面が、サンプルを遮ると判定される**ためです。**バイアス（わずかな余裕）や、法線に沿った半球**で**防ぎます**。このページでは、**自己遮蔽の原因・バイアス・法線方向の半球**を説明します。

!!! tip "ポイント"
    - **自己遮蔽 ＝ 自分の面が、サンプルを遮ると誤判定**。
    - **原因 ＝ 深度の精度・面の傾き**。
    - **対策 ＝ バイアス**（**深度の比較に余裕**）・**法線に沿った半球にサンプルを置く**。
    - **バイアスが大きすぎると、細かい凹凸の AO が消える**。

## 自己遮蔽（平らな面の縞・斑点）
### 症状

**平らな床や壁**に**縞模様・斑点**が出ます。特に**カメラから遠い場所**や**斜めから見た面**に出やすいです。

### 原因

| 原因 | 説明 |
| --- | --- |
| **深度の精度不足** | 遠いほど、深度の量子化の誤差が大きく、**平らな面がわずかに凸凹**に見える |
| **バイアス不足** | その凸凹を遮蔽と誤判定する |
| **斜めの面** | 面が斜めだと**隣の画素との深度差**が大きく、**自己交差**しやすい |
| **法線の誤差** | 深度から復元した法線が、ノイズを含む |

### 対策

| 対策 | 内容 |
| --- | --- |
| **バイアスを大きくする** | **距離に比例**して増やす（`z × β`）。Alchemy・SAO の β |
| **32 ビット（浮動小数点）の深度** | 精度を確保（reverse-Z と併用） |
| **面の傾きに応じたバイアス** | 斜めの面ほど、バイアスを大きく |
| **深度ではなく、ビュー空間の位置で比べる** | 非線形深度の誤差を避ける |
| **法線の質** | G-Buffer の**ジオメトリ法線**を使う（法線マップ込みの法線は、凹凸が AO に出る） |

## よくあるミス

??? failure "平らな床に、縞模様の AO が出る"
    **バイアスを入れる**、**法線に沿った半球**にする。
