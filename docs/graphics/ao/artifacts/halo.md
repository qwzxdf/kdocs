# Halo

**ハロー**は、**物体の輪郭の周りに、明るい（または暗い）縁が出る**現象です。**手前の物体と奥の面で、深度が大きく違う所**で、**サンプルが、手前の物体を遮蔽物と誤認する**と、**奥の面が暗くなる（または、逆に明るくなる）**ためです。このページでは、**ハローの原因・距離による減衰（範囲チェック）・対策**を説明します。

!!! tip "ポイント"
    - **ハロー ＝ 輪郭の周りの、明るい・暗い縁**。
    - **原因 ＝ 大きく離れた物を、遮蔽物として扱う**。
    - **対策 ＝ 範囲チェック**：**サンプルと中心の深度差が、半径より大きければ、遮蔽に数えない**。
    - **滑らかな範囲チェック（`smoothstep`）**で**境を柔らかく**。

## ハロー
### 症状

**手前にある物体の輪郭の周り**（背景側）に、**暗い光の輪**が出ます。人物の頭の周りの壁が**暗く縁取られる**ような見た目です。

### 原因

**手前の物体**（人物）と、**奥の背景**（壁）の**深度差が大きい**境界で、**背景の画素の周りのサンプル**が、**手前の物体の内側**に入ります。**深度バッファでは、人物は面として存在する**ので、**背景の点が人物に遮られている**と判定されます。しかし、実際には**人物は壁から離れて立っている**ので、**壁を暗くする理由はありません**。

### なぜ「深度が離れている」だけで誤判定になるのか

深度バッファは、<strong>画面から見て一番手前の面</strong>しか記録していません。つまり「p の周りの半球の中に、本当に物体があるか」を調べているのではなく、<strong>「画面上の隣の画素の深度が、p より手前か」</strong>を調べているだけです。この近道が、ハローの根本原因です。

具体的な数字で考えます。カメラから人物までが 3 m、壁までが 5 m、AO の半径 R が 0.5 m だとします。壁の点 p のすぐ隣に、人物の輪郭の画素があります。その画素の深度は 3 m で、p の深度 5 m より 2 m も手前です。もし「サンプルが p より手前にあれば遮蔽」とだけ判定すると、人物は p を遮蔽していることになり、<strong>半径 0.5 m のはずの AO が、2 m 離れた物体の影響を受けて</strong>しまいます。人物がカメラに近づくほど、また壁が遠いほど、この誤判定は広がります。

結果として、人物の輪郭に沿って、壁が暗く縁取られます。これが<strong>暗いハロー</strong>です。

逆向きの問題もあります。法線を深度から再構成している方式では、輪郭の画素で法線が不連続になり、バイラテラル ブラーで輪郭をまたいで平均すると、<strong>明るい縁</strong>が出ることがあります（[Bilateral Blur](../filtering/bilateral-blur.md)）。暗いハローも明るいハローも、<strong>「深度の離れた画素を、同じ面の一部として扱ってしまう」</strong>ことが共通の原因です。

### 範囲チェック：遠い遮蔽物の寄与を弱める

対策の基本は、<strong>「p から半径 R より遠い物は、遮蔽物と見なさない」</strong>というルールです。これを範囲チェック（range check）と呼びます。Crytek の SSAO（2007 年）から使われている古典的な方法です。

式にすると、サンプルの深度と p の深度の差 Δz = |z_p − z_s| に対して、重みを次のように決めます。

<div class="formula">w = smoothstep(0, 1, R / Δz)</div>

Δz が R 以下なら R / Δz は 1 以上になり、smoothstep は 1 に張り付くので、遮蔽として<strong>満額</strong>で数えます。Δz が R の 2 倍なら重みは 0.5 の smoothstep（約 0.5）、Δz が R の 10 倍ならほぼ 0 です。つまり「近い遮蔽物は全部数え、遠い遮蔽物ほど急に効かなくなる」という振る舞いになります。

`smoothstep` を使うのは、<strong>境界の段差を作らない</strong>ためです。「Δz > R なら 0、そうでなければ 1」という 2 値の切り替えにすると、物体の端で AO が急に切り替わり、ちらついたり輪郭が見えたりします。

```hlsl
float RangeCheck(float z_center, float z_sample, float radius) {
  float dz = abs(z_center - z_sample);
  return smoothstep(0.0, 1.0, radius / max(dz, 1e-4));
}

// サンプルが手前にあれば遮蔽として数える（重み付き）
occlusion += (z_sample < z_center - kBias ? 1.0 : 0.0)
           * RangeCheck(z_center, z_sample, kRadius);
```

この重みは、AO の「見た目の半径」を守る役目もあります。範囲チェックがなければ、半径をパラメータで 0.5 m に設定しても、実際にはもっと遠くの物体まで AO に効いてしまい、パラメータが意味を失うからです。

### 方式ごとの距離の弱め方

範囲チェックの考え方は、どの方式にも形を変えて入っています。

[Alchemy AO](../alchemy-ao.md) や [HBAO](../hbao.md) は、サンプル点までの距離 r に応じた減衰項を式の中に持ちます。HBAO の論文（Bavoil ら、2008）では、<strong>W(r) = 1 − (r / R)²</strong> のような、R で 0 になる減衰を使って、遠い点の寄与を滑らかに消します。距離が R を超えたサンプルは、地平線の更新自体を行いません。

[GTAO](../gtao.md)（Jimenez ら、2016）は、さらに一歩進めます。遠い遮蔽物を無視するだけでなく、<strong>手前の物体には厚みがある</strong>と仮定します。地平線を探す途中で、サンプルが遠い（減衰が効く）場合は、地平線を「その遠い物体まで上げる」のではなく、元の値に近いままにして、<strong>「壁の手前に立っている薄い物は、壁を全部は隠さない」</strong>ように扱います。この仮定は、柱や人物のような「厚みが有限の物」には正しく、「ずっと奥まで続く壁」には少し甘くなる、割り切りです。

### それでも残る問題と、より良いやり方

範囲チェックにも副作用があります。<strong>本当に大きな遮蔽物も、遠ければ無視してしまう</strong>ことです。たとえば、天井が高い部屋で床の AO を取るとき、半径 R を小さくすると、天井が遮蔽に効かなくなります。これは AO が「近くの」遮蔽だけを見る近似であることの、正しい帰結です。遠くの大きな遮蔽は、AO ではなく、シャドウやライトプローブの役目です（[AO の使い方と誤解](../theory/usage-misconceptions.md)）。

ハローを根本から減らすための選択肢を、効果の大きい順に挙げます。

1. <strong>半径を小さくする</strong>。ハローの太さは、おおむね半径に比例します。ゲームでは 0.3〜1 m 程度が普通です。
2. <strong>バイラテラル ブラーで輪郭をまたがない</strong>。ぼかしが輪郭を越えて平均すると、ハローが広がります。深度と法線の差で重みを落とします。
3. <strong>GTAO の厚みヒューリスティックを使う</strong>。上で述べた、手前の物体の厚みを有限と仮定する方法です。
4. <strong>レイトレース AO を使う</strong>（[RTAO](../world-space/rtao.md)）。レイは実際に空間を進むので、「深度が離れているだけ」の誤判定が起きません。最大距離 R で打ち切るだけで、ハローはほぼ出ません。
5. <strong>2 層の深度を持つ</strong>。手前の面の「裏側」の深度（depth peeling で得る 2 枚目）も使えば、手前の物体の厚みを実測できます。コストが高いので、実際のゲームではほとんど使われません。

## 確認の手順

ハローを直すときは、まず<strong>AO だけを画面に出して</strong>、輪郭の周りを見ます。人物の頭の周りに、背景側へ帯状の暗い領域が見えたら、ハローです。次に、半径のパラメータを半分にして、帯の幅が半分になるかを確かめます。幅が半径に比例していれば、原因は範囲チェックの不足です。幅が変わらなければ、ブラーが輪郭をまたいでいる可能性が高いので、ブラー前の AO を出して比べてください。

## よくあるミス

??? failure "輪郭に、黒いハローが出る"
    **範囲チェック（深度差が半径内のときだけ、遮蔽に数える）**を入れる。それでも残るなら、ブラーが輪郭をまたいでいないかを確認する。

??? failure "範囲チェックを入れたら、大きな遮蔽がなくなった"
    範囲チェックは「半径より遠い遮蔽を無視する」仕組みなので、意図どおりの動作。広い範囲の遮蔽は、シャドウやプローブに任せる。
