# ノイズ・バンディング・ちらつき

**AO は、ノイズが残る・縞（バンディング）が見える・ちらつく**ことが**あります**。**サンプル数・ノイズ パターン・フィルタ・時間蓄積の設定**で**変わります**。このページでは、**ノイズ・バンディング・ちらつき・残像の原因と対策**を説明します。

!!! tip "ポイント"
    - **ノイズ ＝ サンプル不足**。**フィルタ・時間蓄積で消す**。
    - **バンディング ＝ ノイズ無しの規則的パターン**。**画素ごとに回転**。
    - **ちらつき ＝ フレームごとの不安定**。**時間蓄積・ノイズの安定化**。
    - **残像（ゴースト）＝ 時間蓄積の履歴が合わない**。**履歴の拒否**。

## ノイズ・バンディング
| 症状 | 原因 | 対策 |
| --- | --- | --- |
| **ざらざら** | サンプル不足 | ブラー・時間蓄積（[フィルタ](../filtering/index.md)） |
| <strong>縞（バンディング）</strong> | 全画素が同じ向きのサンプル | 画素ごとに回転（ノイズ） |
| **ノイズが消えない** | ぼかしの周期とノイズの周期が合っていない | 4×4 ノイズなら 4×4 ブラー |
| **ノイズがぼかしで残る塊になる** | ホワイト ノイズの低周波成分 | IGN・ブルー ノイズ |

## ちらつきと残像
| 症状 | 原因 | 対策 |
| --- | --- | --- |
| **静止してもちらつく** | フレームごとにノイズ パターンが変わる（時間蓄積の収束が不足） | 時間蓄積の α を下げる・サンプルを増やす |
| **カメラが動くとちらつく** | 深度のちらつき・低解像度の深度 | **フル解像度の深度**（HBAO+ の方針）・ミップは代表の 1 点で |
| <strong>動く物体に残像（ゴースト）</strong> | 履歴の再投影が不正 | 動きベクトル・深度/法線による履歴の棄却 |
| **履歴が使えない画素でノイズが急に増える** | 隠れていた所が現れた | **空間フィルタをその画素だけ強める** |

## よくあるミス

??? failure "動くとちらつく"
    **時間蓄積の履歴拒否・ブレンド率・ノイズの安定化**を確認。
