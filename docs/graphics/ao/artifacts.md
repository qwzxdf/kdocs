# AO のアーティファクト

スクリーン空間 AO は、**深度バッファから、近似的に**遮蔽を求めるので、**特有の見た目の破綻**（アーティファクト）が出ます。**原因が分かれば、対策も分かります**。このページでは、**症状 → 原因 → 対策**の順に、**よく出るアーティファクト**を整理します。理論的な背景は[AO の理論](theory.md)、実装は各方式のページを参照してください。

!!! tip "ポイント"
    - 多くのアーティファクトの原因は、<strong>「深度バッファは、画面から見える手前の面だけ」</strong>。
    - <strong>ハロー</strong>（手前の物の周りが暗い）：<strong>範囲チェック・厚みのヒューリスティック</strong>。
    - <strong>自己遮蔽</strong>（平らな面の縞）：<strong>バイアス</strong>・<strong>深度の精度</strong>。
    - <strong>画面端</strong>：<strong>画面外が見えない</strong>。<strong>ガード バンド</strong>や<strong>フェード</strong>。
    - <strong>ちらつき・ゴースト</strong>：<strong>時間蓄積の履歴の扱い</strong>。
    - <strong>適用の間違い</strong>（直接光に掛ける・ガンマ）も、見た目の不具合の原因になる。

## 症状別の一覧

| 症状 | 主な原因 | 対策 |
| --- | --- | --- |
| <strong>手前の物の周りに暗い輪（ハロー）</strong> | 範囲チェック不足・手前の物の厚みが無限とみなされる | 範囲チェック・厚みの近似・バイラテラル ブラー |
| <strong>平らな面に縞・斑点（自己遮蔽）</strong> | バイアス不足・深度の精度不足 | バイアスを大きく・32 ビット深度・距離で変える |
| **平らな面が灰色** | 球のサンプル（Crytek SSAO） | 半球にする |
| **画面の端で、AO が消える・変** | 画面外の深度が無い | ガード バンド・端でフェード |
| **細い柱の後ろが暗すぎる** | 薄い物の厚みが分からない | 厚みのヒューリスティック・半径を小さく |
| **ざらざらしたノイズ** | サンプル不足 | ブラー・時間蓄積・ノイズの質 |
| <strong>規則的な縞（バンディング）</strong> | サンプルの向きが全画素で同じ | 画素ごとに回転 |
| **動くとちらつく** | 時間方向の不安定・深度のちらつき | 時間蓄積・フル解像度の深度 |
| **動く物体に残像** | 時間蓄積の履歴が不正 | 動きベクトル・深度での履歴の棄却 |
| **暗すぎて、重い感じ** | 強度過多・マルチ バウンスの欠如 | 強度を下げる・マルチ バウンス |
| **直接光の当たりも暗い** | AO を直接光に掛けた | **間接光だけ**に掛ける |
| **遠景がにじんで暗い** | 半径が画面上で大きすぎる・減衰なし | 距離でフェード・半径の制限 |

## ハロー

### 症状

**手前にある物体の輪郭の周り**（背景側）に、**暗い光の輪**が出ます。人物の頭の周りの壁が**暗く縁取られる**ような見た目です。

### 原因

**手前の物体**（人物）と、**奥の背景**（壁）の**深度差が大きい**境界で、**背景の画素の周りのサンプル**が、**手前の物体の内側**に入ります。**深度バッファでは、人物は面として存在する**ので、**背景の点が人物に遮られている**と判定されます。しかし、実際には**人物は壁から離れて立っている**ので、**壁を暗くする理由はありません**。

### 対策

| 対策 | 内容 |
| --- | --- |
| **範囲チェック** | **p と遮蔽物の深度差が半径 R より大きい**なら、寄与を**弱める**（[半球 SSAO](ssao-hemisphere.md)） |
| **式に距離の減衰を入れる** | Alchemy・HBAO の距離の弱め |
| **バイラテラル ブラー** | ぼかしで境界をまたがない |
| **厚みのヒューリスティック** | 手前の物体の厚みを「有限」と仮定して、**奥側は遮蔽しない**（GTAO など） |
| **半径を小さく** | 半径が大きいほど、ハローは広がる |
| <strong>（高コスト）二層の深度</strong> | 手前の面の**裏側**の深度も持つ |

## 自己遮蔽（平らな面の縞・斑点）

### 症状

**平らな床や壁**に**縞模様・斑点**が出ます。特に**カメラから遠い場所**や**斜めから見た面**に出やすいです。

### 原因

| 原因 | 説明 |
| --- | --- |
| **深度の精度不足** | 遠いほど、深度の量子化の誤差が大きく、**平らな面がわずかに凸凹**に見える |
| **バイアス不足** | その凸凹を遮蔽と誤判定する |
| **斜めの面** | 面が斜めだと**隣の画素との深度差**が大きく、**自己交差**しやすい |
| **法線の誤差** | 深度から復元した法線が、ノイズを含む |

### 対策

| 対策 | 内容 |
| --- | --- |
| **バイアスを大きくする** | **距離に比例**して増やす（`z × β`）。Alchemy・SAO の β |
| **32 ビット（浮動小数点）の深度** | 精度を確保（reverse-Z と併用） |
| **面の傾きに応じたバイアス** | 斜めの面ほど、バイアスを大きく |
| **深度ではなく、ビュー空間の位置で比べる** | 非線形深度の誤差を避ける |
| **法線の質** | G-Buffer の**ジオメトリ法線**を使う（法線マップ込みの法線は、凹凸が AO に出る） |

## 画面端

### 症状

**画面の端に近いほど**、AO が**消える**、**暗くなりすぎる**、**縞**が出る、といった不整合が出ます。

### 原因

サンプル点が**画面の外**に出ると**深度が読めません**。**ラップや境界の設定**で**意味のない値**（クランプされた端の画素の深度）を読んでしまいます。

### 対策

| 対策 | 内容 |
| --- | --- |
| **画面外の寄与を 0 にする** | サンプルが画面外なら、**遮蔽なし**として扱う（またはそのサンプルを無視して、割合を調整） |
| **ガード バンド** | **画面より少し広い範囲**を描画して、AO の計算に使う（GBuffer・深度を少し大きく作る） |
| **端でフェード** | 画面の端に近いほど、**AO の強さを弱める** |
| **サンプラーの設定** | 深度は<strong>ボーダー（境界の値）</strong>か、クランプか、意図して選ぶ |

## 薄い物体

### 症状

**細い柱・フェンス・葉**の**後ろ**にある面が**必要以上に暗く**なります。

### 原因

深度バッファは、**手前の面の表の側だけ**を持ちます。**柱がどれだけ薄くても**、**柱の後ろ**にある面の点から見ると、<strong>「厚みが無限の壁」</strong>に見えます。

### 対策

| 対策 | 内容 |
| --- | --- |
| **厚みのヒューリスティック** | 「物体は手前の面から、**一定の厚み**しかない」と仮定して、**地平線の更新を弱める**（GTAO） |
| **深度差による弱め** | 遮蔽物と p の深度差が大きいほど、効きを弱める |
| **半径を小さく** | 影響範囲を狭める |
| <strong>（高コスト）背面の深度</strong> | 背面を描いて、**厚み**を測る |

## ノイズ・バンディング

| 症状 | 原因 | 対策 |
| --- | --- | --- |
| **ざらざら** | サンプル不足 | ブラー・時間蓄積（[フィルタ](filtering.md)） |
| <strong>縞（バンディング）</strong> | 全画素が同じ向きのサンプル | 画素ごとに回転（ノイズ） |
| **ノイズが消えない** | ぼかしの周期とノイズの周期が合っていない | 4×4 ノイズなら 4×4 ブラー |
| **ノイズがぼかしで残る塊になる** | ホワイト ノイズの低周波成分 | IGN・ブルー ノイズ |

## ちらつきと残像

| 症状 | 原因 | 対策 |
| --- | --- | --- |
| **静止してもちらつく** | フレームごとにノイズ パターンが変わる（時間蓄積の収束が不足） | 時間蓄積の α を下げる・サンプルを増やす |
| **カメラが動くとちらつく** | 深度のちらつき・低解像度の深度 | **フル解像度の深度**（HBAO+ の方針）・ミップは代表の 1 点で |
| <strong>動く物体に残像（ゴースト）</strong> | 履歴の再投影が不正 | 動きベクトル・深度/法線による履歴の棄却 |
| **履歴が使えない画素でノイズが急に増える** | 隠れていた所が現れた | **空間フィルタをその画素だけ強める** |

## 適用の間違い（見た目の不具合）

| 症状 | 原因 | 対策 |
| --- | --- | --- |
| **日向まで暗い** | AO を直接光にも掛けた | **間接光（環境光）だけ**に掛ける |
| **全体的に暗く、どんよりする** | 強度・指数が強すぎる・マルチ バウンスなし | `pow` を弱める・マルチ バウンス |
| <strong>ガンマが変（暗部が潰れる）</strong> | ガンマ空間の色に掛けた | **リニア空間で**掛ける |
| **鏡面反射の隅にまぶしい反射** | スペキュラ遮蔽なし | スペキュラ遮蔽（[GTAO](gtao.md)） |
| **空が暗い** | 深度が far の画素（空）を処理して、遮蔽が出る | **空は AO = 1** |
| <strong>半透明の物に、AO が付く（付かない）</strong> | 半透明の深度が書かれていない | 半透明は**別扱い**（深度に書かない、AO を後掛けしない） |
| **UI やパーティクルに掛かる** | 合成の順番 | AO は、**3D シーンのライティングの段階**で、適用 |

## 深度・座標の取り違え

| 症状 | 原因 |
| --- | --- |
| **AO が完全に変・斑模様** | 深度の線形化の式が**射影行列（標準 Z・reverse-Z）と合っていない** |
| **AO が上下逆** | 画面の y（下向き）とビュー空間の y（上向き）の、符号の取り違え |
| **AO の向きが鏡像** | 左手系・右手系の取り違え（法線のワールド → ビューの変換など） |
| **AO がカメラの距離でゆがむ** | `tan(fov/2)` と aspect の取り違え |

## デバッグの進め方

| 手順 | 内容 |
| --- | --- |
| **① 入力を可視化** | **線形深度・法線・復元した位置**を画面に出して、おかしな値がないか確かめる |
| **② AO だけを表示** | 生の結果（ブラー前）を、そのまま白黒で表示 |
| **③ サンプルを、1 つずつ可視化** | 特定の画素で**どのサンプルが遮蔽と判定されたか**を、色で出す |
| **④ ブラー・時間蓄積を切って見る** | どの段階でアーティファクトが出るか切り分ける |
| **⑤ パラメータを極端に振る** | 半径・バイアスを極端にして、**効き方**を観察する |

デバッグ表示の作り方は、[デバッグ描画](../index.md)（予定）と、[調査ツール](../../rendering/tools.md)を参照してください。
