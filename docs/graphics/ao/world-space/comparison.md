# World-Space AO Comparison

**世界空間 AO の 3 方式と、スクリーン空間の AO は、それぞれ得意・不得意が違います**。このページでは、**3 方式の比較・スクリーン空間との使い分け**を説明します。

!!! tip "ポイント"
    - **RTAO**：**最も正確・ハードウェア必要・デノイズ**。
    - **DFAO**：**ハードウェア不要・静的向き**。
    - **VXAO**：**動的に強い・メモリ**。
    - **スクリーン空間 AO**は**安いが、画面外に弱い**。**併用**も**多い**。

## 3 方式の比較
| 項目 | RTAO | DFAO | VXAO |
| --- | --- | --- | --- |
| **データ** | 三角形の BVH | SDF | ボクセルとミップ |
| **精度** | <strong>高（正確）</strong> | 中（SDF の解像度） | 低〜中（ボクセルの解像度） |
| **ノイズ** | **大**（レイ 1〜2 本） | **小** | 小〜中 |
| **動的なシーン** | BVH の更新で対応 | **弱い** | **強い** |
| **ハードウェア** | **レイトレ対応 GPU** | 不要 | 不要 |
| **メモリ** | BVH | SDF ボリューム | ボクセル ボリューム |
| **薄い物・細部** | **正確** | 弱い | 弱い |
| **向く場面** | 高品質・レイトレ対応の環境 | 静的な屋外・広い範囲 | 動的なシーン・GI との併用 |

## スクリーン空間との使い分け
| 状況 | おすすめ |
| --- | --- |
| **広い対応環境** | スクリーン空間（[GTAO](../gtao.md) など） |
| **画面外の遮蔽が必要・最高品質** | RTAO |
| **広い屋外の静的な AO** | DFAO |
| **GI とまとめて、動的に** | VXAO など |
| **併用** | **大きな遮蔽は世界空間の方式**、**細部の接触はスクリーン空間**（組み合わせる） |

## よくあるミス

??? failure "世界空間 AO だけにして、細かい接地感が足りない"
    **スクリーン空間の AO（GTAO など）も併用**して、**細部を補う**。

## これだけ覚える

!!! abstract "まとめ"
    - [x] **3 方式は、精度・必要な機能・コストが違う**
    - [x] **スクリーン空間と併用することが多い**
