# フィルタ（ぼかし・時間方向）

スクリーン空間 AO は、**サンプル数が少ない**（画素あたり 数個〜数十個）ので、**1 フレームの結果は、ノイズだらけ**です。そのノイズを**ぼかしと時間方向の平均**で消すのが前提です。ただし、**ただのぼかし**は、**物体の境界で暗さがにじむ**問題を起こします。このページでは、<strong>境界を守るぼかし（バイラテラル）</strong>・<strong>低解像度からの拡大（アップサンプル）</strong>・**ノイズの種類**・**時間方向の蓄積**を順に説明します。ここの内容は、AO だけでなく、**SSR・SSGI・ソフト シャドウ**など、**ノイズを使うあらゆる効果**に共通します。

!!! tip "ポイント"
    - ノイズの大きい結果を、<strong>空間（ぼかし）</strong>と<strong>時間（過去フレーム）</strong>で平均する。
    - 通常のぼかしは、<strong>境界をまたいで混ぜる</strong>。<strong>バイラテラル</strong>は、<strong>深度（と法線）の近い画素だけ</strong>混ぜる。
    - <strong>分離可能（横 → 縦）</strong>にして、安くする。
    - <strong>低解像度で計算</strong>したら、<strong>深度を使って拡大</strong>（ジョイント バイラテラル アップサンプル）。
    - <strong>時間蓄積</strong>は、<strong>動きベクトル（または深度）で再投影</strong>し、<strong>履歴が不正なら捨てる</strong>。
    - ノイズの質（<strong>IGN・ブルー ノイズ</strong>）が、ぼかしの効率を決める。

## なぜノイズが出るのか

| 原因 | 説明 |
| --- | --- |
| **サンプルが少ない** | モンテカルロの誤差は、`1/√N`。N が 8 なら、**誤差は約 35%** |
| **画素ごとに違う向きを使う** | 規則的な縞（バンディング）を避けるため、わざとランダムにする（**縞をノイズに変える**） |
| **ノイズの方が消しやすい** | **規則的な縞はぼかしても消えない**。ランダムなノイズは、**平均で減る** |

つまり、<strong>「ノイズを出して、ぼかして消す」</strong>のがサンプル数を減らす定石です。

## 空間フィルタ：バイラテラル ブラー

### 通常のぼかしの問題

AO の画像を**そのままぼかす**と**物体の境界**で**手前の物体の AO と、奥の物体の AO が混ざり**ます。手前の物体の縁に**暗い輪**が出たり、**接地の暗さがにじんで広がる**ことがあります。

### バイラテラル：「近いもの」だけを混ぜる

**バイラテラル フィルタ**は、中心の画素と**似た画素だけ**を、重み付きで混ぜます。**似ている**とは、AO では**深度（と法線）が近い**ことです。

<div class="formula">AO′(p) = Σ_q w(p, q) · AO(q) / Σ_q w(p, q)　、　w = w_空間 · w_深度 · w_法線</div>

| 重み | 式の例 | 意味 |
| --- | --- | --- |
| **w_空間** | ガウス、または一様 | 距離が近いほど大 |
| **w_深度** | `exp(−\|z_p − z_q\| · k)` または `1 / (ε + \|z_p − z_q\|)` | **深度が近い**ほど大。**別の面なら 0 に近づく** |
| **w_法線** | `pow(saturate(dot(n_p, n_q)), 8)` | **法線が近い**ほど大。**向きの違う面を混ぜない** |

```hlsl
float BilateralBlur(float2 uv, float2 dir) {
  float center_z = LinearDepth(uv);
  float3 center_n = Normal(uv);
  float sum = 0.0;
  float weight_sum = 0.0;

  [unroll] for (int i = -kRadius; i <= kRadius; ++i) {
    float2 suv = uv + dir * texel_size * i;
    float ao = ao_tex.SampleLevel(point_sampler, suv, 0).r;
    float z = LinearDepth(suv);

    float w = gaussian[abs(i)];
    w *= exp(-abs(center_z - z) * depth_sharpness / center_z);
    w *= pow(saturate(dot(center_n, Normal(suv))), 8.0);

    sum += ao * w;
    weight_sum += w;
  }
  return sum / max(weight_sum, 1e-4);
}
```

| 点 | 説明 |
| --- | --- |
| **深度の差を中心の深度で割る** | **遠いほど、深度の差が大きく出る**ので、相対的な差で比べる |
| **`depth_sharpness`** | 大きいほど、境界を厳しく守る |
| **ポイント サンプリング** | AO と深度は、**補間せず**に読む |

### 分離可能にする（横 → 縦）

2D のぼかしを**横 1 回 ＋ 縦 1 回**に分けると、**N² → 2N** 回の読み込みで済みます。**バイラテラルは、厳密には分離できません**（重みが、2D の位置に依存）が、**実用上は分離して近似**します。

| 方式 | 読み込み回数（半径 4 の例） | 品質 |
| --- | --- | --- |
| <strong>2D（全画素）</strong> | 81 | 正確 |
| <strong>分離（横 → 縦）</strong> | 18 | 縦横の斜めでわずかな乱れ |

### 4×4 ノイズに合わせた、ボックス ぼかし

**4×4 のノイズ テクスチャ**を使った SSAO（[半球 SSAO](ssao-hemisphere.md)）では**ノイズが 4 画素周期**で繰り返すので、**4×4 のボックス ぼかし**で、**周期のパターンがちょうど消えます**。**深度の重み付き**にすれば、境界も守れます。

## アップサンプル：低解像度から戻す

AO は<strong>低周波（なめらか）</strong>なので**半分や 1/4 の解像度**で計算して、**拡大**すると**コストを大きく減らせます**（[低解像度のエフェクト](../../rendering/low-res-effects.md)）。しかし、**単純なバイリニア拡大**は、**境界でにじみます**。

### ジョイント バイラテラル アップサンプル

**拡大先（フル解像度）の深度**と**低解像度の深度**を**比べて**、**近い深度の低解像度の画素**を、重みを大きくして混ぜます。

| 手順 | 内容 |
| --- | --- |
| **① フル解像度の画素の深度** | 拡大先の各画素の深度 `z_full` |
| **② 周りの低解像度画素（2×2）の深度** | `z_low_i` |
| **③ 重みを計算** | `w_i = 双線形の重み × 1 / (ε + \|z_full − z_low_i\|)` |
| **④ 混ぜる** | `AO = Σ w_i · AO_low_i / Σ w_i` |

```hlsl
float UpsampleAO(float2 uv_full) {
  float z_full = LinearDepth(uv_full);
  float2 low_pos = uv_full * low_size - 0.5;
  float2 f = frac(low_pos);
  int2 base = int2(floor(low_pos));

  float sum = 0.0;
  float weight_sum = 0.0;
  [unroll] for (int y = 0; y < 2; ++y) {
    [unroll] for (int x = 0; x < 2; ++x) {
      int2 p = base + int2(x, y);
      float w = (x == 0 ? 1.0 - f.x : f.x) * (y == 0 ? 1.0 - f.y : f.y);
      w *= 1.0 / (0.001 + abs(z_full - low_depth_tex.Load(int3(p, 0)).r));
      sum += ao_low_tex.Load(int3(p, 0)).r * w;
      weight_sum += w;
    }
  }
  return sum / weight_sum;
}
```

| 点 | 説明 |
| --- | --- |
| **低解像度の深度を別途用意** | AO を計算したときの深度（縮小した深度）を保持しておく |
| <strong>「最も近い深度」を選ぶ方式</strong> | 深度が最も近い 1 画素だけを選ぶ（シャープだが階段状になりやすい） |
| **ハローの防止** | 境界で**低解像度の画素が別の面の AO を持つ**のを防ぐ |

## ノイズ パターンの選び方

**ノイズの質**で**ぼかし・時間蓄積の効率**が大きく変わります。

| ノイズ | 特徴 |
| --- | --- |
| **ホワイト ノイズ** | 完全にランダム。<strong>塊（クラスタ）</strong>ができ、**ぼかしでも残りやすい** |
| **4×4 のランダム テクスチャ** | 周期 4。4×4 のぼかしで消せる |
| <strong>Interleaved Gradient Noise（IGN）</strong> | 画素の座標から、**式で計算**。**テクスチャ不要**。**近い画素どうしが離れた値**になる（低周波が少ない）。ぼかしで消えやすい |
| **ブルー ノイズ** | **高周波に偏った**ノイズ。**ぼかしできれいに消える**。テクスチャを用意する必要がある |
| <strong>Bayer 配列（ディザ行列）</strong> | 規則的。縞が出るので時間方向のジッターと併用 |

### IGN の式

```hlsl
float InterleavedGradientNoise(float2 pixel) {
  return frac(52.9829189 * frac(dot(pixel, float2(0.06711056, 0.00583715))));
}
```

**フレームごとに画素の位置をずらす**（`pixel + frame × オフセット`）と、**時間方向にも異なるパターン**になります。

### 時間方向のノイズ

| 方法 | 内容 |
| --- | --- |
| **黄金比の数列** | `frac(index × 0.61803398875)`。**フレームごとの回転角**に使うと、**均等に分散**する |
| **フレーム番号 mod N** | 周期的に、N 通りのパターンを回す |
| **画素ごとにずらす** | **空間と時間の両方で異なるパターン** |

## 時間方向のフィルタ（時間蓄積）

**過去のフレームの AO を、再利用**して、**1 フレームあたりのサンプル数を、実質的に増やします**（[TAA・アップスケーラ](../../rendering/taa-upscaling.md)と同じ発想）。

### 手順

| 手順 | 内容 |
| --- | --- |
| **① 再投影** | **今の画素の位置**を**前フレームの画面の位置**に変換（**動きベクトル**、または**深度とカメラ行列**から） |
| **② 履歴を読む** | 前フレームの AO を、その位置から読む |
| **③ 履歴の検証** | **深度・法線が今と近い**か。<strong>違えば、履歴は別の物（隠れていたものが現れた）</strong> → 捨てる |
| **④ 混ぜる** | `AO = lerp(履歴, 今, α)`。**α は 0.05〜0.2**（小さいほど滑らかだが遅れる） |

```hlsl
float TemporalAO(float2 uv, float current_ao) {
  float2 history_uv = Reproject(uv);
  float history_ao = history_tex.SampleLevel(linear_sampler, history_uv, 0).r;
  float history_z = history_depth_tex.SampleLevel(point_sampler, history_uv, 0).r;

  float depth_diff = abs(LinearDepth(uv) - history_z) / LinearDepth(uv);
  bool valid = all(saturate(history_uv) == history_uv) && depth_diff < 0.05;

  float alpha = valid ? 0.1 : 1.0;
  return lerp(history_ao, current_ao, alpha);
}
```

| 点 | 説明 |
| --- | --- |
| **画面外の履歴** | `history_uv` が、0〜1 の外なら、履歴なし（α = 1） |
| **深度の比較** | 相対的な差で**別の物体**を検出 |
| **α を信頼度で変える** | 履歴が**古い**ほど、**今の寄与を小さく**する（フレーム数を数えて、`α = 1/(n+1)` で平均） |
| **動くオブジェクト** | **動きベクトル**が無いと<strong>残像（ゴースト）</strong>が出る。**カメラの動きだけ**なら、深度とカメラ行列で再投影できる |

### ゴーストと対策

| 問題 | 対策 |
| --- | --- |
| **動く物体の残像** | 動きベクトルで再投影、または**履歴を深度・法線で拒否** |
| **ライトの変化への遅れ** | AO はライトに依存しないので、ほぼ問題なし。**形が変わる**とき（ドア・動く物）に遅れる |
| **カメラの急な動き** | 履歴を捨てる（α を大きく） |
| **履歴が使えない画素のノイズ** | **空間フィルタを強める**（履歴が無い画素だけ、ぼかしを大きくする） |

### 分散のクランプ

**スカラー AO**でも**周囲の画素の最小・最大**（または平均と分散）で、<strong>履歴を制限（クランプ）</strong>すると**古い履歴の暴走**を防げます（TAA の近傍クランプと同じ）。

## 組み合わせ：典型的なパイプライン

| 順番 | 内容 |
| --- | --- |
| **① AO の計算** | 少ないサンプル、画素・フレームごとにノイズの向き |
| **② 空間フィルタ** | **バイラテラル ブラー**（小さな半径で、1〜2 回） |
| **③ 時間蓄積** | 再投影・検証・混ぜる |
| **④ （低解像度なら）アップサンプル** | **ジョイント バイラテラル** |
| **⑤ 適用** | 間接光に掛ける |

**順番は実装で変わります**（空間 → 時間、時間 → 空間）。**ゴーストを避けるため、時間蓄積を空間フィルタの前に置く**構成もあります。

## パラメータの目安

| パラメータ | 目安 |
| --- | --- |
| **ブラーの半径** | 2〜4 画素 |
| **深度の鋭さ** | 境界でにじみが出なくなる最小の値 |
| **時間蓄積の α** | 0.05〜0.2 |
| **深度の棄却しきい値** | 相対 5% 程度 |
| **ノイズ** | IGN またはブルー ノイズ。フレームごとに位置をずらす |

## よくあるミス

??? failure "ぼかしで、深度を考慮せず、物体の縁に暗い輪が出る"
    **バイラテラル**にします（深度・法線の重み）。

??? failure "低解像度の AO を、バイリニアで拡大して、縁がにじむ"
    **深度を使ったアップサンプル**にします。

??? failure "時間蓄積で、履歴を検証せず、動く物体にゴーストが出る"
    **深度・法線で履歴を棄却**します。

??? failure "ノイズが規則的で、ぼかしても縞が残る"
    IGN やブルー ノイズなど、**低周波の少ないノイズ**を使います。

??? failure "時間蓄積の α が小さすぎて、変化に追従しない"
    α を上げるか、**履歴が無効**なときは、α = 1 にします。

??? failure "AO と深度を、補間（リニア）で読む"
    **ポイント サンプリング**で読みます。
