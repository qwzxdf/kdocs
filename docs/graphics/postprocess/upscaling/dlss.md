# DLSS

決め打ちの規則で履歴を使う方式は、動きの激しい場面や細い線で、残像やちらつきが出やすいです。DLSS（Deep Learning Super Sampling）は、<strong>ニューラル ネットワークに「履歴をどう使うか」を学習させる</strong>ことで、この弱点を抑えます。NVIDIA の GPU（RTX）の Tensor コアで動き、専用のハードウェアを前提にしています。

!!! tip "ポイント"
    - 入力は、低解像度のカラー、深度、動きベクトル、ジッター、露出。FSR や XeSS と共通
    - DLSS 2 でアップスケーラとして完成した。ゲームごとの学習が要らなくなった
    - DLSS 3 でフレーム生成が 3.5 で Ray Reconstruction（レイトレースのノイズ除去）が加わった
    - DLSS 4 は、モデルが Transformer 型になり、複数フレームの生成（Multi Frame Generation）が加わった
    - 品質モードに DLAA がある。拡大せず、同じ解像度でアンチエイリアシングだけを行う

## 版ごとの機能 {#versions}

### DLSS 2 {#dlss2}

アップスケーラとして実用になった版です。入力の枠組みは、他のアップスケーラの基準になりました。ゲームごとに学習する必要はなく、1 つのモデルで、多くのゲームに対応します。

### フレーム生成（DLSS 3） {#framegen}

RTX 40 世代以降で使えます。光学フロー（動きを推定するハードウェア）と動きベクトルから、2 つの描画フレームの間に補間フレームを作ります。見かけのフレームレートは上がりますが、操作の応答は上がらないので、元のフレームレートが低いと反応の重さが残ります。この遅延を抑えるために、NVIDIA Reflex と組み合わせて使います。

### Ray Reconstruction（DLSS 3.5） {#rr}

レイトレースの結果は、サンプルが少なくノイジーなため、ノイズ除去が必要です。従来は、手作りのデノイザーを使いましたが、Ray Reconstruction は、これをニューラル ネットワークで置き換え、アップスケールとまとめて行います。

### DLSS 4 {#dlss4}

アップスケーラのモデルが Transformer 型になり、細部の保ち方とゴーストの少なさが向上しました。フレーム生成も、1 つの描画フレームから複数のフレームを作る Multi Frame Generation が加わりました。

## 組み込みの流れ {#integrate}

1. NVIDIA の SDK（または Streamline）を取り込み、対応 GPU かどうかを確認する
2. 描画の解像度と出力の解像度で、DLSS の機能を作る
3. 毎フレーム、ジッターを加えて低解像度で描く
4. カラー、深度、動きベクトルを渡して評価する（Evaluate）。結果が高解像度の画像
5. ポストプロセスと UI を行う

DLSS が使えない GPU でも動くように、FSR などの別の方式に切り替えられる設計にしておきます。

## DLAA {#dlaa}

DLAA（Deep Learning Anti-Aliasing）は、描画解像度と出力解像度が同じ設定です。TAA の代わりに、ニューラル ネットワークでアンチエイリアシングだけを行います。GPU に余力があるときに、最も画質の高い選択肢です。

## よくあるミス {#mistakes}

??? failure "マウスを動かしたときに、遅れて感じる"
    フレーム生成を使うと、見かけのフレーム数は増えても、入力から画面への遅延は減りません。Reflex を併用します。

??? failure "透明な物体や粒子がにじむ"
    動きベクトルや深度を持たない描画物は、アップスケーラに正しく扱われません。透明をアップスケールの後に描くか、マスクで別扱いにします。

## これだけ覚える {#summary}

- DLSS は、ニューラル ネットワークで履歴を使う。RTX 専用
- 2 でアップスケーラ、3 でフレーム生成、3.5 で Ray Reconstruction、4 で Transformer と複数フレーム生成
- 動きベクトルとジッターは他の方式と共通。別方式に切り替えられる設計にする
