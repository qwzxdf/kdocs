# Upscaling

4K で描くと、1080p の 4 倍のピクセルを塗ることになります。ピクセルシェーダーが重いゲームでは、ここが一番の負担です。そこで、<strong>低い解像度で描いて、高い解像度に引き伸ばす</strong>のですが、ただ拡大するとぼやけます。アップスケーラは、ぼやけを抑えながら拡大し、元の画像に近い細部を取り戻す技術です。

!!! tip "ポイント"
    - 種類は 2 つ。1 枚の画像だけで拡大する空間方式（FSR 1）と、過去のフレームも使う時間方式（FSR 2 以降、DLSS、XeSS）
    - 時間方式は、毎フレーム少しずつずらして描く（ジッター）。動きベクトルで過去の画像を合わせ、複数フレームの情報を集める
    - 入力は、低解像度のカラー、深度、動きベクトル、ジッターのずれ、露出。動きベクトルの精度が品質を決める
    - 品質モードで、描く解像度の比率が決まる（Quality で約 67%、Performance で 50% など）
    - フレーム生成は、別の技術。補間したフレームを足して、見かけのフレーム数を増やす

## 空間方式と時間方式 {#types}

空間方式は、1 フレームの画像だけを入力に、エッジを保ちながら拡大します。組み込みやすく、動きベクトルも要りませんが、元の画像に無い細部は取り戻せません。FSR 1 がこれです。

時間方式は、TAA と同じ発想です。毎フレーム、カメラをサブピクセルだけずらして描くと、フレームごとに少しずつ違う位置をサンプルします。動きベクトルで前のフレームを現在の位置に合わせて重ねると、複数フレーム分のサンプルが集まり、低解像度の描画でも、高解像度に近い情報が得られます。

重ねるときは、前のフレームの情報が、いまの画面で有効か（隠れていないか、物体が変わっていないか）を判断します。この判断を、手作りの規則で行うのが FSR 2 以降の分析型、ニューラル ネットワークで行うのが DLSS と XeSS（と FSR 4）です。

## 組み込みに必要なもの {#inputs}

どのアップスケーラも、必要な入力は似ています。

| 入力 | 内容 |
| --- | --- |
| カラー | 低解像度のシーンの色（ポストプロセスの前、HDR のまま） |
| 深度 | 低解像度の深度 |
| 動きベクトル | 各ピクセルが前のフレームからどれだけ動いたか。動く物体の分も含める |
| ジッター | そのフレームで加えたサブピクセルのずらし量 |
| 露出 | 明るさ。自動露出の値 |

<strong>動きベクトルが一番のつまずき</strong>です。スキンアニメーション、粒子、水面、半透明の動きが抜けていると、残像（ゴースト）やにじみが出ます。ジッターは、ゲームの描画側で投影行列に加えます。ライブラリに渡す値と、実際に加えた値が食い違うと、画面が揺れます。

アップスケールは、トーンマッピングより前に行います。LDR にしてから拡大すると、明るい部分の情報が失われます。UI は、アップスケールの後に、本来の解像度で描きます。

## 品質モード {#modes}

描く解像度を、出力の何割にするかを決めます。

| モード | 描く解像度（片辺）の目安 | 倍率 |
| --- | --- | --- |
| Quality | 約 67% | 1.5 倍 |
| Balanced | 約 58% | 1.7 倍 |
| Performance | 50% | 2 倍 |
| Ultra Performance | 約 33% | 3 倍 |

縦横それぞれの比率なので、ピクセル数では、Performance で 4 分の 1 になります。メーカーや版で、名前や比率が少し違います。

## このセクションの構成 {#pages}

- [FSR](fsr.md)：AMD。オープンソースで、どの GPU でも動く
- [DLSS](dlss.md)：NVIDIA。RTX の専用ユニットで動く
- [XeSS](xess.md)：Intel。Arc では専用ユニット、他の GPU でも動く

3 つの比較は次のとおりです。

| 項目 | FSR | DLSS | XeSS |
| --- | --- | --- | --- |
| 対応 GPU | ほぼ全て | NVIDIA RTX | Intel Arc が最適。他社も可 |
| 方式 | 分析型（FSR 4 は機械学習） | 機械学習 | 機械学習 |
| ソース | 公開 | SDK（ソース非公開） | SDK |
| 画質の傾向 | 軽い。細部やゴーストで差が出る | 高い | DLSS に近い（Arc で） |

複数をゲームに入れる場合、入力（カラー、深度、動きベクトル）は共通なので、描画側の準備を 1 回にして、後ろで切り替えます。Streamline のような抽象化レイヤーも使われます。

## これだけ覚える {#summary}

- 低解像度で描いて拡大する。時間方式は、ジッターと動きベクトルで過去のフレームを使う
- 動きベクトルの質が、画質の決め手
- アップスケールはトーンマッピングの前、UI は後
