# カラー グレーディング

**カラー グレーディング**は、<strong>画面全体の色味・明るさ・コントラストを調整して、作品の「ルック」（見た目の雰囲気）</strong>を**決める**工程です。**映画の色調整（カラリスト）と同じ考え方**で**暖かい夕暮れ・冷たい夜・彩度を落とした荒廃した世界**などを**作ります**。**個々の調整は画素ごとに「色 → 色」の関数**なので**まとめて 3D LUT に焼いて、1 回の表引きで適用**するのが**現代の標準**です。このセクションでは、**基本の調整・リフト/ガンマ/ゲイン・ホワイト バランス・3D LUT・LUT の作り方**を、**1 つずつ別のページ**で説明します。

!!! tip "ポイント"
    - グレーディング ＝ <strong>画素の色を、別の色に変換する関数</strong>（<strong>色 → 色</strong>）。
    - <strong>基本の調整</strong>：<strong>露出・コントラスト・彩度・ホワイト バランス・リフト/ガンマ/ゲイン</strong>。
    - <strong>どの調整も「色 → 色」</strong>なので<strong>3D LUT（32³）に焼いて、1 回の表引き</strong>で<strong>適用</strong>できる。
    - <strong>トーンマップの前か後か</strong>：<strong>広い範囲を扱う調整は前（HDR）、仕上げの色味は後（LDR）</strong>。
    - <strong>LUT は、外部ツール（Photoshop・DaVinci）で作る</strong>こともできる。
    - <strong>場所・時間帯ごとに LUT を切り替え・補間</strong>して、<strong>雰囲気を変える</strong>。
