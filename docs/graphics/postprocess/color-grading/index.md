# Color Grading

**カラー グレーディング**は、<strong>画面全体の色味・明るさ・コントラストを調整して、作品の「ルック」（見た目の雰囲気）</strong>を**決める**工程です。**映画の色調整（カラリスト）と同じ考え方**で**暖かい夕暮れ・冷たい夜・彩度を落とした荒廃した世界**などを**作ります**。**個々の調整は画素ごとに「色 → 色」の関数**なので**まとめて 3D LUT に焼いて、1 回の表引きで適用**するのが**現代の標準**です。このセクションでは、**基本の調整・リフト/ガンマ/ゲイン・ホワイト バランス・3D LUT・LUT の作り方**を、**1 つずつ別のページ**で説明します。

!!! tip "ポイント"
    - グレーディング ＝ <strong>画素の色を、別の色に変換する関数</strong>（<strong>色 → 色</strong>）。
    - <strong>基本の調整</strong>：<strong>露出・コントラスト・彩度・ホワイト バランス・リフト/ガンマ/ゲイン</strong>。
    - <strong>どの調整も「色 → 色」</strong>なので<strong>3D LUT（32³）に焼いて、1 回の表引き</strong>で<strong>適用</strong>できる。
    - <strong>トーンマップの前か後か</strong>：<strong>広い範囲を扱う調整は前（HDR）、仕上げの色味は後（LDR）</strong>。
    - <strong>LUT は、外部ツール（Photoshop・DaVinci）で作る</strong>こともできる。
    - <strong>場所・時間帯ごとに LUT を切り替え・補間</strong>して、<strong>雰囲気を変える</strong>。

## カラー グレーディングとは

カラー グレーディングは、映像全体の色味を調整して、作品のルックを作る作業です。映画では、撮影した素材の色をカラリストが調整して、場面ごとの雰囲気を作ります。冷たい青みの夜、暖かいオレンジの夕暮れ、色あせた荒廃した世界。物語の感情を、色で支えるのが目的です。

ゲームでも同じ目的で使いますが、特徴があります。映画は固定された映像を調整しますが、ゲームは、プレイヤーがどこへでも動き、時刻も天候も変わります。そのため、調整は、ステージや時間帯、体力などの状態に応じて、<strong>滑らかに切り替わる</strong>ように設計します。また、リアルタイムで毎フレーム、全画素に適用するので、軽い必要があります。そこで、あらゆる色調整を 1 つの 3D テクスチャ（LUT）に焼いておき、実行時は表引き 1 回で済ませるのが定石です。

このセクションは、まず個々の調整（コントラスト、彩度、リフト・ガンマ・ゲイン、ホワイト バランス）を理解し、それらを LUT にまとめる方法と、LUT を作って運用する方法を順に説明します。

## 全体の位置

グレーディングの位置づけです。まず、ブルームや DOF などを済ませた HDR のカラー画像があります。次に、露出とトーンマップで HDR を LDR に変換します（[Tone Mapping and Exposure](../tonemapping/index.md)）。その後のグレーディングで、LDR（または HDR の対数空間）の色味を調整します。最後に、ガンマ変換して sRGB へ出力します（[Gamma and HDR Output](../tonemapping/gamma-srgb.md)）。
