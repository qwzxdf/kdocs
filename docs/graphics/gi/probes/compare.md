# Comparison with Reflection Probes and Cost

<strong>GI のプローブと反射プローブは、名前が似ていますが役割が違います</strong>。GI のプローブは「拡散の間接光」、反射プローブは「鏡面の反射」です。このページでは違いとコスト・長所短所を説明します。

!!! tip "ポイント"
    - GI プローブ ＝ 拡散・低周波・SH で保存。
    - 反射プローブ ＝ 鏡面・高周波・キューブマップで保存。
    - 両方を併用するのが普通。
    - GI プローブは軽く、動く物体にも使える。ただし、細かい影は出ない。

## 反射プローブとの違い
| 項目 | ライト プローブ | 反射プローブ |
| --- | --- | --- |
| 保存するもの | 放射照度（拡散の間接光） | 放射輝度（周囲の画像） |
| 周波数 | 低い | 高い |
| 保存形式 | SH・少数の数値 | キューブマップ |
| 用途 | 拡散反射 | 鏡面反射 |
| 密度 | やや密 | <strong>疎（部屋ごと）</strong> |

反射プローブは[Reflection Probes](../../reflections/probes/index.md)で説明しています。両方を置いて、拡散と鏡面の間接光をそれぞれ賄います。

## コストと利点
| 項目 | 内容 |
| --- | --- |
| 実行時のコスト | 補間 ＋ SH の評価。非常に安い |
| メモリ | プローブ数 × 係数。ライトマップよりはるかに小さい |
| 動く物体への適用 | 自然に対応 |
| 品質の限界 | 低周波のみ。<strong>細かい間接光の影（接触部）</strong>は出ない（AO で補う） |

## 長所と短所
| 長所 | 短所 |
| --- | --- |
| 動く物体に間接光を与えられる | 低周波のみ（細かい間接影が出ない） |
| 安い・小さい | ライト リーク（壁越しの漏れ） |
| ライトマップと併用しやすい | 配置の手間（品質が置き方次第） |
| 動的な更新に拡張できる | ベイクのままでは、光の変化に追従できない |


### どちらをいつ使うか

ライト プローブは <strong>ほぼすべての 3D ゲームに置く</strong>と考えて構いません。動く物体に自然な陰影を与える最も安い方法だからです。反射プローブは つるつるした面が多いシーン（金属、濡れた床、窓ガラス）で必要になります。マットな素材ばかりのシーンなら、反射プローブは少数で済みます。どちらも、ライトマップと矛盾しない見た目になるよう、同じ光源・同じシーンから作ることが大切です。

### どちらをいつ使うか

ライト プローブは ほぼすべての 3D ゲームに置くと考えて構いません。動く物体に自然な陰影を与える最も安い方法だからです。反射プローブは つるつるした面が多いシーン（金属、濡れた床、窓ガラス）で必要になります。マットな素材ばかりのシーンなら、反射プローブは少数で済みます。どちらも、ライトマップと矛盾しない見た目になるよう、同じ光源・同じシーンから作ることが大切です。

## 反射プローブと GI プローブは別物

「プローブ」という <strong>名前が同じ</strong>ですが、GI プローブ（ライト プローブ、拡散の間接光）と反射プローブ（リフレクション プローブ、鏡面の反射）は目的も保存する、データも違います。

| | GI プローブ（ライト プローブ） | 反射プローブ |
| --- | --- | --- |
| 目的 | 拡散の間接光（環境光） | 鏡面の、反射（周りの景色が映る） |
| 保存するもの | SH 係数（27 個の数） | キューブマップ（周りの景色の画像。128×128×6 など） |
| データの大きさ | 非常に、小さい（数百バイト） | 大きい（数百 KB〜数 MB、ミップつき） |
| 方向の細かさ | ごくなめらか（L2） | 細かい（景色が、そのまま見える） |
| 数 | 数千個（格子状に、密に） | 数十個（部屋ごと、エリアごと） |
| 補間 | 周りのプローブを、補間 | 1 つ（最も近いまたは、影響範囲が重なる 2〜3 個を、ブレンド） |
| 読み方 | 法線で放射照度を、求める | 反射ベクトルでキューブマップを、読む |
| ページ | このセクション | [Reflection Probes](../../reflections/probes/index.md) |

## 同じ「場所」に 2 種類を置く

<strong>部屋の中</strong>に GI プローブ（格子状、数十個）と反射プローブ（1〜2 個）を同時に置き描画のときに両方を、読みます。

```hlsl
// 拡散: GI プローブ（SH）から。鏡面: 反射プローブ（キューブマップ）から。両方を、足す。
float3 diffuse = albedo / 3.14159265 * IrradianceFromSH9(InterpolatedSH(world_pos), N);
float3 specular = SampleReflectionProbe(world_pos, R, roughness) * (f0 * brdf.x + brdf.y);
float3 indirect = kd * diffuse + specular;
```

拡散と鏡面の間接光（[Diffuse and Specular](../theory/diffuse-specular.md)）を 別の、プローブでまかないます。どちらも、場所ごとの光を保存する仕組みで、考え方は似ています。

## コスト

| 項目 | GI プローブ | 反射プローブ |
| --- | --- | --- |
| メモリ（1 個） | 54 バイト（SH L2、16 ビット） | 約 400 KB（128×128×6、ミップつき `R16G16B16A16`） |
| メモリ（シーン全体） | 数千個で、数百 KB〜数 MB | 数十個で、数十 MB |
| 描画時のコスト | 補間（8 プローブ × SH 評価）。軽い | キューブマップの読み込み 1〜2 回。軽い |
| 更新のコスト（動的） | SH を、再計算（軽い） | キューブマップを、再レンダリング（重い） |
| ベイクの時間 | 短い | 短い |

<strong>GI プローブはメモリが小さい</strong>ので、非常に密に、置けます。反射プローブは 1 つが大きいので数を、絞ります。

## 使い分けの目安

| 状況 | 使うもの |
| --- | --- |
| 動く物の拡散の環境光 | GI プローブ |
| 床や水たまりの反射、金属の鏡面 | 反射プローブ |
| 屋外の環境光（空） | 空の SH（1 つ）、空のキューブマップ（1 つ） |
| 室内の環境光 | GI プローブ（部屋ごとに、密に）+ 反射プローブ（部屋ごとに、1 つ） |

## まとめて扱う仕組み

<strong>エンジンによっては</strong>、1 つのプローブが SH とキューブマップの、両方を持つ（ライト プローブ + 反射プローブを、同じ位置にまとめる）作りになっています。配置の手間が減ります。ただし、必要な密度が違う（GI は密、反射は疎）ので別々に配置したほうが、効率的な場合もあります。
