# Comparison with Reflection Probes and Cost

**GI のプローブと、反射プローブは、名前が似ていますが、役割が違います**。**GI のプローブは「拡散の間接光」、反射プローブは「鏡面の反射」**です。このページでは、**違いと、コスト・長所短所**を説明します。

!!! tip "ポイント"
    - **GI プローブ ＝ 拡散・低周波・SH で保存**。
    - **反射プローブ ＝ 鏡面・高周波・キューブマップで保存**。
    - **両方を、併用する**のが**普通**。
    - **GI プローブは、軽く、動く物体にも使える。ただし、細かい影は出ない**。

## 反射プローブとの違い
ライト プローブと反射プローブは、保存するものがまったく違います。ライト プローブは<strong>放射照度</strong>（拡散の間接光）を、SH や少数の数値で保存します。反射プローブは<strong>放射輝度</strong>（周囲の画像そのもの）を、キューブマップで保存します。周波数は、ライト プローブが低く、反射プローブは高いです。用途は、前者が拡散反射、後者が鏡面反射です。置く密度も違い、ライト プローブはやや密に、反射プローブは部屋ごとに 1 個程度と疎に置きます。

**反射プローブ**は、[Reflection Probes](../../reflections/probes/index.md)で説明しています。**両方を置いて**、**拡散と鏡面の間接光**をそれぞれ賄います。

## コストと利点
コストと利点を整理します。実行時のコストは、補間と SH の評価だけで、非常に安いです。メモリは、プローブ数に係数を掛けた量で、ライトマップよりはるかに小さくなります。動く物体への適用は、自然に対応できます。品質の限界は、低周波のみであることで、細かい間接光の影（接触部）は出ないので、AO で補います。

## 長所と短所
長所は、動く物体に間接光を与えられること、安くて小さいこと、ライトマップと併用しやすいこと、動的な更新に拡張できることです。短所は、低周波のみで細かい間接影が出ないこと、壁越しのライト リークがあること、品質が置き方次第で配置の手間がかかること、そしてベイクのままでは光の変化に追従できないことです。

### どちらをいつ使うか

ライト プローブは、**ほぼすべての 3D ゲームに置く**と考えて構いません。動く物体に自然な陰影を与える最も安い方法だからです。反射プローブは、**つるつるした面が多いシーン**（金属、濡れた床、窓ガラス）で必要になります。マットな素材ばかりのシーンなら、反射プローブは少数で済みます。どちらも、**ライトマップと矛盾しない見た目**になるよう、同じ光源・同じシーンから作ることが大切です。
