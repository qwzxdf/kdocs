# ライトマップ UV（UV2）

**ライトマップは、モデルの面ごとに「専用の場所」が必要**で、**通常のテクスチャの UV は、同じ場所を使い回す（重なる）ので、使えません**。**重ならない、専用の UV（UV2）**を用意します。このページでは、**UV2 の条件と、作り方**を説明します。

!!! tip "ポイント"
    - **UV2 ＝ 面が重ならない、ライトマップ専用の UV**。
    - **面と面の間に、余白（パディング）を取る**（にじみ防止）。
    - **面積を、実際の大きさに比例させる**（解像度を揃える）。
    - **自動生成のツールがある**。

## ライトマップ UV（UV2）
**通常のテクスチャ UV**は、**タイリング（繰り返し）や、同じパーツの使い回し**をします。**ライトマップは、各表面点が固有の場所**を持たなければならないので、**専用の UV**（**UV2**、2 番目の UV セット）が必要です。

| 要件 | 理由 |
| --- | --- |
| **重ならない** | **別の面の光**が**混ざる**のを防ぐ |
| **0〜1 の範囲に収める** | **1 枚のテクスチャ**に入る |
| **歪みが少ない** | **テクセルあたりの面積**が**均一**になる（**ライトの解像度が場所で変わらない**） |
| <strong>面ごとの分離（アイランド）</strong> | **面の境目で光が不連続**でもにじまない |
| <strong>マージン（パディング）</strong> | **アイランドの外側**に**余白**を持たせ、**バイリニア補間で隣のアイランドの色**が**にじまない**ようにする |
| **面積に比例した割り当て** | **大きい面は多くのテクセル** |

**UV2 はツール（DCC・エンジン）で自動生成**されることが多く、<strong>パッキング（アイランドの敷き詰め）</strong>は、**ライトマップの効率**を左右します。

### テクセル密度

**ライトマップの 1 テクセルが、ワールドで何 cm か**（**テクセル密度**）が、**影の細かさ**を決めます。

| 密度の目安 | 用途 |
| --- | --- |
| <strong>粗い（例：1 テクセル = 1 m）</strong> | **遠景・床・大きな面** |
| <strong>標準（例：10〜20 cm）</strong> | **屋内・主要な面** |
| <strong>細かい（例：数 cm）</strong> | **影の細部が重要な、重要なオブジェクト** |

**細かくするほど**、**メモリ・ベイク時間**が増えます。

## よくあるミス

??? failure "面の境目に、暗い線やにじみが出る"
    **余白を増やす**・**ベイク後に端の色を広げる**。
