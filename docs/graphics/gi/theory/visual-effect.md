# Visual Effect

<strong>間接光があると影の中が真っ黒ではなくなり、色が周りへにじみ（カラー ブリーディング）、物が「そこにある」ように見えます</strong>。このページでは 間接光が見た目にもたらす効果を説明します。

!!! tip "ポイント"
    - 影の中が真っ黒ではなくなる。
    - 色のにじみ（赤い壁の近くの白い物が赤みを帯びる）。
    - 物が地面になじみ、「浮いて」見えなくなる。
    - 室内の明るさが自然になる。

## 間接光の見た目への効果

間接光が見た目にもたらす効果は、大きく 4 つあります。

### 日陰の明るさ

直接光だけで描くと影の中は完全に真っ黒になります。現実の日陰が真っ黒でないのは、空や周りの壁から回り込む光があるからです。この光があるので影の中の物の形や色が見えます。GI のない絵が「CG っぽい」と感じるのは、この日陰の描き方が不自然だからです。最低限、環境光（アンビエント）を一定値で足すだけでも、真っ黒は避けられます。ただし、一定値では場所による明るさの差が出ず、のっぺりします。

### カラー ブリーディング

赤い壁の隣にある白い床は壁で反射した赤い光を受けて、ほんのり赤く染まります。これが色のにじみ（カラー ブリーディング）です。効果は微妙ですがシーン全体が一体感を持ちます。白い部屋に赤いソファがあるとき、ソファのまわりの壁と床が赤みを帯びる、といった具合です。

### 接地感

[AO](../../ao/index.md) と合わせて物が地面になじみます。AO は「近くの物による遮蔽」を暗さで表し、GI は「近くの物から反射した光」を色で表します。両方が揃うと物が浮いて見える現象が減ります。

### 室内の明るさ

窓から差し込む光が床や壁で何度も反射して、部屋全体を柔らかく照らします。直接光だけでは窓際だけが明るく、奥は真っ暗になってしまいます。GI があれば奥までほんのり明るくなり、自然な室内の明るさが出ます。

### 効果の大きさ

これらの効果は直接光に比べると小さな変化ですが、人間の目は現実の光の回り込みにとても慣れているので、欠けていると違和感を覚えます。品質を上げるための優先順位としては、<strong>影の中が真っ黒でないこと</strong>が最初、次に場所による明るさの差、最後に色のにじみの順に効果が大きいことが多いです。

## 間接光がないとどうなるか

<strong>直接光だけ</strong>でシーンを描くと、影の中は真っ黒で光が当たる、面だけが明るいコントラストの、強すぎる絵になります。現実の世界は光が反射を繰り返して、影の中もほのかに明るいのです。間接光の効果を数値で確かめます。

## 効果 1：日陰が明るくなる

<strong>晴れた日の日陰</strong>の明るさは、日向の約 1/5〜1/10です。真っ暗ではありません。空全体が光源（青い空の光）で日陰を照らすためです。

| 場所 | 照度（目安、lux） |
| --- | --- |
| 日向（晴れ） | 約 100,000 |
| 日陰（空の光だけ） | 約 10,000〜20,000 |
| 曇りの日 | 約 20,000 |
| 室内（窓際） | 約 1,000 |

日向と日陰の比は約 5〜10 倍です。GI の環境光が無いと日陰は完全な、0（無限大のコントラスト）になります。

```hlsl
// 直接光だけ（日陰は真っ黒）。
float3 color = albedo * g_sun_color * n_dot_l * shadow;

// 間接光（空の光）を足す。日陰でも、albedo × 環境光 で、ほのかに、明るい。
float3 ambient = albedo * IrradianceFromSH9(g_sky_sh, N) / 3.14159265;
float3 color2 = albedo * g_sun_color * n_dot_l * shadow + ambient;
```

1 行足すだけで 日陰が真っ黒でなくなり、絵の印象が大きく変わります。間接光の最も基本的な効果です。

## 効果 2：カラー ブリーディング（色のにじみ）

<strong>色のついた面</strong>（赤い壁）に光が当たると 反射した光もその色に染まります。その光が隣の白い面を照らすと、白い面がうっすら赤くなります。これをカラー ブリーディングと、呼びます。

```text
白い光 ──→ 赤い壁（albedo 0.8, 0.1, 0.1）──→ 反射光は、赤い（0.8, 0.1, 0.1 に、比例）
                              ↓
                       隣の、白い床が、赤く、染まる
```

1 回のバウンスで床に届く光は、壁の `albedo` に比例します。

```hlsl
// 赤い壁からの、1 バウンスの、光（簡易な、見積もり）。
float3 bounced = wall_albedo * wall_direct_irradiance / 3.14159265;     // 壁が反射する、放射輝度（拡散）
float3 floor_indirect = floor_albedo * bounced * form_factor;           // 床に届く量。form_factor: 壁と床の、幾何学的な、関係（見える割合）
```

`form_factor`（形状係数）は 壁が床から、どれだけ広く見えるか（近く、大きいほど大きい）を表します（ラジオシティの、基本的な量。Goral ら 1984）。壁が近いほどにじみが強くなります。

| 状況 | にじみの強さ |
| --- | --- |
| 赤い壁のすぐ近くの白い物 | 強い |
| 壁から離れる | 弱い（`form_factor` が、小さい） |
| 暗い壁 | 弱い（反射が少ない） |

## 効果 3：接地感（物が地面になじむ）

<strong>間接光が遮られた</strong>場所（物と地面の、接する所、角）は暗くなります。AO（[AO](../../ao/index.md)）がこの暗さを表します。物が地面に「乗っている」感じ（接地感）が出ます。GI があると AO が自然に含まれます（遮蔽された光は届かないので）。

## 効果 4：室内の明るさ

<strong>窓から差し込む光</strong>は 床や壁で何度も、反射して部屋全体をほのかに、照らします。直接光だけでは日だまりだけが明るく他は、真っ暗です。

### 何回反射するか：等比級数

平均的なアルベド `ρ`（反射率）の、閉じた部屋で光が何度も反射するとき、全体の明るさは初めの光の何倍になるでしょうか。k 回目の反射で光は `ρ^k` 倍になるので合計は、等比級数です。

```text
合計 = 1 + ρ + ρ² + ρ³ + … = 1 / (1 − ρ)
```

| 部屋の平均アルベド ρ | 合計（倍率） | 見た目 |
| --- | --- | --- |
| 0.2（暗い床・壁） | 1.25 倍 | 間接光は、わずか |
| 0.5（中くらい） | 2 倍 | 間接光が直接光と同じくらい |
| 0.8（白い部屋） | 5 倍 | 間接光が直接光の 4 倍。部屋が明るい |

白い部屋ほど 間接光の寄与が大きく、GI の有無で見た目が大きく、変わります。

## 効果の大きさの目安

| 場面 | 間接光が全体の明るさに、占める割合 |
| --- | --- |
| 晴れた屋外（日向） | 10〜20%（空の光 + 地面の反射） |
| 晴れた屋外（日陰） | ほぼ 100%（日陰は、間接光だけ） |
| 室内（窓からの光） | 50〜90%（直接光が当たらない部分は 100%） |
| 洞窟（入口からの光） | ほぼ 100% |

<strong>屋外の日向</strong>では 直接光が支配的なので GI の効果は、小さく見えますが日陰、室内、洞窟では GI が見た目のすべてです。

## GI を近似する簡易な方法

<strong>GI の効果を手軽に得る</strong>には、簡単な近似があります。

| 方法 | 内容 | 効果 |
| --- | --- | --- |
| 半球ライト | 上は空の色、下は地面の色（[Using the Sky for Lighting](../../atmosphere/sky-models/sky-lighting.md)） | 日陰の、明るさ（方向性はわずか） |
| AO | 隙間を暗く（[AO](../../ao/index.md)） | 接地感 |
| マルチ バウンスの AO（GTAO） | AO をアルベドに応じて明るく戻す（[GTAO](../../ao/gtao.md)） | 白い面の、AO が暗すぎない |
| 環境光のプローブ（SH） | 場所ごとに、環境光を補間 | 場所による、明るさの違い（[Probe GI](../probes/index.md)） |
