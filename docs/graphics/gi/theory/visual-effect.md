# Visual Effect

<strong>間接光があると、影の中が真っ黒ではなくなり、色が周りへにじみ（カラー ブリーディング）、物が「そこにある」ように見えます</strong>。このページでは、<strong>間接光が、見た目にもたらす効果</strong>を説明します。

!!! tip "ポイント"
    - 影の中が、真っ黒ではなくなる。
    - 色のにじみ（赤い壁の近くの白い物が、赤みを帯びる）。
    - 物が地面になじみ、「浮いて」見えなくなる。
    - 室内の明るさが、自然になる。

## 間接光の見た目への効果

間接光が見た目にもたらす効果は、大きく 4 つあります。

### 日陰の明るさ

直接光だけで描くと、影の中は完全に真っ黒になります。現実の日陰が真っ黒でないのは、空や周りの壁から回り込む光があるからです。この光があるので、影の中の物の形や色が見えます。GI のない絵が「CG っぽい」と感じるのは、この日陰の描き方が不自然だからです。最低限、環境光（アンビエント）を一定値で足すだけでも、真っ黒は避けられます。ただし、一定値では場所による明るさの差が出ず、のっぺりします。

### カラー ブリーディング

赤い壁の隣にある白い床は、壁で反射した赤い光を受けて、ほんのり赤く染まります。これが色のにじみ（カラー ブリーディング）です。効果は微妙ですが、シーン全体が一体感を持ちます。白い部屋に赤いソファがあるとき、ソファのまわりの壁と床が赤みを帯びる、といった具合です。

### 接地感

[AO](../../ao/index.md) と合わせて、物が地面になじみます。AO は「近くの物による遮蔽」を暗さで表し、GI は「近くの物から反射した光」を色で表します。両方が揃うと、物が浮いて見える現象が減ります。

### 室内の明るさ

窓から差し込む光が、床や壁で何度も反射して、部屋全体を柔らかく照らします。直接光だけでは、窓際だけが明るく、奥は真っ暗になってしまいます。GI があれば、奥までほんのり明るくなり、自然な室内の明るさが出ます。

### 効果の大きさ

これらの効果は、直接光に比べると小さな変化ですが、人間の目は、現実の光の回り込みにとても慣れているので、欠けていると違和感を覚えます。品質を上げるための優先順位としては、<strong>影の中が真っ黒でないこと</strong>が最初、次に<strong>場所による明るさの差</strong>、最後に色のにじみの順に効果が大きいことが多いです。

## よくあるミス

??? failure "GI なしで、影の中が真っ黒"
    <strong>最低限、環境光（アンビエント）を入れる</strong>。
