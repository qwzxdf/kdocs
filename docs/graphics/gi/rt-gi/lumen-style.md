# Lumen-Style Approaches

<strong>Lumen のような方式は、シーンを簡略化した表現（距離場やサーフェス キャッシュ）でレイを飛ばし、結果をキャッシュして、再利用します</strong>。<strong>ハードウェアのレイトレが無くても動く</strong>のが特徴です。このページでは、この方式の構成と、利点・欠点を説明します。

!!! tip "ポイント"
    - シーンを簡略化して持つ（距離場・サーフェス キャッシュ）。
    - 画面のプローブから、簡略化したシーンへトレース。
    - 結果をキャッシュして、時間的に再利用。
    - ハードウェア RT が無い環境でも動く。
    - 細部の精度は、ハードウェア RT に劣る。

## Lumen 的な方式
<strong>Unreal Engine 5 の Lumen</strong>は、<strong>ハードウェア レイトレースが無くても</strong>動くGIです。複数の手法を階層的に組み合わせています。

| 要素 | 内容 |
| --- | --- |
| サーフェス キャッシュ | <strong>メッシュの表面を小さな「カード」</strong>にキャプチャし、各カードに直接光・間接光を保存（ヒット点の光を安く得るため） |
| 距離場によるトレース | メッシュごとの SDFとグローバル SDFで、ソフトウェア レイトレース（[Distance Field Shadows](../../shadows/sdf-shadows.md)） |
| <strong>画面空間トレース（最初の手段）</strong> | 近距離は画面の深度バッファで精密にトレース（[SSGI](../ssgi.md)） |
| スクリーン プローブ | 画面上に間引いて置いたプローブから、レイを飛ばし、画素へ補間（画素ごとにレイを飛ばさない） |
| <strong>ワールド プローブ（遠距離）</strong> | 遠くの光は世界空間の粗いプローブから |
| HW RT モード | 対応 GPUでは、距離場の代わりにハードウェア レイトレース |


<strong>サーフェス キャッシュ</strong>は、メッシュの表面を小さな「カード」としてキャプチャし、各カードに直接光と間接光を保存します。レイが当たった点の光を、安く得るための仕組みです。三角形から毎回ライティングを計算する代わりに、カードの上のテクスチャを読めば済みます。<strong>距離場によるトレース</strong>は、メッシュごとの SDF とグローバル SDF を使ったソフトウェアのレイトレースです（[Distance Field Shadows](../../shadows/sdf-shadows.md)）。<strong>画面空間トレース</strong>は、近距離を画面の深度バッファで精密に追う、最初の手段です（[SSGI](../ssgi.md)）。画面で見つからなければ、距離場に移ります。

<strong>スクリーン プローブ</strong>が、コストを下げる鍵です。画面を 16×16 画素程度のタイルに区切り、タイルごとに 1 個のプローブを置いて、プローブからだけレイを飛ばします。各プローブは、八面体マップに方向ごとの放射輝度を持ちます。画素は、周りのプローブから補間して間接光を得ます。<strong>画素ごとにレイを飛ばさない</strong>ので、レイの数を 1/100 以下に減らせます。<strong>ワールド プローブ（遠距離）</strong>は、遠くの光を、世界空間の粗いプローブから読みます。そして、対応 GPU では、距離場の代わりに<strong>ハードウェア レイトレース</strong>のモードも使えます。

## 考え方のまとめ

Lumen の設計思想は、<strong>「正確さを段階ごとに捨てて、コストを下げる」</strong>ことです。近距離は画面の深度で精密に、中距離は距離場で粗く、遠距離はワールド プローブでさらに粗く追います。見た目への影響は、近いほど大きく、遠いほど小さいので、この配分が理にかなっています。レイは画素ごとでなく、間引いたプローブから飛ばし、結果はキャッシュとして時間方向に再利用します。

トレードオフは、簡略化したシーンを使うことで、細部の精度が落ちることです。薄い壁、小さな隙間、細かい模様の物体では、距離場の解像度が足りず、光漏れや暗すぎる箇所が出ます。ハードウェアのレイトレースを併用すれば、これらは大きく改善されます。

## よくあるミス

??? failure "薄い壁や小さい物で、光漏れが起きる"
    <strong>簡略化の精度を上げる</strong>・<strong>ハードウェア RT を併用</strong>する。
