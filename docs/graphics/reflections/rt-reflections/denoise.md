# Denoising

<strong>1 画素 1 本のレイでは、粗い面の反射はノイズだらけ</strong>になります。これを時間方向（前フレームの再利用）と、空間方向（周囲の画素との平均）のフィルタで消すのがデノイザです。このページではデノイズの仕組みと、長所・短所を説明します。

!!! tip "ポイント"
    - 時間フィルタ：前フレームの結果を再投影して混ぜる。
    - 空間フィルタ：法線・深度・粗さが近い画素だけ平均。
    - 反射は見る角度で変わるので、反射の「当たった位置」で再投影する（仮想位置）。
    - デノイズ後はぼやけ・ゴーストに注意。

## ノイズ除去（デノイズ）
<strong>画素ごと 1 本</strong>では ノイズが大きすぎます。デノイザーで空間・時間の平均を取ります。

| 要素 | 内容 |
| --- | --- |
| 時間蓄積 | 再投影で過去フレームと混ぜる。反射像はヒット距離を使って仮想的な位置へ再投影 |
| 空間フィルタ | バイラテラル（深度・法線・粗さ）。粗さに比例して広く |
| ヒット距離 | 近い当たり（接地部）は、フィルタを狭く遠い当たりは広く（反射の見た目が距離でぼけるため） |
| 分散による制御 | 時間的な分散が大きい画素は、フィルタを強く（SVGF の考え方） |
| ホタル除去 | 極端に明るいサンプルを、制限する |


### なぜ「仮想位置」で再投影するのか

鏡面反射は見る角度が変わると、映る像の位置が変わります。普通のオブジェクトなら画素の位置から前フレームの位置を求めれば再投影できます。しかし、反射像は表面にあるのでなく鏡の奥に「虚像」として存在します。カメラが動くと表面は少ししか動かなくても、虚像は大きく動きます。そこで、ヒット距離を使って虚像の位置（鏡の奥の位置）を求め、その位置を前フレームに再投影すると、反射像が正しく追従します。表面の位置で再投影すると反射像がずるずる滑ってゴーストになります。

### なぜ「仮想位置」で再投影するのか

鏡面反射は見る角度が変わると、映る像の位置が変わります。普通のオブジェクトなら画素の位置から前フレームの位置を求めれば再投影できます。しかし、反射像は表面にあるのでなく鏡の奥に「虚像」として存在します。カメラが動くと表面は少ししか動かなくても、虚像は大きく動きます。そこで、ヒット距離を使って虚像の位置（鏡の奥の位置）を求め、その位置を前フレームに再投影すると、反射像が正しく追従します。表面の位置で再投影すると反射像がずるずる滑ってゴーストになります。

代表的なデノイザー：

代表的なデノイザーは 3 つあります。SVGF（Spatiotemporal Variance-Guided Filtering）は、分散を使った時空間のバイラテラルで、レイトレ反射・GI の定番です。ReBLUR / ReLAX（NVIDIA NRD）は、ヒット距離と粗さを考慮した実用的なデノイザー群です。自作の場合は確率的 SSR のリゾルブ、時間蓄積、バイラテラルをそのまま流用できます。

## 長所と短所
| 長所 | 短所 |
| --- | --- |
| 画面外・裏側・半透明の向こうまで正確 | レイトレ対応 GPU が必要 |
| 反射の反射も可能 | コストが大きい（BVH・シェーディング・デノイズ） |
| 品質が高い（ハロー・厚みの問題なし） | ノイズが出る。デノイザーが必須 |
| シーン全体を一貫して扱える | 動く物体の BVH 更新・メモリ |

## 反射のノイズ

<strong>粗い面</strong>の RT 反射は 1 画素 1 本の、レイをランダムな方向に飛ばすので、ノイズだらけです。GI のデノイズ（[Fighting Noise](../../gi/rt-gi/noise.md)）と、似ていますが反射には反射特有の問題が、あります。

| | GI（拡散の間接光） | 反射（鏡面） |
| --- | --- | --- |
| ノイズの性質 | 低周波（なめらかな、光） | 高周波（反射する物の、細かい形が見える） |
| 視点依存 | 無し | 有り（見る角度で反射が、変わる） |
| 時間蓄積 | 画面上の同じ点を、再投影で追える | 反射像は、画面上の点とは別の位置に動く（視差）。再投影が難しい |
| フィルタの範囲 | 広く、ぼかしてもよい（なめらか） | 広く、ぼかすと反射の形が失われる（鏡面は、くっきり） |

## 反射の時間蓄積：反射像の位置を追う

<strong>反射する面</strong>（床）の 画素は、カメラが動かなくても反射像（映っている物）が動けば、変わります。普通の再投影（面の位置を再投影）は面の色には、正しいですが反射像は面より奥に、映っているのでずれて反射がぼやけます。

```text
カメラが、右に、動く:
   床の点 P は、画面上で、左へ動く（面の動き）
   P に映る、反射像（遠い物）は、画面上で、もっと、少ししか、動かない（遠いので）
   → P の位置で、再投影すると、反射像が、ずれて、ぼやける（ゴースト）
```

### 反射像の位置を再投影する

反射像が当たった、ヒット位置（反射の中の物の位置）を、再投影します。ヒット位置の前フレームでの画面位置で履歴を、読みます。

```hlsl
// 反射の、ヒット位置（ワールド）を、前フレームの画面へ投影して、反射像の、履歴を読む。
float3 hit_world = position + reflect_dir * hit_distance;                    // 反射レイが、当たった位置
float4 prev_clip = mul(float4(hit_world, 1.0), g_prev_view_proj);
float2 prev_uv = prev_clip.xy / prev_clip.w * float2(0.5, -0.5) + 0.5;
float4 history = g_reflection_history.SampleLevel(g_linear_clamp, prev_uv, 0);
```

鏡面の、反射像は「ヒット位置」が、画面上でどこに動くかで追えます（仮想的な鏡像の位置を追う、考え方）。面の位置で再投影するより反射像が、ずれません。

粗い面（反射がぼやけている）では、面の位置での再投影でもあまり、目立たない（ぼけているので）。粗さに応じて 2 つの再投影を、混ぜる方法もあります。

## 空間フィルタ

<strong>時間蓄積の後</strong>、まだ残るノイズを空間フィルタで、ぼかします。GI のデノイザーと同じエッジを保つ、フィルタ（À-Trous など）を、使いますが反射の特徴に合わせます。

| 工夫 | 内容 |
| --- | --- |
| 粗さに比例したフィルタ半径 | 粗い面は、広くぼかすつるつるの面はほとんどぼかさない（ぼかすと反射が、失われる） |
| ヒット距離を考慮 | 反射の、ヒット位置が遠いほどぼけが大きい（反射の円錐が、広がる）。ヒット距離に応じてフィルタ半径を、変える |
| 法線・深度でエッジを保つ | GI と同じ。別の面をまたいで混ぜない |
| ヒット位置でエッジを保つ | 反射像の、境目（別の物が映っている）を、越えない |

```hlsl
// フィルタ半径を、粗さとヒット距離から決める。つるつる・近い反射は、ほとんど、ぼかさない。
float radius = g_max_filter_radius * saturate(roughness * 2.0) * saturate(hit_distance / g_blur_distance);
```

## ノイズを減らす入力側の工夫

| 工夫 | 内容 |
| --- | --- |
| 可視法線のサンプリング（Heitz、2018） | 無駄なサンプルを減らし、ノイズが少ない（[Ray Generation](ray-generation.md)） |
| ブルー ノイズ | ノイズの粒が均一で、フィルタが効きやすい |
| 明るさのクランプ | ファイアフライ（太陽を拾った、白い点）を抑える |
| 粗さに応じたミップ | 反射先の、テクスチャを粗いミップで読む（高周波を、減らす） |
| 複数レイ（粗い面） | 粗さが、大きい画素はレイを増やす |

## 専用のデノイザーを使う

<strong>デノイザーを自作</strong>するのは、大変です。ライブラリがあります。

| ライブラリ | 内容 |
| --- | --- |
| NVIDIA Real-Time Denoisers（NRD） | 反射・拡散・影の、リアルタイム デノイザー。ReBLUR、ReLAX など |
| AMD FidelityFX Denoiser | 反射・影の、デノイザー |
| Intel Open Image Denoise | オフライン向けの、高品質デノイザー（ニューラル ネット）。リアルタイムには重い |

反射と拡散を 別々に、デノイズするのが一般的です（性質が、違うため。[Diffuse and Specular](../../gi/theory/diffuse-specular.md)）。

## 限界

| 問題 | 内容 |
| --- | --- |
| ぼやけ | 強くフィルタすると、鏡面反射の細部が失われる |
| ゴースト | 時間蓄積で、動く物の反射が残像を引く |
| ちらつき | 粗い面でデノイザーの判断が、揺れる |
| つるつるの面 | ほぼノイズが、ないのでデノイズ不要（ぼかさない） |
