# Denoising

**1 画素 1 本のレイでは、粗い面の反射は、ノイズだらけ**になります。**これを、時間方向（前フレームの再利用）と、空間方向（周囲の画素との平均）のフィルタで消すのがデノイザ**です。このページでは、**デノイズの仕組みと、長所・短所**を説明します。

!!! tip "ポイント"
    - **時間フィルタ：前フレームの結果を再投影して混ぜる**。
    - **空間フィルタ：法線・深度・粗さが近い画素だけ、平均**。
    - **反射は、見る角度で変わるので、反射の「当たった位置」で再投影する**（仮想位置）。
    - **デノイズ後は、ぼやけ・ゴーストに注意**。

## ノイズ除去（デノイズ）
**画素ごと 1 本**では、**ノイズ**が大きすぎます。**デノイザー**で**空間・時間**の平均を取ります。

デノイズの構成要素は、次のとおりです。<strong>時間蓄積</strong>は、再投影で過去のフレームと混ぜますが、反射像は、ヒット距離を使って<strong>仮想的な位置</strong>へ再投影するのが重要です。<strong>空間フィルタ</strong>は、深度・法線・粗さを手がかりにしたバイラテラルで、粗さに比例して範囲を広げます。<strong>ヒット距離</strong>によってフィルタの幅を変え、近い当たり（接地部）は狭く、遠い当たりは広くします。反射の見た目が距離でぼけるためです。<strong>分散による制御</strong>は、時間的な分散が大きい画素のフィルタを強める SVGF の考え方です。<strong>ホタル除去</strong>は、極端に明るいサンプルを制限します。

### なぜ「仮想位置」で再投影するのか

鏡面反射は、見る角度が変わると、映る像の位置が変わります。普通のオブジェクトなら、画素の位置から前フレームの位置を求めれば再投影できます。しかし、反射像は、表面にあるのでなく、鏡の奥に「虚像」として存在します。カメラが動くと、表面は少ししか動かなくても、虚像は大きく動きます。そこで、ヒット距離を使って虚像の位置（鏡の奥の位置）を求め、その位置を前フレームに再投影すると、反射像が正しく追従します。表面の位置で再投影すると、反射像がずるずる滑ってゴーストになります。

**代表的なデノイザー**：

代表的なデノイザーは、3 つあります。<strong>SVGF</strong>（Spatiotemporal Variance-Guided Filtering）は、分散を使った時空間のバイラテラルで、レイトレ反射・GI の定番です。<strong>ReBLUR / ReLAX</strong>（NVIDIA NRD）は、ヒット距離と粗さを考慮した、実用的なデノイザー群です。<strong>自作</strong>の場合は、確率的 SSR のリゾルブ、時間蓄積、バイラテラルを、そのまま流用できます。

## 長所と短所
レイトレ反射の長所は、画面外・裏側・半透明の向こうまで正確に映せること、反射の反射も可能なこと、ハローや厚みの問題がなく品質が高いこと、シーン全体を一貫して扱えることです。短所は、レイトレ対応の GPU が必要なこと、BVH・シェーディング・デノイズでコストが大きいこと、ノイズが出てデノイザーが必須なこと、動く物体の BVH 更新とメモリが重いことです。
