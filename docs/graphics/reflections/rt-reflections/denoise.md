# Denoising

<strong>1 画素 1 本のレイでは、粗い面の反射は、ノイズだらけ</strong>になります。<strong>これを、時間方向（前フレームの再利用）と、空間方向（周囲の画素との平均）のフィルタで消すのがデノイザ</strong>です。このページでは、デノイズの仕組みと、長所・短所を説明します。

!!! tip "ポイント"
    - 時間フィルタ：前フレームの結果を再投影して混ぜる。
    - 空間フィルタ：法線・深度・粗さが近い画素だけ、平均。
    - 反射は、見る角度で変わるので、反射の「当たった位置」で再投影する（仮想位置）。
    - デノイズ後は、ぼやけ・ゴーストに注意。

## ノイズ除去（デノイズ）
<strong>画素ごと 1 本</strong>では、<strong>ノイズ</strong>が大きすぎます。デノイザーで空間・時間の平均を取ります。

| 要素 | 内容 |
| --- | --- |
| 時間蓄積 | 再投影で過去フレームと混ぜる。反射像はヒット距離を使って、仮想的な位置へ再投影 |
| 空間フィルタ | バイラテラル（深度・法線・粗さ）。粗さに比例して、広く |
| ヒット距離 | <strong>近い当たり（接地部）</strong>は、フィルタを狭く、遠い当たりは広く（反射の見た目が距離でぼけるため） |
| 分散による制御 | 時間的な分散が大きい画素は、フィルタを強く（SVGF の考え方） |
| ホタル除去 | 極端に明るいサンプルを、制限する |


### なぜ「仮想位置」で再投影するのか

鏡面反射は、見る角度が変わると、映る像の位置が変わります。普通のオブジェクトなら、画素の位置から前フレームの位置を求めれば再投影できます。しかし、反射像は、表面にあるのでなく、鏡の奥に「虚像」として存在します。カメラが動くと、表面は少ししか動かなくても、虚像は大きく動きます。そこで、ヒット距離を使って虚像の位置（鏡の奥の位置）を求め、その位置を前フレームに再投影すると、反射像が正しく追従します。表面の位置で再投影すると、反射像がずるずる滑ってゴーストになります。

### なぜ「仮想位置」で再投影するのか

鏡面反射は、見る角度が変わると、映る像の位置が変わります。普通のオブジェクトなら、画素の位置から前フレームの位置を求めれば再投影できます。しかし、反射像は、表面にあるのでなく、鏡の奥に「虚像」として存在します。カメラが動くと、表面は少ししか動かなくても、虚像は大きく動きます。そこで、ヒット距離を使って虚像の位置（鏡の奥の位置）を求め、その位置を前フレームに再投影すると、反射像が正しく追従します。表面の位置で再投影すると、反射像がずるずる滑ってゴーストになります。

<strong>代表的なデノイザー</strong>：

代表的なデノイザーは、3 つあります。<strong>SVGF</strong>（Spatiotemporal Variance-Guided Filtering）は、分散を使った時空間のバイラテラルで、レイトレ反射・GI の定番です。<strong>ReBLUR / ReLAX</strong>（NVIDIA NRD）は、ヒット距離と粗さを考慮した、実用的なデノイザー群です。<strong>自作</strong>の場合は、確率的 SSR のリゾルブ、時間蓄積、バイラテラルを、そのまま流用できます。

## 長所と短所
| 長所 | 短所 |
| --- | --- |
| 画面外・裏側・半透明の向こうまで正確 | レイトレ対応 GPU が必要 |
| 反射の反射も可能 | コストが大きい（BVH・シェーディング・デノイズ） |
| 品質が高い（ハロー・厚みの問題なし） | ノイズが出る。デノイザーが必須 |
| シーン全体を一貫して扱える | 動く物体の BVH 更新・メモリ |

## よくあるミス

??? failure "動く反射が、尾を引く（ゴースト）"
    <strong>履歴の拒否</strong>を<strong>強める</strong>、ブレンド率を上げる。
