# Color Lookup and Fading

<strong>当たりが見つかったら、その画素の「前フレームまたは現フレームの色」を持ってきます</strong>。<strong>ただし、画面の端や、カメラに向かう反射は、信頼できないので、フェード（徐々に弱める）が必要</strong>です。このページでは、どの色を使うか・フェードの掛け方を説明します。

!!! tip "ポイント"
    - 当たった画素の色を、反射色として使う。
    - 前フレームの色を使うと、反射の中の反射も映る（ただし、ずれに注意）。
    - 画面の端・カメラ向きの反射・粗い面は、フェードで弱める。
    - 信頼度 ＝ 端からの距離 × 向き × 距離 × 粗さを掛け合わせる。
    - フェードした分は、フォールバックで補う。

## 色の取得
<strong>当たった画素の色</strong>を反射として使います。<strong>どの画像から取るか</strong>が重要です。

| 取得元 | 利点 | 欠点 |
| --- | --- | --- |
| 今のフレームの、SSR を除いたシーン色 | 最新 | SSR を適用する前の画像が必要（反射のパスの前の色を残す） |
| 前フレームの最終画像 | 手軽（すでに反射・ポストが乗っている） | 1 フレーム遅れる（動く物にずれ）。反射の反射が入る（二重） |
| 前フレームを動きベクトルで再投影 | 遅れの補正 | 動きベクトルが必要 |

<strong>多くの実装は前フレームの最終画像</strong>（<strong>ブルーム前</strong>の HDR）を使い、動きベクトルで再投影します。

## フェード：信頼できない反射を弱める
SSR は<strong>画面にあるものしか映せません</strong>。<strong>信頼できない反射</strong>は、フェードして、フォールバック（[フォールバック](../ssr-fallback.md)）に任せます。

| 要因 | 内容 |
| --- | --- |
| 画面端 | 当たりが画面の端に近いほど、弱める（`edge_fade = saturate((0.5 − |uv − 0.5|) / margin)`） |
| レイの長さ | 遠いほど、弱める（遠くの当たりは不確か） |
| 粗さ | 粗いほど、弱める（SSR はくっきりした反射が得意） |
| 向き | 反射がカメラの方へ戻る（`R·V` が負で大きい）場合は画面に映っていない面を指す。弱める |
| 厚みの検証 | 当たった場所の深度差が、不自然なら、弱める |
| 当たらなかった | 信頼度 0（フォールバックのみ） |

```hlsl
float SSRConfidence(float2 hit_uv, float ray_length, float roughness, float3 R_vs) {
  float2 d = abs(hit_uv - 0.5) * 2.0;
  float edge = 1.0 - smoothstep(0.8, 1.0, max(d.x, d.y));
  float distance_fade = 1.0 - saturate(ray_length / max_distance);
  float rough_fade = 1.0 - saturate(roughness / max_roughness);
  float facing = saturate(1.0 + R_vs.z * 4.0);
  return edge * distance_fade * rough_fade * facing;
}
```

### 信頼度の考え方

信頼度は、それぞれの要因を<strong>掛け算</strong>で合成します（上のコード）。どれか 1 つでも 0 に近ければ全体が 0 に近づき、その反射を使いません。信頼度は 0〜1 の連続値にしておくことが大切で、これは次のページ以降で扱うフォールバックとの合成に使います。`信頼度 × SSR の色 + (1 − 信頼度) × プローブの色` のように混ぜれば、SSR が効く場所から効かない場所へ、なめらかに移行します（[SSR Fallback and Compositing](../ssr-fallback.md)）。
