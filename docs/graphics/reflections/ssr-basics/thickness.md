# 厚み（thickness）

**深度バッファには、物体の「表の面」しか入っておらず、厚みの情報がありません**。**そのため、レイが物体の裏側へ抜けたのか、本当に当たったのか、見分けがつきません**。**「厚み」のしきい値を決めて、レイとバッファの深度の差が、厚みより小さい時だけ、当たりとする**のが**標準的な対策**です。このページでは、**厚みの考え方・値の決め方・より良い方法**を説明します。

!!! tip "ポイント"
    - **深度バッファは、表の面しか持たない**ので、**厚みが分からない**。
    - **深度の差が「厚み」以内なら当たり、それ以上なら、裏へ抜けた（外れ）**。
    - **厚みが小さい → 薄い物を見逃す**。**大きい → 物の後ろまで反射してしまう**。
    - **距離に応じて厚みを変える**と、**遠くでも破綻しにくい**。
    - **より良いやり方は、裏面の深度も描く**（[SSR の改良](../ssr-hiz.md)）。

## 厚み（thickness）
深度バッファには、**面の手前側の位置しか**ありません。**面の「厚み」が分かりません**。レイが**面の奥に入った**とき、それが**本当にその物体に当たった**のか、**物体の向こう側へ抜けた**のかを、区別できません。

| 厚みの設定 | 結果 |
| --- | --- |
| **無限大** | レイが面の奥に入ったら、**常に当たり**。**柱の向こうの別の物を柱の反射として表示** |
| <strong>有限（一定値）</strong> | 面の奥 **thickness 以内**に入ったときだけ、当たり。**薄い物の後ろへ抜けるレイ**は、当たらない |
| **薄すぎる** | **厚みのある物体**でもレイが**深く入った**と判定され、**取りこぼす**（穴が開く） |

**厚みはシーンの大きさ**（メートル単位）**に合わせた値**にします（0.1〜1 m 程度から調整）。**距離に応じて増やす**（遠いほど、画素が大きいので厚みも大きく）と、安定します。

!!! note "厚みの限界"
    **一定の厚み**は**近似**です。**薄い物体**（柵）と**厚い物体**（壁）を、同じ値で扱えません。**限界**として、受け入れる設計です。

## よくあるミス

??? failure "物の裏側の、見えないはずの物が、反射に映る"
    **厚みのしきい値を小さく**する。
