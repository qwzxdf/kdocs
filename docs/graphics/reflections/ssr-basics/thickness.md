# Thickness

<strong>深度バッファには、物体の「表の面」しか入っておらず、厚みの情報がありません</strong>。<strong>そのため、レイが物体の裏側へ抜けたのか、本当に当たったのか、見分けがつきません</strong>。「厚み」のしきい値を決めて、レイとバッファの深度の差が、厚みより小さい時だけ、当たりとするのが標準的な対策です。このページでは、厚みの考え方・値の決め方・より良い方法を説明します。

!!! tip "ポイント"
    - 深度バッファは、表の面しか持たないので、厚みが分からない。
    - 深度の差が「厚み」以内なら当たり、それ以上なら、裏へ抜けた（外れ）。
    - 厚みが小さい → 薄い物を見逃す。大きい → 物の後ろまで反射してしまう。
    - 距離に応じて厚みを変えると、遠くでも破綻しにくい。
    - より良いやり方は、裏面の深度も描く（[Hi-Z SSR](../ssr-hiz.md)）。

## 厚み（thickness）

深度バッファには、面の手前側の位置しかありません。面の「厚み」が分からないのです。レイが面の奥に入ったとき、本当にその物体に当たったのか、物体の向こう側へ抜けたのかを、区別できません。

例として、画面の中央に細い柱があり、その向こうに壁があるとします。反射レイが柱の画素の上を通るとき、レイは柱の手前側の面より奥に入っていきます。もし「面より奥なら当たり」とだけ判定すれば、レイが柱の横をかすめて、壁に向かっているだけでも、「柱に当たった」と判定してしまいます。結果として、柱の向こうの壁の反射が柱の色に置き換わり、不自然な引き伸ばしが出ます。

### 厚みのしきい値

そこで、「面の奥 thickness 以内」にレイが入ったときだけ、当たりとします。thickness を超えて奥へ入ったレイは、「物体を裏側へ抜けた」と見なし、当たりにしません。

厚みの設定による結果は、次のとおりです。無限大にすると、レイが面の奥に入れば常に当たりになり、柱の向こうの別の物を柱の反射として表示します。有限の一定値にすると、薄い物の後ろへ抜けるレイが当たらなくなり、正しくなります。ただし、薄すぎる値にすると、厚みのある物体でもレイが深く入った時点で外れと判定され、取りこぼし（穴）が出ます。

厚みは、シーンの大きさ（メートル単位）に合わせた値にします。0.1〜1 m 程度から調整を始めます。遠くでは、画素 1 つが覆う実際の大きさが大きくなるので、<strong>距離に応じて厚みを増やす</strong>（画素の大きさに比例させる）と、遠くでも安定します。

!!! note "厚みの限界"
    <strong>一定の厚み</strong>は<strong>近似</strong>です。薄い物体（柵）と厚い物体（壁）を、同じ値で扱えません。限界として、受け入れる設計です。

### より良いやり方：裏面の深度を使う

厚みを一定値で近似するのでなく、<strong>実際の厚みを測る</strong>方法があります。物体の裏面（背面）も深度として描いておくと、表の面と裏の面の深度差が、その画素の厚みになります。レイが表の面より奥に入り、かつ裏の面より手前にいる間は、物体の内側にいると判定できます。裏面の深度を描くには、背面カリングを反転して追加の描画パスが必要ですが、厚みの扱いが正確になります。Hi-Z トレースと組み合わせた実装でも、この方法が使われます（[Hi-Z SSR](../ssr-hiz.md)）。

## 深度バッファは、「面」しか、知らない

<strong>深度バッファ</strong>が、持っているのは、<strong>各画素で、カメラに、最も、近い、面の、距離</strong>だけです。その面の、裏（物の、厚み）や、手前の物に、隠れた、奥の物は、知りません。SSR で、レイが、深度バッファと、交差したとき、その面が、どれだけ、厚いかが、分からないので、仮定が、必要になります。これが、厚み（thickness）の、問題です。

## 当たりの、判定

<strong>レイ上の、点の、深度</strong>と、<strong>その画素の、深度</strong>を、比べて、当たりかを、判定します。

```text
diff = レイの深度 − 画面の深度

diff < 0       : レイが、面より手前（まだ、面に、達していない）→ 当たりなし
0 ≤ diff < T   : レイが、面の「裏」に入ったが、厚み T 以内 → 当たり
diff ≥ T       : レイが、面の裏に入って、かつ、厚み T を超えた → 当たりなし（物の「向こう」を、通り抜けた）
```

```hlsl
float diff = ray_depth - scene_depth;
bool hit = (diff > 0.0) && (diff < g_thickness);
```

<strong>厚み `T`</strong> は、<strong>「物が、これくらいの、厚さ</strong>まで、あると、仮定する」値です。

## 厚みの、大小の、トレードオフ

| 厚み T | 結果 |
| --- | --- |
| 小さい（0.1 m など） | 細い物（フェンス、手すり）は、すり抜ける（レイが、物の、裏に、入る前に、T を、超えて、見逃す）。偽の当たりは、少ない |
| 大きい（2 m など） | すり抜けは、減るが、偽の当たりが、増える。レイが、手前の物の、裏（実際は、向こうに、物は、無い）を、当たりと、誤認 |

```text
 偽の当たり（T が大きすぎる）:
        ┃柱（手前）
 カメラ ●──→ 柱の向こう側を、通る反射レイ
        レイが、柱の、深度の「裏」に入った瞬間、T 以内なので、「柱に当たった」と、誤認（実際は、柱の向こうの、何かが、映るはず）
```

<strong>厚みが、大きすぎる</strong>と、<strong>柱の、すぐ後ろ</strong>で、反射が、柱の色に、染まったり、引き伸ばされた、縞状の、アーティファクトが、出ます。

## 厚みの、決め方

| 方法 | 内容 |
| --- | --- |
| 一定の値（定数） | 簡単。場面に、合わせて、調整（0.2〜1 m） |
| 距離に比例 | 遠くの物ほど、画面上の、1 画素が、広いので、厚みも、大きく（`T = 画素の、ワールド上の、大きさ × k`） |
| 物ごとに、G バッファに、厚みを、保存 | メッシュごと（薄い板、厚い箱）に、適切な、厚みを、持たせる。正確だが、G バッファの、チャンネルが、必要 |
| 裏面の、深度バッファ（デプス ピーリングの、2 層目） | 物の、裏面の、深度を、別に、保存し、表と、裏の差が、その画素の、厚み。最も、正確。描画が、増える |

### 距離に、比例させる

```hlsl
// 距離に比例した、厚み。遠いほど、1 画素が、広いので、厚みを、大きくする。
float pixel_world_size = scene_depth * g_pixel_angle;                       // 1 画素が、その距離で、覆う、ワールドの大きさ
float thickness = max(g_min_thickness, pixel_world_size * g_thickness_scale);
```

<strong>遠くの、物</strong>ほど、<strong>深度バッファの、解像度が、粗く</strong>（1 画素が、広い範囲）、厚みを、大きく、取らないと、すり抜けます。近くは、小さくします。

## 厚みの、調整だけでは、解決できない

<strong>厚みの、仮定は、近似</strong>で、<strong>限界</strong>が、あります。

| 場面 | 問題 |
| --- | --- |
| 細い物（フェンス）と、厚い物（壁）が、混在 | どちらにも、合う、厚みが、無い。薄い物は、すり抜け、厚い物の、裏で、偽の当たり |
| カメラに、近い（画面上で、大きい）物 | 深度が、急に、変わる（物の、縁）。縁で、偽の当たり |
| 物の、縁（シルエット）の、近く | 深度が、不連続で、縁を、またぐレイは、どちらの面に、当たったか、不定 |

## 偽の当たりを、減らす、工夫

| 工夫 | 内容 |
| --- | --- |
| 当たった点の、法線を、確認 | 当たった画素の、法線が、レイと、同じ向き（面の、表を、向いている）なら、無効（裏から、当たった）。物の、表側に、当たる、はず |
| 当たった点の、位置を、確認（再投影） | 当たった画素の、ワールド位置と、レイの位置が、近いか |
| 深度の、勾配を、確認 | 当たった画素の、周りの、深度の差が、大きい（縁）なら、信頼度を、下げる |

```hlsl
// 当たった画素の、法線が、レイと、同じ向き（面の裏から、当たった）なら、無効にする。
float3 hit_normal = DecodeNormal(g_gbuffer_normal.Load(int3(hit_pixel, 0)));
if (dot(hit_normal, reflect_dir_vs) > 0.0) return false;                    // 面が、レイの方を、向いていない → 裏から当たった
```
