# Thickness

<strong>深度バッファには物体の「表の面」しか入っておらず、厚みの情報がありません</strong>。そのためレイが物体の裏側へ抜けたのか、本当に当たったのか見分けがつきません。「厚み」のしきい値を決めてレイとバッファの深度の差が厚みより小さい時だけ当たりとするのが標準的な対策です。このページでは厚みの考え方・値の決め方・より良い方法を説明します。

!!! tip "ポイント"
    - 深度バッファは表の面しか持たないので、厚みが分からない。
    - 深度の差が「厚み」以内なら当たり、それ以上なら裏へ抜けた（外れ）。
    - 厚みが小さい → 薄い物を見逃す。大きい → 物の後ろまで反射してしまう。
    - 距離に応じて厚みを変えると、遠くでも破綻しにくい。
    - より良いやり方は、裏面の深度も描く（[Hi-Z SSR](../ssr-hiz.md)）。

## 厚み（thickness）

深度バッファには面の手前側の位置しかありません。面の「厚み」が分からないのです。レイが面の奥に入ったとき本当にその物体に当たったのか、物体の向こう側へ抜けたのかを区別できません。

例として画面の中央に細い柱があり、その向こうに壁があるとします。反射レイが柱の画素の上を通るとき、レイは柱の手前側の面より奥に入っていきます。もし「面より奥なら当たり」とだけ判定すれば、レイが柱の横をかすめて壁に向かっているだけでも、「柱に当たった」と判定してしまいます。結果として、柱の向こうの壁の反射が柱の色に置き換わり、不自然な引き伸ばしが出ます。

### 厚みのしきい値

そこで、「面の奥 thickness 以内」にレイが入ったときだけ、当たりとします。thickness を超えて奥へ入ったレイは、「物体を裏側へ抜けた」と見なし、当たりにしません。

厚みの設定による結果は次のとおりです。無限大にするとレイが面の奥に入れば常に当たりになり、柱の向こうの別の物を柱の反射として表示します。有限の一定値にすると薄い物の後ろへ抜けるレイが当たらなくなり、正しくなります。ただし、薄すぎる値にすると厚みのある物体でもレイが深く入った時点で外れと判定され、取りこぼし（穴）が出ます。

厚みはシーンの大きさ（メートル単位）に合わせた値にします。0.1〜1 m 程度から調整を始めます。遠くでは画素 1 つが覆う実際の大きさが大きくなるので、<strong>距離に応じて厚みを増やす</strong>（画素の大きさに比例させる）と、遠くでも安定します。

!!! note "厚みの限界"
    一定の厚みは近似です。薄い物体（柵）と厚い物体（壁）を同じ値で扱えません。限界として受け入れる設計です。

### より良いやり方：裏面の深度を使う

厚みを一定値で近似するのでなく、実際の厚みを測る方法があります。物体の裏面（背面）も深度として描いておくと、表の面と裏の面の深度差がその画素の厚みになります。レイが表の面より奥に入りかつ裏の面より手前にいる間は、物体の内側にいると判定できます。裏面の深度を描くには背面カリングを反転して追加の描画パスが必要ですが、厚みの扱いが正確になります。Hi-Z トレースと組み合わせた実装でも、この方法が使われます（[Hi-Z SSR](../ssr-hiz.md)）。

## 深度バッファは「面」しか、知らない

<strong>深度バッファ</strong>が持っているのは、各画素でカメラに最も近い面の、距離だけです。その面の裏（物の厚み）や手前の物に隠れた、奥の物は知りません。SSR でレイが深度バッファと、交差したときその面がどれだけ、厚いかが分からないので仮定が必要になります。これが厚み（thickness）の、問題です。

## 当たりの判定

<strong>レイ上の点の深度</strong>と その画素の、深度を比べて当たりかを判定します。

```text
diff = レイの深度 − 画面の深度

diff < 0       : レイが、面より手前（まだ、面に、達していない）→ 当たりなし
0 ≤ diff < T   : レイが、面の「裏」に入ったが、厚み T 以内 → 当たり
diff ≥ T       : レイが、面の裏に入って、かつ、厚み T を超えた → 当たりなし（物の「向こう」を、通り抜けた）
```

```hlsl
float diff = ray_depth - scene_depth;
bool hit = (diff > 0.0) && (diff < g_thickness);
```

厚み `T` は 「物がこれくらいの、厚さまであると仮定する」値です。

## 厚みの大小のトレードオフ

| 厚み T | 結果 |
| --- | --- |
| 小さい（0.1 m など） | 細い物（フェンス、手すり）はすり抜ける（レイが物の裏に入る前に T を超えて見逃す）。偽の当たりは少ない |
| 大きい（2 m など） | すり抜けは減るが、偽の当たりが増える。レイが手前の物の裏（実際は向こうに物は、無い）を当たりと誤認 |

```text
 偽の当たり（T が大きすぎる）:
        ┃柱（手前）
 カメラ ●──→ 柱の向こう側を、通る反射レイ
        レイが、柱の、深度の「裏」に入った瞬間、T 以内なので、「柱に当たった」と、誤認（実際は、柱の向こうの、何かが、映るはず）
```

<strong>厚みが大きすぎる</strong>と 柱の、すぐ後ろで反射が柱の色に染まったり、引き伸ばされた縞状のアーティファクトが出ます。

## 厚みの決め方

| 方法 | 内容 |
| --- | --- |
| 一定の値（定数） | 簡単。場面に合わせて調整（0.2〜1 m） |
| 距離に比例 | 遠くの物ほど、画面上の 1 画素が広いので厚みも、大きく（`T = 画素の、ワールド上の、大きさ × k`） |
| 物ごとに G バッファに厚みを保存 | メッシュごと（薄い板、厚い箱）に適切な厚みを持たせる。正確だが G バッファのチャンネルが必要 |
| 裏面の深度バッファ（デプス ピーリングの、2 層目） | 物の裏面の深度を別に保存し表と、裏の差がその画素の厚み。最も正確。描画が増える |

### 距離に比例させる

```hlsl
// 距離に比例した、厚み。遠いほど、1 画素が広いので、厚みを大きくする。
float pixel_world_size = scene_depth * g_pixel_angle;                       // 1 画素がその距離で、覆う、ワールドの大きさ
float thickness = max(g_min_thickness, pixel_world_size * g_thickness_scale);
```

<strong>遠くの物</strong>ほど 深度バッファの、解像度が粗く（1 画素が広い範囲）、厚みを大きく取らないとすり抜けます。近くは小さくします。

## 厚みの調整だけでは解決できない

<strong>厚みの仮定は近似</strong>で 限界があります。

| 場面 | 問題 |
| --- | --- |
| 細い物（フェンス）と厚い物（壁）が混在 | どちらにも合う厚みが無い。薄い物はすり抜け厚い物の裏で、偽の当たり |
| カメラに近い（画面上で大きい）物 | 深度が急に変わる（物の縁）。縁で偽の当たり |
| 物の縁（シルエット）の近く | 深度が不連続で縁をまたぐレイはどちらの面に当たったか不定 |

## 偽の当たりを減らす工夫

| 工夫 | 内容 |
| --- | --- |
| 当たった点の法線を確認 | 当たった画素の法線がレイと、同じ向き（面の表を向いている）なら、無効（裏から当たった）。物の表側に当たるはず |
| 当たった点の位置を確認（再投影） | 当たった画素の、ワールド位置とレイの位置が近いか |
| 深度の勾配を確認 | 当たった画素の周りの、深度の差が大きい（縁）なら信頼度を下げる |

```hlsl
// 当たった画素の、法線がレイと、同じ向き（面の裏から、当たった）なら、無効にする。
float3 hit_normal = DecodeNormal(g_gbuffer_normal.Load(int3(hit_pixel, 0)));
if (dot(hit_normal, reflect_dir_vs) > 0.0) return false;                    // 面がレイの方を向いていない → 裏から当たった
```
