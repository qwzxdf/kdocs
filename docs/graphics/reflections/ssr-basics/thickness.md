# Thickness

<strong>深度バッファには、物体の「表の面」しか入っておらず、厚みの情報がありません</strong>。<strong>そのため、レイが物体の裏側へ抜けたのか、本当に当たったのか、見分けがつきません</strong>。「厚み」のしきい値を決めて、レイとバッファの深度の差が、厚みより小さい時だけ、当たりとするのが標準的な対策です。このページでは、厚みの考え方・値の決め方・より良い方法を説明します。

!!! tip "ポイント"
    - 深度バッファは、表の面しか持たないので、厚みが分からない。
    - 深度の差が「厚み」以内なら当たり、それ以上なら、裏へ抜けた（外れ）。
    - 厚みが小さい → 薄い物を見逃す。大きい → 物の後ろまで反射してしまう。
    - 距離に応じて厚みを変えると、遠くでも破綻しにくい。
    - より良いやり方は、裏面の深度も描く（[Hi-Z SSR](../ssr-hiz.md)）。

## 厚み（thickness）

深度バッファには、面の手前側の位置しかありません。面の「厚み」が分からないのです。レイが面の奥に入ったとき、本当にその物体に当たったのか、物体の向こう側へ抜けたのかを、区別できません。

例として、画面の中央に細い柱があり、その向こうに壁があるとします。反射レイが柱の画素の上を通るとき、レイは柱の手前側の面より奥に入っていきます。もし「面より奥なら当たり」とだけ判定すれば、レイが柱の横をかすめて、壁に向かっているだけでも、「柱に当たった」と判定してしまいます。結果として、柱の向こうの壁の反射が柱の色に置き換わり、不自然な引き伸ばしが出ます。

### 厚みのしきい値

そこで、「面の奥 thickness 以内」にレイが入ったときだけ、当たりとします。thickness を超えて奥へ入ったレイは、「物体を裏側へ抜けた」と見なし、当たりにしません。

厚みの設定による結果は、次のとおりです。無限大にすると、レイが面の奥に入れば常に当たりになり、柱の向こうの別の物を柱の反射として表示します。有限の一定値にすると、薄い物の後ろへ抜けるレイが当たらなくなり、正しくなります。ただし、薄すぎる値にすると、厚みのある物体でもレイが深く入った時点で外れと判定され、取りこぼし（穴）が出ます。

厚みは、シーンの大きさ（メートル単位）に合わせた値にします。0.1〜1 m 程度から調整を始めます。遠くでは、画素 1 つが覆う実際の大きさが大きくなるので、<strong>距離に応じて厚みを増やす</strong>（画素の大きさに比例させる）と、遠くでも安定します。

!!! note "厚みの限界"
    <strong>一定の厚み</strong>は<strong>近似</strong>です。薄い物体（柵）と厚い物体（壁）を、同じ値で扱えません。限界として、受け入れる設計です。

### より良いやり方：裏面の深度を使う

厚みを一定値で近似するのでなく、<strong>実際の厚みを測る</strong>方法があります。物体の裏面（背面）も深度として描いておくと、表の面と裏の面の深度差が、その画素の厚みになります。レイが表の面より奥に入り、かつ裏の面より手前にいる間は、物体の内側にいると判定できます。裏面の深度を描くには、背面カリングを反転して追加の描画パスが必要ですが、厚みの扱いが正確になります。Hi-Z トレースと組み合わせた実装でも、この方法が使われます（[Hi-Z SSR](../ssr-hiz.md)）。

## よくあるミス

??? failure "物の裏側の、見えないはずの物が、反射に映る"
    <strong>厚みのしきい値を小さく</strong>する。
