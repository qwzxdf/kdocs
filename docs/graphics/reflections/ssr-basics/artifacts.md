# Artifacts and Evaluation

**SSR には、決まった「弱点」があります**。**これを知っておくと、見た目の不具合の原因が、すぐに分かります**。このページでは、**SSR の代表的な問題点（アーティファクト）と、長所・短所の整理**を説明します。

!!! tip "ポイント"
    - **画面外・隠れた物は、映らない**（最大の弱点）。
    - **画面の端で、反射が欠ける**。
    - **薄い物を飛び越える・裏が映る（厚み）**。
    - **動くと、ちらつく**。
    - **長所は、シーンが複雑でも、コストがほぼ一定**。

## 問題点（アーティファクト）
SSR の代表的な不具合を、症状ごとに説明します。

**反射が画面の端で消える・切れる**のは、画面外のものが映らないためで、エッジ フェードとフォールバックで対処します。**反射に穴や縞が出る**のは、歩幅が大きすぎて薄い物を飛び越すためで、歩幅を小さくする、厚みを調整する、Hi-Z を使う（[Hi-Z SSR](../ssr-hiz.md)）といった対策があります。**物の裏側が映らない**のは、深度バッファが手前の面しか持たないための仕様で、フォールバックで補います。**反射が引き伸ばされる**のは、厚みが大きすぎて手前の物に当たり続けるためで、厚みを調整します。**動く物体にずれやゴーストが出る**のは、前フレームの色を使うためで、動きベクトルで再投影して対処します。**反射する物体自身が映り込む**のは、レイが自分の面に当たるためで、始点を法線方向に少しずらします。**透明物が映らない**のは、半透明が深度に書かれないための仕様で、別扱いにします。**粗い面の反射がくっきりしすぎる**のは、粗さを考慮していないためで、ぼかしや確率的 SSR（[Stochastic SSR](../ssr-stochastic.md)）で対処します。

## 長所と短所
SSR の長所は、追加のシーン描画が不要で軽いこと、あらゆる形の面と動く物に使えること、接地部の細かい反射（足元）に強いこと、深度・法線・色があれば作れることです。短所は、画面に映らない物は反射しないこと、厚みと歩幅の調整が難しいこと、画面端や視点の変化で反射が現れたり消えたりすること、粗い面でノイズやにじみが出ることです。

**シーンが複雑でも、コストがほぼ一定**であることも、SSR の大きな長所です。レイトレーシングは、シーンの三角形が増えるほど遅くなりますが、SSR は画面の画素数と歩数でコストが決まるので、ポリゴン数に左右されません。この性質が、SSR を現代のゲームの標準的な反射手法にしました。
