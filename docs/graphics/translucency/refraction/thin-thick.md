# Thin and Thick Glass

<strong>窓ガラスのような「薄いガラス」は、屈折でほとんどずれません</strong>が、ガラスの塊のような「厚いガラス」は、大きくずれます。両者でモデルを使い分けると無駄なく、自然に見えます。このページでは使い分けの基準を説明します。

!!! tip "ポイント"
    - 薄いガラス：ほぼ透明 ＋ 反射。屈折はほぼ無視。
    - 厚いガラス：屈折 ＋ 厚みによる色。
    - 球体・瓶などは前面と背面の 2 回の屈折。
    - 使い分けでコストを抑える。

## 薄いガラスと厚いガラス
| 種類 | 例 | 屈折 | 表現 |
| --- | --- | --- | --- |
| <strong>薄いガラス（板）</strong> | 窓・ガラス戸 | ほぼ無視（入口と出口で相殺） | 透過 ＋ 反射（フレネル） のみ |
| 厚いガラス・水 | 瓶・水槽・宝石 | 目立つ | 屈折 ＋ 厚みの色 ＋ 反射 |
| 曇りガラス | すりガラス | ぼやける | 背景を、ミップや大きなブラーで読む（粗さに応じて） |

窓ガラスは 屈折を省いて、単純な半透明にすれば十分です。

### 曇りガラス（粗い屈折）

粗い面ほど背景がぼやけて見えるので、背景コピーのミップ（ブラー済み）を、粗さに応じて読みます。

```hlsl
float mip = roughness * kMaxMip;
float3 background = scene_color_mips.SampleLevel(linear_clamp, refract_uv, mip).rgb;
```

背景のコピーにミップ チェーンを作っておく（[ブルームのダウンサンプル](../../postprocess/bloom/index.md)と同様）。

### なぜ薄いガラスの屈折は無視できるのか

ガラス板に斜めから光が入ると、入口で曲がりガラス内を直進して、出口で逆向きに同じだけ曲がります。出た光は入る前と平行でずれるだけです。そのずれは板の厚みに比例し薄い板ならわずかです。そのため、窓ガラスの向こうの景色はほぼそのまま見えます。厚いガラスや水ではずれが大きく、曲面なら像が拡大・縮小・反転するので、屈折の表現が必要になります。

## 薄いガラスと厚いガラス

屈折の扱い方は <strong>ガラスの厚み</strong>で、大きく変わります。

| | 薄いガラス（窓、ガラス板、水面） | 厚いガラス（瓶、球、宝石、水晶） |
| --- | --- | --- |
| 光の通り道 | 入口と出口が、平行（ほぼ同じ向きで出る）。ほぼまっすぐ通る | 内部で大きく、曲がる。出口の向きが入口と大きく違う |
| 見え方 | 向こうがほぼ、そのまま見える。わずかにずれる | 向こうが大きく歪む。上下左右が逆転することも |
| 必要な計算 | ごく小さな、ずらし（画面空間で十分） | 入口の屈折 + 出口の屈折（2 回の屈折）。内部の反射 |
| 代表例 | 窓、コップの壁、ガラス板 | 水晶球、ガラス玉、ダイヤモンド、水の入ったコップ（全体） |

## 薄いガラス：1 回で十分

薄い平行なガラス板では <strong>入射の屈折</strong>と、出射の屈折がちょうど打ち消し合い光は、元の向きのまま少しずれて出てきます。ずれは厚みと入射角で決まり薄ければ、ごくわずかです。

```text
 空気 | ガラス | 空気
      ╲       ╲
       ╲___    ╲        入射の向きと、出射の向きは、同じ（平行）
            ╲    ╲___   ずれ（横ずれ）は、厚みに比例
```

このため 窓ガラスは 画面空間の屈折（[Screen-Space Refraction](screen-space.md)）で、十分です。ずらし量をごく小さくするかほぼゼロに、します。フレネル反射と表面の汚れ厚みによる、わずかな色が見た目の主役です。

## 厚いガラス：屈折が 2 回

球や瓶のような <strong>厚い</strong>ガラスでは光が、入口で 1 回曲がり、内部を通って出口でもう 1 回曲がります。

```text
 空気 | ガラス球                 | 空気
      ╲╲         ╲╲
       ╲╲ ←入口で屈折  ╲╲ ←出口で屈折
```

入口の屈折ベクトルと 物体の内部を通った、出口の位置・法線が必要です。

### 近似の方法

| 方法 | 内容 | 精度 |
| --- | --- | --- |
| 背面の法線を使う（Wyman、2005） | 1. 背面の深度と法線を、テクスチャに描く。2. 前面で入口の屈折を計算し、背面までの距離を推定する。3. 出口の位置と背面の法線で、2 回目の屈折を計算する | 凸な形で、よく合う |
| 解析的な形 | 球、箱に対してレイと形の交差を数式で、解く | 完全（形が単純なら） |
| レイトレーシング | 実際に光線を、追跡する | 完全。重い |

Wyman（2005）の 画像空間の、近似は次のとおりです。

1. 物体の背面を描いて深度（視点からの、距離）と法線をテクスチャに保存する
2. 前面の画素で入口の屈折ベクトル `T₁` を `refract(V, N_front, 1/n)` で求める
3. 物体の厚み `d`（前面と背面の、深度の差）から出口の位置を `P_out ≈ P_front + T₁ × d` と、推定する
4. 出口の位置の背面の法線 `N_back` で、2 回目の屈折を `T₂ = refract(T₁, −N_back, n)` で求める
5. `T₂` の方向にシーンをサンプルする（画面空間の、ずらし）

```hlsl
// 厚いガラスの、2 回屈折（Wyman 2005 の考え方）。
float3 V = normalize(input.world_position - g_camera_position);
float3 N_front = normalize(input.world_normal);

// ① 入口の屈折
float3 T1 = refract(V, N_front, 1.0 / g_ior);

// ② 背面までの距離（厚み）。背面の深度から。
float thickness = ThicknessFromBackDepth(input);

// ③ 出口の位置を、推定
float3 P_out = input.world_position + T1 * thickness;

// ④ 出口での、背面の法線で、2 回目の屈折
float3 N_back = FetchBackNormal(P_out);                       // 背面の法線テクスチャから
float3 T2 = refract(T1, -N_back, g_ior);
if (dot(T2, T2) < 1e-5) T2 = reflect(T1, -N_back);            // 全反射したら、反射させる（内部反射）

// ⑤ T2 の向きで、シーンを読む（出口の位置から、T2 の向きに、少し進んだ点を、画面に投影）
float3 sample_pos = P_out + T2 * g_refract_distance;
float2 uv = ProjectToScreenUV(sample_pos);
float3 refracted = g_scene_copy.Sample(g_linear_clamp, uv).rgb;
```

`refract` がゼロ ベクトルを返したときは、全反射です。反射の向きで代用します（内部反射の、1 回分の近似）。

## 凹んだ形、複雑な形

背面を 1 層だけ使う近似は <strong>凸な形</strong>（視線が、入口と出口で 1 回ずつ通る）を、前提にしています。凹んだ形（コップ、ドーナツ、複雑な彫像）では視線が複数回、通るのでうまくいきません。

| 形 | 対応 |
| --- | --- |
| 凸（球、瓶、宝石の単純なカット） | 背面の法線を使う近似で、よい |
| 軽く凹む | 近似の誤差を、許容 |
| 強く凹む複雑 | レイトレーシング、または事前に焼いたキューブマップ（物体の内部の屈折を、焼く） |
| 宝石（ダイヤモンド） | 内部の、複数回の反射が見た目の本質。キューブマップに焼くまたは専用の、トリック（[Dispersion](dispersion.md) と組み合わせる） |

## 厚みと薄さの中間

ほとんどのゲームのガラス（コップ、瓶、窓）は <strong>薄い壁</strong>の 空洞です。

| 物 | 扱い |
| --- | --- |
| ガラスのコップ | 薄い壁として、扱う（画面空間の小さなずらし + フレネル + 厚みによる色）。中の水は別（水のシェーダー） |
| ワインのボトル | 壁は薄いが、中の液体が屈折を起こす。液体を別メッシュとして厚いガラスの、近似で |
| 魚の水槽 | 水が大きな塊。水の体積として扱う（[Water](../../water/index.md)） |
| 氷の塊 | 厚い。内部の散乱、屈折。厚みとぼかしで近似（[Thickness and Color](thickness-color.md)） |
