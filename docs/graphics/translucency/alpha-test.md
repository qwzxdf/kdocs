# アルファ テスト

**葉・草・金網・フェンス・髪の毛**のように、<strong>「ある所は完全に透明、ある所は完全に不透明」</strong>な物は、<strong>ブレンドではなく「アルファ テスト」</strong>で描きます。**画素ごとに、「残すか、捨てるか」の 2 択**なので、**順序に依存せず**、**深度バッファにも普通に書けます**。ただし、**縁がギザギザ**になり、**ミップ マップで、遠くの葉が薄くなる**問題があります。このページでは、**`clip` の使い方・Alpha to Coverage・ハッシュド アルファ・ミップの対策・パフォーマンスへの影響**を説明します。

!!! tip "ポイント"
    - アルファ テスト ＝ <strong>アルファが閾値未満の画素を、`clip` で捨てる</strong>。<strong>半透明のブレンドは、しない</strong>。
    - <strong>順序に依存しない</strong>。<strong>深度も書ける</strong>。<strong>不透明と同じパス</strong>で描ける。
    - 欠点：<strong>縁がギザギザ</strong>（エイリアシング）。<strong>ミップで、遠くが薄くなる</strong>。
    - <strong>Alpha to Coverage</strong>：<strong>アルファを、MSAA のカバレッジに変換</strong>して、<strong>縁を滑らかに</strong>。
    - <strong>ハッシュド アルファ</strong>：<strong>ノイズとの比較で、確率的に捨てる</strong>。<strong>TAA で滑らかに</strong>。
    - <strong>Early-Z が効かなくなる</strong>（`clip` があるため）。<strong>オーバードロー・コストに注意</strong>。

## clip による基本のアルファ テスト

**ピクセル シェーダーで、アルファが閾値未満なら、その画素を捨てます**。

```hlsl
float4 PSMain(VsOutput input) : SV_Target {
  float4 color = albedo_texture.Sample(linear_sampler, input.uv);
  clip(color.a - 0.5);
  return color;
}
```

| 点 | 説明 |
| --- | --- |
| **`clip(x)`** | **`x < 0` なら、その画素を捨てる**（`discard` と同じ） |
| **`color.a - 0.5`** | **アルファが 0.5 未満なら、捨てる** |
| **閾値 0.5** | **標準**。**調整可能**（マテリアルごとに） |
| **ブレンドなし** | **通常の不透明描画**として、**色を書く**。**深度も書く** |

**不透明と同じパス**で描け、**ソート不要**です。**葉・草・金網**は、**これで十分**なことが多いです。

## アルファ テストの欠点

### 縁がギザギザ

**アルファの境目を、0 か 1 で切る**ので、**縁が階段状**になります（**エイリアシング**）。**MSAA でも、`clip` の結果は、画素単位**なので、**滑らかになりません**。

### ミップで遠くの葉が薄くなる

**葉のテクスチャを、ミップ マップで縮小**すると、**アルファ チャンネルも平均**されて、**遠くで、アルファが全体に低くなります**。**閾値 0.5 を超える画素が減り、遠くの木が、スカスカ**に見えます。

| 距離 | ミップ | 見た目 |
| --- | --- | --- |
| **近い** | **ミップ 0** | **葉の形が、正しい** |
| **遠い** | **高いミップ** | **アルファが平均されて、0.5 未満の画素が多くなり、葉が消える** |

### 対策：ミップの面積を保つ（カバレッジ保存）

**ミップごとに、アルファの閾値を超える画素の割合（カバレッジ）が、元と同じになる**よう、**アルファを調整**します。

```hlsl
float alpha = albedo_texture.Sample(linear_sampler, input.uv).a;
float mip = albedo_texture.CalculateLevelOfDetail(linear_sampler, input.uv);
alpha *= 1.0 + mip * kMipScale;
clip(alpha - 0.5);
```

| 方法 | 内容 |
| --- | --- |
| **ミップごとのスケール** | **ミップ レベルに応じて、アルファを大きく**する（簡易） |
| **ミップ生成時にカバレッジ保存** | **ミップ チェーンを作るとき、各レベルのアルファの閾値を調整**して、**カバレッジを一定に保つ**（ツール側） |
| **距離でアルファを下げる閾値** | **遠くでは、閾値を下げる** |

**ミップ生成の段階**で**カバレッジを保存**するのが、**正確**です（**テクスチャ ツールのオプション**）。

## Alpha to Coverage

**MSAA を使っているとき**、**アルファの値を、そのまま「カバレッジ（どのサンプルを塗るか）」に変換**する機能です。**アルファ 0.5 なら、4 サンプルのうち 2 つを塗る**ことで、**縁が滑らかな段階**になります。

```cpp
D3D11_BLEND_DESC desc = {};
desc.AlphaToCoverageEnable = TRUE;
desc.RenderTarget[0].RenderTargetWriteMask = D3D11_COLOR_WRITE_ENABLE_ALL;
device->CreateBlendState(&desc, &alpha_to_coverage_state);
```

| 点 | 説明 |
| --- | --- |
| **`AlphaToCoverageEnable`** | **ピクセル シェーダーの出力アルファを、カバレッジ マスクに変換** |
| **MSAA が必要** | **MSAA の描画先**（`SampleDesc.Count` が 2 以上）でのみ**有効** |
| **ブレンドは不要** | **アルファ ブレンドとは別の機構**。**深度も書ける** |
| **効果** | **縁が、MSAA のサンプル数ぶんの段階で滑らかに** |

**4x MSAA では 5 段階**（0/4〜4/4）の**透明度**しか**表せません**。**ディザリングのようなパターン**が**見える**ことがあります。

## ハッシュド アルファ（確率的アルファ テスト）

**アルファを「確率」と見なし、画素ごとのノイズ（ハッシュ）と比べて、捨てるか残すか**を決めます。**1 フレームでは、ノイズ状**ですが、**TAA（時間蓄積）で平均されて、滑らかな半透明**に見えます。

```hlsl
float Hash(float2 p) {
  return frac(sin(dot(p, float2(12.9898, 78.233))) * 43758.5453);
}

float alpha = albedo_texture.Sample(linear_sampler, input.uv).a;
float threshold = Hash(input.position.xy);
clip(alpha - threshold);
```

| 点 | 説明 |
| --- | --- |
| <strong>`threshold`（ランダム）</strong> | **画素ごとに違う閾値**。**アルファが 0.3 なら、約 30% の画素が残る** |
| **TAA と併用** | **毎フレーム、違うノイズ**にすると、**時間平均で滑らかな半透明** |
| **ミップにも強い** | **アルファが薄くなっても、確率的に残る**ので、**スカスカにならない** |
| **欠点** | **TAA がないと、ノイズが見える** |

**ハッシュ（ノイズ）を、ワールド座標・オブジェクト座標**から作る（**Wyman と McGuire の Hashed Alpha Testing**）と、**動いても、ノイズが物体に貼りつく**ので**安定**します。

## ディザ透明

**カメラに近づいた物を、半透明にして向こうを見えるようにする**（例：**キャラの前の壁・木**）ときに、**ブレンドではなく、ディザ パターンで捨てる**方法があります。

```hlsl
static const float kBayer4x4[16] = {
    0.0 / 16, 8.0 / 16, 2.0 / 16, 10.0 / 16,
    12.0 / 16, 4.0 / 16, 14.0 / 16, 6.0 / 16,
    3.0 / 16, 11.0 / 16, 1.0 / 16, 9.0 / 16,
    15.0 / 16, 7.0 / 16, 13.0 / 16, 5.0 / 16};

uint2 p = uint2(input.position.xy) % 4;
float threshold = kBayer4x4[p.y * 4 + p.x];
clip(fade_alpha - threshold);
```

**不透明のまま、深度も書き、ソートも不要**で、**半透明のような見た目**になります（**ゲームのカメラが、壁を透かす**用途で定番）。

## パフォーマンス：Early-Z が効かない

**`clip` を含むシェーダーは、「深度を書くかどうか」が、シェーダー実行後でないと決まらない**ため、**Early-Z（シェーダーの前に深度テスト）が、使えません**。

| 項目 | 内容 |
| --- | --- |
| **Early-Z** | **ピクセル シェーダーの前に深度テストを行い、隠れた画素のシェーダーを省く** |
| **`clip` があると** | **ハードウェアは、シェーダー後でないと、深度を書くか分からない** |
| **影響** | **隠れた葉でも、シェーダーが走る**（**オーバードローが重い**） |

### 対策

| 方法 | 内容 |
| --- | --- |
| **深度プリパスで、アルファ テスト物も描く** | **深度だけ**を、<strong>軽いシェーダー（テクスチャ 1 回と `clip`）</strong>で先に描き、**本描画は深度 `EQUAL`**。**本描画の重いシェーダーが、見える葉にだけ走る** |
| **不透明物を先に描く** | **アルファ テスト物の前に、不透明物を描いて、深度を埋める**（**Early-Z が、アルファ テスト物を隠す**） |
| **ジオメトリで形を作る** | **葉を、アルファの形に近い多角形**で作り、**無駄な透明部分**を**減らす**（**オーバードローを減らす**） |
| **`[earlydepthstencil]`** | **強制的に Early-Z**（`clip` の結果が深度に影響しない場合のみ。**通常は使えない**） |

**不透明 → アルファ テスト → 半透明**の**順で描く**のが、**一般的な構成**です。

## 影・深度パスでのアルファ テスト

**影（シャドウ マップ）や深度プリパス**でも、**葉の形で影を落とす**には、**アルファ テストが必要**です。**これらのパスにも、同じ `clip`** を**入れ**ます（[特殊な影](../shadows/special-cases/index.md)）。

## 方式の比較

| 方式 | 縁 | 順序 | 深度 | コスト | 用途 |
| --- | --- | --- | --- | --- | --- |
| <strong>clip（アルファ テスト）</strong> | ギザギザ | 不要 | 書ける | 低〜中 | 草・葉・金網 |
| **Alpha to Coverage** | 滑らか（MSAA） | 不要 | 書ける | MSAA のコスト | 草・葉（MSAA 使用時） |
| **ハッシュド アルファ** | 滑らか（TAA） | 不要 | 書ける | 低 | 草・葉・髪（TAA 使用時） |
| **ディザ透明** | 網目状 | 不要 | 書ける | 低 | カメラ前の遮蔽物を透かす |
| **ブレンド** | 滑らか | **必要** | 書かない | 中〜大 | ガラス・煙 |

## よくあるミス

??? failure "葉のテクスチャを、ミップありでアルファ テストして、遠くの木がスカスカになる"
    **ミップ生成でカバレッジを保存**する、または**ハッシュド アルファ**。

??? failure "アルファ テストの葉に、縁のギザギザが残る"
    <strong>Alpha to Coverage（MSAA）</strong>または**ハッシュド アルファ ＋ TAA**。

??? failure "影のシャドウ パスに `clip` を入れず、葉の影が四角くなる"
    **シャドウ パスにも、アルファ テスト**を入れる。

??? failure "アルファ テスト物を先に大量に描いて、重い"
    **不透明物を先に描き**、**深度プリパス**を使う。

??? failure "テクスチャのアルファに、縁の色にじみがあって、葉の周りに白い線が出る"
    **透明部分の RGB を、葉の色で埋める**（ディレーション）。
