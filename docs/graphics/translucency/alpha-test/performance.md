# Performance and Shadow Passes

**アルファ テストを使うシェーダーは、Early-Z（早期の深度テスト）が効かず、重くなります**。**影や深度のパスでも、アルファ テストが必要**です。このページでは、**パフォーマンスへの影響と、影・深度パスでの扱い**を説明します。

!!! tip "ポイント"
    - **clip を使うと、Early-Z が無効**（または、効きが悪い）。
    - **対策：深度プリパスで、アルファ テストを先に済ませる**。
    - **葉などは、ポリゴンで形に切り抜くと、clip を減らせる**。
    - **影のパスでも、アルファ テストが必要**（葉の影が板状にならない）。

## パフォーマンス：Early-Z が効かない
**`clip` を含むシェーダーは、「深度を書くかどうか」が、シェーダー実行後でないと決まらない**ため、**Early-Z（シェーダーの前に深度テスト）が、使えません**。

Early-Z が効かない理由です。Early-Z は、ピクセル シェーダーの前に深度テストを行い、隠れた画素のシェーダーを省く仕組みです。`clip` があると、ハードウェアはシェーダーの後でないと、深度を書くか分かりません。その影響で、隠れた葉でもシェーダーが走り、オーバードローが重くなります。

### 対策

対策は 4 つです。深度プリパスにアルファ テスト物も描く方法は、軽いシェーダー（テクスチャ 1 回と `clip`）で深度だけを先に描き、本描画は深度 `EQUAL` にします。本描画の重いシェーダーを、見える画素だけに限定できます。不透明物を先に描き、アルファ テスト物の前に深度を埋めておくと、Early-Z がアルファ テスト物を隠してくれます。ジオメトリで形を作る方法は、葉をアルファの形に近い多角形で作り、無駄な透明部分を減らして、オーバードローを減らします。`[earlydepthstencil]` で強制的に Early-Z にする方法もありますが、`clip` の結果が深度に影響しない場合のみで、通常は使えません。

**不透明 → アルファ テスト → 半透明**の**順で描く**のが、**一般的な構成**です。

## 影・深度パスでのアルファ テスト
**影（シャドウ マップ）や深度プリパス**でも、**葉の形で影を落とす**には、**アルファ テストが必要**です。**これらのパスにも、同じ `clip`** を**入れ**ます（[特殊な影](../../shadows/special-cases/index.md)）。

## よくあるミス

??? failure "葉が多いシーンで、フレーム時間が伸びる"
    **ポリゴンを切り抜いて**、**clip の面積を減らす**。
