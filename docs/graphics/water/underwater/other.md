# Other Underwater Elements

<strong>水中の雰囲気は霧や光だけでなく、粒子・色補正・音でも作れます</strong>。このページでは 水中の他の要素を説明します。

!!! tip "ポイント"
    - 浮遊する粒子（マリン スノー）で、深さの感じを出す。
    - 色補正で全体を青緑に寄せる。
    - 音をこもらせる（ローパス フィルタ）。
    - 画面の端を少し歪ませると、水中らしい。

## 水中の他の要素
| 要素 | 内容 |
| --- | --- |
| 視界 | 水中の霧で見える距離を制限 |
| ゆらぎ | 画面全体を法線の動きで少し歪ませる（[Post-Processing](../../postprocess/index.md)） |
| 泡の粒子 | ゆっくり上がる泡（パーティクル） |
| マリン スノー | 漂う小さな粒（ほこり）。奥行き感が出る |
| 音 | ローパス フィルタ（こもった音） |
| 色補正 | 青緑に寄せる |

## 水中らしさを作る小さな要素

霧とコースティクス、光の筋に加えて <strong>小さな要素</strong>を足すと、水中の雰囲気が大きく変わります。

## 浮遊粒子（マリン スノー）

水中には <strong>細かい粒子</strong>（プランクトンの死骸、泥、微生物）が ゆっくり漂っています。カメラの周りに小さな白い点を、ゆっくり動かすだけで水中にいる感じが、出ます。

| 項目 | 内容 |
| --- | --- |
| 数 | 数百〜数千個 |
| 大きさ | 小さい（数ピクセル）。奥にあるほど小さく |
| 動き | ゆっくり漂いゆっくり沈む。水流（フロー マップ）があれば、流れに乗る |
| 範囲 | カメラの周りの、箱の中。箱の外に出た粒子は反対側へ戻す（ループ） |
| ライティング | 光の筋の中で、明るく光る（散乱）。影の中は暗い |
| 描画 | 加算ブレンド、またはアルファ ブレンドの小さな板（ビルボード） |

```hlsl
// 粒子: カメラの周りの箱の中に、ループさせる（箱の外に出ると、反対側に出る）。
float3 pos = initial_position + velocity * time;
pos = camera_position + fmod(pos - camera_position + box_size * 0.5, box_size) - box_size * 0.5;
```

カメラの周りの箱の中だけに、粒子を置き 箱の外に出た粒子は、反対側から再登場させると数百個で、無限に広がる粒子の海に見えます。

## 泡（気泡）

| 種類 | 内容 |
| --- | --- |
| 吐いた息（ダイバー） | プレイヤーの口から、大きな泡が上昇する。だんだん大きくなる（水圧が下がる） |
| 水に落ちた物の泡 | 水に入った瞬間、多数の小さな泡。数秒で水面へ上がる |
| スクリュー、物の動き | 船のスクリューの後ろに、泡の帯 |
| 火山、熱水 | 地面から泡が立ち上る |

泡は <strong>パーティクル</strong>で表現します。上に向かって上昇しゆらゆら揺れ、水面で消えるようにします。

| パラメーター | 目安 |
| --- | --- |
| 上昇速度 | 0.2〜0.5 m/s |
| 揺れ | 左右に小さなサイン波 |
| 寿命 | 水面に着くまで（または、固定の時間） |
| 見た目 | 半透明の丸。縁が明るく中心が透ける。小さなハイライト |

## 水の動き（ゆらぎ）

水中では <strong>水の流れ</strong>で 海藻が、ゆらゆら揺れ、物がわずかに漂います。

| 要素 | 方法 |
| --- | --- |
| 海藻、サンゴ | 頂点シェーダーで、ゆっくりした揺れ（[Wind](../../terrain/vegetation/wind.md) と、同じ方法をゆっくり大きな波長で） |
| 魚の群れ | ボイド（群れの、アルゴリズム）で動かす。GPU で数千匹 |
| 浮かぶごみ | 水の流れに沿って、ゆっくり動かす |

水中の動きは 空気中よりはるかに、ゆっくりで 周期も長い。同じ式でも速さの係数を小さくします。

## 画面の歪み（水中のレンズ効果）

カメラが水の中に入ると <strong>画面全体が、ゆらゆらと歪んで</strong>見えます（光が、波打つ水の中を通るため。マスクを通して見るときも歪む）。

```hlsl
// ポストプロセス: 画面を、ゆっくり歪ませる。
float2 wobble = float2(
    sin(uv.y * 20.0 + time * 1.5),
    cos(uv.x * 20.0 + time * 1.2)) * 0.002;           // ごく小さく（0.002 程度）
float3 color = g_scene.Sample(g_linear_clamp, uv + wobble).rgb;
```

歪みは ごくわずかにします。強すぎると 酔います。

## 色補正

水中は全体の <strong>色味</strong>が変わります。

| 要素 | 変更 |
| --- | --- |
| 彩度 | 下げる（赤が失われ全体が、青緑に偏る） |
| コントラスト | 下げる（霧で、コントラストが落ちる） |
| 色相 | 青緑に寄せる（カラー グレーディング、[Color Grading](../../postprocess/color-grading/index.md)） |
| 周辺減光 | 強める（暗い、閉じた視界の印象） |
| 被写界深度 | 遠くをぼかす（水の濁りで遠くが、ぼやける） |

水に入った瞬間にカラー グレーディングの、LUT を切り替える（または、補間する）と 水の中に入ったことが、はっきり伝わります。

## 音

見た目だけでなく <strong>音</strong>も水中の、雰囲気を大きく変えます。

| 要素 | 変更 |
| --- | --- |
| 周波数 | 高音をカットする（ローパス フィルタ）。水中ではこもった音になる |
| 反響 | 音がぼやけて遠くまで届く |
| 環境音 | 水のごぼごぼ、という低音。泡の音 |
| 水面の上の音 | 小さく、こもって聞こえる（逆に水面の上から、水中の音はほぼ聞こえない） |

水に入る 境目で フィルタを、なめらかに切り替えると水中に入った感じが、出ます。

## 水に入った瞬間と出る瞬間

| 瞬間 | 演出 |
| --- | --- |
| 水に入る | 水しぶき泡、画面の水滴、音のフィルタ、霧と色補正の切り替え（数フレームで、補間） |
| 水から出る | 画面を水が、流れ落ちる（レンズの水滴）、音が元に戻る霧と色補正が元に戻る |

<strong>瞬間的に切り替える</strong>と不自然です。水面をまたぐ間（0.2〜0.5 秒）で、補間します（[The Underside of the Surface and Crossing It](surface-back.md)）。
