# Flow Maps

<strong>川や渦の水は一方向に流れます</strong>。フローマップ（流れの向きを入れたテクスチャ）で、法線マップを流すと流れを表現できます。このページではフローマップの使い方を説明します。

!!! tip "ポイント"
    - フローマップ ＝ 各位置の、流れの向きを入れたテクスチャ。
    - その向きに法線マップの UV をずらす。
    - ずらし続けると歪むので、2 層を交互にブレンドする。
    - 川・滝・渦の表現に使う。

## フローマップ（水の流れ）
<strong>川の流れ</strong>は波動のシミュレーションとは別に、流れの向きを描いたテクスチャ（フローマップ）で表現します。法線マップをその向きに流すことで水が流れて見えます。

フローマップは各点の流れの向き（RG に 2D ベクトル）を持つテクスチャです。

```hlsl
float2 flow = flow_map.Sample(linear_clamp, uv).rg * 2.0 - 1.0;
float flow_time = time * flow_speed;

float phase0 = frac(flow_time);
float phase1 = frac(flow_time + 0.5);
float2 uv0 = world_uv - flow * phase0 * flow_strength;
float2 uv1 = world_uv - flow * phase1 * flow_strength;

float3 n0 = normal_map.Sample(linear_wrap, uv0).xyz * 2.0 - 1.0;
float3 n1 = normal_map.Sample(linear_wrap, uv1).xyz * 2.0 - 1.0;

float blend = abs(phase0 * 2.0 - 1.0);
float3 flow_normal = normalize(lerp(n0, n1, blend));
```

| 点 | 説明 |
| --- | --- |
| `frac(time)` | UV が流れ続けるとテクスチャが引き伸ばされるので、周期的に元に戻す |
| 位相をずらした 2 つ | 0 と 0.5 ずらした 2 つを交互にブレンドして、戻る瞬間の「跳び」を隠す |
| `blend` | 片方が戻る（見えなくなる）タイミングでもう片方が最大 |
| `world_uv` に乱数を足す | 場所ごとに位相をずらすと、全体が同時に切り替わらない |

### フローマップの作り方

| 方法 | 内容 |
| --- | --- |
| 手描き | ペイント ツールで流れの向きを描く（色が向き） |
| シミュレーション | 地形の傾きから、流れを計算して焼き込む（高い所から低い所へ） |
| 障害物を避ける | 岩の周りで流れが曲がるように、向きを描く |
| 流速を長さで | ベクトルの長さを流れの速さにする |

## フロー マップとは

川、滝、水路では水が <strong>一定の方向に流れます</strong>。法線マップを一方向にスクロールさせるだけでは、水面が全体として一定の向きに、滑るように見えます。実際の川は、場所ごとに流れの向きと速さが、違います（岩の周りで曲がる渦を巻く）。

フロー マップは 水面の、各位置の流れの向きと速さを記録したテクスチャです。水面の法線や泡をそのベクトルに沿って、動かします。

| チャンネル | 内容 |
| --- | --- |
| R | 流れの x 成分（0〜1 → −1〜1） |
| G | 流れの z 成分（0〜1 → −1〜1） |
| B（任意） | 流れの速さまたは、泡の量 |

```hlsl
// フロー マップから、流れの向きと速さを読む（0〜1 を、−1〜1 にする）。
float2 flow = g_flow_map.Sample(g_linear_clamp, flow_uv).xy * 2.0 - 1.0;
```

## 単純に流すとどうなるか

UV を <strong>時間に比例して流れの向きに、ずらす</strong>と模様が 流れて見えます。

```hlsl
float2 uv = world_uv - flow * time * speed;      // 流れの向きに、時間とともに、動かす
float3 n = g_normal_map.Sample(g_linear_wrap, uv).xyz;
```

しかし、これには 問題があります。流れの向きが 場所ごとに違うので、時間が経つと UV が場所ごとに、違う量だけずれて模様が引き伸ばされ、ねじれます。

```text
時刻 0:   ▒▒▒▒▒▒▒▒  きれいな模様
時刻 5:   ▒▒░░▒▒░░  場所ごとに、ずれて、引き伸ばされる
時刻 20:  ░░░░░░░░  模様が、ほとんど、線になる
```

## 2 つの位相を混ぜる（Portal 2 の方法）

Vlachos（2010）は <strong>この、引き伸ばしを避ける方法</strong>を示しています。

1. 時間を周期的に 0 → 1 に、動かす（のこぎり波）。ずらす量が一定の範囲でリセットされる
2. リセットの瞬間は模様がぱっと、元に戻るので半周期ずれたもう 1 つを、用意する
3. 2 つを交互にフェードしながら混ぜる

```hlsl
// 2 つの位相: 周期 1 のこぎり波を、半周期ずらして、2 つ用意する。
float phase0 = frac(time * flow_speed);
float phase1 = frac(time * flow_speed + 0.5);

// それぞれの位相で、UV をずらして、法線マップを読む。
float2 uv0 = world_uv - flow * phase0 * flow_scale;
float2 uv1 = world_uv - flow * phase1 * flow_scale + 0.5;           // 0.5 は、2 つの模様が、重ならないよう、ずらす
float3 n0 = g_normal_map.Sample(g_linear_wrap, uv0).xyz * 2.0 - 1.0;
float3 n1 = g_normal_map.Sample(g_linear_wrap, uv1).xyz * 2.0 - 1.0;

// 重み: 位相が 0 や 1 に近い（リセット直前直後）ほど小さく、0.5 付近で最大。
float w0 = 1.0 - abs(2.0 * phase0 - 1.0);
float3 n = normalize(lerp(n1, n0, w0));         // w0 が 1 のとき n0、0 のとき n1
```

| 位相 phase0 | w0 | 見えるもの |
| --- | --- | --- |
| 0（リセット直後） | 0 | n1（位相 0.5。最大にずれている安定した状態） |
| 0.5 | 1 | n0（位相 0.5） |
| 1（リセット直前） | 0 | n1 |

リセットの瞬間は重みが 0 の方の模様なのでぱっと、戻っても 見えません。

### 模様が周期的に脈打つ問題

周期ごとに 2 つの模様が 入れ替わるので、水面が一定の周期で脈打つように、見えることがあります。軽減策は次のとおりです。

| 対策 | 内容 |
| --- | --- |
| 位相にノイズ | 位相に、位置依存のノイズを足して場所ごとに周期を、ずらす |
| 周期を長くする | 周期が、長いほど脈打ちがゆっくりで目立たない（ただし、引き伸ばしが大きくなる） |
| 3 つの位相 | 3 位相で、重みを混ぜる。よりなめらかになる |

```hlsl
// 位相に、位置依存の、ずれを足して、水面全体が、同時に、脈打たないようにする。
float noise = g_noise.Sample(g_linear_wrap, world_uv * 0.5).r;
float phase0 = frac(time * flow_speed + noise);
float phase1 = frac(time * flow_speed + noise + 0.5);
```

## 流れの速さを法線マップの、スクロール速度に

流れの<strong>速さ</strong>はフロー ベクトルの長さで、表します。速い所ほど模様が速く流れます。流れがゼロ（静かな所）のとき模様は、止まって見えます。

```hlsl
float speed = length(flow);
// 流れが弱いほど、波も穏やかに（法線の強さを、速さで変える）
float normal_strength = lerp(0.3, 1.0, saturate(speed));
```

## フロー マップの作り方

| 方法 | 内容 |
| --- | --- |
| 手描き | ブラシで流れの向きを、描く（専用のツール、または Photoshop の拡張） |
| 地形から計算 | 地形の、高さマップから水が流れる向き（斜面の下り）を、求める。川の流れを自動で作る（[Rivers and Lakes](../../terrain/generation/rivers.md) の、D8 法の方向） |
| 流体シミュレーション | 川のシミュレーション（流体の計算）の結果を、焼く |
| 障害物の周りに曲げる | 岩や、橋脚の周りの流れを回り込む向きで、描く |

川の中心線（スプライン）から、<strong>流れの向きをスプラインの接線方向</strong>として、作る方法もあります。川の岸に近いほど流れを 遅くします（岸は摩擦で、遅い）。

```text
岸に近い所: 流れが遅い（0.2）
川の中央:   流れが速い（1.0）
```

## 泡やごみも流す

水面の上の <strong>泡</strong>、木の葉、油など水に浮かぶ模様も同じフロー マップで、流せます（[Persistent Foam](../shore-foam/foam-history.md)）。

| 流す対象 | 方法 |
| --- | --- |
| 泡のテクスチャ | 法線と同じ、2 位相の混ぜ合わせ |
| 泡の履歴（蓄積されたもの） | 履歴のテクスチャを、フロー マップの向きに毎フレーム、少しずつずらして書き直す（移流） |
| 水面に浮くオブジェクト | 位置を、フロー マップの向きに動かす（物理の、外力として） |

## 移流（advection）：テクスチャ自体を流す

2 位相の方法は <strong>模様のテクスチャ</strong>を流す、簡単な方法です。蓄積した情報（泡の履歴）を、流すときは毎フレーム、流れの向きの逆向きにサンプルして、書き直す方法（移流、Neyret 2003 の考え方の、一部）を使います。

```hlsl
// 前のフレームの泡の量を、流れに沿って動かす（半ラグランジュ法）。
float2 flow = g_flow_map.Sample(g_linear_clamp, uv).xy * 2.0 - 1.0;
float2 prev_uv = uv - flow * flow_scale * dt;               // 流れの上流側から、読む
float foam = g_foam_prev.Sample(g_linear_clamp, prev_uv).r;
```

「自分の位置に流れてきたのは、上流の位置にあった泡」と考えて、上流を読むのがポイントです。読み方を逆にすると泡が逆流します。
