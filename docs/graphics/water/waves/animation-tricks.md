# 波の動かし方の工夫

**波を動かすには、時間を進めるだけではなく、「繰り返しを隠す」「遠くを省く」といった工夫**が必要です。このページでは、**波のアニメーションの工夫**を説明します。

!!! tip "ポイント"
    - **波の位相に、ノイズを足して、規則性を崩す**。
    - **距離に応じて、波の数を減らす**（LOD）。
    - **時間の値が大きくなると、精度が落ちる**ので、**周期でリセット**する。
    - **風向きと強さで、波のパラメータを切り替える**。

## 波の動かし方の工夫
| 工夫 | 内容 |
| --- | --- |
| **距離で波の本数を減らす** | **遠くは細かい波を省略**（**LOD**）。**ちらつきの防止** |
| **風向き・強さのパラメータ** | **風の向きで波の向き**を**風の強さで振幅・波長**を**変える** |
| **波長から速さを決める** | **深い水の波は`速さ = √(g·λ / 2π)`**（**長い波ほど速い**）。**自然な分散** |
| **ランダム化** | **波ごとの向きを基準の向きの周りでばらす** |

<div class="formula">波の速さ c = √( g · λ / (2π) )　（g = 9.8 m/s²、λ = 波長）</div>

## よくあるミス

??? failure "長時間プレイすると、波がカクつく"
    **時間を周期でラップ**させる。
