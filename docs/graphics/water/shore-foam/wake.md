# 航跡と衝突

**船の後ろや、物が水に当たった所には、泡の筋（航跡）ができます**。**物の位置を、泡のバッファに書き込む**ことで、**表現**できます。このページでは、**航跡と衝突の泡**を説明します。

!!! tip "ポイント"
    - **物が通った位置に、泡を書き込む**。
    - **書き込みは、バッファを描く（スプラット）**。
    - **履歴で、ゆっくり消える**。
    - **速さに応じて、強さを変える**。

## 航跡と衝突
**船や泳ぐキャラクターの後ろ**には**泡の筋**が**残ります**。

| 方法 | 内容 |
| --- | --- |
| **ブラシで泡の履歴に描く** | **物の位置に丸い点を描き込む**（[波紋と水面のインタラクション](../interaction/index.md)） |
| **パーティクル** | **しぶきをパーティクルで出す** |
| **水中の物の深度** | **岸辺と同じ深度差で杭の周りに自動で輪が出る** |

## よくあるミス

??? failure "船が通っても、泡の筋が出ない"
    **物の位置を、泡のバッファに書き込む**。

## これだけ覚える
