# Water Color Parameters

<strong>水の見た目はいくつかのパラメータで決まります</strong>。パラメータの意味と目安を知っておくと、調整が楽になります。このページでは水の色のパラメータを説明します。

    - 吸収係数（色ごと）。

    - 海・湖・プールで、値を変える。

## 水の色のパラメータ
| パラメータ | 内容 |
| --- | --- |
| 浅い水の色 | 明るい青緑（岸辺・白い砂の上） |
| 深い水の色 | 濃い青（沖） |
| 吸収係数 σ | RGB ごと。値を大きくすると浅いうちに濃い色 |
| 透明度の距離 | 底が見える深さ。σ で調整 |
| 屈折の強さ | 歪みの大きさ |
| スペキュラの鋭さ | ハイライトの広がり |
| 泡の色・量 | 岸辺・波頂の泡 |

<strong>場所ごとに（湖・海・沼）変えられるよう、パラメータはマテリアルとして持つ</strong>のが扱いやすいです。

### 値の決め方

パラメータを決めるときはまず見せたい水の種類を決めます。透明度の高い南国の海はσ を小さくして底まで見せ、浅い色を明るい水色にします。濁った川はσ を大きくして数十 cm で底が見えなくなり、散乱の色を茶色や緑にします。北の海は深い色を暗い青灰色にし、スペキュラの粗さを上げます。

実在の水の吸収係数は赤が約 0.45 /m、緑が約 0.07 /m、青が約 0.02 /m です（きれいな水）。この値をそのまま使うと水深 5 m でほぼ赤が消える物理的に正しい見た目になります。ゲームでは見やすさのためにこれを数倍〜十倍に誇張することが多いです。アーティストが扱いやすいように、σ を直接触らせるのでなく「この深さで底が見えなくなる」という透明度の距離をパラメータにして、内部で σ に変換する設計がよく使われます。

## 物理的なパラメーターと、アーティスト向けのパラメーター

水のマテリアルには 2 つの流儀があります。

| 流儀 | パラメーター | 長所 | 短所 |
| --- | --- | --- | --- |
| 物理ベース | 吸収係数 `a`（RGB）、後方散乱 `b_b`、屈折率 | 現実の水を再現できる。値の意味が明確 | アーティストが直感で扱いにくい |
| アーティスト向け | 浅い所の色、深い所の色、「透明度の距離」 | 直感的。色を直接、指定できる | 現実からずれても、気づきにくい。照明の変化に追従しにくい |

おすすめは <strong>内部を物理ベースにして入力は、アーティスト向けにする</strong>組み合わせです。アーティストが「この深さで底が見えなくなる（透明度の距離）」「深い所の色」を指定し、そこから吸収係数を自動で計算します。

## 透明度の距離から吸収係数を決める

「<strong>ここまでの深さなら底が見える</strong>」という、透明度の距離（セッキ ディスクの深さに近い）を指定すると吸収係数に換算できます。

```text
透過率が、ほぼ見えなくなる値（たとえば 5%）になる距離を、D とすると:
exp(−a × D) = 0.05   →   a = −ln(0.05) / D = 3.0 / D
```

```cpp
// 透明度の距離（メートル）から、吸収係数を作る。RGB で、赤が強く、青が弱くなるよう、比を掛ける。
float3 AbsorptionFromVisibility(float visibility_m, float3 color_ratio) {
  const float a = 3.0f / visibility_m;            // 赤、緑、青の平均がこの値になる
  return {a * color_ratio.x, a * color_ratio.y, a * color_ratio.z};
}

// 例: 澄んだ海（透明度 20 m）。赤は、青の 15 倍吸収される。
const float3 absorption = AbsorptionFromVisibility(20.0f, {2.1f, 0.5f, 0.14f});
```

比 `color_ratio` は水の種類で決めます。赤をよく吸収するほど 青く澄んだ水です。

## パラメーターの一覧と目安

| パラメーター | 内容 | 目安 |
| --- | --- | --- |
| 吸収係数 `a`（RGB、1/m） | 色ごとの吸収の強さ | 澄んだ水 (0.3, 0.05, 0.01)、濁った水 (1.0, 0.4, 0.3) |
| 後方散乱 `b_b`（1/m） | 水自体が返す光の量 | 澄んだ水 0.003、濁った水 0.02 |
| 屈折率 | スネルの法則と、フレネル | 1.33（水）。ほぼ変えない |
| 屈折の歪み | 画面のコピーの、ずらし量 | 0.02〜0.05 |
| 反射の強さ | フレネルに掛ける倍率 | 1.0（物理どおり）。0.8〜1.2 で調整 |
| 粗さ（`roughness`） | スペキュラーと、反射のぼけ | 風速から決める（[Specular](specular.md)）。0.02〜0.3 |
| 波の法線の強さ | 細かい法線の、傾きの倍率 | 1.0 |
| 泡の色・量 | 波頭と岸の泡 | 白、密度は風と地形で変える |
| 水面の高さ | 海面のレベル | ワールドの基準 |

## 水の種類のプリセット

場所ごとにパラメーターのセット（プリセット）を持つと <strong>海、湖、池、プール、沼</strong>を 1 つの水シェーダーで、作り分けられます。

| 種類 | 吸収 a（RGB） | 後方散乱 b_b | 透明度 | 粗さ | 特徴 |
| --- | --- | --- | --- | --- | --- |
| 南国の海 | (0.35, 0.06, 0.02) | 0.004 | 30 m | 0.1〜 | 鮮やかな青緑。浅瀬は白い砂が透ける |
| 外洋 | (0.45, 0.07, 0.03) | 0.005 | 20 m | 0.15〜 | 深い青。波が大きい |
| 湖 | (0.7, 0.25, 0.2) | 0.015 | 8 m | 0.05〜 | 緑がかった、静かな水面 |
| 川 | (1.0, 0.45, 0.4) | 0.03 | 3 m | 0.05〜 | 茶〜緑。流れがある |
| 沼 | (2.0, 1.0, 0.9) | 0.05 | 1 m | 0.03 | 暗い緑茶色。透けない |
| プール | (0.25, 0.04, 0.02) | 0.002 | 全部見える | 0.02 | 底のタイルが見える。塩素の青 |

数値は 見た目の出発点です。ゲームの明るさ・露出に合わせて、調整してください。

```cpp
// プリセットを構造体で持つ。
struct WaterMaterial {
  float3 absorption;          // 1/m
  float backscatter;          // 1/m
  float visibility_m;         // 透明度（参考値。absorption を自動で決めるときに使う）
  float roughness;
  float refraction_strength;
  float reflection_scale;
  float normal_strength;
  float foam_amount;
};

constexpr WaterMaterial kOcean = {{0.45f, 0.07f, 0.03f}, 0.005f, 20.0f, 0.15f, 0.03f, 1.0f, 1.0f, 0.6f};
constexpr WaterMaterial kLake  = {{0.70f, 0.25f, 0.20f}, 0.015f, 8.0f, 0.05f, 0.02f, 1.0f, 0.6f, 0.1f};
```

```hlsl
cbuffer WaterMaterialCB : register(b3) {
  float3 g_absorption;
  float g_backscatter;
  float g_roughness;
  float g_refraction_strength;
  float g_reflection_scale;
  float g_normal_strength;
  float g_foam_amount;
  float3 pad;
};
```

## 場所ごとに水を変える

湖から川へ <strong>水の種類がつながっている</strong>ところは、境目でパラメーターを補間します。

| 方法 | 内容 |
| --- | --- |
| 水域ごとに別のメッシュ | メッシュごとに、マテリアルを設定。境目がはっきり分かれる |
| 頂点カラーで補間 | 頂点にプリセットの重みを持たせて補間する |
| テクスチャでパラメーターを描く | 水の濁り深さをマップに描いて、読む（岸の近くだけ緑にするなど） |

## 天候と時間帯

水の見た目は <strong>空の光</strong>で変わります。

| 要因 | 変わるもの |
| --- | --- |
| 晴れ → 曇り | `deep_color` が暗く、グレーに。太陽の反射が消える |
| 昼 → 夕方 | 反射がオレンジに。深い水の色が暗くなる |
| 夜 | 空の光がほぼ無い。水はほぼ黒（月や街灯の反射だけ） |
| 雨 | 粗さが増える（水面に雨粒の波）。反射がにじむ |

吸収係数は 水そのものの性質なので、時間帯では変えません。変えるのは入ってくる光（`incident_light`）です（[Scattering Color (SSS-Like)](scattering.md)）。
