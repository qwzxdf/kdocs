# Water Color Parameters

**水の見た目は、いくつかのパラメータで決まります**。**パラメータの意味と目安を知っておくと、調整が楽**になります。このページでは、**水の色のパラメータ**を説明します。

!!! tip "ポイント"
    - **浅瀬の色・深場の色**。
    - **吸収係数（色ごと）**。
    - **フレネルの F0 ・粗さ**。
    - **海・湖・プールで、値を変える**。

## Water Color Parameters {#水の色のパラメータ}
| パラメータ | 内容 |
| --- | --- |
| **浅い水の色** | **明るい青緑**（岸辺・白い砂の上） |
| **深い水の色** | **濃い青**（沖） |
| **吸収係数 σ** | **RGB ごと**。**値を大きくすると浅いうちに濃い色** |
| **透明度の距離** | **底が見える深さ**。**σ で調整** |
| **屈折の強さ** | **歪みの大きさ** |
| **スペキュラの鋭さ** | **ハイライトの広がり** |
| **泡の色・量** | **岸辺・波頂の泡** |

**場所ごとに（湖・海・沼）変えられるよう、パラメータはマテリアルとして持つ**のが**扱いやすい**です。

### How to Choose Values {#値の決め方}

パラメータを決めるときは、まず<strong>見せたい水の種類</strong>を決めます。透明度の高い南国の海は、σ を小さくして底まで見せ、浅い色を明るい水色にします。濁った川は、σ を大きくして数十 cm で底が見えなくなり、散乱の色を茶色や緑にします。北の海は、深い色を暗い青灰色にし、スペキュラの粗さを上げます。

実在の水の吸収係数は、赤が約 0.45 /m、緑が約 0.07 /m、青が約 0.02 /m です（きれいな水）。この値をそのまま使うと、水深 5 m でほぼ赤が消える物理的に正しい見た目になります。ゲームでは、見やすさのために、これを数倍〜十倍に誇張することが多いです。アーティストが扱いやすいように、σ を直接触らせるのでなく、「この深さで底が見えなくなる」という透明度の距離をパラメータにして、内部で σ に変換する設計がよく使われます。

## Common Mistakes {#よくあるミス}

??? failure "海も湖も同じパラメータで、変化が出ない"
    **環境ごとにプリセット**を用意する。
