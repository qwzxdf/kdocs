# その他の最適化

これまでのページで扱わなかった、**描画の最適化の手法**を、<strong>「何が重く」「何を改善するか」</strong>の形で、まとめます。**それぞれが、独立した話題**なので、**気になったものから**、読んでください。

!!! tip "ポイント"
    - <strong>影</strong>：<strong>カスケード シャドウ マップ（CSM）・影のカリング・更新頻度の削減</strong>。
    - <strong>LOD・インポスター</strong>：<strong>遠い物の、頂点・ピクセルを、減らす</strong>。
    - <strong>テクスチャ ストリーミング</strong>：<strong>必要な、ミップだけを、メモリに置く</strong>（<strong>VRAM・帯域</strong>）。
    - <strong>VRS（可変レート シェーディング）</strong>：<strong>画面の場所ごとに、シェーディングの細かさを、変える</strong>。
    - <strong>TAA・アップスケーラ</strong>：<strong>低解像度で描き、時間情報で、補う</strong>。
    - <strong>非同期コンピュート</strong>：<strong>グラフィックスと、コンピュートを、同時に走らせる</strong>。
    - <strong>パーティクル・半透明</strong>：<strong>オーバードロー・縮小バッファ</strong>。

## 影のコスト

**影マップ**は、**光の視点から、シーンを、もう一度描く**ので、**ドロー コール・頂点処理**が、**ほぼ、倍**になります。

| 重い所 | 対策 |
| --- | --- |
| **広い範囲を、1 枚で、覆う** | <strong>カスケード シャドウ マップ（CSM）</strong>：**カメラの近くは細かく、遠くは粗く**、**複数枚に分割** |
| **影を落とす物が、多い** | **影用の、カリング**（**カメラの視錐台ではなく、光の視錐台で**）。**小さな物・遠い物は、影を、落とさない** |
| **毎フレーム、全カスケードを更新** | **遠いカスケードは、数フレームに 1 回**（**更新頻度を、下げる**） |
| **動かない物の影** | **静的な影は、キャッシュ**（**動く物だけ、毎フレーム**） |
| **解像度が高い** | **必要最小限**（**フィルタリング（PCF）で、粗さを、ごまかす**） |
| **影用の、LOD** | **影は、低い LOD の、メッシュで描く** |
| <strong>点光源の影（6 面）</strong> | **影を、落とすライトを、制限**（**重要なライトだけ**） |

## LOD とインポスター

| 手法 | 説明 |
| --- | --- |
| **離散 LOD** | **距離で、メッシュを、切り替え**（頂点が、減る） |
| **インポスター** | **非常に遠い物（木・建物）を、画像 1 枚（ビルボード）に**。**頂点・ピクセルが、激減** |
| **ハイブリッド** | **近い：メッシュ／中間：簡易メッシュ／遠い：インポスター** |
| **シェーダー LOD** | **遠い物は、軽いシェーダー**（**法線マップなどを、省略**） |
| **LOD の、ポップ対策** | **ディザ フェード・距離のヒステリシス**（[カリング](culling.md)） |

## テクスチャ ストリーミング

**全テクスチャの、全ミップを、メモリに置く**と、**VRAM が足りません**。**画面に映る大きさに、必要な、ミップだけ**を、**読み込みます**。

| 点 | 説明 |
| --- | --- |
| **ミップ ストリーミング** | **遠い物は、小さなミップだけ**を、メモリに置く。**近づいたら、大きなミップを、読み込む** |
| **効果** | **VRAM の、削減**・**読み込み時間の、短縮** |
| **バーチャル テクスチャ** | **巨大なテクスチャを、タイル（ページ）単位**で、**必要な部分だけ**読み込む（**地形・広大なマップ**） |
| **圧縮** | **BC 圧縮**で、**VRAM・帯域を、減らす**（[メモリ帯域幅](bandwidth.md)・[テクスチャ](../../3d/mesh-textures.md)） |
| **注意** | **読み込みが、間に合わない**と、**ぼやけた、画像が見える**（**ストリーミングの、遅れ**） |

## VRS（可変レート シェーディング）

**画面の全ピクセルに、同じ細かさで、シェーダーを動かす**のは、**無駄**なことがあります（**暗い所・動きの速い所・周辺視野**）。**VRS** は、**場所ごとに、シェーディングのレートを、変えます**（例：**2×2 ピクセルを、1 回の計算で**）。

| 点 | 説明 |
| --- | --- |
| **使いどころ** | **ぼやけた・暗い・速く動く領域**。**画面の、周辺**（VR の、フォービエイテッド レンダリング） |
| **効果** | **ピクセルシェーダーの、負荷が、減る** |
| **対応** | **DX12 Ultimate**（Tier 1 / 2）・一部のハード（**DX11 では、使えない**） |
| **注意** | **レートを、落としすぎると、荒れる** |

## TAA とアップスケーラ

<strong>TAA（時間的アンチエイリアシング）</strong> は、**毎フレーム、サブピクセルずつ、ずらして描き**、**過去のフレームと、混ぜて**、**滑らかな画**にします。

| 利点 | 説明 |
| --- | --- |
| **エッジの、滑らかさ** | **MSAA より、安く、広く効く**（ディファードとも、相性が良い） |
| **ノイズの、平均化** | **AO・SSR・影の、サンプル数を、減らせる**（**時間で、平均**） |
| **アップスケールの土台** | **DLSS・FSR・TAAU は、TAA の延長**（**低解像度で描き、高解像度へ**）（[縮小バッファの効果](low-res-effects.md)） |
| **注意** | **ゴースト（残像）・ぼやけ**。**動きベクトルの、精度が、重要** |

## 非同期コンピュート

**GPU は、グラフィックス（描画）と、コンピュート**を、**同時に、走らせられます**（**別のキュー**）。**描画が、帯域で詰まっている間に、演算中心のコンピュートを、走らせる**など、**GPU の空きを、埋める**使い方です。

| 点 | 説明 |
| --- | --- |
| **向く組み合わせ** | <strong>影マップ（深度のみ・ALU が空く）× AO・ライト カリング（コンピュート）</strong> |
| **対応** | **DX12・Vulkan**（**DX11 では、使えない**） |
| **注意** | **同期（フェンス）の設計**が、必要。**効果は、GPU・内容による**（**測る**） |

## パーティクルと半透明

**半透明は、Early-Z で捨てられず、重なる**（[オーバードロー](overdraw.md)）。

| 工夫 | 説明 |
| --- | --- |
| **縮小バッファに描く** | **煙・霧・炎を、半分・4 分の 1 解像度**で描き、**合成** |
| **枚数・サイズを、減らす** | **画面の、大半を覆う、巨大な板は、避ける** |
| **板を、形に沿って切り詰める** | **透明な部分の、ピクセルを、減らす** |
| **ソフト パーティクルの、深度読み込み** | **深度を、読む**ので、**帯域に、注意** |
| **GPU パーティクル** | **コンピュートで、更新**（**CPU の負担ゼロ**）（[データ配置](../data-layout.md)） |

## ポストプロセスの、整理

| 工夫 | 説明 |
| --- | --- |
| **パスを、まとめる** | **ブルーム・トーンマップ・カラー グレーディングを、1 パス**に（**読み書きの帯域を、減らす**） |
| **縮小して計算** | **ブラー・AO**（[縮小バッファの効果](low-res-effects.md)） |
| **不要な効果を、切る** | **見た目への影響が、小さい効果**は、**やめる** |
| **フォーマット** | **HDR バッファを、必要以上に、重くしない**（R11G11B10 など）（[メモリ帯域幅](bandwidth.md)） |

## 最適化の、進め方

| 手順 | 内容 |
| --- | --- |
| **① 測る** | **CPU か GPU か**（[何が重いのか](bottlenecks.md)） |
| **② ボトルネックを、特定** | **ドロー コール・頂点・ピクセル・帯域** |
| **③ 対応する手法を、選ぶ** | <strong>[詳細ページの、地図](index.md)</strong> を参照 |
| **④ 1 つずつ、変えて、測る** | **効果を、確認**（**複数、同時に変えない**） |
| **⑤ 見た目を、確認** | **品質が、落ちすぎていないか** |

## よくあるミス

??? failure "影の、更新を、毎フレーム、全部やる"
    **遠いカスケード・静的な影**を、**間引き・キャッシュ**します。

??? failure "全テクスチャを、フル解像度・無圧縮で、常駐させる"
    **BC 圧縮・ストリーミング**にします。

??? failure "TAA の、動きベクトルが、不正確で、ゴーストが出る"
    **動く物・スキニングの、動きベクトル**を、**正しく**出します。

??? failure "非同期コンピュートで、同期が、悪く、逆に遅くなる"
    **測って**確認し、**同期点を、最小**にします。

??? failure "ポストプロセスを、1 つずつ、別パスで、全画面にかける"
    **まとめて、1 パス**にします。
