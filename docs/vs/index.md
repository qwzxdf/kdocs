# Visual Studio

C++ でゲームを作る学生の多くは、<strong>Visual Studio（ビジュアル スタジオ）</strong> を使います。このカテゴリでは、**C++23 のコードを動かすための設定**、**外部ライブラリの入れ方**、**デバッグのやり方**、**よく出るエラー**を、Visual Studio の画面に沿ってまとめています。このサイトのサンプルコードは C++23 で書かれているので、まず「[C++23 を使えるようにする設定](settings.md)」を済ませてください。

## 用語

| 用語 | 意味 |
| --- | --- |
| ソリューション（`.sln`） | プロジェクトをまとめる入れ物。ゲーム本体、ツール、ライブラリなど |
| プロジェクト（`.vcxproj`） | 1 つの実行ファイル（`.exe`）や、ライブラリ（`.lib`）を作る単位 |
| 構成（Configuration） | **Debug**（デバッグ用）と **Release**（製品用）など、ビルド設定の組 |
| プラットフォーム | **x64**（64 ビット）か Win32（32 ビット）。今は **x64 にする** |
| ビルド | ソースコードを実行できるファイルにすること（コンパイル + リンク） |
| MSVC（エムエスブイシー） | Visual Studio が使うコンパイラ。GCC、Clang とは別のもの |
