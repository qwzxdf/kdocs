# インストールとプロジェクトの作成

Visual Studio で C++ を始めるときの、インストールから「Hello」を動かすところまでです。

!!! tip "ポイント"
    - インストールのとき、<strong>「C++ によるデスクトップ開発」</strong>のワークロードにチェックを入れる。
    - プロジェクトは <strong>「空のプロジェクト」</strong> か <strong>「コンソール アプリ」</strong> で作る。
    - プラットフォームは **x64**。構成は開発中は **Debug**。
    - ファイルは**ソリューション フォルダーの中にまとめて**置く（`src/`、`third_party/` など）。

## インストール

1. [Visual Studio の公式サイト](https://visualstudio.microsoft.com/ja/) から **Visual Studio Community**（学生・個人は無料）をダウンロードする
2. インストーラーを起動して、**ワークロード**の画面で <strong>「C++ によるデスクトップ開発」</strong> にチェックを入れる
3. 必要に応じて、右側の「インストールの詳細」で、次を足す

| コンポーネント | 何に使うか |
| --- | --- |
| Windows 11（または 10）SDK | Windows のヘッダとライブラリ。ワークロードに含まれる |
| **vcpkg パッケージ マネージャー** | 外部ライブラリを入れる（[外部ライブラリの入れ方](libraries.md)） |
| **C++ AddressSanitizer** | メモリのバグ探し（[デバッグ](debugging.md)） |
| C++ CMake ツール | CMake のプロジェクトを開くとき（[CMake で使う](cmake.md)） |
| 日本語の言語パック | メニューが日本語になる（インストール時の言語タブ） |

!!! note "バージョンを確認する"
    メニューの「ヘルプ」→「Microsoft Visual Studio について」でバージョンが分かります。このサイトの C++23 のサンプルを動かすには、**2022 の 17.9 以降**（できれば最新）を使います。`<print>` は 17.7、`<mdspan>` は 17.9 から使えます。古いときは、Visual Studio Installer で「更新」を押します。

## プロジェクトを作る

1. Visual Studio を起動して、<strong>「新しいプロジェクトの作成」</strong> を選ぶ
2. 一覧から <strong>「コンソール アプリ」</strong>（C++）を選んで「次へ」
3. **プロジェクト名**（半角英数字、たとえば `MyGame`）と**場所**を入れる
   - 場所のパスに**日本語やスペースを入れない**（ライブラリやツールが失敗する原因になります）
   - 「ソリューションとプロジェクトを同じディレクトリに配置する」は、**チェックしない**ほうが整理しやすい
4. <strong>「作成」</strong> を押す

`MyGame.cpp` に `Hello World` を出すコードが入ります。**Ctrl + F5**（デバッグなしで開始）で実行できます。

### 「空のプロジェクト」を使うとき

ゲームのように、自分でファイルを作っていくなら <strong>「空のプロジェクト」</strong> のほうが、余計なファイルが入りません。`main.cpp` を自分で追加します。

1. ソリューション エクスプローラーでプロジェクトを右クリック → **追加 → 新しい項目**
2. <strong>C++ ファイル（.cpp）</strong> を選んで、名前を `main.cpp` にして追加
3. 次のコードを書いて、**Ctrl + F5** を押す

```cpp
#include <print>

int main() {
  std::println("Hello, C++23!");
}
```

```text title="実行結果"
Hello, C++23!
```

`std::println` がエラーになるときは、[C++23 の設定](settings.md) を先に済ませてください。

## ソリューションとプロジェクトのしくみ

```text
MyGame/                       ← ソリューション フォルダー
├── MyGame.sln                ← ソリューション（プロジェクトの入れ物）
├── MyGame/                   ← プロジェクト フォルダー
│   ├── MyGame.vcxproj        ← プロジェクトの設定（ビルド設定がここに書かれる）
│   ├── MyGame.vcxproj.filters← ソリューション エクスプローラーのフォルダー分け
│   ├── main.cpp
│   └── ...
├── x64/Debug/                ← ビルド結果（.exe など）。Git に入れない
└── .vs/                      ← Visual Studio の一時ファイル。Git に入れない
```

| 用語 | 説明 |
| --- | --- |
| ソリューション エクスプローラー | 右側（または左側）に出る、ファイルの一覧。ここでファイルを追加・削除する |
| フィルター | ソリューション エクスプローラー上の**見かけだけ**のフォルダー。実際のフォルダーとは別 |
| スタートアップ プロジェクト | F5 で実行されるプロジェクト。太字で表示される。右クリック → 「スタートアップ プロジェクトに設定」 |

!!! warning "フィルターと実際のフォルダーは別"
    ソリューション エクスプローラーで「新しいフィルター」を作っても、ディスク上にはフォルダーはできません。整理したいときは、**エクスプローラーでフォルダーを作ってファイルを移し**、ソリューション エクスプローラーの上部の「**すべてのファイルを表示**」ボタンで、ファイルをプロジェクトに含めなおします。

## 複数のプロジェクトを持つ

ゲームでは、<strong>ゲーム本体（exe）</strong> と<strong>エンジン（lib）</strong>、<strong>ツール（exe）</strong> のように、プロジェクトを分けることがあります。

1. ソリューションを右クリック → **追加 → 新しいプロジェクト** で、「静的ライブラリ」（C++）を追加する
2. ゲーム本体のプロジェクトを右クリック → **追加 → 参照** → ライブラリのプロジェクトにチェックを入れる
3. ゲーム本体の `追加のインクルード ディレクトリ` に、ライブラリの `include` フォルダーを足す（[外部ライブラリの入れ方](libraries.md)）

## Git に入れないもの

`.gitignore` に次を書いておきます（Visual Studio の「Git」メニューから作成すると自動で入ります）。

```text
.vs/
x64/
Debug/
Release/
*.user
*.suo
*.ipch
```
