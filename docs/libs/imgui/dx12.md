# DirectX 12 での初期化まとめ

DirectX 11 の ImGui は、`Init` に `device` と `context` を渡すだけでした（[仕組みと最小のコード](basics.md)）。DirectX 12 では、**ディスクリプタ ヒープ・フレームごとのリソース・GPU の完了待ち**を自分で用意する必要があり、初期化でつまずきやすいです。このページは**面倒な所だけを順番にまとめます**。

!!! warning "バージョンで変わる"
    DX12 バックエンドの初期化関数は、バージョンによって引数が違います（1.91 系で `ImGui_ImplDX12_InitInfo` 構造体を使う形に変わりました）。**自分が入れた `imgui_impl_dx12.h` を開いて**、関数のシグネチャを確認してください。このページは考え方とつまずく場所の説明が中心です。

!!! tip "ポイント"
    - DX11 と違い、<strong>SRV 用のディスクリプタ ヒープ</strong>（シェーダーから見える）を<strong>自分で作って渡す</strong>。
    - フォントのテクスチャ用に<strong>ディスクリプタを 1 つ</strong>使う。ゲームの画像を `ImGui::Image` で出すなら、さらに必要。
    - <strong>フレーム数（`NumFramesInFlight`）</strong>を、スワップチェーンのバッファ数と合わせる。
    - 描画の前に<strong>`SetDescriptorHeaps` で、そのヒープをコマンド リストに設定</strong>する。忘れると描画されない。
    - 終了・リサイズの前に<strong>GPU の完了を待つ</strong>（フェンス）。待たずに解放するとクラッシュする。
    - RTV のフォーマットは、<strong>スワップチェーンと同じ</strong>にする。

## ① SRV 用のディスクリプタ ヒープ

ImGui のフォント テクスチャは、**シェーダーから読めるディスクリプタ**として登録する必要があります。**ヒープの種類は `CBV_SRV_UAV`、フラグは `SHADER_VISIBLE`** です。

```cpp
D3D12_DESCRIPTOR_HEAP_DESC desc = {};
desc.Type = D3D12_DESCRIPTOR_HEAP_TYPE_CBV_SRV_UAV;
desc.NumDescriptors = 64;
desc.Flags = D3D12_DESCRIPTOR_HEAP_FLAG_SHADER_VISIBLE;
device->CreateDescriptorHeap(&desc, IID_PPV_ARGS(&srv_heap));
```

| 点 | 説明 |
| --- | --- |
| **個数** | フォント用に 1 個。`ImGui::Image` で画像を出すなら、その分も（余裕を持って 64 や 128 など） |
| **ヒープは使い回す** | 他の描画と同じヒープでもよい（その中の 1 枠を ImGui に割り当てる） |
| **shader visible は 1 種類につき 1 つしか設定できない** | `SetDescriptorHeaps` で同時に設定できる `CBV_SRV_UAV` ヒープは 1 つ。**ゲーム側のヒープと、ImGui のヒープを別々に設定して描画の途中で切り替える**ことになる |

## ② Win32 バックエンド

DX11 と同じです。

```cpp
ImGui::CreateContext();
ImGui_ImplWin32_Init(hwnd);
```

## ③ DX12 バックエンドの初期化

### 古い形（1.90 系まで）

```cpp
ImGui_ImplDX12_Init(
    device,
    kFrameCount,
    DXGI_FORMAT_R8G8B8A8_UNORM,
    srv_heap,
    srv_heap->GetCPUDescriptorHandleForHeapStart(),
    srv_heap->GetGPUDescriptorHandleForHeapStart());
```

| 引数 | 型 | 意味 |
| --- | --- | --- |
| `device` | `ID3D12Device*` | デバイス |
| `num_frames_in_flight` | `int` | 同時に GPU が処理中のフレーム数。**スワップチェーンのバッファ数**と合わせる |
| `rtv_format` | `DXGI_FORMAT` | 描画先（バックバッファ）のフォーマット。**スワップチェーンと同じ** |
| `cbv_srv_heap` | `ID3D12DescriptorHeap*` | ① で作った SRV ヒープ |
| `font_srv_cpu_desc_handle` | `D3D12_CPU_DESCRIPTOR_HANDLE` | フォント用の枠（CPU 側のハンドル） |
| `font_srv_gpu_desc_handle` | `D3D12_GPU_DESCRIPTOR_HANDLE` | フォント用の枠（GPU 側のハンドル）。CPU と**同じ枠**を指すこと |

### 新しい形（1.91 系以降）

構造体にまとめて渡します。`CommandQueue` を渡すのは、**フォントのアップロードや、ビューポート機能で必要**だからです。

```cpp
ImGui_ImplDX12_InitInfo init_info = {};
init_info.Device = device;
init_info.CommandQueue = command_queue;
init_info.NumFramesInFlight = kFrameCount;
init_info.RTVFormat = DXGI_FORMAT_R8G8B8A8_UNORM;
init_info.DSVFormat = DXGI_FORMAT_UNKNOWN;
init_info.SrvDescriptorHeap = srv_heap;
init_info.SrvDescriptorAllocFn = [](ImGui_ImplDX12_InitInfo* info,
                                    D3D12_CPU_DESCRIPTOR_HANDLE* out_cpu,
                                    D3D12_GPU_DESCRIPTOR_HANDLE* out_gpu) {
  // ヒープから空き枠を 1 つ取り出して返す
};
init_info.SrvDescriptorFreeFn = [](ImGui_ImplDX12_InitInfo* info,
                                   D3D12_CPU_DESCRIPTOR_HANDLE cpu,
                                   D3D12_GPU_DESCRIPTOR_HANDLE gpu) {
  // 枠を空きに戻す
};
ImGui_ImplDX12_Init(&init_info);
```

| 項目 | 説明 |
| --- | --- |
| **`SrvDescriptorAllocFn` / `FreeFn`** | ImGui が必要なときに、**ディスクリプタの枠を自分で確保・返却**してもらう。簡単な「空き番号のリスト」を作って渡す |
| **`DSVFormat`** | 深度バッファを使わないなら `UNKNOWN` |

!!! tip "空き枠の管理は、自作の小さなクラスでよい"
    「使っていない番号のスタック」と「ヒープの先頭ハンドル + 番号 × インクリメント量」を持つクラスを作ります。**ImGui 用だけでなく、ゲームの画像用の枠の確保にも**使い回せます。

## ④ 毎フレームの描画

```cpp
ImGui_ImplDX12_NewFrame();
ImGui_ImplWin32_NewFrame();
ImGui::NewFrame();

ImGui::ShowDemoWindow();

ImGui::Render();

ID3D12DescriptorHeap* heaps[] = {srv_heap};
command_list->SetDescriptorHeaps(1, heaps);
ImGui_ImplDX12_RenderDrawData(ImGui::GetDrawData(), command_list);
```

| 手順 | 注意 |
| --- | --- |
| **順序** | `NewFrame`（DX12 → Win32 → ImGui）→ UI を書く → `Render` → 描画データを送る |
| **描画先** | **先に `OMSetRenderTargets` で、バックバッファを設定**しておく（ImGui は、**今設定されているレンダーターゲット**に描く） |
| **`SetDescriptorHeaps`** | **ImGui の描画の直前に必ず**。ゲーム側が別のヒープを設定していても、ここで切り替える |
| **ゲームの描画の後** | UI は一番上に重ねるので、**ゲームの描画が終わったあと、`Present` の前**に描く |
| **リソース バリア** | バックバッファが `RENDER_TARGET` の状態であること。ImGui の描画後に `PRESENT` へ戻す |

## ウィンドウのリサイズ

DX12 では、**バックバッファを作り直す前に、GPU の処理が全部終わっている**必要があります。

| 手順 | 内容 |
| --- | --- |
| ① | **GPU の完了を待つ**（フェンスですべてのフレームの完了を待つ） |
| ② | バックバッファへの参照（RTV やリソース）を**全部解放** |
| ③ | `IDXGISwapChain::ResizeBuffers` |
| ④ | RTV を作り直す |

**ImGui 側で特別な処理は不要**です（画面サイズは `NewFrame` で、`io.DisplaySize` として自動で取得されます）。ただし、**ステップ ① を忘れて**クラッシュするのが、最もよくある失敗です。

## 終了

```cpp
WaitForGpu();

ImGui_ImplDX12_Shutdown();
ImGui_ImplWin32_Shutdown();
ImGui::DestroyContext();
```

**GPU がまだ ImGui のリソース（頂点バッファ・フォント）を使っている間に `Shutdown` すると**、クラッシュやデバッグ レイヤーのエラーになります。**必ず先に完了を待ちます**。

## ゲームの画像を ImGui に出す

DX12 では、`ImTextureID` に**GPU ディスクリプタ ハンドルの値**（`ptr`）を入れます（[テクスチャと画像](textures.md)）。

```cpp
ImTextureID id = static_cast<ImTextureID>(gpu_handle.ptr);
ImGui::Image(id, ImVec2(256, 256));
```

| 点 | 説明 |
| --- | --- |
| **SRV を ImGui のヒープに作る** | `CreateShaderResourceView` の出力先は、**ImGui の `SetDescriptorHeaps` で設定するヒープの中**。別のヒープのハンドルを渡しても、描画されない |
| **寿命** | GPU が描き終わるまで、その枠を再利用しない（フレームごとに枠を使い回す設計なら、`NumFramesInFlight` 分ずらす） |
| **ゲームの画面を出す** | レンダーターゲットのテクスチャを `PIXEL_SHADER_RESOURCE` の状態にして SRV を作る。ImGui の描画が終わったら、元の状態へ戻す |

## つまずきやすい点

??? failure "何も描画されない"
    `SetDescriptorHeaps` を呼んでいない、レンダーターゲットが設定されていない、ゲームの描画より前に ImGui を描いている、のどれかです。

??? failure "フォントが真っ白・文字が出ない"
    フォント用のハンドル（CPU と GPU）が、**同じ枠を指していない**、またはヒープが `SHADER_VISIBLE` でない。

??? failure "リサイズ・終了でクラッシュする"
    GPU の完了待ちが足りません。フェンスで全フレームを待ちます。

??? failure "`NumFramesInFlight` がスワップチェーンと違う"
    ImGui のフレームごとのバッファが、足りなくなったり、使用中のものを上書きしたりします。

??? failure "ImGui の画像が真っ黒（`ImGui::Image`）"
    SRV を別のヒープに作っている、またはリソースの状態が `PIXEL_SHADER_RESOURCE` でない。

??? failure "sRGB のバックバッファで、色が薄く見える"
    ImGui は色をそのまま書くので、**sRGB フォーマットの RTV**だと変換が二重にかかり、ガンマが変わります。UI だけ、UNORM の RTV で描く方法もあります。
