# ImGui 関数早見表

ImGui の関数は数百個あり、<strong>「どの関数を呼ぶと画面に何が出るのか」</strong>を覚えるのが最初の壁です。このセクションは、**関数を目的別に並べて、「何が出るか・主な引数・戻り値」を一覧**にした**早見表**です。<strong>実際の見た目（ギャラリー）</strong>と<strong>動き（アニメーション）</strong>も付けています。**読む本ではなく、引く辞書**として使ってください。

## 早見表の一覧

| ページ | 内容 |
| --- | --- |
| [ウィジェット](widgets.md) | テキスト・ボタン・チェック・スライダー・ドラッグ・入力・コンボ・リスト・色・プロット・画像 |
| [コンテナ](containers.md) | ツリー・タブ・テーブル・メニュー・ポップアップ・ツールチップ・ドラッグ＆ドロップ |
| [レイアウトとウィンドウ](layout.md) | ウィンドウ・子ウィンドウ・並べる・間隔・カーソル・幅・スクロール・ID |
| [状態と入力](state-io.md) | `IsItem…`・`GetIO`・キーとマウス・スタイルの Push/Pop |
| [描画（ImDrawList）](draw.md) | 線・四角・円・文字・クリップ・独自のウィジェット |
| [フラグ](flags.md) | `ImGuiWindowFlags`・`InputTextFlags`・`TreeNodeFlags`・`TableFlags` ほか |
