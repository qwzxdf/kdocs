# イージング

**イージング**は**時間の進み方と値の進み方の対応を変える**ことで、動きに「感触」をつける技術です。一定の速さで動く（線形）と、機械的で硬い印象になります。ゆっくり動き出して、速くなり、最後にゆっくり止まると、**自然で気持ちよい動き**になります。UI の出入り・キャラクターのジャンプ・カメラの移動・ダメージ数字の跳ね方など、ゲームのほぼ全ての動きに使われます。

!!! tip "ポイント"
    - イージング関数は<strong>t（0〜1）を受け取り、変換した t（ほぼ 0〜1）を返す</strong>。それを lerp に渡す。
    - 名前は<strong>種類（Quad・Cubic・Expo など）＋ 方向（In・Out・InOut）</strong>。
    - <strong>Out（最初が速く、最後が遅い）</strong>が、UI で最もよく使う。反応が良く感じる。
    - <strong>In</strong>は動き出しがゆっくり。<strong>InOut</strong>は両端がゆっくり。
    - <strong>Back</strong>は行き過ぎて戻る。<strong>Elastic</strong>は弾む。<strong>Bounce</strong>は跳ねる。
    - <strong>時間（duration）と、イージング関数を分けて</strong>管理する。

## 仕組み

イージング関数 `f(t)` は、**0〜1 の時間の割合 t** から、<strong>0〜1 の「進み具合」</strong> を返します。その結果を、lerp の t として使います。

```cpp
float t = std::clamp(elapsed / duration, 0.0f, 1.0f);
float eased = EaseOutCubic(t);
Vector3 position = Vector3::Lerp(start, end, eased);
```

| 値 | 意味 |
| --- | --- |
| **`t`** | 時間の割合（0 から 1 に一定の速さで増える） |
| **`eased`** | 進み具合（イージング関数で変形した結果） |
| **`f(0) = 0`・`f(1) = 1`** | 始点と終点は変わらない（途中の進み方だけが変わる） |

## In・Out・InOut

| 方向 | 動き | 使いどころ |
| --- | --- | --- |
| **In** | ゆっくり始まり、速く終わる（加速） | 画面外へ飛んでいく・落下・退場 |
| **Out** | 速く始まり、ゆっくり終わる（減速） | **UI の登場・ポップアップ・着地**。反応が良く感じる |
| **InOut** | 両端がゆっくり、中間が速い | 画面の切り替え・カメラの移動・往復 |

!!! tip "迷ったら Out"
    ボタンを押したあとの動きなど、**ユーザーの操作に対する反応**は、**Out 系**にします。動き出しが速いので、「反応が良い」と感じます。In 系は反応が遅れて感じるので、操作の直後には向きません。

### 種類ごとの特徴

| 種類 | 式（In の場合） | 特徴 |
| --- | --- | --- |
| **Linear** | `t` | 一定の速さ。機械的 |
| **Sine** | `1 - cos(t × π / 2)` | 最もゆるやか。自然 |
| **Quad** | `t²` | ほどよい。標準的 |
| **Cubic** | `t³` | Quad より強い。UI でよく使う |
| **Quart** | `t⁴` | さらに強い |
| **Quint** | `t⁵` | 最も強い多項式。動きが急 |
| **Expo** | `2^(10t - 10)` | 指数。始まりが極端に遅い。ズームなどに |
| **Circ** | `1 - √(1 - t²)` | 円弧の形。止まり際が急 |
| **Back** | 行き過ぎて戻る | 弾むようなオーバーシュート。ポップアップに |
| **Elastic** | 振動しながら収束 | ゴムのような揺れ。強い演出 |
| **Bounce** | 跳ねる | ボールが床で弾む |

**Quad → Cubic → Quart → Quint** は、同じ形で**べき乗が大きいほど急**になります。迷ったら **Cubic** が万能です。

## 実装

多項式のものは、短く書けます。

```cpp
float EaseInQuad(float t) { return t * t; }
float EaseOutQuad(float t) { return 1.0f - (1.0f - t) * (1.0f - t); }
float EaseInOutQuad(float t) {
  return t < 0.5f ? 2.0f * t * t : 1.0f - std::pow(-2.0f * t + 2.0f, 2.0f) / 2.0f;
}

float EaseInCubic(float t) { return t * t * t; }
float EaseOutCubic(float t) {
  float u = 1.0f - t;
  return 1.0f - u * u * u;
}
float EaseInOutCubic(float t) {
  return t < 0.5f ? 4.0f * t * t * t : 1.0f - std::pow(-2.0f * t + 2.0f, 3.0f) / 2.0f;
}

float EaseInSine(float t) { return 1.0f - std::cos(t * std::numbers::pi_v<float> / 2.0f); }
float EaseOutSine(float t) { return std::sin(t * std::numbers::pi_v<float> / 2.0f); }

float EaseOutExpo(float t) { return t >= 1.0f ? 1.0f : 1.0f - std::pow(2.0f, -10.0f * t); }
```

### Back（オーバーシュート）

```cpp
float EaseOutBack(float t) {
  constexpr float c1 = 1.70158f;
  constexpr float c3 = c1 + 1.0f;
  float u = t - 1.0f;
  return 1.0f + c3 * u * u * u + c1 * u * u;
}
```

`c1` が**行き過ぎる量**を決めます（1.70158 で約 10% 行き過ぎる）。値を大きくするとさらに行き過ぎます。

### Elastic（弾む）

```cpp
float EaseOutElastic(float t) {
  constexpr float c4 = 2.0f * std::numbers::pi_v<float> / 3.0f;
  if (t <= 0.0f) return 0.0f;
  if (t >= 1.0f) return 1.0f;
  return std::pow(2.0f, -10.0f * t) * std::sin((t * 10.0f - 0.75f) * c4) + 1.0f;
}
```

### Bounce（跳ねる）

```cpp
float EaseOutBounce(float t) {
  constexpr float n1 = 7.5625f;
  constexpr float d1 = 2.75f;
  if (t < 1.0f / d1) {
    return n1 * t * t;
  }
  if (t < 2.0f / d1) {
    t -= 1.5f / d1;
    return n1 * t * t + 0.75f;
  }
  if (t < 2.5f / d1) {
    t -= 2.25f / d1;
    return n1 * t * t + 0.9375f;
  }
  t -= 2.625f / d1;
  return n1 * t * t + 0.984375f;
}
```

### In・InOut を Out から作る

<strong>Out の関数が 1 つあれば、In と InOut は機械的に作れます。</strong>

```cpp
float EaseIn(float (*out)(float), float t) { return 1.0f - out(1.0f - t); }
float EaseInOut(float (*out)(float), float t) {
  return t < 0.5f ? (1.0f - out(1.0f - 2.0f * t)) * 0.5f : 0.5f + out(2.0f * t - 1.0f) * 0.5f;
}
```

| 変換 | 式 | 意味 |
| --- | --- | --- |
| **Out → In** | `1 - Out(1 - t)` | 時間を反転して、値も反転 |
| **Out → InOut** | 前半は In を半分、後半は Out を半分 | 両端をなめらかに |

## イージングの使い方

### 1. 時間を管理するクラスを作る

```cpp
class Tween {
 public:
  Tween(float from, float to, float duration, float (*ease)(float))
      : from_(from), to_(to), duration_(duration), ease_(ease) {}

  void Update(float delta_time) { elapsed_ += delta_time; }

  float Value() const {
    float t = std::clamp(elapsed_ / duration_, 0.0f, 1.0f);
    return std::lerp(from_, to_, ease_(t));
  }

  bool Finished() const { return elapsed_ >= duration_; }

 private:
  float from_;
  float to_;
  float duration_;
  float (*ease_)(float);
  float elapsed_ = 0.0f;
};
```

| 点 | 説明 |
| --- | --- |
| **時間（経過）を持つ** | 毎フレーム `delta_time` を足す |
| **イージング関数を差し替え可能に** | 関数ポインタ・`std::function` |
| **終了の判定** | `elapsed >= duration` |
| **値は 1 フレームごとに、計算し直す** | 前の値に足し続けない（誤差が積み重なる） |

### 2. 使い分けの目安

| 場面 | おすすめ |
| --- | --- |
| **UI のウィンドウが開く** | OutCubic・OutBack（ポップ感） |
| **UI のウィンドウが閉じる** | InCubic |
| **画面の切り替え・カメラ移動** | InOutCubic・InOutSine |
| **ボタンを押した反応** | OutQuad・OutBack（少し弾ませる） |
| **ダメージ数字が跳ねる** | OutBounce・OutBack |
| **ゴムのような演出** | OutElastic |
| **落下する物** | InQuad（重力のような加速） |
| **ズームイン・ズームアウト** | InOutExpo・InOutCubic |
| **HP バーの減少** | OutQuad（すっと減って、止まる） |
| **フェードイン・フェードアウト** | InOutSine・Linear |
| **ゆっくり出てくる文字** | OutSine |

### 3. 時間は同じでも、感触が違う

イージングは**移動の総時間を変えずに、「速さの配分」を変える**ものです。**同じ 0.3 秒**でも、Linear と OutCubic では、まったく違う印象になります。**速く動くイージングは、総時間を少し短く**すると、きびきびします。UI は 0.15〜0.3 秒が目安です。

## イージングで気をつけること

| 点 | 説明 |
| --- | --- |
| **`t` を clamp する** | `t` が 1 を超えると、関数によっては**値が大きく外れる**（Back・Elastic では特に） |
| **Back・Elastic は範囲外の値を返す** | 0 未満や 1 を超える値になる。**色や不透明度**に使うと不正な値になる（clamp する） |
| **多段のイージングの合成** | 前半を InQuad、後半を OutQuad のように、組み合わせられる |
| **逆方向のアニメーション** | 戻るときは、**In と Out を入れ替える**と自然 |
| **動いている最中の再開** | 現在の値から、新しい目標へ始め直す（速度が不連続になる。気になるなら[スムージング](smoothing.md)） |
| **カーブの自作** | ベジェ曲線の 4 点（CSS の `cubic-bezier(x1, y1, x2, y2)` と同じ）で、好みの形が作れる（[曲線](curves.md)） |

## イージングと「指数減衰」の違い

どちらも「なめらかに目標へ近づく」ように見えますが**用途が違います**。

| | イージング | 指数減衰（Damp） |
| --- | --- | --- |
| **時間** | **終わりの時間が決まっている** | 終わりがない（永遠に近づく） |
| **目標が動く** | 途中で変わると不自然 | **追従が自然**（動く目標に強い） |
| **使いどころ** | 演出・UI・決まった動き | カメラ・追尾・値の追いかけ |

**決まった時間で完了する動き**には**イージング**、**動き続ける目標を追う**には**指数減衰**（[補間](interpolation.md)・[スムージング](smoothing.md)）を使います。

## よくあるミス

??? failure "`t` が 1 を超えて、Elastic・Back で大きく外れる"
    `std::clamp(t, 0.0f, 1.0f)` を通します。

??? failure "不透明度や色に Back・Elastic を使い、範囲外の値になる"
    結果も clamp します。

??? failure "動き出しが遅い In 系を、ボタンの反応に使って、もたつく"
    Out 系にします。

??? failure "イージングを、毎フレーム「現在値」に対して適用する"
    `lerp(current, target, ease(t))` のように現在値に毎回かけると二重にかかります。**開始値**から計算します。

??? failure "移動時間が長すぎて、動きが遅く感じる"
    UI は 0.15〜0.3 秒が目安です。
