# ゲーム数学

ゲームを作っていると**数式を書く場面**が何度も出てきます。キャラクターを滑らかに動かす、敵に狙いをつける、カメラをなめらかに追従させる、ダメージを計算する、ランダムに敵を出す、といった処理は、ほぼすべて数学です。このセクションは、**ゲーム制作で実際に使う数学**を、まとめて並べたものです。大学の数学のように証明を追うのではなく、<strong>「何に使うか」「式はどう書くか」「どこで間違えやすいか」</strong>を中心に書きます。

3D の座標変換（行列・クォータニオン・カメラ）は、[3D ゲーム](../3d/index.md)のセクションに詳しく書いてあります。ここではそれ以外の、**2D・3D に共通して使う数学**を扱います。

!!! tip "ポイント"
    - ゲーム数学の中心は<strong>「ベクトル」「補間」「角度」「確率」「誤差」</strong>の 5 つ。
    - まず<strong>線形補間（lerp）</strong>を使いこなせば、動き・色・UI・カメラの多くが書ける。
    - 動きの「気持ちよさ」は<strong>イージング</strong>で決まる。
    - ベクトルの<strong>内積・外積</strong>は視野判定・反射・左右の判定に毎回出てくる。
    - 浮動小数点には<strong>誤差</strong>がある。<strong>== で比べない</strong>。
    - 乱数は<strong>分布</strong>を意識する。「円の中の一様なランダム」は、見た目より難しい。

## 読む順番の目安

| 目的 | おすすめの順 |
| --- | --- |
| **まず基本を固めたい** | 三角関数 → 補間 → イージング → ベクトル公式 |
| **2D ゲームを作る** | 三角関数 → ベクトル公式 → 交差判定 → 座標系と格子 → 乱数 |
| **3D ゲームを作る** | ベクトル公式 → 交差判定 → [3D のセクション](../3d/index.md) |
| **動きを気持ちよくしたい** | 補間 → イージング → スムージング → 運動 |
| **バランス調整をしたい** | 乱数 → ゲームバランス |
