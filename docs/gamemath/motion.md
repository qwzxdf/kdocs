# 運動と物理の数学

ゲームの動きの大半は、**位置・速度・加速度**の 3 つで書けます。ジャンプ・重力・弾・ばね・摩擦はどれもこの 3 つの関係から出てきます。物理エンジン（Jolt など）を使う場合も**自分で動きを書く場面**（弾・カメラ・UI・簡単なキャラの移動）は多く、そのとき必要になるのが、このページの内容です。

!!! tip "ポイント"
    - <strong>位置 ← 速度 ← 加速度</strong>。<strong>毎フレーム、加速度を速度に速度を位置に足す</strong>。
    - 足すときは<strong>必ず `dt`（経過時間）を掛ける</strong>。フレームレートに左右されない動きにする。
    - 積分の方法は<strong>半陰的オイラー法（速度を先に更新）</strong>が、ゲームの標準。
    - ジャンプは<strong>初速と重力から、高さと滞空時間を逆算</strong>できる。
    - 摩擦・空気抵抗は<strong>速度に比例して減らす</strong>。<strong>`dt` に依存しない書き方</strong>がある。
    - 動く的を狙うには<strong>偏差射撃</strong>（弾が届く時間を先に求める）。

## 位置・速度・加速度

| 量 | 意味 | 単位 | 関係 |
| --- | --- | --- | --- |
| **位置 x** | どこにいるか | m | 速度を積み重ねたもの |
| **速度 v** | 位置の変化の速さ | m/s | 加速度を積み重ねたもの |
| **加速度 a** | 速度の変化の速さ | m/s² | 力 ÷ 質量 |

```cpp
velocity += acceleration * dt;
position += velocity * dt;
```

| 点 | 説明 |
| --- | --- |
| **`dt` を掛ける** | 1 フレームの長さ（秒）。60 FPS なら約 0.0167 |
| **速度が先、位置が後** | **半陰的オイラー法**。位置を先に更新するより安定する |
| **単位をそろえる** | 「メートル」「秒」で統一する（ピクセルやフレーム単位で書くと後で困る） |

## 積分の方法（時間を進める計算）

運動の式を、**1 フレームずつ進める**方法です。

| 方法 | 式 | 特徴 |
| --- | --- | --- |
| **明示的オイラー法** | `x += v × dt; v += a × dt` | 簡単。**エネルギーが増えて不安定**になりやすい |
| **半陰的オイラー法** | `v += a × dt; x += v × dt` | **ゲームの標準**。簡単でばねなどでも安定 |
| **Verlet 法** | `x_new = 2x - x_old + a × dt²` | 速度を持たない。**ロープ・布・位置ベースの物理**に向く |
| **Velocity Verlet** | 位置と速度を半ステップずつ更新 | 精度が高い。軌道計算向き |
| <strong>RK4（ルンゲ・クッタ）</strong> | 4 回評価して平均 | 高精度。重い。物理シミュレーション向き |

**ゲームでは半陰的オイラー法で十分**です。物理エンジンも同じ形を使っています。

### 固定タイムステップ

**`dt` が毎フレーム違う**と、物理の結果が変わります（再現できない・不安定になる）。**物理は固定の刻み**（1/60 秒など）で進めます。

```cpp
accumulator += frame_time;
while (accumulator >= kFixedDt) {
  Step(kFixedDt);
  accumulator -= kFixedDt;
}
```

詳しくは[ゲームループ](../engine/game-loop.md)にあります。

## 等加速度運動と放物線

**一定の加速度**（重力など）での運動は**式で直接**求められます。

```text
位置: x(t) = x0 + v0 × t + (1/2) × a × t²
速度: v(t) = v0 + a × t
```

### ジャンプ

重力を `g`（下向きの加速度）、ジャンプの初速を `v0` とすると、**頂点の高さ**と**滞空時間**は次のとおりです。

| 求めるもの | 式 |
| --- | --- |
| **最高点の高さ H** | `H = v0² / (2g)` |
| **最高点に達する時間** | `t = v0 / g` |
| **着地までの時間** | `2 v0 / g` |
| **高さ H を跳ぶ初速** | `v0 = √(2 g H)` |
| **最高点まで T 秒にしたい** | `g = 2H / T²`、`v0 = 2H / T` |

```cpp
float JumpVelocity(float height, float gravity) {
  return std::sqrt(2.0f * gravity * height);
}
```

!!! tip "ジャンプの「感触」は、数値で決める"
    実際の重力（9.8 m/s²）のままだとゲームでは**ふわふわ**した感触になります。**高さ H と最高点までの時間 T を先に決めて**、そこから `g` と `v0` を逆算すると、思い通りの感触になります。**上昇中は軽く、落下中は重く**（落下時だけ重力を 1.5〜2 倍）するときびきびします。

### 弾・投擲の軌道

初速 `v0` を角度 θ で発射すると、水平 `v0 cos θ`・垂直 `v0 sin θ` の初速になります。

| 求めるもの | 式 |
| --- | --- |
| **水平の飛距離**（同じ高さに着地） | `R = v0² sin(2θ) / g` |
| **最も遠くへ飛ぶ角度** | 45 度 |
| **目標へ当てる初速の角度** | 2 次方程式（解が 2 つ：低い弾道と高い弾道） |

```cpp
Vector3 Trajectory(Vector3 start, Vector3 initial_velocity, float gravity, float t) {
  return start + initial_velocity * t + Vector3(0.0f, -0.5f * gravity * t * t, 0.0f);
}
```

**軌道の予測線**（投げる前に見せる）は、この式を少しずつ `t` を進めて点を並べるだけで描けます。

## 摩擦・空気抵抗・減衰

物体が**自然に止まる**ための減速です。

| 種類 | 式 | 特徴 |
| --- | --- | --- |
| <strong>線形減衰（空気抵抗）</strong> | `v *= (1 - damping × dt)` | 速度に比例して減る |
| **指数減衰** | `v *= exp(-damping × dt)` | **dt に依存しない**。正しい |
| <strong>一定の摩擦（クーロン摩擦）</strong> | 速さを一定量ずつ減らす | 床の上で止まる |
| **2 乗抵抗** | `v *= (1 - c × |v| × dt)` | 速いほど強く抵抗（落下の終端速度） |

```cpp
velocity *= std::exp(-damping * delta_time);
```

| 点 | 説明 |
| --- | --- |
| **`v *= 0.98f` を毎フレーム** | **フレームレートで減り方が変わる**（60 FPS と 144 FPS で違う）。指数減衰にする |
| **完全に止まらない** | 指数減衰は 0 にならない。十分小さければ、0 にする |
| **摩擦で止まる** | `speed = max(0, speed - friction × dt)` のように**符号を超えない**ようにする |

### 終端速度

**落下する物体**は、空気抵抗である速さ以上に速くならなくなります。**速度の上限を設ける**ことで、簡単に表せます。

```cpp
velocity.y = std::max(velocity.y, -kTerminalVelocity);
```

## ばね（フックの法則）

**変位に比例して、引き戻す力**です。

```text
力 F = -k × (x - x_rest)
```

| 記号 | 意味 |
| --- | --- |
| **k** | ばね定数（大きいほど硬い） |
| **x_rest** | 自然長（力が 0 になる位置） |
| **減衰 c** | `F_damping = -c × v`（振動を収める） |

```cpp
Vector3 SpringForce(Vector3 position, Vector3 rest, Vector3 velocity, float stiffness, float damping) {
  return (rest - position) * stiffness - velocity * damping;
}
```

| 使いどころ | 説明 |
| --- | --- |
| **カメラの追従・UI の揺れ** | ばねで目標へ近づく（[スムージング](smoothing.md)） |
| **ロープ・髪・布** | 点をばねでつなぐ |
| **車のサスペンション** | ばね ＋ ダンパー |
| **ボスの揺れ・やられ演出** | 一度引っ張って、離す |

<strong>硬いばね（k が大きい）を、大きな `dt` で解くと、発散（爆発）</strong>します。**サブステップ**で刻むか、**陰的な方法**を使います。

## 衝突応答

物体が衝突したあとの**速度の変化**です。

### 反発（跳ね返り）

壁（法線 n）に当たったとき、法線方向の速度を**反発係数 e** を掛けて反転します（[ベクトル公式](vector-recipes.md)）。

| 反発係数 e | 意味 |
| --- | --- |
| **0** | 完全非弾性（くっつく・止まる） |
| **0〜1** | 一部のエネルギーを失って跳ね返る |
| **1** | 完全弾性（エネルギーを失わず跳ね返る） |

### 2 つの物体の衝突（インパルス）

質量 m1・m2 の物体が衝突するとき、**相対速度の法線成分**から、<strong>インパルス（力積）</strong>を計算します。

```text
j = -(1 + e) × (v_rel・n) / (1/m1 + 1/m2)
v1 += (j / m1) × n
v2 -= (j / m2) × n
```

| 点 | 説明 |
| --- | --- |
| **質量が大きいほど動かない** | 質量が非常に大きい（または無限大）なら、壁として扱える |
| **互いに近づいているときだけ** | `v_rel・n < 0` のときだけ適用（離れていくときは何もしない） |
| **本格的に** | 回転・摩擦・複数接触は物理エンジンに任せる（[Jolt](../libs/jolt/index.md)） |

## 偏差射撃（動く的への狙い）

**動いている的**を狙うとき、**今の位置**を撃っても外れます。**弾が届くまでの間に的が動く先**を撃つ必要があります。

的の位置 P、的の速度 V、弾の発射位置 S、弾の速さ s のとき、**弾が当たる時間 t** を求めます。

```text
|P + V t - S| = s t
```

これを展開すると、**t の 2 次方程式**になります。

```cpp
bool InterceptTime(Vector3 shooter, Vector3 target, Vector3 target_velocity, float bullet_speed, float* t_out) {
  Vector3 d = target - shooter;
  float a = target_velocity.Dot(target_velocity) - bullet_speed * bullet_speed;
  float b = 2.0f * d.Dot(target_velocity);
  float c = d.Dot(d);
  if (std::abs(a) < 1e-6f) {
    if (std::abs(b) < 1e-6f) return false;
    float t = -c / b;
    if (t < 0.0f) return false;
    *t_out = t;
    return true;
  }
  float disc = b * b - 4.0f * a * c;
  if (disc < 0.0f) return false;
  float root = std::sqrt(disc);
  float t1 = (-b - root) / (2.0f * a);
  float t2 = (-b + root) / (2.0f * a);
  float t = std::min(t1, t2) > 0.0f ? std::min(t1, t2) : std::max(t1, t2);
  if (t < 0.0f) return false;
  *t_out = t;
  return true;
}
```

`t` が求まれば、**狙う位置 ＝ `target + target_velocity × t`** です。

| 点 | 説明 |
| --- | --- |
| **解がないとき** | 弾が的の速さに追いつけない。今の位置を狙うなどの代替の動きにする |
| **重力のある弾** | さらに放物線の式を組み合わせる（数値的に解くことが多い） |
| **簡易版** | 距離 ÷ 弾の速さでおおよその `t` を出し、その先を狙う（反復して精度を上げる） |
| **敵 AI のわざと外す** | 精度を落としたい場合は、狙う位置にランダムなずれを足す |

## 回転運動

| 量 | 直線運動での対応 |
| --- | --- |
| **角度 θ** | 位置 x |
| **角速度 ω** | 速度 v |
| **角加速度 α** | 加速度 a |
| **慣性モーメント I** | 質量 m |
| **トルク τ** | 力 F |

```text
ω += (τ / I) × dt
θ += ω × dt
```

2D の回転は、角度 1 つで済みます。3D は**回転を表す量が軸と大きさのベクトル**（角速度ベクトル）になり、**慣性テンソル**（3×3 の行列）が必要になります。**自作はせず、物理エンジンに任せる**のが現実的です。

## 運動のコツ

| 状況 | 工夫 |
| --- | --- |
| **ジャンプの入力の受け付け** | 着地の**数フレーム前**（バッファ）と、**足場を離れた数フレーム後**（コヨーテタイム）も、ジャンプを許す |
| **可変ジャンプ** | ボタンを離したら、上昇の速度を減らす（短押し・長押しで高さが変わる） |
| **加速・減速** | 入力に対して、**目標速度へ近づく**（急に最高速にならない） |
| **斜め移動が速い** | 入力ベクトルを**正規化**する（`(1, 1)` の長さは約 1.41） |
| **床に沿って動く** | 床の法線で速度を**射影**して、斜面を歩く |
| **垂直・水平の分離** | 水平（ユーザー操作）と垂直（重力）を別々に処理すると書きやすい |

## よくあるミス

??? failure "`dt` を掛けずに、フレームごとの固定量を足す"
    フレームレートで速さが変わります。必ず `dt` を掛けます。

??? failure "`v *= 0.98f` で減衰して、フレームレートで止まり方が違う"
    `exp(-damping × dt)` にします。

??? failure "斜め入力で、移動が速くなる"
    入力ベクトルを正規化します。

??? failure "`dt` が大きく、弾や落下が壁をすり抜ける"
    固定タイムステップ・サブステップ・光線判定にします。

??? failure "実際の重力（9.8）のまま、ふわふわする"
    高さと時間から、重力と初速を逆算します。

??? failure "硬いばねが、爆発する"
    サブステップで刻むか、減衰を足します。
