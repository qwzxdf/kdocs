# 乱数と確率

ゲームには**ランダム**がたくさん出てきます。敵の出現・ドロップ・ダメージのばらつき・パーティクルの散らばり・地形の生成などです。ただ、「ランダム」の正体は**疑似乱数**という**規則的な計算**です。種類・分布・偏りのない使い方を知らないと、**偏った結果**や**再現できないバグ**を生みます。このページでは、C++ の乱数の使い方と、ゲームでよく使う**サンプリングの公式**を説明します。

!!! tip "ポイント"
    - コンピューターの乱数は<strong>疑似乱数</strong>。<strong>シード（種）</strong>が同じなら、<strong>同じ列</strong>になる（<strong>再現可能</strong>）。
    - C++ では<strong>`<random>`</strong>。<strong>エンジン（乱数の源）と、分布（形）を分ける</strong>。
    - <strong>`rand()` は使わない</strong>。品質が低く、偏る。
    - <strong>円・球の中の一様な点</strong>は、<strong>半径に `√` を掛ける</strong>（そのまま使うと中心に偏る）。
    - <strong>重み付き抽選</strong>は、<strong>累積の重み</strong>で引く。
    - ゲームでは<strong>用途ごとに乱数エンジンを分ける</strong>（<strong>演出用とゲームロジック用</strong>）。

## 疑似乱数の仕組み

<strong>疑似乱数生成器（PRNG）</strong>は、<strong>状態（数個の整数）</strong>を持ち、**呼ぶたびに状態を更新**して、**数を返します**。同じ初期状態（シード）からは**必ず同じ列**が出ます。

| 性質 | 説明 |
| --- | --- |
| **再現性** | シードが同じなら、結果が同じ。**リプレイ・テスト・デバッグ**に便利 |
| **周期** | 一巡して元に戻るまでの長さ。**長いほど良い**（現代のものは非常に長い） |
| **品質** | 統計的な偏りが少ないか。**ゲームには十分なものが多い** |
| **速さ** | 1 回の生成にかかる時間 |
| **暗号用途ではない** | 次の値が予測できる。**セキュリティには使えない** |

### 主な乱数エンジン

| エンジン | 特徴 |
| --- | --- |
| **`std::mt19937`** | メルセンヌ・ツイスタ。標準。周期が長い。状態が大きい（約 2.5 KB） |
| **`std::mt19937_64`** | 64 ビット版 |
| **`std::minstd_rand`** | 小さく速い。品質は低め |
| **PCG** | 小さく、速く、品質が高い（標準ではない）。**ゲームでよく選ばれる** |
| **xoshiro / xoroshiro** | 非常に速い。品質も高い。**ゲームで人気** |
| **`std::random_device`** | OS の乱数源。**シードを作る**ために使う |

## `<random>` の使い方

**エンジン**と**分布**を別々に作って、組み合わせます。

```cpp
std::random_device device;
std::mt19937 engine(device());

std::uniform_int_distribution<int> dice(1, 6);
int roll = dice(engine);

std::uniform_real_distribution<float> unit(0.0f, 1.0f);
float r = unit(engine);
```

| 分布 | 内容 |
| --- | --- |
| **`uniform_int_distribution<T>(a, b)`** | **a〜b の整数**（両端を含む）。**サイコロ** |
| **`uniform_real_distribution<T>(a, b)`** | **a 以上 b 未満の小数** |
| **`normal_distribution<T>(mean, sd)`** | **正規分布**（平均・標準偏差）。**ばらつき**のある値 |
| **`bernoulli_distribution(p)`** | **確率 p で true**。**クリティカル判定** |
| **`discrete_distribution<int>(weights)`** | **重み付き抽選** |
| **`exponential_distribution<T>(lambda)`** | **指数分布**。出現間隔 |
| **`poisson_distribution<int>(mean)`** | ポアソン分布。一定時間内の出現回数 |

### よくある間違い

| 間違い | 正しくは |
| --- | --- |
| **`rand() % 6`** | **偏りがある**。`uniform_int_distribution` を使う |
| **毎回エンジンを作る** | **使い回す**。毎回シードから始めると、同じ値になる |
| **`std::random_device` を毎回呼ぶ** | 重い。シードを作るときだけ |
| **`time(nullptr)` をシードに複数のエンジンを同時に作る** | 同じ秒に作ると同じシードになる |
| **スレッドで同じエンジンを共有** | データ競合。スレッドごとに持つ |

### シードと再現性

| 用途 | シード |
| --- | --- |
| **通常のプレイ** | `random_device` から（毎回違う） |
| **リプレイ・再現** | **シードを保存**して、同じシードで再実行 |
| **ステージの自動生成** | シードを**ユーザーに見せて**、共有可能に（「シード値 12345」） |
| **テスト** | **固定のシード**で結果を固定 |

**ゲームの流れ（敵の動き・ドロップ）に使う乱数と見た目の演出（パーティクル）に使う乱数は別のエンジン**にします。演出で乱数を使ってもゲームの流れの**再現性が壊れない**ようにするためです。

## 自前で作る乱数（xorshift）

**小さく・速く・状態を見やすく**したいときは、自作します。

```cpp
class Xorshift32 {
 public:
  explicit Xorshift32(uint32_t seed) : state_(seed == 0 ? 1 : seed) {}

  uint32_t Next() {
    state_ ^= state_ << 13;
    state_ ^= state_ >> 17;
    state_ ^= state_ << 5;
    return state_;
  }

  float NextFloat() { return static_cast<float>(Next() >> 8) * (1.0f / 16777216.0f); }

 private:
  uint32_t state_;
};
```

| 点 | 説明 |
| --- | --- |
| **状態は 1 つの整数** | 保存・コピーが簡単（セーブデータにも入れられる） |
| **シードは 0 にしない** | 0 のままだとずっと 0 |
| **`>> 8` して `/ 2^24`** | 上位の 24 ビットを使って、0〜1 の小数にする（`float` の仮数が 24 ビット） |

## 範囲と整数の乱数

| 目的 | 書き方 |
| --- | --- |
| **0〜1 の小数** | `uniform_real_distribution<float>(0, 1)` |
| **a〜b の小数** | `a + (b - a) × r`（r は 0〜1） |
| <strong>a〜b の整数（両端を含む）</strong> | `uniform_int_distribution(a, b)` |
| **配列のランダムな要素** | `index = uniform_int_distribution<size_t>(0, size - 1)` |
| **-1 か 1** | `bernoulli` で決めて、`2 × b - 1` |
| **確率 p で起こる** | `r < p`（r は 0〜1） |

## 円・球の中の一様な点

「円の中のランダムな点」を、**半径と角度を乱数で決める**と、**中心に偏って**しまいます。

```cpp
float r = radius * unit(engine);
float a = 2.0f * kPi * unit(engine);
Vector2 p(r * std::cos(a), r * std::sin(a));
```

これは**間違いです**。半径が小さい所に点が集まります。

### なぜ偏るのか

円の面積は**半径の 2 乗**に比例します。半径が大きい所のほうが、**面積が広い**ので**多くの点が必要**です。半径を一様に選ぶと中心近くに**点が詰まります**。

### 正しい方法

**半径に `√` を掛けます**。

```cpp
Vector2 RandomInCircle(Xorshift32& rng, float radius) {
  float r = radius * std::sqrt(rng.NextFloat());
  float a = 2.0f * kPi * rng.NextFloat();
  return Vector2(r * std::cos(a), r * std::sin(a));
}
```

| 形 | 方法 |
| --- | --- |
| <strong>円の中（一様）</strong> | 半径に **`√(乱数)`** を掛ける |
| **円周上** | 半径は固定、角度だけランダム |
| <strong>球の中（一様）</strong> | 半径に **`∛(乱数)`**（立方根）を掛ける ＋ 向きは球面上の一様な点 |
| <strong>球面上（一様）</strong> | `z = 2u - 1`、`φ = 2π v`、`r = √(1 - z²)` → `(r cos φ, r sin φ, z)` |
| **矩形・箱の中** | 各軸を一様に |
| <strong>棄却法（簡単）</strong> | 箱の中の点を引き、**円の外なら捨てて引き直す** |

```cpp
Vector3 RandomOnSphere(Xorshift32& rng) {
  float z = 2.0f * rng.NextFloat() - 1.0f;
  float phi = 2.0f * kPi * rng.NextFloat();
  float r = std::sqrt(std::max(0.0f, 1.0f - z * z));
  return Vector3(r * std::cos(phi), r * std::sin(phi), z);
}
```

!!! warning "球面で、緯度・経度を一様にしてはいけない"
    **緯度（θ）と経度（φ）を一様に乱数**にすると**極に点が集まります**。`z`（高さ）を一様にして、そこから半径を出す方法を使います。

## 重み付き抽選

**確率の違う選択肢**から 1 つを選びます（ドロップ・ガチャ）。

### 累積の重み

```cpp
size_t PickWeighted(const std::vector<float>& weights, Xorshift32& rng) {
  float total = std::accumulate(weights.begin(), weights.end(), 0.0f);
  float r = rng.NextFloat() * total;
  for (size_t i = 0; i < weights.size(); ++i) {
    r -= weights[i];
    if (r < 0.0f) {
      return i;
    }
  }
  return weights.size() - 1;
}
```

| 点 | 説明 |
| --- | --- |
| **重みは確率でなくてよい** | 合計が 1 でなくても、比で決まる（例：70・20・10 → 70%・20%・10%） |
| **合計を掛ける** | 乱数を 0〜合計 の範囲にして、重みを引いていく |
| **標準にもある** | `std::discrete_distribution` |
| **多数の選択肢** | 累積和を作って、**二分探索**。さらに速いのは**エイリアス法** |

### ドロップの設計

| パターン | 説明 |
| --- | --- |
| **独立した判定** | アイテムごとに独立に「落ちる」か判定。**複数落ちる可能性** |
| **排他の抽選** | 1 つだけ選ぶ（重み付き抽選） |
| **テーブルの階層** | 「レア度」を先に決め、そのレアの中から選ぶ |
| **抽選しない** | 条件による確定ドロップ |

## シャッフル（Fisher–Yates）

**配列をランダムに並べ替える**ときは、**Fisher–Yates 法**を使います。

```cpp
template <typename T>
void Shuffle(std::vector<T>& v, std::mt19937& engine) {
  for (size_t i = v.size() - 1; i > 0; --i) {
    std::uniform_int_distribution<size_t> dist(0, i);
    std::swap(v[i], v[dist(engine)]);
  }
}
```

標準の **`std::shuffle`**（`<algorithm>`）が、同じことをします。

| 点 | 説明 |
| --- | --- |
| **`std::sort` に乱数の比較を渡さない** | 偏る。比較の矛盾でクラッシュすることもある |
| **カードの山** | 一度シャッフルして、上から引く（重複なしの抽選） |
| **ステージの順番** | シャッフルして、順に使う |

## 正規分布（ばらつき）

**平均付近に集まり、離れるほど少ない**分布です。**ダメージのばらつき**・**命中の散らばり**・**自然な揺らぎ**に向きます。

```cpp
std::normal_distribution<float> spread(0.0f, 2.0f);
float offset = spread(engine);
```

| 点 | 説明 |
| --- | --- |
| **平均と標準偏差** | 約 68% が ±1 標準偏差、約 95% が ±2 標準偏差に入る |
| **値の範囲** | 理論上は無限。**clamp する**（極端な値を捨てる） |
| **一様分布との違い** | 一様は**どの値も同じ確率**。正規分布は**中央が多い** |
| **簡易な近似** | 複数の一様乱数を足す（3〜4 個を足すと釣鐘型に近づく） |

## ノイズ関数

**ランダムだが隣り合う値が連続している**関数です。**地形・雲・炎・揺らぎ**に使います。**乱数は隣り合う値に関係がない**ので、そのままではつながりのない模様になります。

| ノイズ | 特徴 |
| --- | --- |
| <strong>値ノイズ（Value Noise）</strong> | 格子点に乱数を置いて、**補間**する。簡単。四角っぽさが出る |
| **パーリン ノイズ** | 格子点に**勾配ベクトル**を置いて、補間。**自然**。標準的 |
| **シンプレックス ノイズ** | パーリンの改良版。**高次元でも速い**・方向の偏りが少ない |
| **ワーリー（セル）ノイズ** | 点からの距離。**セル状・石・泡** |
| <strong>fBm（フラクタル）</strong> | 周波数を倍にして、振幅を半分にしながら、**重ねる**。**自然な地形** |

```text
fBm(x) = Σ  振幅_i × noise(x × 周波数_i)   （i = 0, 1, 2, ...）
         振幅_{i+1} = 振幅_i / 2,  周波数_{i+1} = 周波数_i × 2
```

| 使いどころ | 説明 |
| --- | --- |
| **地形の高さ** | 2D ノイズを高さに |
| **洞窟・ボクセル地形** | 3D ノイズを密度に |
| **雲・煙・炎** | 時間を 1 軸として、ノイズを動かす |
| **カメラ・ダメージの揺れ** | 1D ノイズで滑らかな揺れ（ランダムなガタつきより自然） |
| **ランダムな歩行** | 向きをノイズで連続的に変える |

## 確率の基本

| 概念 | 式 | 例 |
| --- | --- | --- |
| **独立な事象の積** | `P(A かつ B) = P(A) × P(B)` | クリティカル 20% かつ 命中 80% → 16% |
| <strong>どちらか（排他）</strong> | `P(A または B) = P(A) + P(B)` | 出る目が 1 または 2 → 1/3 |
| **少なくとも 1 回** | `1 - (1 - p)^n` | 5% を 10 回引いて 1 回は当たる → 約 40% |
| **期待値** | `Σ(値 × 確率)` | 平均でいくつ得られるか |

詳しくは[ゲームバランスの数学](balance.md)にあります。

## よくあるミス

??? failure "`rand() % n` を使う"
    偏りがあります。`uniform_int_distribution` にします。

??? failure "毎回エンジンを作り直して、同じ値が続く"
    エンジンは、**1 つを使い回します**。

??? failure "円の中の点を、半径を一様にして決め、中心に偏る"
    半径に `√` を掛けます。

??? failure "演出とゲーム内容で、同じエンジンを共有して、再現できなくなる"
    用途ごとにエンジンを分けます。

??? failure "複数スレッドで 1 つのエンジンを共有する"
    スレッドごとに持ちます。

??? failure "`std::sort` の比較に乱数を使って、シャッフルしたつもりになる"
    `std::shuffle` を使います。
