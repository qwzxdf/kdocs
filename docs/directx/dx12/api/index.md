# API リファレンス

DirectX 12 の API を、インターフェースや構造体ごとに引ける辞書です。手順を追って読む解説は、上のページ（[DirectX 12 Guide](../index.md)）にあります。ここでは、メソッドや値を 1 つずつ、シグネチャ、引数、戻り値、落とし穴まで書きます。

コード ブロックの中の名前（`CreateCommittedResource` など）は、ここに載っているものならクリックでこのページの該当の節へ飛べます。
