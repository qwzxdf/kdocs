# std::gcd

<div class="page-badges" markdown>
<span class="rank rank-sometimes">たまに</span>
<span class="ver ver-17">C++17</span>
`#include <numeric>`
</div>

画面の解像度 1920×1080 を「16:9」と書きたい。タイルの模様が 12 マスと 18 マスで繰り返されるとき、両方がきれいに揃う単位を知りたい。分数の 6/8 を 3/4 に約分したい。こうした場面で共通して必要になるのが、<strong>2 つの整数を両方とも割り切れる、いちばん大きい数</strong>、つまり最大公約数です。

`std::gcd` はこれを返します。ユークリッドの互除法を自分で書く必要はありません。`constexpr` なので、コンパイル時にも使えます。

!!! tip "ポイント"
    - `std::gcd(12, 18)` は 6。両方を割り切れる数のうち、最大のものを返す
    - 負の値は、絶対値で扱う。結果は常に 0 以上
    - 片方が 0 なら、もう片方の絶対値が返る。両方 0 なら 0
    - 割った商を求めて約分に使うなら、`a / g` と `b / g` を使う。`g` が 0 のときだけ注意する
    - 整数型だけを受け取る。`float` や `bool` を渡すとコンパイルエラー

!!! info "このページを読む前に"
    [`<numeric>`](numeric.md) の概要を先に読むと分かりやすいです。

## 関数の詳しい説明

### std::gcd {#gcd}

<span class="ver ver-17">C++17</span>

```cpp
template <class M, class N>
constexpr std::common_type_t<M, N> gcd(M m, N n);
```

| 引数 | 型 | 意味 |
| --- | --- | --- |
| `m` | 整数型 | 1 つ目の整数 |
| `n` | 整数型 | 2 つ目の整数 |

引数は 2 つとも、整数型です。`bool` は含まれません。`float` や `double` を渡すとコンパイルエラーになるので、浮動小数点数の最大公約数を求めたいときは、整数に直してから呼びます。

型が違う 2 つの値を渡すこともできます。戻り値は両方の型の共通型（`std::common_type_t`）です。`int` と `long long` なら `long long` です。符号つきと符号なしを混ぜると、共通型が符号なしになり、意図しない変換が起きやすいので、同じ型にそろえておくのが無難です。

負の値を渡すと、絶対値として扱われます。`std::gcd(-12, 18)` は 6 です。結果が負になることはありません。

戻り値は 2 つの引数の最大公約数です。互いに素（1 以外の公約数がない）なら 1 になります。片方が 0 のときは、もう片方の絶対値、両方 0 のときは 0 を返します。0 はどんな数でも割り切れるので、`gcd(0, 5)` は 5 になる、という考え方です。

落とし穴は、<strong>絶対値が共通型で表せない場合は未定義動作</strong>になることです。たとえば `int` の最小値 `INT_MIN` は、絶対値が `int` に収まらないので、`std::gcd(INT_MIN, 0)` は危険です。普通のゲームの数値では起きませんが、ハッシュ値のような、全範囲の値を渡す場合には注意します。

### 何をしているのか

最大公約数は、ユークリッドの互除法で求まります。2 つの数のうち大きいほうを小さいほうで割った余りに置き換える操作を、余りが 0 になるまで繰り返します。

```cpp
// 12 と 18 の場合の流れ（互除法）
// gcd(18, 12) → 18 % 12 = 6
// gcd(12,  6) → 12 %  6 = 0
// 余りが 0 になった時点の「小さいほう」が答え → 6
```

標準ライブラリの実装も、この考え方（あるいはその高速な変形）を使います。計算量は、小さいほうの値の桁数に比例する程度で、通常の整数なら数十回の割り算で終わります。

## 実際に動かしてみる

```cpp
#include <numeric>
#include <print>

int main() {
  std::println("gcd(12, 18)  = {}", std::gcd(12, 18));   // 両方を割り切る最大の数
  std::println("gcd(0, 5)    = {}", std::gcd(0, 5));     // 片方が 0 なら、もう片方
  std::println("gcd(0, 0)    = {}", std::gcd(0, 0));     // 両方 0 なら 0
  std::println("gcd(-12, 18) = {}", std::gcd(-12, 18));  // 絶対値で扱う
}
```

```text title="実行結果"
gcd(12, 18)  = 6
gcd(0, 5)    = 5
gcd(0, 0)    = 0
gcd(-12, 18) = 6
```

## ゲームでの使いどころ

### 画面の縦横比を求める

解像度から縦横比を出すには、幅と高さを最大公約数で割ります。

```cpp
#include <numeric>
#include <print>

int main() {
  const int resolutions[][2] = {{1920, 1080}, {1280, 720}, {800, 600}};
  for (const auto& r : resolutions) {
    const int g = std::gcd(r[0], r[1]);             // 幅と高さの最大公約数
    std::println("{}x{} -> {}:{}", r[0], r[1], r[0] / g, r[1] / g);
  }
}
```

```text title="実行結果"
1920x1080 -> 16:9
1280x720 -> 16:9
800x600 -> 4:3
```

`g` で割った商が、それ以上約分できない最も簡単な比になります。`g` が 0 になるのは、幅も高さも 0 のときだけなので、0 で割る事故を避けるには、入力が 0 でないことを確かめます。

### 分数を約分する

アイテムの出現確率を「6/8」のように分数で管理していて、画面には「3/4」と表示したい、という場合も同じです。分子と分母を最大公約数で割ります。

```cpp
struct Fraction {
  int num;  // 分子
  int den;  // 分母

  void Reduce() {
    const int g = std::gcd(num, den);  // 負の値も絶対値で扱われる
    if (g != 0) {
      num /= g;
      den /= g;
    }
  }
};
```

### タイルの繰り返し周期

幅 12 マスの模様と幅 18 マスの模様を並べて敷き詰めるとき、2 つの模様が揃う最小の幅は最小公倍数 [`std::lcm`](lcm.md) で、きれいに分割できる単位の大きさは `gcd` で求まります。

## よくあるミス

??? failure "型が違う"
    符号つきと符号なしを混ぜると、共通型が符号なしになり、負の値の扱いがずれます。同じ型にそろえます。

??? failure "浮動小数点数を渡す"
    `std::gcd(1.5, 3.0)` はコンパイルエラーです。整数だけを受け取ります。

??? failure "`INT_MIN` を渡して未定義動作になる"
    絶対値が型に収まらない値は、渡してはいけません。範囲の広い値を扱うなら `long long` にします。

??? failure "0 で割ってしまう"
    約分の `a / g` は、`a` と `b` がともに 0 のとき `g` が 0 になり、0 除算です。入力を確かめるか、`g != 0` を確認します。
