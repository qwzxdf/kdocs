# std::floor

<div class="page-badges" markdown>
<span class="rank rank-must">必須</span>
`#include <cmath>`
</div>

タイルマップのゲームでは、キャラクターが立っている座標 `(12.7, 3.2)` から、「今どのマスにいるか」を求めたくなります。小数を切り捨てて `(12, 3)` にすればよい、と考えて `(int)` でキャストすると、座標が負の側へ行ったときにズレます。`std::floor` は、小数を常に小さいほうの整数へそろえる関数で、このズレが起きません。

!!! tip "ポイント"
    - `(int)` のキャストは 0 に向かって切り捨てる。負の数では `floor` と結果が違う。
    - マスの座標を求めるときは、座標が負になる可能性があるなら `floor` を使う。
    - 戻り値は小数型。添え字などに使うときは `static_cast<int>` で変換する。

!!! info "このページを読む前に"
    [`<cmath>`](../cmath.md) の一覧を先に見ると、ほかの数学関数との関係が分かります。

## 関数の詳しい説明

### std::floor {#floor}

```cpp
float floor(float x);
```

`x` が正の数なら、`(int)` のキャストと `floor` は同じ結果になります。違いが出るのは負の数です。`-1.5` を `(int)` に変換すると `-1`（0 に近づく向き）になりますが、`std::floor(-1.5)` は `-2`（小さい向き）です。

戻り値の型は、渡した型と同じ小数型です。`std::floor(2.7f)` は `float` の `2.0f` で、`int` ではありません。`vector` の添え字に使うなら、`static_cast<int>(std::floor(x))` と書きます。値が `int` に収まらないほど大きい場合は、変換そのものが未定義動作になります。

- x 以下で一番大きい整数（マイナスでも「小さいほう」へ）。座標からマスの番号を出すのに使います

## 実際に動かしてみる

```cpp
#include <cmath>
#include <print>

int main() {
  std::println("{} {}", std::floor(-1.5), std::floor(1.5));
}
```

```text title="実行結果"
-2 1
```

## ゲームでの使いどころ

マスを求める計算が、いちばん多い使いどころです。1 マスが 32 ピクセルのマップで、座標 `x` のマスは `static_cast<int>(std::floor(x / 32.0f))` で求まります。マップの原点が左上にあり、座標が負にならないなら、`(int)` のキャストで足りますが、スクロールするマップで原点がずれる場合は `floor` が必要です。

整数に切り捨てた位置を使って、グリッドに分けた空間でオブジェクトを管理する「空間ハッシュ」でも使います。座標をセルの大きさで割って `floor` すると、どのセルに入るかが決まります。負の座標でも同じ式で動くのが利点です。

## よくあるミス

??? failure "負の座標を `(int)` で切り捨てる"
    `(int)(-0.5f)` は `0` になります。`-0.5` はマス `-1` にいるのに、マス `0` と判定されて、原点付近だけ 2 マスが同じ扱いになります。座標が負になりうる場合は `floor` を使います。

??? failure "戻り値を整数だと思って添え字に使う"
    `v[std::floor(x)]` はコンパイルエラーか警告になります。`floor` の戻り値は小数型です。`static_cast<int>(std::floor(x))` と書きます。

??? failure "`int` の割り算で済む場面に `floor` を使う"
    整数どうしの割り算 `a / b` は 0 に向かって切り捨てます。`a` と `b` が正の整数のときは、`floor` を使わずに `a / b` と書くだけで足ります。
