# std::cos

<div class="page-badges" markdown>
<span class="rank rank-must">必須</span>
`#include <cmath>`
</div>

プレイヤーが向いている方向（角度）が分かっているとき、その向きに 1 歩進んだ位置を求めたくなります。角度から「前」のベクトルを作るのが `cos` と `sin` の組で、`cos` は x 方向、`sin` は y 方向の成分を返します。`sin` と同じ形で、90 度だけずれた波を作る関数だと捉えてもよいです。

!!! tip "ポイント"
    - 角度 `a` の向きのベクトルは `(cos a, sin a)`。この形は何度も使う。
    - 引数はラジアン。度の値は `度 × π / 180` で変換する。
    - `cos(a)` は `sin(a + π/2)` と同じ。波の位相がずれているだけ。

!!! info "このページを読む前に"
    角度の単位（度とラジアン）が分かると読みやすいです。度は `度 × π / 180` でラジアンになります。

## 関数の詳しい説明

### std::cos {#cos}

```cpp
float cos(float radians);
```

`x` はラジアンです。戻り値は −1 から 1 で、`cos(0)` が 1、`cos(π/2)` が 0、`cos(π)` が −1 です。`sin` のグラフを左に 90 度ずらした形になります。

2 つのベクトルのなす角を求めたいときは、`cos` の逆関数 `acos` を使います。正規化した 2 つのベクトルの内積が、そのまま `cos(なす角)` になるので、`std::acos(dot)` で角度が出ます。

- コサイン。`{cos(a), sin(a)}` が角度 a の向きの長さ 1 のベクトルです

```cpp
#include <cmath>
#include <print>

int main() {
  // 時間でふわふわ上下する（振幅 4、0.5 秒ごと）
  for (float t : {0.0f, 0.125f, 0.25f}) {
    float offset = std::sin(t * 2.0f * 3.14159265f / 0.5f) * 4.0f;
    std::println("t={} → {:.1f}", t, offset);
  }
  std::println("{:.1f}", std::cos(0.0f));
}
```

```text title="実行結果"
t=0 → 0.0
t=0.125 → 4.0
t=0.25 → -0.0
1.0
```

`-0.0` は、sin(π) が計算誤差でほんの少しマイナス（-0.0000003 くらい）になったものです。

## ゲームでの使いどころ

キャラクターの向き（角度）から、前方への移動量を求めるのが代表例です。2D のゲームでは `x += speed * std::cos(angle) * dt; y += speed * std::sin(angle) * dt;` と書きます。

視野判定にも使います。敵の視線の向きと、プレイヤーへの方向の内積を求めると、それが `cos(なす角)` です。「前方 60 度以内にいるか」は、`dot > std::cos(60度をラジアンにした値)` で調べられます。`acos` を呼ぶより、`cos` を一度計算して内積と比べるほうが速くなります。

## よくあるミス

??? failure "度とラジアンを混ぜる"
    `std::cos(60.0f)` は 60 ラジアンのコサインです。60 度なら `std::cos(60.0f * pi / 180.0f)` で、結果は `0.5` です。ゲームの設定値は度で持ち、計算の直前にラジアンに直す、という約束を決めておくと混乱しません。

??? failure "`cos(a) == 0` で 90 度かを調べる"
    浮動小数点の誤差があるので、`std::cos(π/2)` は正確な 0 になりません（約 `6e-17`）。`==` で比べず、`std::abs(c) < 1e-6f` のように許容誤差で比べます。

??? failure "内積と角度を行き来しすぎる"
    内積から `acos` で角度を出し、また `cos` で内積に戻す、という処理を毎フレーム何百回もすると重くなります。比較は内積のまま行います。
