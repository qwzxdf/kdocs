# std::sin

<div class="page-badges" markdown>
<span class="rank rank-must">必須</span>
`#include <cmath>`
</div>

キャラクターを円を描くように動かしたいとき、または画面の端でふわふわと上下に揺らしたいとき、位置を時間に応じて滑らかに往復させる関数が必要になります。サイン波（`std::sin`）は、まさにそのための関数です。入力が増えると、出力が −1 と 1 の間をなめらかに往復します。

!!! tip "ポイント"
    - 引数は度ではなくラジアン。度の値は `度 × π / 180` で変換する。
    - 揺れの大きさは、`sin` の結果に掛ける。速さは、`sin` に渡す時間に掛ける。
    - `std::numbers::pi_v<float>` で `float` の π が使える。

!!! info "このページを読む前に"
    角度の単位（度とラジアン）が分かると読みやすいです。度は `度 × π / 180` でラジアンになります。

## 関数の詳しい説明

### std::sin {#sin}

```cpp
float sin(float radians);
```

`x` はラジアンです。`std::sin(90.0f)` と書いても、90 度のサインにはなりません。度の値は、`90.0f * std::numbers::pi_v<float> / 180.0f` で変換してから渡します。

戻り値は −1 から 1 の間です。`sin(0)` が 0、`sin(π/2)` が 1、`sin(π)` が 0、`sin(3π/2)` が −1 で、2π ごとに同じ値を繰り返します。

`x` が非常に大きいと、精度が落ちます。時間を足し続けた値をそのまま渡すと、長時間動かしたときに揺れ方が粗くなります。`fmod(t, 2π)` で周期の中に収めてから渡すと安全です。

- サイン。引数は**ラジアン**（180 度 = π）。揺れ（上下にふわふわ）にも使えます

## 実際に動かしてみる

```cpp
#include <cmath>
#include <numbers>
#include <print>

int main() {
  std::println("{:.1f} {:.1f}", std::sin(0.0), std::sin(std::numbers::pi / 2));
}
```

```text title="実行結果"
0.0 1.0
```

## ゲームでの使いどころ

揺れの表現が最も多い使いどころです。ふわふわと浮かぶアイテムは、`y = base_y + std::sin(time * 3.0f) * 0.2f` のように書きます。`3.0f` が速さ、`0.2f` が揺れの幅です。時間に比例して `sin` の引数を増やせば、一定の周期で往復します。

円運動にも使います。半径 `r` の円周上の位置は、`x = cx + r * cos(a)`、`y = cy + r * sin(a)` で、角度 `a` を少しずつ増やすと円を描きます。`cos` と組にして使うのが基本です。

カメラのゆれ、光の明滅、ポリゴンの波打つアニメーション（水面など）でも使います。

## よくあるミス

??? failure "度の値をそのまま渡す"
    `std::sin(30.0f)` は 30 度のサインではなく、30 ラジアンのサインです。結果は `-0.988` で、期待した `0.5` になりません。度から変換する関数を 1 つ用意しておくと、間違いが減ります。

??? failure "時間を足し続けて長時間後に揺れが粗くなる"
    `time` を毎フレーム足し続けて `sin(time)` に渡すと、数時間後には `float` の精度が足りなくなり、揺れがカクカクします。`time` を `2π` で割った余りに保つか、`double` を使います。

??? failure "`sin` と `cos` を逆に使う"
    角度 `a` の向きのベクトルは `(cos a, sin a)` です。x 方向が `cos`、y 方向が `sin` です。入れ替えると、90 度ずれた向きになります。
