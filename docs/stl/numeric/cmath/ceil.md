# std::ceil

<div class="page-badges" markdown>
<span class="rank rank-often">よく使う</span>
`#include <cmath>`
</div>

100 個のアイテムを 1 ページに 8 個ずつ表示するとき、ページ数は 100 ÷ 8 = 12.5 で、13 ページが必要です。割り算の結果を切り捨てると 12 ページになって、最後の 4 個が表示されません。`std::ceil` は小数を常に大きいほうの整数へそろえるので、「端数が出たら 1 つ増やす」計算を一行で書けます。

!!! tip "ポイント"
    - `ceil(a / b)` で「割り切れなければ 1 つ増やす」。整数の割り算にしないよう、どちらかを小数にする。
    - 整数どうしなら `(a + b - 1) / b` と書くと、小数に変換せずに同じ結果になる。
    - 戻り値は小数型。添え字などには `static_cast<int>` が要る。

!!! info "このページを読む前に"
    [`<cmath>`](../cmath.md) の一覧を先に見ると、ほかの数学関数との関係が分かります。

## 関数の詳しい説明

### std::ceil {#ceil}

```cpp
float ceil(float x);
```

`x` が整数ぴったりなら、そのままの値が返ります。`std::ceil(3.0)` は `3.0` です。浮動小数点の誤差で `3.0000001` になっていると、`4.0` が返ります。たとえば `0.1 * 30` が `3.0000000000000004` になるような計算の結果に使うと、思ったより 1 大きくなります。

負の数では、0 に近いほうへ丸めます。`std::ceil(-1.5)` は `-1` です。「大きいほう」という意味は、数直線の右、ということです。

- x 以上で一番小さい整数（切り上げ）

## 実際に動かしてみる

```cpp
#include <cmath>
#include <print>

int main() {
  std::println("{} {}", std::ceil(1.2), std::ceil(-1.2));
}
```

```text title="実行結果"
2 -1
```

## ゲームでの使いどころ

ページ分割のほか、必要な個数の見積もりに使います。キャラクターの HP が 250 で、1 回の攻撃が 40 のダメージなら、倒すのに必要な攻撃回数は `std::ceil(250.0f / 40.0f)` で 7 回です。

テクスチャの分割にも使います。1 枚の画像を 64 ピクセルのタイルに分けるとき、幅が 200 ピクセルなら `ceil(200.0f / 64.0f)` で 4 枚のタイルが要ります。端が余る分も、1 枚として数えられます。

## よくあるミス

??? failure "整数の割り算を `ceil` に渡す"
    `std::ceil(100 / 8)` は、`100 / 8` が先に整数の割り算で `12` になってから `ceil` に渡るので、結果は `12` です。`std::ceil(100.0 / 8)` のように、どちらかを小数にします。整数のまま済ませるなら `(100 + 8 - 1) / 8` です。

??? failure "誤差で 1 大きくなる"
    割り算の結果が理論上は整数ぴったりなのに、誤差で `3.0000000000000004` のようになると、`ceil` が `4` を返します。割る数と割られる数が整数なら、整数のまま `(a + b - 1) / b` で計算します。

??? failure "負の数に使って向きを間違える"
    `std::ceil(-1.5)` は `-1` です。「絶対値が大きいほう」ではなく「数直線の右」です。0 から遠ざけたいときは、符号で場合分けして `floor` と使い分けます。
