# std::pow

<div class="page-badges" markdown>
<span class="rank rank-often">よく使う</span>
`#include <cmath>`
</div>

ゲームのダメージ計算で「レベルが上がるごとに 1.1 倍」のような指数的な成長を書きたいとき、同じ数を何度も掛けるコードを書くのは面倒です。`std::pow(x, y)` は x の y 乗を返します。小数の指数も使えるので、ガンマ補正（`pow(色, 2.2)`）やイージングの曲線にも登場します。

!!! tip "ポイント"
    - 2 乗や 3 乗は `x * x`、`x * x * x` と書く。`pow` を呼ぶより速く、誤差も少ない。
    - 負の底に小数の指数を渡すと NaN になる。
    - 整数どうしの `pow` は `double` で返る。整数のべき乗が必要なら、自分でループを書く。

!!! info "このページを読む前に"
    [`<cmath>`](../cmath.md) の一覧を先に見ると、ほかの数学関数との関係が分かります。

## 関数の詳しい説明

### std::pow {#pow}

```cpp
float pow(float base, float exp);
```

`x` が底、`y` が指数です。`std::pow(2.0, 10)` は `1024` です。指数が整数でなくても動き、`std::pow(9.0, 0.5)` は `3`（平方根と同じ）になります。

`x` が負で、`y` が整数でない小数のときは、実数にならないので NaN が返ります。`std::pow(-8.0, 1.0 / 3.0)` は立方根のつもりでも NaN です。立方根が欲しいときは `std::cbrt` を使います。

`x` が 0 で `y` が負のときは、0 で割ることになるので無限大が返ります。

引数に `int` を渡すと `double` 版が呼ばれ、戻り値も `double` です。`int` のべき乗の結果が欲しいときに、`static_cast<int>(std::pow(10, 3))` と書くと、誤差で `999` になることがあります。整数のべき乗は、掛け算のループで書くのが確実です。

- `base` の `exp` 乗。2 乗するだけなら `x * x` と書くほうが速くて正確です

## 実際に動かしてみる

```cpp
#include <cmath>
#include <print>

int main() {
  std::println("{} {}", std::pow(2.0, 10), std::pow(9.0, 0.5));
}
```

```text title="実行結果"
1024 3
```

## ゲームでの使いどころ

最も多いのは、ガンマ補正です。画像の色は、人間の目に合わせて暗い部分に多くのデータを割り当てた形（sRGB）で保存されています。光の計算は線形な値で行うので、`std::pow(c, 2.2f)` で線形に直し、最後に `std::pow(c, 1.0f / 2.2f)` で戻します。実際の描画はシェーダーで行いますが、色を CPU で扱うときにも出てきます。

イージングで加速や減速の曲線を作るときも使います。`t` が 0〜1 のとき、`std::pow(t, 3.0f)` は最初ゆっくりで後半に急激に増える曲線、`1 - std::pow(1 - t, 3.0f)` はその逆です。指数を変えるだけで強さを調整できます。

ダメージ計算に使うときは、`pow` を毎フレーム大量に呼ぶと重くなります。レベルごとの値を表にしておいて、引くだけにすると速くなります。

## よくあるミス

??? failure "2 乗に `pow` を使う"
    `std::pow(x, 2)` は関数呼び出しになり、`x * x` より遅く、浮動小数点の誤差もわずかに大きくなります。2 乗や 3 乗は掛け算で書きます。

??? failure "整数のべき乗に `pow` を使って 1 ずれる"
    `static_cast<int>(std::pow(10, 3))` は、内部の計算の誤差で `999.9999999` になり、`999` に切り捨てられることがあります。整数のべき乗はループで書くか、`std::round` を通してから `int` にします。

??? failure "負の数の小数乗"
    `std::pow(-8.0, 1.0 / 3.0)` は NaN です。立方根が欲しいなら `std::cbrt(-8.0)` で `-2` が得られます。

| 名前 | 違い |
