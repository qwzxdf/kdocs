# std::mt19937

<div class="page-badges" markdown>
<span class="rank rank-must">必須</span>
<span class="ver ver-11">C++11</span>
`#include <random>`
</div>

`std::mt19937` は、**乱数を作る「エンジン」の定番**です。質が良く、速く、周期が非常に長い（2^19937 − 1）ので、ゲームの乱数ならこれを使えばまず困りません。エンジンは**生の整数**を出すだけなので、実際は [`uniform_int_distribution`](uniform_int_distribution.md) などの**分布**と組み合わせて使います。64 ビットの値が欲しいときは `std::mt19937_64` です。

!!! tip "ポイント"
    - **エンジンは 1 つ作って使い回す。** 状態が約 5KB あるので、関数のたびに作らない。
    - 種（シード）は `std::random_device{}()` か固定値。同じ種なら、必ず同じ列が出る（リプレイ・テストに使える）。
    - `rand()` は使わない。品質が低く、偏りがある。

!!! info "このページを読む前に"
    [`<random>`](../random.md) の概要を先に読むと分かりやすいです。

## 関数の詳しい説明

### std::mt19937 {#mt19937}

```cpp
using mt19937 = std::mersenne_twister_engine<std::uint_fast32_t, 32, 624, 397, 31,
                                              0x9908b0df, 11, 0xffffffff, 7, 0x9d2c5680, 15, 0xefc60000, 18, 1812433253>;
using mt19937_64 = /* 64 ビット版 */;
```

| 引数 | 型 | 意味 | 省略すると |
| --- | --- | --- | --- |
| `seed` | `unsigned` | 乱数の出発点。同じ種なら同じ列が出る | `5489` |

- 戻り値: `operator()` で 32 ビット整数（`mt19937_64` なら 64 ビット整数）を返す
- 計算量: O(1)

```cpp
#include <print>
#include <random>

int main() {
  std::mt19937 a(1);
  std::mt19937 b(1);
  std::println("同じ種なら同じ値？ {}", a() == b());

  std::mt19937 c;  // 種を省略すると 5489
  std::println("{}", c());

  std::mt19937_64 d;  // 64 ビット版
  std::println("{}", d());
}
```

```text title="実行結果"
同じ種なら同じ値？ true
3499211612
14514284786278117030
```

### seed, discard {#seed}

```cpp
void seed(result_type value);
void discard(unsigned long long z);
```

| 引数 | 型 | 意味 |
| --- | --- | --- |
| `value` | `result_type` | 新しい種 |
| `z` | 整数 | 読み飛ばす回数 |

- 戻り値: なし
- 計算量: seed は O(624)、discard は O(z)

## ゲームでの使いどころ

| 場面 | 書き方 |
| --- | --- |
| 敵の行動、ドロップ、ダンジョン生成 | `std::mt19937 rng{seed};` |
| リプレイ（同じ乱数を再現する） | 種を保存して、再生時に同じ種でエンジンを作る |
| マルチスレッド | スレッドごとに別のエンジンを持つ（共有はしない） |

## よくあるミス

??? failure "関数のたびにエンジンを作る"
    作るたびに約 5KB の初期化が走ります。1 度だけ作って、参照で渡すか、メンバに持ちます。

??? failure "種に time(nullptr) を使う"
    1 秒以内に 2 回作ると同じ列になります。`std::random_device` を使います。

??? failure "複数のスレッドで共有する"
    エンジンはスレッドセーフではありません。スレッドごとに持ちます。
