# std::is_trivially_copy_assignable

<div class="page-badges" markdown>
<span class="rank rank-rare">知ってるだけ</span>
<span class="ver ver-11">C++11</span>
`#include <type_traits>`
</div>

コピー代入が、メモリのコピーで済むかを判定します。

!!! tip "ポイント"
    - `::value`（または `_v` 版）が `bool` の定数。
    - コンパイル時に決まるので、`if constexpr` や `static_assert` に使える。
    - 型だけを見る（値は見ない）。

!!! info "このページを読む前に"
    [<type_traits>](../type_traits.md) の概要を先に読むと分かりやすいです。

## 関数の詳しい説明

### std::is_trivially_copy_assignable {#is_trivially_copy_assignable}

```cpp
template <class T>
struct is_trivially_copy_assignable;
template <class T>
inline constexpr bool is_trivially_copy_assignable_v = is_trivially_copy_assignable<T>::value;
```

| 引数 | 型 | 意味 |
| --- | --- | --- |
| `T` | 型 | 調べる型 |

- 戻り値: 条件を満たせば `true`（コンパイル時の定数）
- 計算量: コンパイル時のみ


## 実際に動かしてみる

```cpp
#include <print>
#include <string>
#include <type_traits>

int main() {
  std::println("{}", std::is_trivially_copy_assignable_v<int>);
  std::println("{}", std::is_trivially_copy_assignable_v<std::string>);
}
```

```text title="実行結果"
true
false
```

## よくあるミス

??? failure "値と型を取り違える"
    `is_trivially_copy_assignable` は型を調べます。変数を渡すときは `decltype(x)` にします。
