# std::is_scalar

<div class="page-badges" markdown>
<span class="rank rank-rare">知ってるだけ</span>
<span class="ver ver-11">C++11</span>
`#include <type_traits>`
</div>

値を 1 つだけ持つ型です。算術型・列挙型・ポインタ・メンバへのポインタ・`nullptr_t` を含み、クラスや配列は含みません。

!!! tip "ポイント"
    - `::value`（または `_v` 版）が `bool` の定数。
    - コンパイル時に決まるので、`if constexpr` や `static_assert` に使える。
    - 型だけを見る（値は見ない）。

!!! info "このページを読む前に"
    [<type_traits>](../type_traits.md) の概要を先に読むと分かりやすいです。

## 関数の詳しい説明

### std::is_scalar {#is_scalar}

```cpp
template <class T>
struct is_scalar;
template <class T>
inline constexpr bool is_scalar_v = is_scalar<T>::value;
```

| 引数 | 型 | 意味 |
| --- | --- | --- |
| `T` | 型 | 調べる型 |

- 戻り値: 条件を満たせば `true`（コンパイル時の定数）
- 計算量: コンパイル時のみ


## 実際に動かしてみる

```cpp
#include <print>
#include <type_traits>

struct S {};

int main() {
  std::println("{}", std::is_scalar_v<int*>);
  std::println("{}", std::is_scalar_v<S>);
}
```

```text title="実行結果"
true
false
```

## よくあるミス

??? failure "値と型を取り違える"
    `is_scalar` は型を調べます。変数を渡すときは `decltype(x)` にします。
