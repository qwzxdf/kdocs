# std::is_abstract

<div class="page-badges" markdown>
<span class="rank rank-rare">知ってるだけ</span>
<span class="ver ver-11">C++11</span>
`#include <type_traits>`
</div>

`= 0` の純粋仮想関数を持つクラスは、インスタンスを作れません。それを判定します。

!!! tip "ポイント"
    - `::value`（または `_v` 版）が `bool` の定数。
    - コンパイル時に決まるので、`if constexpr` や `static_assert` に使える。
    - 型だけを見る（値は見ない）。

!!! info "このページを読む前に"
    [<type_traits>](../type_traits.md) の概要を先に読むと分かりやすいです。

## 関数の詳しい説明

### std::is_abstract {#is_abstract}

```cpp
template <class T>
struct is_abstract;
template <class T>
inline constexpr bool is_abstract_v = is_abstract<T>::value;
```

| 引数 | 型 | 意味 |
| --- | --- | --- |
| `T` | 型 | 調べる型 |

- 戻り値: 条件を満たせば `true`（コンパイル時の定数）
- 計算量: コンパイル時のみ


## 実際に動かしてみる

```cpp
#include <print>
#include <type_traits>

struct A {
  int x;
};
struct Abs {
  virtual void f() = 0;
};

int main() {
  std::println("{}", std::is_abstract_v<Abs>);
  std::println("{}", std::is_abstract_v<A>);
}
```

```text title="実行結果"
true
false
```

## よくあるミス

??? failure "値と型を取り違える"
    `is_abstract` は型を調べます。変数を渡すときは `decltype(x)` にします。
