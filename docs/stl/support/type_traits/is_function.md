# std::is_function

<div class="page-badges" markdown>
<span class="rank rank-rare">知ってるだけ</span>
<span class="ver ver-11">C++11</span>
`#include <type_traits>`
</div>

`void(int)` のような関数そのものの型かを判定します。関数ポインタ（`void(*)(int)`）は関数の型ではありません。

!!! tip "ポイント"
    - `::value`（または `_v` 版）が `bool` の定数。
    - コンパイル時に決まるので、`if constexpr` や `static_assert` に使える。
    - 型だけを見る（値は見ない）。

!!! info "このページを読む前に"
    [<type_traits>](../type_traits.md) の概要を先に読むと分かりやすいです。

## 関数の詳しい説明

### std::is_function {#is_function}

```cpp
template <class T>
struct is_function;
template <class T>
inline constexpr bool is_function_v = is_function<T>::value;
```

| 引数 | 型 | 意味 |
| --- | --- | --- |
| `T` | 型 | 調べる型 |

- 戻り値: 条件を満たせば `true`（コンパイル時の定数）
- 計算量: コンパイル時のみ


## 実際に動かしてみる

```cpp
#include <print>
#include <type_traits>

int main() {
  std::println("{}", std::is_function_v<void(int)>);
  std::println("{}", std::is_function_v<void (*)(int)>);
}
```

```text title="実行結果"
true
false
```

## よくあるミス

??? failure "関数ポインタに使う"
    関数ポインタは `is_pointer` です。`is_function` は関数そのものの型だけです。
