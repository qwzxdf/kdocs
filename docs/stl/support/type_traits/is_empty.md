# std::is_empty

<div class="page-badges" markdown>
<span class="rank rank-rare">知ってるだけ</span>
<span class="ver ver-11">C++11</span>
`#include <type_traits>`
</div>

メンバ変数も仮想関数も持たない空のクラスは、「型だけの目印」として使われます。そうした型かを判定します。空の基底クラスは、継承しても大きさが増えない最適化（空の基底の最適化）の対象になります。

!!! tip "ポイント"
    - `::value`（または `_v` 版）が `bool` の定数。
    - コンパイル時に決まるので、`if constexpr` や `static_assert` に使える。
    - 型だけを見る（値は見ない）。

!!! info "このページを読む前に"
    [<type_traits>](../type_traits.md) の概要を先に読むと分かりやすいです。

## 関数の詳しい説明

### std::is_empty {#is_empty}

```cpp
template <class T>
struct is_empty;
template <class T>
inline constexpr bool is_empty_v = is_empty<T>::value;
```

| 引数 | 型 | 意味 |
| --- | --- | --- |
| `T` | 型 | 調べる型 |

- 戻り値: 条件を満たせば `true`（コンパイル時の定数）
- 計算量: コンパイル時のみ


## 実際に動かしてみる

```cpp
#include <print>
#include <type_traits>

struct E {};
struct NE {
  int x;
};

int main() {
  std::println("{}", std::is_empty_v<E>);
  std::println("{}", std::is_empty_v<NE>);
}
```

```text title="実行結果"
true
false
```

## よくあるミス

??? failure "値と型を取り違える"
    `is_empty` は型を調べます。変数を渡すときは `decltype(x)` にします。
