# 自作型

標準ライブラリにはないけれど、ゲーム制作で**自分で作っておくと便利な型**をまとめます。

各ページには、設計意図・実装全文・使用例・STL との組み合わせ方を載せる予定です。

| 型 | 重要度 | 速さ | 一言で |
| --- | --- | --- | --- |
| `Vec2` / `Vec3` | <span class="rank rank-must">必須</span> | <span class="perf perf-4">◎</span> | 座標・速度のベクトル |
| `Rect` | <span class="rank rank-often">よく使う</span> | <span class="perf perf-4">◎</span> | 当たり判定用の矩形 |
| `Timer` | <span class="rank rank-often">よく使う</span> | <span class="perf perf-4">◎</span> | 経過時間とクールダウン |
| `Handle` | <span class="rank rank-sometimes">たまに</span> | <span class="perf perf-4">◎</span> | ポインタの代わりに使う ID |

すべて執筆予定です。
